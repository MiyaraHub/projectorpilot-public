Dall'accesso alla dashboard

  • Accedi a Home Assistant con il suo accesso OAuth.
  • Integrazione: l'app aggiunge l'integrazione di base jvc_projector di Home Assistant, inviando host, porta e password.
  • Sensore: un sensore mobile_app comunica tramite un webhook.
  • Sincronizza controlli avanzati crea script con il prefisso ppjvc.
  • Dashboard: una dashboard Lovelace in stile di base o in stile HACS.
  • Una checklist di configurazione mostra che cosa è stato fatto e che cosa resta da fare.
Home Assistant richiede il componente aggiuntivo Domotica.
