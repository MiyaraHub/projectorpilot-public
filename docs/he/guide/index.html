מדריך למשתמש של Projector Pilot

כל מה שצריך כדי להוסיף את המקרן ולהשתמש בכל מסך - לוח הבקרה, השלט העמוק, תפריט התמונה המלא, עדשה ממונעת, סצנות ואוטומציה ביתית אמיתית. כל מסך מסתגל לחומרה שלכם: האפליקציה מציגה רק את הבקרות שהמקרן שלכם באמת חושף, וכל ערך נקרא בחזרה מהמקרן, לעולם לא מנוחש. לכן ייתכן שהמסכים שלכם יציגו פחות אפשרויות ממה שעמוד מפרט כאן, וזו האפליקציה שכנה, לא שבורה.

עיון במדריך

כל מסך, מוסבר

התחילו בתחילת העבודה, ואז צללו לכל מסך. שום דבר כאן לא דורש חשבון בענן - Projector Pilot מדברת עם המקרן שלכם ברשת הביתית דרך ESC/VP21, PJLink ו-Epson Web Control, בכל ערוץ שעונה.

הוספת המקרן

סרקו את הרשת או הוסיפו לפי IP, הריצו את סריקת היכולות החד-פעמית, בדיקת חיבור ושמירה. באותה רשת Wi-Fi, תוך כדקה.
📊

קריאת לוח הבקרה

הפעלה, קלט, מצב צבע ומידע הקרנה בזמן אמת, עם כרטיסים שאתם מוסיפים, מסתירים ומסדרים מחדש כדי לבנות את התצוגה שאתם רוצים.
🎭

שמירת סצנה

תעדו הפעלה, קלט, תמונה, עדשה ועוד, ואז החזירו את כל החדר בנגיעה אחת - והעבירו אותו ל-Home Assistant.

הורידו את האפליקציה והצטרפו
