הוספת מקרן Epson או PJLink תוך כדקה

Projector Pilot מוצאת את המקרן שלכם ברשת הביתית - בלי חשבון בענן, בלי קוד צימוד. חברו את הטלפון לאותה רשת Wi-Fi, הוסיפו את המקרן פעם אחת, והאפליקציה סורקת מה הוא יודע לעשות וזוכרת את זה. הנה כל התהליך.

לפני שמתחילים

מה צריך

  • אותה רשת. הטלפון, הטאבלט או המחשב שלכם חייבים להיות באותה רשת Wi-Fi (או LAN קווית) כמו המקרן. האפליקציה מדברת עם המקרן ישירות ברשת הזו.
  • מקרן דלוק או במצב המתנה. השאירו את המקרן דלוק, או במצב המתנה כשבקרת רשת מופעלת - רוב דגמי Epson עונים גם במצב המתנה, כך שאפשר להדליק אותם מהאפליקציה.
  • כתובת ה-IP של המקרן (רק אם מוסיפים ידנית). היא נמצאת בתפריט הרשת של המקרן עצמו - ראו בהמשך איפה לחפש.
אין מקרן בהישג יד? לחצו על התנסות במצב הדגמה במסך הראשון, וכל האפליקציה רצה מול מקרן Epson QB1000 אמיתי שהוקלט ועונה כמו מקרן אמיתי - כך אפשר לנסות כל מסך לפני שקונים משהו.
צעד אחר צעד

הוספת מקרן

פתחו את הוספת מקרן ובחרו איך למצוא אותו. שני המסלולים מסתיימים באותו מקום.

  1. בחרו סריקת רשת או הוספה לפי IP. סריקת רשת מחפשת ברחבי ה-Wi-Fi או ה-LAN הקווית כל מה שעונה כמקרן, וממלאת את הכתובת בשבילכם. הוספה לפי IP קיימת לפעמים שמעדיפים להקליד את הכתובת בעצמכם.
  2. בחרו את המקרן, או הזינו את ה-IP שלו. אחרי סריקה, לחצו על המקרן ברשימה. ידנית, הקלידו את כתובת ה-IP מתפריט הרשת של המקרן והמשיכו.
  3. תנו לסריקת היכולות לרוץ. בהוספה ראשונה האפליקציה בודקת את המקרן ומציגה סרגל התקדמות כדי שתראו כמה נשאר. היא שואלת את המקרן מה הוא באמת תומך בו - אילו פרוטוקולים עונים, אילו בקרות קיימות, טווחי העדשה והתמונה - כך שהאפליקציה מציגה לכם רק בקרות אמיתיות.
  4. לחצו על בדיקת חיבור. האפליקציה מוודאת שהיא מגיעה למקרן וקוראת ממנו את הזהות שלו. אם המקרן דורש סיסמת Web Control, הזינו אותה כאן; האפליקציה בודקת אם בכלל נדרשת סיסמה ומודיעה לכם בכל מקרה.
  5. שמרו. המקרן נוסף וסריקת היכולות שלו נשמרת - פותחים את האפליקציה שוב והיא לא סורקת מחדש. אתם נוחתים בלוח הבקרה, עם קריאה חיה.
מקרן נסרק פעם אחת והתוצאה נשמרת. בגלל זה ההפעלה השנייה מיידית - האפליקציה כבר יודעת מה החומרה שלכם מסוגלת לעשות.
איתור הכתובת

איפה נמצאת כתובת ה-IP של המקרן

אם מוסיפים לפי IP, צריך את כתובת המקרן ברשת. בכל מקרן Epson היא מוצגת באותו מקום.

  1. במקרן, פתחו את התפריט שעל המסך ועברו אל רשת (או מתקדם › רשת בדגמים מסוימים).
  2. פתחו תצורת רשת › LAN קווית או LAN אלחוטית וקראו את כתובת ה-IP.
  3. הקלידו את הכתובת הזו בהוספה לפי IP. כדאי להגדיר בראוטר כתובת קבועה או שמורה, כדי שהיא לא תשתנה לאפליקציה מתחת לידיים.
הגדרות הרשת נמצאות במקרן, לא באפליקציה. Projector Pilot מגיעה למקרן דרך הרשת הזו, ולכן היא מציגה את עמוד הרשת בתצוגה ברורה לקריאה בלבד - את הכתובות משנים בממשק של המקרן עצמו.
אם הוא לא מתחבר

תיקונים מהירים

  • בדקו שוב את הרשת. טלפון שעבר לרשת אורחים או לנתונים סלולריים לא יראה את המקרן. אותה רשת, בשני הצדדים.
  • העירו את המקרן. דגם שהמתנת הרשת בו כבויה לא יענה עד שיודלק. הדליקו אותו פעם אחת והוסיפו אותו.
  • מבקש סיסמה? הזינו את הסיסמה של Web Control (היחידה שהעמוד של המקרן עצמו מבקש). האפליקציה מטפלת בסיסמאות הנפרדות של המקרן - ראו את מדריך השלט.
  • מקרן PJLink בלבד? זה מכשיר רגיל לגמרי. האפליקציה עוברת לכל ערוץ שעונה, כך שמקרן בלי Web Control עדיין עובד.
