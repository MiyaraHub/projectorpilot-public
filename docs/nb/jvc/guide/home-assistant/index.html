Home Assistant

Sett opp JVC-prosjektoren din i Home Assistant

Appen logger inn på Home Assistant, legger prosjektoren til i Home Assistants egen JVC Projector-integrasjon, publiserer scenene og kontrollene dine som script, og bygger et dashbord. Du limer aldri inn et token og skriver aldri YAML. Det krever tillegget Home Automation.

Les dette først

Én kontroller om gangen

En JVC-prosjektor betjener én nettverkskontroller om gangen. Mens denne appen er åpen og koblet til prosjektoren, kan ikke Home Assistant nå den. Home Assistants prosjektorkontroller og script fungerer når appen er lukket, og appen slipper prosjektoren når den går i bakgrunnen.

Steg 1

Logg inn

  1. Åpne Innstillinger, Hjemmeautomasjon, Home Assistant.
  2. Skriv inn Home Assistant-adresse, som begynner med http:// eller https://.
  3. Trykk på Logg inn. Home Assistants egen påloggingsside åpnes i nettleseren; logg inn der og kom tilbake.
  4. Trykk på Test tilkoblingen for å bekrefte.
Hvis Home Assistant ikke kan nås, sjekk adressen, og at denne enheten er på samme nettverk som Home Assistant.
Steg 2

Hva Home Assistant har

Et panel leser Home Assistant og merker hver del Funnet, Ikke installert eller Kunne ikke avgjøre. Sjekk igjen leser den på nytt.

DelTrengs for
Mobile App-integrasjonSensoren for direkte status.
JVC Projector-integrasjonStyre denne prosjektoren fra Home Assistant.
HACSBare den stilede utformingen av dashbordet.
Steg 3

Sjekkliste for oppsett

  1. Logg inn på Home Assistant.
  2. Legg til denne prosjektoren i Home Assistants JVC Projector-integrasjon. Trykk på Legg til. Appen sender prosjektorens adresse, port og nettverkspassord til Home Assistants JVC Projector-integrasjon, etter at den har spurt deg først.
  3. Aktiver enhetene scriptene trenger. Noen JVC Projector-enheter starter deaktivert i Home Assistant; trykk på Aktiver ved siden av hver enkelt. Home Assistant kan trenge en omlasting eller en omstart før den vises.
  4. Sensor for direkte status. Slå på Send prosjektorens tilstand. Sensoren opprettes neste gang appen sender prosjektorens tilstand mens den er tilkoblet.
Om passordet. Når du legger til prosjektoren, sendes nettverkspassordet til Home Assistant og lagres der, i JVC Projector-oppføringen. Appen sender det ingen andre steder. Appen slipper prosjektoren mens Home Assistant kobler til den, og kobler deretter til igjen.
Hvilken oppføring?

Hvordan appen finner prosjektoren din i Home Assistant

Appen finner JVC Projector-oppføringen ut fra prosjektorens MAC-adresse, så koble til prosjektoren minst én gang først. Hvis Home Assistant ikke har noen oppføring med den MAC-adressen, eller mer enn én, sier sjekklisten det og hva du skal gjøre. Hvis prosjektoren har flyttet, tilbyr appen å sende den nye adressen til Home Assistant.

Sensoren

Sanntidstilstand

Sensorens tilstand er strømmen appen sist leste, og attributtene er inngangen, modellen og innstillingene appen har lest. Den går gjennom Mobile App-integrasjonen og sender ingenting til prosjektoren. Den oppdateres hver gang tilstanden endres mens appen er åpen og tilkoblet.

Script

Scener og kontroller

Hver lagrede scene blir et script i Home Assistant som kjører gjennom JVC Projector-enhetene. Et script inneholder ingen adresse og intet passord. Script-id-er begynner med ppjvc.

  • Sync With HA skriver scenene dine som script og viser hvor mange trinn hvert av dem har, og hva som ble utelatt og hvorfor.
  • Sync Advanced Controls publiserer script for strøm, innganger, bildemodus, objektivminner og Skjul.
  • Resultater telles: hvor mange script som ble synkronisert, hvor mange Home Assistant avviste, og om den bekreftet at de ble lastet på nytt.
  • Fjern foreldreløse script sletter script denne appen har opprettet som ingen scene bruker lenger. Den viser dem og spør først.
Hvis noe en synkronisering er avhengig av ikke er lest, blir ingenting skrevet, endret eller fjernet. En synkronisering kjører aldri halvveis på en gjetning.
Dashbord

Et ferdig dashbord

Send dashbord bygger et prosjektordashbord i Home Assistant ut fra JVC Projector-enhetene, scriptene og sensoren. Kopier dashbord kopierer det i stedet, så du kan lime det inn i et nytt dashbord selv. Alt om det står på siden om Home Assistant-dashbordet.

Regler

Hva appen aldri gjør

  • Ingenting forlater enheten mens demoprojektoren er valgt eller Hjemmeautomasjon ikke er låst opp.
  • Koble fra fjerner koblingen bare fra denne appen. Prosjektorens enhet og enheter blir værende i Home Assistant til du sletter dem der.
  • Hvis Home Assistant slutter å godta påloggingen, sier appen fra og ber deg logge inn på nytt.
