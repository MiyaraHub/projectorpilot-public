Projector Pilot-brukerveiledning

Alt du trenger for å legge til prosjektoren og bruke hver skjerm - dashbordet, den dype fjernkontrollen, hele bildemenyen, motorisert objektiv, scener og ekte hjemmeautomatisering. Hver skjerm tilpasser seg maskinvaren din: appen viser bare kontrollene prosjektoren faktisk eksponerer, og hver verdi leses tilbake fra prosjektoren, aldri gjettet. Skjermene dine kan derfor vise færre alternativer enn en side lister her, og det er appen som er ærlig, ikke ødelagt.

Bla i veiledningen

Hver skjerm, forklart

Start med Kom i gang, og dykk deretter ned i hvilken som helst skjerm. Ingenting her krever en skykonto - Projector Pilot snakker med prosjektoren på ditt eget nettverk over ESC/VP21, PJLink og Epson Web Control, med den som svarer.

Ny i Projector Pilot?

Tre skjermer gjør mesteparten av jobben.

🚀

Legg til prosjektoren din

Skann nettverket eller legg til via IP, kjør den ene mulighetsskanningen, Test tilkobling og Lagre. På samme Wi-Fi på omtrent ett minutt.
📊

Les dashbordet

Strøm, inngang, fargemodus og projeksjonsinfo i sanntid, med kort du legger til, skjuler og sorterer for å bygge visningen du vil ha.
🎭

Lagre en scene

Fang opp strøm, inngang, bilde, objektiv og mer, og kall opp hele rommet med ett trykk - og gi det videre til Home Assistant.

Skaff deg appen og følg med

Engangskjøp. Ingen reklame, ingen abonnement, ingen skykonto. Koble til Epson- eller PJLink-prosjektoren på ditt eget nettverk.
