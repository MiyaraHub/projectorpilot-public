Otomasi rumah

Hubungkan proyektor Anda ke rumah Anda

Biarkan seisi rumah bereaksi saat proyektor menyala, masuk standby, berganti input, atau memanggil skenario. Tiga tautan berada di bawah Pengaturan, Otomatisasi Rumah: pemicu webhook, Hubitat, dan Home Assistant. Ketiganya memerlukan add-on Otomatisasi Rumah, dijual terpisah atau dalam bundel; Pro saja tidak mencakupnya.

Pilih satu

Tautan mana yang dipakai

Webhook

Sistem apa pun yang menerima permintaan web: Node-RED, server rumah, otomatisasi cloud. Aplikasi mengirim, Anda yang menentukan apa yang terjadi.

Hubitat

Cermin satu arah untuk daya dan input ke perangkat di hub Anda, melalui Maker API, agar Rule Machine bertindak atasnya.

Home Assistant

Menyiapkan integrasi JVC Projector milik Home Assistant sendiri, skrip untuk skenario Anda, dan dasbor siap pakai.

Webhook

Pemicu otomatisasi

Pemicu mengirim permintaan web ke alamat yang Anda masukkan saat sesuatu terjadi pada proyektor ini. Setiap proyektor memiliki daftarnya sendiri. Ketuk Tambah pemicu, lalu pilih:

  • Saat: Proyektor menyala, Proyektor masuk standby, Input berubah (ke input apa pun atau input tertentu), atau Skenario dipanggil (skenario apa pun atau skenario tertentu).
  • Metode: POST (default), PUT, atau GET.
  • Alamat web: alamat http:// atau https:// dengan nama host.
  • Aktif, untuk menjeda pemicu tanpa menghapusnya.
Alamat yang diawali http:// dikirim tanpa enkripsi, dan editor menyatakannya. Gunakan https:// jika sistem Anda mendukungnya.
Payload

Apa yang dibawa permintaan

POST dan PUT mengirim isi JSON; GET tidak mengirimnya. Satu-satunya header yang ditambahkan aplikasi adalah Content-Type. Kolom yang tidak berlaku untuk peristiwa itu dihilangkan.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
KolomArti
eventpower_on, power_off, input_changed, atau scene_recalled.
projectorNama proyektor di aplikasi.
inputInput, seperti hdmi1 atau hdmi2.
scene_id, scene_nameSkenario, untuk pemanggilan skenario.
timestampKapan terjadinya, dalam UTC.
testAda, dan bernilai true, hanya pada permintaan yang dikirim oleh Kirim uji.
Pengiriman

Satu percobaan, dilaporkan apa adanya

  • Setiap peristiwa dikirim sekali, dengan batas 10 detik, dan pengalihan tidak diikuti.
  • Pemicu menampilkan hasil terakhirnya: Terkirim pada suatu waktu dengan kode status, Ditolak, Tidak ada jawaban, Alamat tidak dapat dijangkau, Koneksi aman gagal, atau Belum dikirim.
  • Kirim uji mengirim permintaan yang ditandai sebagai uji, sehingga Anda dapat menyambungkan sisi lain sebelum proyektor melakukan apa pun.
Kapan pemicu aktif

Aturannya

  • Hanya selama aplikasi terbuka dan terhubung ke proyektor. Aplikasi memantau status proyektor; aplikasi bukan layanan latar belakang.
  • Perubahan, bukan pembacaan. Pembacaan pertama setelah aplikasi terhubung hanya menetapkan titik awal, sehingga membuka aplikasi tidak memicu "menyala" untuk proyektor yang sudah menyala.
  • Tidak pernah dari proyektor demo. Tidak ada yang keluar dari perangkat selama proyektor demo dipilih atau Otomatisasi Rumah belum dibuka.
  • Disimpan dengan aman. Alamat pemicu disimpan di penyimpanan aman perangkat.
Hubitat

Cerminkan proyektor ke Hubitat

Aplikasi mencerminkan proyektor ini ke perangkat di hub Hubitat Anda melalui Maker API: menyala dan standby, serta input sebagai HDMI 1 atau HDMI 2, mana pun yang diterima perangkat. Rule Machine kemudian dapat bertindak atasnya.

  1. Di Hubitat, tambahkan Maker API dan catat ID aplikasinya (angka dalam URL-nya) dan token aksesnya.
  2. Di aplikasi, masukkan Alamat hub, ID aplikasi Maker API, dan Token akses.
  3. Ketuk Temukan perangkat dan pilih perangkat yang mewakili proyektor ini. Jika tidak ada yang mirip, tambahkan Virtual Switch bernama sesuai proyektor di Hubitat lalu coba lagi.
  4. Aktifkan Cerminkan status proyektor. Perangkat mengikuti proyektor setiap kali berubah selagi aplikasi terbuka dan terhubung.
Hanya satu arah. Tidak ada yang dikirim dari Hubitat ke proyektor. Putuskan Tautan menghapus tautan dari aplikasi.
Home Assistant

Tautan terdalam

Aplikasi masuk ke Home Assistant, menambahkan proyektor Anda ke integrasi JVC Projector miliknya, menerbitkan skenario dan kontrol Anda sebagai skrip, dan membuat dasbor. Fitur ini punya halamannya sendiri: Penyiapan Home Assistant dan dasbor Home Assistant.
