Webhook pada peristiwa proyektor

  • Peristiwa: daya nyala, standby, perubahan input, dan skenario.
  • Permintaan: POST, PUT, atau GET ke alamat yang Anda masukkan.
  • Pemicu hanya aktif saat aplikasi terbuka dan terhubung, dan tidak pernah dari proyektor demo.
