Prise en main

Ajoutez votre projecteur Epson ou PJLink en à peine une minute

Projector Pilot trouve votre projecteur sur votre propre réseau, sans compte cloud ni code d'appairage. Connectez votre téléphone au même Wi-Fi, ajoutez le projecteur une seule fois, et l'appli analyse ce qu'il sait faire et s'en souvient. Voici toute la procédure.

Avant de commencer

Ce qu'il vous faut

  • Même réseau. Votre téléphone, votre tablette ou votre ordinateur doit être sur le même Wi-Fi (ou réseau filaire LAN) que le projecteur. L'appli communique directement avec le projecteur sur ce réseau.
  • Projecteur allumé ou en veille. Laissez le projecteur allumé, ou en veille avec le contrôle réseau activé : la plupart des modèles Epson répondent en veille, ce qui vous permet de les allumer depuis l'appli.
  • L'adresse IP du projecteur (seulement si vous ajoutez à la main). Elle se trouve dans le menu réseau du projecteur - voir plus bas où chercher.
Pas de projecteur sous la main ? Touchez Explorer le mode démo sur le premier écran et toute l'appli fonctionne avec un véritable Epson QB1000 capturé, qui répond comme un vrai projecteur - vous pouvez ainsi essayer chaque écran avant tout achat.
Pas à pas

Ajouter un projecteur

Ouvrez Ajouter un projecteur et choisissez comment le trouver. Les deux chemins mènent au même résultat.

  1. Choisissez Rechercher sur le réseau ou Ajouter par IP. La recherche sur le réseau parcourt votre Wi-Fi ou votre réseau LAN filaire à la recherche de tout appareil qui répond comme un projecteur, et renseigne l'adresse pour vous. Ajouter par IP est là pour les fois où vous préférez saisir l'adresse vous-même.
  2. Choisissez votre projecteur, ou saisissez son IP. Après une recherche, touchez le projecteur dans la liste. À la main, saisissez l'adresse IP indiquée dans le menu réseau du projecteur et continuez.
  3. Laissez l'analyse des capacités se dérouler. Lors d'un premier ajout, l'appli sonde le projecteur et affiche une barre de progression pour que vous voyiez où elle en est. Elle demande au projecteur ce qu'il prend réellement en charge - quels protocoles répondent, quelles commandes existent, les plages d'objectif et d'image - pour ne vous montrer que de vraies commandes.
  4. Touchez Tester la connexion. L'appli confirme qu'elle joint le projecteur et relit son identité. Si le projecteur demande un mot de passe Web Control, saisissez-le ici ; l'appli détermine si un mot de passe est nécessaire et vous le dit dans les deux cas.
  5. Enregistrez. Le projecteur est ajouté et son analyse des capacités est mémorisée : rouvrez l'appli et elle ne refait pas l'analyse. Vous arrivez sur le tableau de bord, en lecture directe.
Un projecteur n'est analysé qu'une seule fois et le résultat est mis en cache. C'est pourquoi le deuxième lancement est instantané : l'appli sait déjà ce que votre matériel peut faire.
Trouver l'adresse

Où se trouve l'IP de votre projecteur

Si vous ajoutez par IP, il vous faut l'adresse du projecteur sur votre réseau. Tous les Epson l'affichent au même endroit.

  1. Sur le projecteur, ouvrez le Menu à l'écran et allez à Réseau (ou Étendu › Réseau sur certains modèles).
  2. Ouvrez Configuration réseau › LAN filaire ou LAN sans fil et lisez l'Adresse IP.
  3. Saisissez cette adresse dans Ajouter par IP. Il vaut la peine de définir une adresse fixe ou réservée sur votre routeur pour qu'elle ne change jamais sous les pieds de l'appli.
Les réglages réseau se trouvent sur le projecteur, pas dans l'appli. Projector Pilot joint le projecteur via ce réseau, c'est pourquoi la page réseau s'affiche en lecture seule : vous modifiez les adresses sur l'interface du projecteur lui-même.
Si la connexion échoue

Solutions rapides

  • Vérifiez le réseau. Un téléphone passé sur un Wi-Fi invité ou sur le réseau mobile ne verra pas le projecteur. Même réseau, aux deux bouts.
  • Réveillez le projecteur. Un modèle dont la veille réseau est désactivée ne répondra pas tant qu'il n'est pas allumé. Allumez-le une fois et ajoutez-le.
  • Invite de mot de passe ? Saisissez le mot de passe Web Control (le seul que demande la page web du projecteur). L'appli gère les autres mots de passe du projecteur - voir le guide de la Télécommande.
  • Projecteur PJLink uniquement ? C'est un appareil tout à fait ordinaire. L'appli se rabat sur le transport qui répond, donc un projecteur sans Web Control fonctionne aussi.
