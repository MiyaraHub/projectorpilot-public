Home Assistant · Hubitat · Webhooks

Votre projecteur, dans Home Assistant et Hubitat.

Projector Pilot publie l'état en direct de votre projecteur et chaque commande vers Home Assistant, Hubitat et tout webhook de votre choix. Configurez-le une fois, et votre maison connectée pilote le projecteur toute seule - sans téléphone sur le réseau, sans cloud au milieu.

Ce que fait la domotique

La domotique transforme Projector Pilot, d'une télécommande dans votre main, en un appareil que toute votre maison peut voir. Elle expose ce que fait le projecteur - alimentation, entrée, mode couleur, valeurs d'image, heures de lampe - et donne à votre maison connectée une commande pour tout ce que l'appli peut modifier.

  • Elle publie l'état. Le projecteur apparaît comme un capteur Home Assistant, un appareil Hubitat ou une charge JSON sur votre webhook, avec les mêmes mesures que celles que l'appli vous montre.
  • Elle publie les commandes. Chaque scène que vous enregistrez, ainsi que l'alimentation, chaque entrée, chaque mode couleur et chaque mémoire d'objectif, devient quelque chose qu'une automatisation ou un assistant vocal peut exécuter.
  • Elle fonctionne sans serveur. Une fois les scripts configurés, Home Assistant envoie les commandes directement à l'adresse IP du projecteur. Votre téléphone n'a pas besoin d'être sur le réseau, et rien ne passe par un compte cloud.
La domotique est un module complémentaire payant. C'est un achat unique, distinct de Projector Pilot Pro, et un pack permet d'acheter les deux ensemble à prix réduit. Pas d'abonnement, pas de compte, pas de cloud. Voir les tarifs.

Trois voies d'accès, un seul hub

Réglages › Domotique est le hub. Choisissez la plateforme que vous utilisez - Home Assistant, Hubitat ou Webhooks - et configurez-la là. Vous pouvez en brancher plusieurs à la fois ; elles sont indépendantes.

Home Assistant

Configurer Home Assistant

Connectez-vous depuis l'appli, publiez le projecteur comme capteur, collez un bloc dans votre configuration et synchronisez. Ensuite, Home Assistant pilote lui-même le projecteur.

  1. Ouvrez Réglages › Domotique › Home Assistant.
  2. Saisissez votre adresse Home Assistant (par exemple http://homeassistant.local:8123 ou son IP), puis touchez Se connecter. C'est une connexion dans le navigateur auprès de votre propre instance - il n'y a aucun jeton à coller. Utilisez votre identifiant Home Assistant habituel, avec la double authentification et tout le reste.
  3. L'appli publie le projecteur comme capteur, avec une entité du type sensor.projector_pilot_epson_qb1000b_qb1000w, qui porte l'alimentation, l'entrée, le mode couleur, les valeurs d'image et les heures de lampe.
  4. Activez Envoyer l'état du projecteur pour que ces mesures se mettent à jour dans Home Assistant dès qu'elles changent tant que l'appli est ouverte, et activez Sync Advanced Controls pour publier des scripts pour les modes d'image, les entrées, les mémoires d'objectif et l'alimentation.
  5. Collez le bloc shell_command (ci-dessous) dans votre configuration.yaml, redémarrez Home Assistant, puis touchez Sync With HA.

Le bloc shell_command

Voilà toute l'astuce du fonctionnement sans serveur. L'appli écrit une commande que Home Assistant exécute pour parler au Web Control du projecteur, et chaque script synchronisé appelle cette commande avec un verbe différent. Touchez Copier le bloc dans l'appli et collez-le dans configuration.yaml. L'exemple ci-dessous est illustratif : l'appli renseigne l'adresse et le nom de commande propres à votre projecteur :

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

Exemple uniquement. L'appli génère le vôtre avec la vraie IP du projecteur et un nom dérivé de son numéro de série.

Pourquoi sans serveur. Ce curl s'exécute sur la machine Home Assistant, pas sur votre téléphone. Home Assistant joint directement l'IP du projecteur via Web Control, donc une automatisation se déclenche que l'appli soit ouverte ou non, et que votre téléphone soit à la maison ou non. L'utilisateur digest EPSONWEB est l'identifiant Web Control ; l'appli utilise le mot de passe Web Control déjà enregistré pour le projecteur.

Tester la connexion, synchroniser et nettoyer

  • Tester la connexion vérifie que l'appli joint votre Home Assistant et que le shell_command collé s'y trouve bien, pour que vous découvriez une faute de frappe avant de construire quoi que ce soit dessus.
  • Sync With HA écrit ou met à jour les scripts de vos scènes et commandes, et construit un tableau de bord Projector Pilot prêt à l'emploi directement dans Home Assistant. Relancez-le à tout moment quand vous ajoutez une scène ou changez une commande : il met à jour sur place au lieu d'empiler des doublons.
  • Supprimer les scripts orphelins trouve les scripts écrits par l'appli qui n'ont plus de scène ou de commande correspondante - par exemple après la suppression d'une scène - indique précisément lesquels il va supprimer, et demande d'abord. Rien n'est supprimé avant votre confirmation. Il ne touche jamais qu'aux scripts créés par Projector Pilot ; rien d'autre dans votre Home Assistant n'est perturbé, et si Home Assistant ne veut pas lister ses scripts, rien n'est supprimé.
Liste de configuration

L'appli vous dit ce qui est fait et ce qui manque

L'écran Home Assistant comporte une Liste de configuration et un panneau Ce que contient votre Home Assistant, pour ne jamais deviner quelle étape reste à faire. Chaque ligne indique si c'est fait, manquant ou impossible à déterminer, et ce qu'il faut faire ensuite.

  • Connecté à Home Assistant - connecté et répond. Si Home Assistant ne répond pas, la ligne vous dit de vérifier l'adresse et que votre téléphone est sur le même réseau.
  • Projecteur ajouté à Home Assistant - indique si Home Assistant a déjà ce projecteur. Sinon, la ligne vous envoie ajouter l'intégration PJLink, et l'étape d'ajout d'intégration affiche l'hôte et le port PJLink que Home Assistant demande.
  • Capteur de mesures enregistré - le capteur qui porte les mesures de votre projecteur. Il s'enregistre la première fois que l'appli lit le projecteur, et la ligne propose Enregistrer maintenant ou Activer quand quelque chose l'en empêche.
  • Ce que contient votre Home Assistant - HACS (la boutique communautaire), l'intégration Epson Projector Link, l'intégration PJLink et les commandes Projector Pilot dans configuration.yaml. Chacun affiche Trouvé, Non installé ou Impossible de savoir, avec des boutons Comment installer et Ouvrir dans HACS quand ils sont utiles.
Vérifier à nouveau vous dit ce qui a été trouvé. Touchez Vérifier à nouveau après avoir corrigé quelque chose et l'appli relit votre Home Assistant et rapporte le résultat, au lieu de vous laisser vous demander si ça a marché. Une ligne qui n'a pas pu être vérifiée affiche Impossible de savoir, jamais un oui ou un non deviné.
Fonctionne avec ce que vous avez déjà

Prise en charge de l'intégration PJLink native, et des cartes plus riches si vous les avez

Projector Pilot détecte ce que votre Home Assistant a d'installé et s'y adapte. Il fonctionne avec l'intégration PJLink native fournie d'origine avec Home Assistant, donc un projecteur PJLink que vous y avez déjà ajouté est traité à part entière.

  • Les cartes intégrées d'abord. Si vous n'avez aucune carte communautaire, Sync construit votre tableau de bord avec les cartes intégrées de Home Assistant et vous le dit à la fin. Cela fonctionne dès le départ.
  • Amélioré quand des cartes HACS sont installées. L'appli vérifie lesquelles des cartes communautaires (Mushroom, button-card, card-mod, apexcharts-card) sont installées et remplace chaque carte par la version plus riche quand vous l'avez. Le guide du tableau de bord fait main va plus loin si vous voulez le look verre vert complet.
  • Les scènes et commandes demandent un seul collage. Si Home Assistant n'a pas encore de commande pour envoyer au projecteur, le tableau de bord est quand même construit avec les mesures en direct, et une carte Terminer la configuration vous guide : touchez Copier le bloc, collez-le dans configuration.yaml, redémarrez Home Assistant, puis touchez Sync à nouveau.
  • Rien d'installé ? Collez à la main. Si rien n'est installé dans Home Assistant, vous pouvez quand même tout copier depuis l'appli et le coller vous-même.
  • Un mot de passe est signalé. Le bloc de commande que vous collez indique quand il contient un mot de passe de projecteur, pour que vous le sachiez avant de le partager ou de le stocker.
Pendant que le projecteur est éteint

Des mesures qui restent en place

Un projecteur en veille communique très peu, donc un tableau de bord deviendrait normalement vide. Le capteur de dernière valeur connue, facultatif, conserve dans Home Assistant les dernières mesures de votre projecteur - l'entrée, les heures de lampe ou de laser - pendant qu'il est éteint.

  • C'est un bloc facultatif de plus : collez-le à la fin de configuration.yaml (ou ajoutez seulement ses lignes sous une section template: existante) et redémarrez Home Assistant. L'appli propose un bouton Vérifier qu'il est présent qui vous dit si Home Assistant l'a.
  • Une extinction arrive désormais dans Home Assistant comme off, donc le tableau de bord et vos automatisations voient le projecteur comme éteint quand il l'est.
Les scènes comme scripts

Chaque scène devient un script Home Assistant

Après une synchronisation, vos scènes ne restent pas coincées dans l'appli. Chacune, ainsi que l'alimentation, chaque entrée, chaque mode couleur et chaque mémoire d'objectif que votre projecteur possède réellement, est écrite comme un script Home Assistant.

  • Les automatisations peuvent les exécuter. « Au coucher du soleil, si la TV s'allume, lancer Movie Night » est une automatisation Home Assistant tout à fait normale une fois la scène devenue un script.
  • Les assistants vocaux peuvent les exécuter. Exposez un script à votre assistant et « allume Movie Night » règle l'entrée, le mode d'image et la mémoire d'objectif ensemble.
  • Seules vos vraies commandes apparaissent. L'appli écrit un script pour chaque entrée, mode couleur et mémoire d'objectif que le projecteur signale, et non une liste générique devinée.
  • Retirer la synchronisation ne retire que ce que l'appli a écrit. Désactivez la synchronisation, ou utilisez Supprimer les scripts orphelins (qui les liste et demande d'abord), et Projector Pilot supprime les scripts qu'il a créés et rien d'autre.
Les scripts sont nommés de façon qu'un renommage mette à jour le même. Les noms de script sont dérivés du projecteur et de la commande, donc resynchroniser après avoir renommé une scène met à jour le script existant au lieu de créer une seconde copie.
Le tableau de bord

Sync construit le tableau de bord pour vous

Vous n'avez pas à construire une vue Lovelace à la main, et vous n'avez plus à en coller une non plus. Quand vous touchez Sync With HA, l'appli construit un tableau de bord Projector Pilot complet directement dans Home Assistant via sa propre API : l'état en direct du projecteur et un bouton pour chaque scène et commande synchronisée. Il apparaît dans la barre latérale de Home Assistant sous le nom Projector Pilot - ouvrez-le et c'est fini.

  1. Connectez-vous à Home Assistant dans l'appli.
  2. Collez une fois le bloc Copier de l'appli dans configuration.yaml et redémarrez Home Assistant (la seule étape manuelle - Home Assistant ne permet pas aux applis d'ajouter cette commande à distance).
  3. Touchez Sync With HA. Le tableau de bord est construit pour vous et apparaît dans la barre latérale sous le nom Projector Pilot.
Vous préférez le coller vous-même ? Copier le tableau de bord est toujours là sur l'écran Home Assistant. Touchez-le, puis dans Home Assistant allez à Réglages › Tableaux de bord › Ajouter un tableau de bord, créez un tableau de bord vide, ouvrez son menu à trois points › Modifier le tableau de bord › menu à trois points › Éditeur de configuration brute, et collez le YAML copié.

Qu'il soit construit pour vous ou que vous le colliez, le tableau de bord est le même - une carte d'état plus un bouton pour chaque commande (extrait illustratif) :

views:
  - title: Projector
    cards:
      - type: entity
        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_power_on
      - type: button
        name: Movie Night
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_scene_movie_night

Exemple uniquement. Votre tableau de bord porte la vraie entité de votre projecteur et vos propres scènes.

Indépendant du modèle. Le tableau de bord est construit à partir des capacités de votre projecteur - l'entité, les valeurs d'image, les entrées, les modes couleur, les mémoires d'objectif et les scènes qu'il a réellement signalés. Les captures d'écran ici sont celles d'un QB1000 ; votre modèle peut afficher d'autres entrées, commandes et mesures. Pour un tableau complet en verre vert comme celui de l'illustration, suivez le guide pas à pas du tableau de bord ou téléchargez la vue complète et changez deux chaînes.
Envie d'un mur plus riche ? Les mêmes scripts pilotent les cartes que vous voulez. Si vous avez utilisé AVR Maestro, l'approche est identique : construisez des tuiles de source et de mode éclairées, des en-têtes en direct et un historique à partir du capteur unique et des scripts synchronisés.
Hubitat

Configurer Hubitat

Sur Hubitat, Projector Pilot reflète le projecteur sur un appareil de votre hub via le Maker API, afin que Rule Machine puisse lire et agir sur l'alimentation, la sourdine et l'entrée.

  1. Dans Hubitat, activez l'application Maker API, notez son URL d'accès et son jeton, et choisissez les appareils qu'elle expose.
  2. Dans Projector Pilot, ouvrez Réglages › Domotique › Hubitat et saisissez les informations Maker API de votre hub.
  3. Choisissez l'appareil qui représente le projecteur. L'appli suggère le plus probable ; sélectionnez-le ou choisissez le vôtre.
  4. L'appli reflète l'alimentation, la sourdine et l'entrée sur cet appareil, en n'envoyant que les commandes que l'appareil accepte.
  5. Créez des règles Rule Machine sur cet appareil comme pour n'importe quel autre - c'est l'état du projecteur qui les pilote.
Seulement ce que l'appareil accepte. L'appli n'envoie une valeur de projecteur à Hubitat que si l'appareil choisi prend en charge cette commande, et ne pousse donc jamais quelque chose que l'appareil rejetterait.
Webhooks

Configurer les Webhooks

Les webhooks sont la solution universelle. L'appli envoie une requête à une URL de votre choix quand le projecteur s'allume, s'éteint, change d'entrée ou rappelle une scène - un webhook Home Assistant, Node-RED, IFTTT, ou tout ce qui accepte du JSON.

  1. Ouvrez Réglages › Domotique › Webhooks.
  2. Saisissez l'URL vers laquelle envoyer. Un webhook Home Assistant ressemble à http://homeassistant.local:8123/api/webhook/your-id.
  3. Choisissez les événements qui déclenchent le webhook : allumage, extinction, changement d'entrée, rappel de scène - et filtrez éventuellement sur une entrée ou une scène précise.
  4. Définissez éventuellement une charge personnalisée si le service récepteur attend une forme particulière ; sinon l'appli envoie son JSON par défaut.
  5. Enregistrez. L'appli envoie une requête à chaque événement correspondant à partir de là.

La charge par défaut est du JSON simple - un événement, le projecteur et la valeur qui a changé :

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

Exemple de charge. Un événement de changement d'entrée ou d'alimentation contient les champs qui le concernent.

Se reconnecter règle tout. Si vous reliez Home Assistant à une nouvelle adresse, l'appli met à jour d'un coup tous les webhooks qui pointent vers lui, donc déplacer une instance ne signifie pas modifier chacun à la main.

Dépannage

La connexion renvoie à la page de connexion

Vérifiez que l'adresse saisie est bien celle par laquelle vous joignez Home Assistant, port compris (généralement :8123). La connexion est une véritable connexion dans le navigateur auprès de votre instance, donc votre nom d'utilisateur, votre mot de passe et votre code à deux facteurs s'appliquent tous. Sur un téléphone, la connexion aboutit que le navigateur intégré à l'appli renvoie le résultat ou que le rappel local arrive en premier ; si elle reste bloquée, fermez la feuille et touchez à nouveau Se connecter.

Le capteur du projecteur n'apparaît pas dans Home Assistant

Le capteur est publié tant que l'appli est ouverte et que Envoyer l'état du projecteur est activé, donc ouvrez l'appli et vérifiez ce réglage. Vérifiez ensuite Outils de développement › États dans Home Assistant et filtrez sur projector_pilot. Un projecteur en veille publie très peu ; réveillez-le et les mesures se remplissent.

Les scripts synchronisés sont absents

Les scripts sont écrits par Sync With HA, qui exige que le bloc shell_command soit déjà collé dans configuration.yaml et que Home Assistant ait été redémarré une fois. Lancez d'abord Tester la connexion : elle vous dit si le bloc est présent. Puis synchronisez à nouveau. Si d'anciens scripts inutiles encombrent la liste, utilisez Supprimer les scripts orphelins.

Un script fonctionne dans l'appli mais pas depuis Home Assistant quand mon téléphone est absent

C'est tout l'intérêt du bloc shell_command : c'est lui qui permet à Home Assistant de joindre seul l'IP du projecteur. Si cela ne marche que lorsque l'appli est ouverte, le bloc n'est probablement pas collé ou Home Assistant n'a pas été redémarré après le collage. Confirmez avec Tester la connexion, redémarrez Home Assistant et synchronisez.

FAQ

Réponses rapides

Mon téléphone doit-il rester sur le réseau pour que les automatisations Home Assistant s'exécutent ?

Non. Une fois le bloc shell_command collé dans Home Assistant et la synchronisation faite, Home Assistant envoie les commandes directement à l'adresse IP du projecteur. Projector Pilot n'est que l'outil de configuration ; ensuite, Home Assistant parle au projecteur de façon autonome, que votre téléphone soit à la maison ou non.

Comment le projecteur apparaît-il dans Home Assistant ?

Sous forme de capteur, par exemple sensor.projector_pilot_epson_qb1000b_qb1000w, qui porte l'alimentation, l'entrée, le mode couleur, les valeurs d'image et les heures de lampe, mis à jour dès qu'elles changent tant que l'appli est ouverte. Activez Sync Advanced Controls et l'appli écrit aussi un script Home Assistant pour chaque scène, ainsi que pour l'alimentation, chaque entrée, chaque mode couleur et chaque mémoire d'objectif de votre projecteur.

La domotique est-elle gratuite ?

La domotique est un module complémentaire payant, à achat unique, distinct de Projector Pilot Pro. Un pack permet d'acheter les deux ensemble à prix réduit. Voir la page des tarifs.
