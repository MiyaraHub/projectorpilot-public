Tableau de bord Home Assistant

Un tableau de bord de projecteur dans Home Assistant

Un appui construit un tableau de bord complet pour votre projecteur JVC dans Home Assistant : alimentation, état, options d'image, vos scènes, entrées, mémoires d'objectif, mesures du signal et plus encore. Il est construit à partir de ce que votre Home Assistant possède réellement, et ne contient ni adresse ni mot de passe. Il nécessite le module Home Automation.

Avant d'envoyer

Ce qu'il faut

  • Home Assistant lié, avec le projecteur ajouté à l'intégration JVC Projector. Voir la configuration de Home Assistant.
  • Scripts synchronisés si vous voulez des boutons de scène, d'alimentation, d'entrée, de mémoire d'objectif et de commande. Le tableau de bord utilise les scripts qui existent.
  • Le capteur d'état en direct activé, pour les tuiles d'état et de mesures.
  • Un compte administrateur dans Home Assistant, car la création d'un tableau de bord en exige un. Sans lui, Home Assistant refuse et l'app le dit.
Deux façons

Envoyer ou copier

  • Envoyer le tableau de bord crée le tableau de bord dans Home Assistant, dans la barre latérale, avec le nom de votre projecteur pour titre et l'icône de projecteur. Renvoyez-le pour le mettre à jour. La synchronisation avec Home Assistant l'envoie aussi.
  • Copier le tableau de bord n'envoie rien. Il copie le tableau de bord pour que vous le colliez vous-même dans l'éditeur de configuration brute d'un nouveau tableau de bord, et que vous le modifiiez à votre guise.
Chaque projecteur reçoit son propre tableau de bord, à une adresse qui commence par projector-pilot-jvc-, de sorte que deux projecteurs ne s'écrasent jamais l'un l'autre.
Disposition

Ce qu'il contient, de haut en bas

Une section n'apparaît que si elle contient quelque chose : un projecteur sans mémoires d'objectif n'a donc pas de section de mémoires d'objectif.

SectionContient
En-têteLe nom du projecteur, la dernière mise à jour de l'état, l'alimentation, l'état et les heures de la source lumineuse.
ImageL'entrée et les options d'image que Home Assistant propose pour le projecteur, comme le mode d'image, la puissance lumineuse, le contrôle dynamique, Clear Motion Drive, l'anamorphique, le traitement HDR et le mode d'installation, là où votre modèle les propose et où elles sont activées.
ScènesUn bouton par script de scène.
AlimentationScripts d'alimentation.
EntréesScripts d'entrée.
Mémoires d'objectifUn bouton par emplacement de mémoire d'objectif de votre modèle.
CommandesLes autres scripts de commande, comme les modes d'image et le masquage.
SignalRésolution, profondeur de couleur, espace colorimétrique, colorimétrie et HDR, tels que Home Assistant les indique.
MesuresLes réglages que l'app a lus, depuis le capteur d'état en direct.
Apparence

Cartes de base ou apparence stylisée

De base

Construit uniquement avec les cartes propres à Home Assistant. Fonctionne sur n'importe quel Home Assistant, rien à installer.

Stylisé

Utilise button-card, card-mod et les cartes Mushroom de HACS pour un rendu plus riche. Utilisé uniquement quand les trois sont présents.

Si l'une des trois manque, l'app envoie la version de base et vous indique quelles cartes installer depuis HACS pour l'apparence stylisée. Installez-les, puis renvoyez le tableau de bord.

Honnête par conception

Pourquoi certaines choses n'y figurent pas

  • Pas de jauges. JVC ne fournit aucune plage pour les niveaux que Home Assistant indique : le tableau de bord ne dessine donc pas une jauge qu'il devrait deviner.
  • Ni adresse ni mot de passe. Le tableau de bord ne contient que des identifiants d'entités, des noms et des libellés.
  • Aucune entité inventée. Une tuile n'apparaît que pour une entité ou un script qui existe dans votre Home Assistant.
En cas de problème

Messages

  • Tableau de bord envoyé. Ouvrez-le depuis la barre latérale de Home Assistant.
  • Refusé. Home Assistant a refusé le tableau de bord : connectez-vous avec un compte administrateur, puis renvoyez-le.
  • Connexion non acceptée. Reconnectez-vous, puis envoyez le tableau de bord.
  • Aucune réponse. Home Assistant n'a pas répondu, le tableau de bord n'a donc pas été confirmé. Vérifiez la connexion et renvoyez-le.
  • Non autorisé. Rien ne quitte l'appareil tant que le projecteur de démo est sélectionné ou que Home Automation n'est pas déverrouillé.
Le tableau de bord contrôle le projecteur via l'intégration JVC Projector de Home Assistant, qui ne peut joindre le projecteur que lorsque cette app n'y est pas connectée. Fermez l'app avant d'utiliser le tableau de bord.
