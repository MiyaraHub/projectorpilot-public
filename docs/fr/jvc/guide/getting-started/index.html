Prise en main

Ajoutez votre projecteur

L'app trouve les projecteurs JVC D-ILA sur votre propre réseau et communique directement avec eux.

Ajouter un projecteur

Lancez la recherche ou saisissez l'adresse

  • La recherche sur le réseau cherche les projecteurs sur votre propre sous-réseau /24.
  • Par adresse IP lorsque la recherche ne le trouve pas. Le port par défaut est 20554.
  • Mot de passe réseau : celui défini sur le projecteur. Il est conservé dans le stockage sécurisé de l'appareil, sur cet appareil uniquement, et n'est pas inclus dans les sauvegardes.
  • Connexion adaptée à la génération : les modèles 2024 sont essayés d'abord avec SHA-256, puis sans.
  • Un projecteur déplacé est retrouvé grâce à son adresse MAC après trois tentatives échouées.
Pas de projecteur sous la main

Le projecteur de démo

  • Le projecteur de démo est simulé sur l'appareil lui-même, ce qui vous permet d'essayer tous les écrans sans matériel.
  • Tout est déverrouillé sur le projecteur de démo. Les déclencheurs d'automatisation ne se déclenchent jamais depuis celui-ci.
