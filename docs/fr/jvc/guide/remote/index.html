Télécommande

La télécommande, sur votre téléphone

L'onglet Télécommande pilote les menus propres au projecteur et propose chaque touche de télécommande que documente votre modèle. Il comporte quatre pages entre lesquelles vous glissez : Télécommande, Fonctionnement, Appareil et Réseau.

Page Télécommande

Naviguer dans les menus du projecteur

  • Navigation. Un pavé directionnel rond avec Haut, Bas, Gauche, Droite et OK, plus Menu et Retour, comme sur la télécommande JVC.
  • Entrée. Sur les modèles dont la table de touches la comporte, une touche Entrée fait défiler les entrées. C'est une touche Pro.
  • Source d'entrée. Un bouton par entrée que propose votre modèle, comme HDMI 1 et HDMI 2. HDMI 1 est gratuit ; les autres nécessitent Pro.
  • Plus de commandes. Mode d'image, masquage et toutes les autres touches de télécommande, sur une page à part.
  • Actualiser. Le bouton d'actualisation de la barre du haut relit l'état du projecteur.
Version gratuite

Appuis de navigation gratuits

Sans Pro, les touches du pavé directionnel (Haut, Bas, Gauche, Droite, OK, Retour et Menu) sont comptées. Vous disposez de 20 appuis pour toute la durée de vie de l'installation, puis de 3 par jour. Pro supprime le décompte.

  • Le compteur sous le pavé directionnel indique « 18 appuis de navigation gratuits restants », puis « 3 appuis de navigation gratuits restants aujourd'hui » une fois les 20 premiers épuisés.
  • Quand une journée commence. Le quota quotidien se réinitialise à minuit, heure locale, et non 24 heures après votre dernier appui. Le jour où les 20 premiers s'épuisent, les 3 de ce jour sont encore disponibles.
  • Ce qui compte. Un appui est compté quand l'app l'envoie, même si le projecteur n'en accuse ensuite pas réception. Rien n'est compté tant que l'app n'est pas connectée, sur le projecteur de démo, ou avec Pro.
  • Quand ils sont épuisés. Le pavé directionnel reste à l'écran, n'envoie rien, et affiche « Les appuis de navigation gratuits du jour sont épuisés. D'autres arrivent demain, ou débloquez Pro pour des appuis illimités. »
Le décompte est-il réinitialisé si je réinstalle l'app ?

Sur iOS et macOS, non : une seconde copie est conservée dans le Trousseau et le décompte le plus élevé l'emporte. Sur Android, le décompte repart de zéro après une réinstallation, sauf si la sauvegarde propre à Android restaure les données de l'app. Sous Windows, il repart de zéro après une réinstallation.

Plus de commandes

Toutes les autres touches de télécommande

Plus de commandes est une page Pro. Elle commence par une carte de mode d'image quand votre modèle peut le régler, puis Masquage, puis les touches de télécommande regroupées selon leur fonction. Seules les touches que documente la table de votre modèle apparaissent.

Selon le modèle

Les touches dont dispose votre modèle

Chaque génération JVC a sa propre table de touches, et l'app la choisit d'après le code de modèle indiqué par le projecteur. Une touche que votre modèle n'a pas n'est pas proposée. Si une touche atteint un jour un modèle qui ne l'a pas, l'app n'envoie rien et nomme la commande et le modèle, en terminant par « Rien n'a été envoyé. » Un modèle que l'app ne liste pas dispose tout de même de l'alimentation, de l'entrée et des touches de télécommande.

Page Fonctionnement

Comment le projecteur fonctionne

La page Fonctionnement contient Minuterie d'arrêt, Mode éco, Déclencheur, Masquage éco et Control4, sur les modèles qui les prennent en charge. Tout est Pro.

Mode éco et réseau. Avec le Mode éco activé, le projecteur peut cesser de répondre sur le réseau en veille, ce qui peut empêcher l'app de le rallumer. L'app vous prévient avant que vous ne l'activiez. Les documents de commandes JVC ne tranchent pas, l'avertissement dit donc « peut ».
Page Appareil

Ce que le projecteur indique sur lui-même

La page Appareil (Pro) comporte deux sections. Projecteur affiche le code du modèle et les autres mesures que votre modèle indique sur lui-même. Signal affiche ce que le projecteur indique sur le signal entrant, et est omise quand il n'y a pas de signal. Appuyer sur un projecteur dans Réglages ouvre les mêmes détails sous le nom Infos de l'appareil.

Page Réseau

Une vue en lecture seule de son réseau

La page Réseau (Pro) affiche les réglages LAN filaire du projecteur : DHCP, Adresse IP, Sous-réseau, Passerelle, Port et Adresse MAC, dans la mesure où votre modèle les indique. Ils sont en lecture seule volontairement : l'app joint le projecteur via ce même réseau, et changer l'adresse d'ici couperait sa propre connexion. Modifiez-les dans le menu à l'écran du projecteur, puis reconnectez-vous ; Premiers pas traite des projecteurs qui ont changé d'adresse.

Questions

Questions sur la télécommande

Quelles touches comptent dans les appuis gratuits ?

Haut, Bas, Gauche, Droite, OK, Retour et Menu, et seulement quand l'appui est envoyé à un projecteur connecté. L'alimentation et HDMI 1 sont toujours gratuits.

Pourquoi une touche est-elle absente ?

L'app affiche les touches que liste la table de commandes de votre modèle. Une touche que votre modèle ne documente pas n'est pas affichée.

La télécommande fonctionne-t-elle sur le projecteur de démo ?

Oui, et les appuis sur la démo ne sont jamais comptés.
