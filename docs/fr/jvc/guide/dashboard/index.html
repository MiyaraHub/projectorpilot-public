Tableau de bord

Votre projecteur en un coup d'oeil

Le tableau de bord affiche le projecteur sélectionné : s'il est connecté, s'il est allumé, ce qu'il affiche, ainsi que les cartes que vous choisissez. Tout ce qui s'y trouve est lu depuis le projecteur, rien n'est deviné.

Carte d'état

Connexion et alimentation

  • Nom et modèle. Le nom du projecteur, son adresse et le modèle qu'il a indiqué. Le projecteur de démo porte un badge DÉMO.
  • Pastille d'alimentation. Affichée dès que le projecteur a signalé qu'il est allumé ou en veille. L'alimentation est gratuite sur tous les projecteurs.
  • Libellé d'état quand l'alimentation n'est pas encore connue : Connexion, Déconnecté, Injoignable, Problème de mot de passe, Recherche sur le réseau, ou un état d'alimentation comme Alimentation : veille ou Alimentation : préchauffage.
  • Le préchauffage et le refroidissement affichent une barre de progression, « Préchauffage... » ou « Refroidissement... ». Pendant ces phases, l'app interroge le projecteur toutes les 2 secondes, et toutes les 15 secondes sinon.
Alimentation

L'extinction demande d'abord confirmation

Éteindre le projecteur affiche « Éteindre le projecteur ? » avec un rappel : l'image s'éteint pour tous ceux qui regardent. L'allumage ne demande rien. Un projecteur laser ou à lampe lance alors son propre refroidissement avant d'atteindre la veille, et la carte le suit.

Votre disposition

Personnaliser le tableau de bord

  1. Appuyez sur Personnaliser dans la barre du haut.
  2. Faites glisser une carte pour la déplacer, ou appuyez sur le moins d'une carte pour la retirer.
  3. Appuyez sur Ajouter pour récupérer une carte depuis « Ajouter une carte », ou sur RÉINITIALISER pour la disposition par défaut.
  4. Touchez Terminé.
La disposition est un réglage unique pour toute l'app : chaque projecteur affiche donc les mêmes cartes dans le même ordre, moins celles que son modèle ne propose pas.
Plusieurs projecteurs

Passer d'un projecteur à l'autre

  • Quand plusieurs projecteurs sont enregistrés, une rangée de pastilles de noms apparaît ; appuyez sur l'une d'elles pour la sélectionner. Le titre dans la barre du haut permet aussi de changer de projecteur.
  • Le bouton Ajouter un projecteur en ajoute un autre à tout moment.
  • Le menu du projecteur contient Renommer, Modifier la connexion, Changer le mot de passe et Supprimer. Supprimer retire le projecteur et son mot de passe enregistré de cet appareil. Sur le projecteur de démo, le seul élément est Fermer la démo.
  • Tirez vers le bas pour actualiser : l'app relit les cartes, ou se reconnecte si elle n'est pas connectée.
Messages

Quand il n'y a aucune carte

Un tableau de bord vide en donne la raison, il n'est donc jamais simplement blanc.

  • Non connecté : « Non connecté à ce projecteur, aucune de ses commandes ne peut donc être affichée. »
  • Veille : « Le projecteur est en veille. Ses commandes apparaissent une fois qu'il est allumé. »
  • Préchauffage ou refroidissement : les commandes reviennent quand le projecteur se stabilise.
  • Toutes les cartes retirées : Personnaliser les ramène.
  • Mauvais mot de passe : « Le projecteur a refusé le mot de passe réseau. Appuyez pour le saisir à nouveau. »
  • Hors ligne : l'échec en termes clairs, par exemple « Rien n'a répondu à cette adresse sur le port 20554. » La page d'aide explique chaque cas.
Écran d'accueil

Widgets

Avec Pro, sur Android et iOS, cinq widgets placent le projecteur sur votre écran d'accueil. Chacun est configuré pour un seul projecteur.

Projector Quick Control

Alimentation, entrée, mode d'image et masquage.

Projector Status

Alimentation, connexion et heures de la source lumineuse.

Projector Scenes

Un appui applique une scène enregistrée.

Projector Info

Alimentation, entrée, mode d'image et source lumineuse.

Projector Input

Un appui change l'entrée.

Un widget ne parle jamais lui-même au projecteur. Un appui ouvre l'app, qui envoie la commande en passant par les mêmes vérifications que le tableau de bord ; si l'app ne parvient pas à se connecter en 30 secondes, l'appui est abandonné. Les widgets ne contiennent ni adresse ni mot de passe.
