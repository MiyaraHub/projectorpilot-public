Le manuel

Guide de l'utilisateur de Projector Pilot D-ILA

Comment ajouter votre projecteur JVC D-ILA et utiliser chaque écran. Chaque écran suit votre modèle : l'app lit le code de modèle indiqué par le projecteur et propose les fonctions que documente la table de commandes JVC de ce modèle, et rien d'autre.

Parcourir le guide

Chaque écran, expliqué

Commencez par Premiers pas. Rien ici ne nécessite de compte : l'app communique avec le projecteur sur votre propre réseau via le port TCP 20554.

Avant de commencer

Ce qu'il vous faut

  • Un projecteur JVC D-ILA avec un port LAN, relié à votre réseau par câble. La page d'aide liste les familles de modèles que l'app connaît.
  • Un téléphone, une tablette ou un ordinateur sur le même réseau local. L'app fonctionne uniquement sur le réseau local ; elle n'a aucun service cloud à traverser.
  • Le mot de passe réseau du projecteur, s'il y en a un de défini sur le projecteur. Les modèles récents utilisent 8 à 10 caractères.
  • Pas encore de projecteur ? Le projecteur de démo, simulé sur votre appareil, ouvre chaque écran. Voir Premiers pas.
Gratuit et payant

Ce qui est gratuit

L'alimentation, HDMI 1 et un quota de navigation sont gratuits sur tous les projecteurs. Pro débloque le reste du projecteur ; Home Automation débloque les liens vers votre maison connectée. Les deux sont des achats uniques.

Gratuit

Allumage et veille, HDMI 1, et 20 appuis de navigation pour toute la durée de vie de l'installation, puis 3 par jour.

Pro

Toutes les entrées et touches de télécommande, l'image, l'objectif, l'installation, les scènes, la maintenance, le motif de test et les widgets d'écran d'accueil.

Domotique

Les déclencheurs webhook, le miroir Hubitat et le lien Home Assistant, y compris son tableau de bord.

Le détail complet se trouve sur la page des tarifs.

Selon le modèle

Pourquoi une commande peut manquer

  • Le modèle ne la documente pas. Un réglage que la table de commandes JVC ne liste pas pour votre modèle n'est pas affiché, plutôt qu'envoyé à l'aveugle.
  • Le projecteur n'y répond pas. Un réglage auquel le projecteur continue de ne pas répondre tant qu'il est allumé est affiché désactivé, avec « Ce projecteur ne répond pas à ce réglage. »
  • Un autre réglage la bloque. Certains réglages ne s'appliquent que dans certaines conditions, comme le Traitement HDR avec un signal HDR. La commande indique quel réglage la bloque.
  • Le projecteur est en veille. La plupart des réglages apparaissent une fois le projecteur allumé.
La prise en charge est découverte à partir du projecteur lui-même ; une formule comme « sur les modèles qui le prennent en charge » dans tout ce guide signifie donc exactement cela : l'app vérifie votre modèle, puis affiche ce qui s'applique.
