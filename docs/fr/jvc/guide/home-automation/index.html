Domotique

Connectez votre projecteur à votre maison

Laissez le reste de la maison réagir quand le projecteur s'allume, passe en veille, change d'entrée ou rappelle une scène. Trois liens se trouvent sous Réglages, Home Automation : déclencheurs webhook, Hubitat et Home Assistant. Tous trois nécessitent le module Home Automation, vendu seul ou dans le pack ; Pro seul ne l'inclut pas.

À choisir

Quel lien utiliser

Webhooks

N'importe quel système qui accepte une requête web : Node-RED, un serveur domestique, une automatisation cloud. L'app envoie, vous décidez de la suite.

Hubitat

Un miroir à sens unique de l'alimentation et de l'entrée vers un appareil de votre hub, via Maker API, sur lequel Rule Machine peut agir.

Home Assistant

Configure l'intégration JVC Projector propre à Home Assistant, des scripts pour vos scènes et un tableau de bord prêt à l'emploi.

Webhooks

Déclencheurs d'automatisation

Un déclencheur envoie une requête web à une adresse que vous saisissez quand quelque chose se produit sur ce projecteur. Chaque projecteur a sa propre liste. Appuyez sur Ajouter un déclencheur, puis choisissez :

  • Quand : Le projecteur s'allume, Le projecteur passe en veille, L'entrée change (vers n'importe quelle entrée ou une entrée précise), ou Une scène est rappelée (n'importe quelle scène ou une scène précise).
  • Méthode : POST (par défaut), PUT ou GET.
  • Adresse web : une adresse http:// ou https:// avec un nom d'hôte.
  • Activé, pour suspendre un déclencheur sans le supprimer.
Une adresse qui commence par http:// est envoyée sans chiffrement, et l'éditeur le signale. Utilisez https:// quand votre système le permet.
Charge utile

Ce que la requête transporte

POST et PUT envoient un corps JSON ; GET n'en envoie pas. Le seul en-tête que l'app ajoute est Content-Type. Un champ qui ne s'applique pas à l'événement est omis.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
ChampSignification
eventpower_on, power_off, input_changed ou scene_recalled.
projectorLe nom du projecteur dans l'app.
inputL'entrée, par exemple hdmi1 ou hdmi2.
scene_id, scene_nameLa scène, pour un rappel de scène.
timestampQuand cela s'est produit, en UTC.
testPrésent, et vrai, uniquement sur une requête envoyée par Envoyer un test.
Livraison

Une seule tentative, rapportée honnêtement

  • Chaque événement est envoyé une fois, avec une limite de 10 secondes, et les redirections ne sont pas suivies.
  • Le déclencheur affiche son dernier résultat : Livré à une heure avec le code d'état, Refusé, Aucune réponse, Adresse injoignable, Échec de la connexion sécurisée, ou Pas encore envoyé.
  • Envoyer un test envoie une requête marquée comme test, pour que vous puissiez câbler l'autre extrémité avant que le projecteur ne fasse quoi que ce soit.
Quand les déclencheurs se déclenchent

Les règles

  • Uniquement quand l'app est ouverte et connectée au projecteur. L'app surveille l'état du projecteur ; ce n'est pas un service d'arrière-plan.
  • Des changements, pas des lectures. La première lecture après la connexion de l'app ne fait que fixer le point de départ : ouvrir l'app ne déclenche donc pas « s'allume » pour un projecteur déjà allumé.
  • Jamais depuis le projecteur de démo. Rien ne quitte l'appareil tant que le projecteur de démo est sélectionné ou que Home Automation n'est pas déverrouillé.
  • Enregistré de façon sécurisée. Les adresses des déclencheurs sont conservées dans le stockage sécurisé de l'appareil.
Hubitat

Dupliquer le projecteur dans Hubitat

L'app duplique ce projecteur sur un appareil de votre hub Hubitat via Maker API : allumé et veille, et l'entrée sous la forme HDMI 1 ou HDMI 2, pour celles que l'appareil accepte. Rule Machine peut ensuite agir dessus.

  1. Dans Hubitat, ajoutez Maker API et notez son identifiant d'app (le nombre dans ses URL) et son jeton d'accès.
  2. Dans l'app, saisissez l'Adresse du hub, l'identifiant d'app Maker API et le Jeton d'accès.
  3. Appuyez sur Trouver l'appareil et choisissez l'appareil qui représente ce projecteur. Si aucun ne convient, ajoutez dans Hubitat un Virtual Switch portant le nom du projecteur et réessayez.
  4. Activez Dupliquer l'état du projecteur. L'appareil suit le projecteur à chaque changement tant que l'app est ouverte et connectée.
À sens unique. Rien n'est envoyé de Hubitat vers le projecteur. Dissocier supprime le lien de l'app.
Home Assistant

Le lien le plus poussé

L'app se connecte à Home Assistant, ajoute votre projecteur à son intégration JVC Projector, publie vos scènes et vos commandes sous forme de scripts et construit un tableau de bord. Elle a ses propres pages : la configuration de Home Assistant et le tableau de bord Home Assistant.
