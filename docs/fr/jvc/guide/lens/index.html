Objectif

Objectif et installation

Cadrez l'image depuis votre siège. L'onglet Objectif comporte deux pages, Objectif et Installation, et n'affiche que les mouvements et les réglages que documente votre modèle. La commande de l'objectif fait partie de Pro.

Page Objectif

Décalage, mise au point et zoom

  • Décalage de l'objectif. Un pavé avec décalage vers le haut, le bas, la gauche et la droite. Choisissez de combien chaque appui déplace : 1, 5, 10 ou 25 pas.
  • Mise au point. Mise au point proche et Mise au point lointaine.
  • Zoom. Zoom grand angle et Zoom téléobjectif.
  • Chaque carte n'apparaît que si la table de commandes de votre modèle liste ce mouvement.
Entraînement de l'objectif

Maintenir pour actionner le moteur

Sur les modèles qui le prennent en charge, la carte Entraînement de l'objectif actionne un moteur d'objectif tant que vous maintenez une direction. Relâcher l'arrête, et un seul moteur fonctionne à la fois. Un bouton Arrêt est également présent.

Si l'arrêt n'a pas pu être envoyé, l'app le dit : l'objectif a peut-être atteint la fin de sa course dans cette direction. Rien n'est caché.
Où est l'objectif ?

Aucun affichage de position

Les projecteurs JVC n'indiquent pas la position de l'objectif : l'app n'en affiche donc aucune et ne la devine pas. Regardez l'écran pendant que vous déplacez l'objectif, et enregistrez la position qui vous plaît dans une mémoire d'objectif.

Mémoire d'objectif

Rappeler et enregistrer des positions

Les mémoires d'objectif stockent la position de l'objectif sur le projecteur lui-même. L'app affiche une pastille Mémoire pour chaque emplacement de votre modèle.

  1. Rappeler : appuyez sur une pastille Mémoire. Le projecteur déplace l'objectif vers cette position.
  2. Enregistrer : appuyez sur Enregistrer la position actuelle et choisissez un emplacement dans Enregistrer dans l'emplacement. Si l'emplacement a déjà un nom, la boîte de dialogue indique lequel elle remplace.
  3. Confirmer : Enregistrer la mémoire d'objectif demande une dernière fois, car l'enregistrement remplace tout ce qui se trouve dans cet emplacement.
Enregistrer la position actuelle n'apparaît que sur les modèles qui prennent en charge l'enregistrement d'une mémoire d'objectif via le réseau. Le rappel et l'enregistrement font partie de Pro.
Page Installation

Comment le projecteur est installé

  • Type d'installation, la façon dont le projecteur est monté.
  • Anamorphique, pour les installations avec un objectif anamorphique.
  • Format de l'écran, Taille de l'écran et Gain de l'écran, qui décrivent votre écran au projecteur.
  • Mode haute altitude.
  • Verrouillage de l'objectif.
  • Correction trapézoïdale (verticale).
  • Réglage de l'écran et Données de réglage de l'écran.
Seuls les réglages que documente votre modèle apparaissent. Le masque et la position de l'image se trouvent sur la page Affichage de Image ; le mode d'installation et les touches de télécommande anamorphiques sont dans Plus de commandes, sur l'onglet Télécommande.
Cadrage en un appui

La mémoire d'objectif dans les scènes et dans Home Assistant

  • Ajoutez la carte Mémoire d'objectif au tableau de bord pour rappeler une position depuis le premier écran.
  • Avec Home Automation, Sync Advanced Controls publie un script pour chaque mémoire d'objectif vers Home Assistant, et le tableau de bord Home Assistant les affiche sous forme de boutons.
Pas à pas

Une routine de cadrage

  1. Affichez le motif de test du projecteur depuis Réglages, Outils, Motif de test, sur les modèles qui en proposent un via le réseau.
  2. Utilisez le pavé de décalage de l'objectif avec un grand pas pour vous approcher, puis passez à 1 pas pour les derniers appuis.
  3. Réglez le Zoom et la Mise au point avec leurs boutons, ou maintenez une direction sur la carte Entraînement de l'objectif sur les modèles qui en ont une.
  4. Enregistrez le résultat dans un emplacement de mémoire d'objectif, pour ne plus jamais avoir à le refaire.
  5. Éteignez le motif de test, et ajoutez la carte Mémoire d'objectif au tableau de bord si vous changez souvent de cadrage.
Questions

Questions sur l'objectif

Pourquoi n'y a-t-il pas de carte Entraînement de l'objectif ?

L'Entraînement de l'objectif n'apparaît que sur les modèles dont la table de commandes le liste. Sans lui, les boutons de décalage, de mise au point et de zoom déplacent quand même l'objectif pas à pas, sur les modèles qui les prennent en charge.

Où sont conservées les mémoires d'objectif ?

Sur le projecteur lui-même. L'app lit quels emplacements votre modèle possède et les rappelle ou les enregistre là-bas : une mémoire enregistrée dans l'app est donc la même que celle que contient le projecteur.

La commande de l'objectif est-elle gratuite ?

Non. Le décalage de l'objectif, la mise au point, le zoom, l'Entraînement de l'objectif et les mémoires d'objectif font partie de Pro. Voir Tarifs.
