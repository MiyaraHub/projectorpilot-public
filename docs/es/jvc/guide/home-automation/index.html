Domótica

Conecta tu proyector con tu hogar

Haz que el resto de la casa reaccione cuando el proyector se enciende, pasa a espera, cambia de entrada o recupera una escena. Hay tres enlaces en Ajustes, Home Automation: disparadores webhook, Hubitat y Home Assistant. Los tres requieren el complemento Home Automation, que se vende por separado o en el paquete; Pro por sí solo no lo incluye.

Elige uno

Qué enlace usar

Webhooks

Cualquier sistema que acepte una petición web: Node-RED, un servidor doméstico, una automatización en la nube. La app envía, tú decides qué pasa.

Hubitat

Un espejo unidireccional del encendido y la entrada en un dispositivo de tu hub, mediante Maker API, para que Rule Machine actúe sobre él.

Home Assistant

Configura la integración JVC Projector del propio Home Assistant, scripts para tus escenas y un panel listo para usar.

Webhooks

Disparadores de automatización

Un disparador envía una petición web a una dirección que introduces cuando ocurre algo en este proyector. Cada proyector tiene su propia lista. Toca Añadir disparador y elige:

  • Cuando: El proyector se enciende, El proyector pasa a espera, Cambia la entrada (a cualquier entrada o a una concreta) o Se recupera una escena (cualquier escena o una concreta).
  • Método: POST (el predeterminado), PUT o GET.
  • Dirección web: una dirección http:// o https:// con un nombre de host.
  • Activado, para pausar un disparador sin borrarlo.
Una dirección que empieza por http:// se envía sin cifrar, y el editor lo avisa. Usa https:// cuando tu sistema lo admita.
Carga útil

Qué lleva la petición

POST y PUT envían un cuerpo JSON; GET no envía ninguno. La única cabecera que añade la app es Content-Type. Un campo que no se aplica al evento se omite.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
CampoSignificado
eventpower_on, power_off, input_changed o scene_recalled.
projectorEl nombre del proyector en la app.
inputLa entrada, como hdmi1 o hdmi2.
scene_id, scene_nameLa escena, en una recuperación de escena.
timestampCuándo ocurrió, en UTC.
testPresente, y verdadero, solo en una petición enviada con Enviar prueba.
Entrega

Un intento, informado con honestidad

  • Cada evento se envía una vez, con un límite de 10 segundos, y no se siguen las redirecciones.
  • El disparador muestra su último resultado: Entregado a una hora con el código de estado, Rechazado, Sin respuesta, No se pudo llegar a la dirección, Falló la conexión segura o Aún no enviado.
  • Enviar prueba envía una petición marcada como prueba, para que puedas preparar el otro extremo antes de que el proyector haga nada.
Cuándo se activan los disparadores

Las reglas

  • Solo mientras la app está abierta y conectada al proyector. La app vigila el estado del proyector; no es un servicio en segundo plano.
  • Cambios, no lecturas. La primera lectura tras conectarse la app solo fija el punto de partida, así que abrir la app no activa "se enciende" para un proyector que ya estaba encendido.
  • Nunca desde el proyector de demostración. No sale nada del dispositivo mientras el proyector de demostración está seleccionado o Home Automation no está desbloqueado.
  • Guardados de forma segura. Las direcciones de los disparadores se guardan en el almacenamiento seguro del dispositivo.
Hubitat

Refleja el proyector en Hubitat

La app refleja este proyector en un dispositivo de tu hub Hubitat mediante Maker API: encendido y espera, y la entrada como HDMI 1 o HDMI 2, según cuáles de ellas acepte el dispositivo. Rule Machine puede entonces actuar sobre ello.

  1. En Hubitat, añade Maker API y anota su id de app (el número de sus URL) y su token de acceso.
  2. En la app, introduce la Dirección del hub, el id de app de Maker API y el Token de acceso.
  3. Toca Buscar dispositivo y elige el dispositivo que representa este proyector. Si ninguno lo parece, añade en Hubitat un Virtual Switch con el nombre del proyector y vuelve a intentarlo.
  4. Activa Refleja el estado del proyector. El dispositivo sigue al proyector siempre que este cambia mientras la app está abierta y conectada.
Solo en un sentido. No se envía nada de Hubitat al proyector. Desvincular elimina el enlace de la app.
Home Assistant

El enlace más profundo

La app inicia sesión en Home Assistant, añade tu proyector a su integración JVC Projector, publica tus escenas y controles como scripts y crea un panel. Tiene sus propias páginas: configuración de Home Assistant y el panel de Home Assistant.
