Projector Pilot D-ILA

Preguntas frecuentes

Preguntas y respuestas

  • ¿Qué app necesito? Projector Pilot sirve para proyectores Epson mediante ESC/VP21 y Web Control, y para cualquier proyector PJLink. Projector Pilot D-ILA sirve para proyectores JVC D-ILA.
  • ¿Las apps necesitan una cuenta o un servicio en la nube? No. Ambas apps se comunican con el proyector en tu propia red local.
  • ¿Son suscripciones? No. Cada app tiene un nivel gratuito, y sus compras de Pro, Home Automation y del paquete son de pago único.
