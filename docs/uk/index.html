FAQ

Питання і відповіді

  • Який застосунок мені потрібен? Projector Pilot призначений для проєкторів Epson через ESC/VP21 і Web Control та для будь-якого проєктора з PJLink. Projector Pilot D-ILA призначений для проєкторів JVC D-ILA.
  • Чи потрібен застосункам обліковий запис або хмарний сервіс? Ні. Обидва застосунки спілкуються з проєктором у вашій власній локальній мережі.
  • Це підписки? Ні. Кожен застосунок має безкоштовний рівень, а покупки Pro, Home Automation і комплекту є одноразовими.
