Дашборд проєктора в Home Assistant

Один дотик будує повний дашборд для вашого проєктора JVC у Home Assistant: живлення, стан, параметри зображення, ваші сцени, входи, пам'ять об'єктива, показання сигналу тощо. Він будується з того, що справді є у вашому Home Assistant, і не містить ні адреси, ні пароля. Потрібен додаток «Домашня автоматизація».

Перед надсиланням

Що потрібно

  • Home Assistant прив'язано, а проєктор додано до інтеграції JVC Projector. Дивіться налаштування Home Assistant.
  • Скрипти синхронізовано, якщо вам потрібні кнопки сцен, живлення, входів, пам'яті об'єктива та керування. Дашборд використовує ті скрипти, що існують.
  • Сенсор живого стану увімкнено, для плиток стану та показань.
  • Обліковий запис адміністратора у Home Assistant, бо для створення дашборда він потрібен. Без нього Home Assistant відмовляє, і застосунок повідомляє про це.
Два способи

Надіслати або копіювати

  • Надіслати панель створює дашборд у Home Assistant, на бічній панелі, з назвою вашого проєктора та піктограмою проєктора. Надішліть його знову, щоб оновити. Синхронізація з Home Assistant теж його надсилає.
  • Копіювати дашборд нічого не надсилає. Він копіює дашборд, щоб ви самі вставили його в редактор необробленої конфігурації нового дашборда й змінили на свій розсуд.
Кожен проєктор отримує власний дашборд за адресою, що починається з projector-pilot-jvc-, тому два проєктори ніколи не перезаписують один одного.
Розташування

Що на ньому, згори донизу

Розділ з'являється, лише коли в ньому щось є, тож проєктор без пам'яті об'єктива не матиме розділу пам'яті об'єктива.

Вигляд

Базові картки або стилізований вигляд

Базовий

Побудований лише з власних карток Home Assistant. Працює в будь-якому Home Assistant, нічого встановлювати не треба.

Стилізований

Використовує картки button-card, card-mod і Mushroom з HACS для багатшого вигляду. Застосовується лише тоді, коли наявні всі три.

Якщо відсутня будь-яка з трьох, застосунок надсилає базову версію й повідомляє, які картки встановити з HACS для стилізованого вигляду. Встановіть їх і надішліть знову.

Чесно за задумом

Чому деяких речей на ньому немає

  • Жодних шкал. JVC не задає діапазону для рівнів, які повідомляє Home Assistant, тож дашборд не малює шкалу, яку довелося б вгадувати.
  • Жодної адреси чи пароля. Дашборд містить лише ідентифікатори сутностей, назви та підписи.
  • Жодних вигаданих сутностей. Плитка з'являється лише для сутності або скрипта, що існує у вашому Home Assistant.
Якщо щось пішло не так

Повідомлення

  • Дашборд надіслано. Відкрийте його на бічній панелі Home Assistant.
  • Відхилено. Home Assistant відхилив дашборд: увійдіть з обліковим записом адміністратора, потім надішліть знову.
  • Вхід не прийнято. Увійдіть знову, потім надішліть дашборд.
  • Немає відповіді. Home Assistant не відповів, тому дашборд не підтверджено. Перевірте підключення й надішліть знову.
  • Не дозволено. Нічого не залишає пристрій, поки вибрано демопроєктор або Домашню автоматизацію не розблоковано.
Дашборд керує проєктором через інтеграцію JVC Projector у Home Assistant, яка може дістатися проєктора, лише поки цей застосунок до нього не підключений. Закрийте застосунок, перш ніж користуватися дашбордом.
