Home Assistant · βήμα προς βήμα

Φτιάξτε έναν πίνακα ελέγχου προβολέα για το Home Assistant σε περίπου μία ώρα

Η εφαρμογή φτιάχνει ήδη έναν λειτουργικό πίνακα ελέγχου όταν κάνετε Συγχρονισμό - αυτή η σελίδα είναι η πολυτελής, χειροποίητη εκδοχή. Δέκα βήματα, το YAML κάθε κάρτας και μια πλήρης προβολή που επικολλάτε με μία κίνηση. Πλακίδια πράσινου γυαλιού, ζωντανή ένδειξη εικόνας, οι Σκηνές σας και ένα γράφημα ωρών λέιζερ, όλα από έναν αισθητήρα προβολέα. Αλλάξτε δύο συμβολοσειρές και είναι δικός σας.

Ο Συγχρονισμός φτιάχνει έναν δωρεάν4 κάρτες HACS για την εμφάνισηΠλακίδια πληροφοριών ζωντανά αμέσωςΚουμπιά μετά από μία επικόλληση
Θέλετε απλώς έναν λειτουργικό πίνακα; Τον έχετε ήδη. Πατήστε Συγχρονισμός με HA στην εφαρμογή και φτιάχνει για εσάς έναν έτοιμο πίνακα ελέγχου Projector Pilot, στην πλαϊνή γραμμή του Home Assistant, με κάθε χειριστήριο και τον ζωντανό αισθητήρα - χωρίς κάρτες, χωρίς YAML, χωρίς επικόλληση. Δείτε το Ο Συγχρονισμός φτιάχνει τον πίνακα για εσάς. Αυτή η σελίδα είναι για να φτιάξετε με το χέρι την πιο πλούσια έκδοση «πράσινου γυαλιού» ή για να προσαρμόσετε ό,τι σας έδωσε ο Συγχρονισμός.
Βιάζεστε για την προσαρμοσμένη εμφάνιση; Πηγαίνετε στο βήμα 10, κατεβάστε την πλήρη προβολή, αλλάξτε δύο συμβολοσειρές και τα τρία id Σκηνών, και επικολλήστε την. Τα ενδιάμεσα βήματα εξηγούν τι κάνει κάθε κομμάτι, ώστε να μπορείτε να το αλλάξετε.

Πριν ξεκινήσετε

  • Το Projector Pilot είναι συνδεδεμένο με το Home Assistant. Ο οδηγός ρύθμισης καλύπτει τη σύνδεση και την ενεργοποίηση του Αποστολή της κατάστασης του προβολέα. Θα πρέπει να βλέπετε τον προβολέα σας ως αισθητήρα στο Home Assistant πριν χτίσετε οτιδήποτε πάνω του.
  • Έχετε κάνει συγχρονισμό τουλάχιστον μία φορά. Ρυθμίσεις › Αυτοματισμός Σπιτιού › Home Assistant › Συγχρονισμός με HA, αφού επικολλήσετε το Copy block της εφαρμογής στο configuration.yaml και κάνετε επανεκκίνηση του Home Assistant. Αυτό δημιουργεί τα scripts που καλεί κάθε κουμπί ελέγχου παρακάτω.
  • Ο προβολέας σας είναι ενεργοποιημένος όσο χτίζετε. Τα χαρακτηριστικά εικόνας παρακάτω είναι αυτά που ένας προβολέας σε αναμονή αφήνει ως επί το πλείστον κενά.

Δύο πηγές τροφοδοτούν αυτό το dashboard, και η διαφορά τους μετράει σε κάθε βήμα παρακάτω.

Προέρχεται απόΣας δίνει
Ο αισθητήρας προβολέα, sensor.YOUR_PROJECTORΚάθε ένδειξη. Λειτουργία, είσοδος, λειτουργία χρώματος, όλες οι τιμές εικόνας, HDR και σήμα, φακός και γεωμετρία, ώρες λυχνίας. Ζωντανές μόλις συνδεθείτε και συγχρονίσετε, χωρίς να χρειάζεται Copy block.
Τα συγχρονισμένα scripts της εφαρμογής, script.projpilot_YOURSERIAL_...Κάθε χειριστήριο. Λειτουργία, είσοδοι, λειτουργίες χρώματος, μνήμες φακού και οι Σκηνές σας. Αυτά υπάρχουν μόνο αφού επικολληθεί το Copy block, γίνει επανεκκίνηση του Home Assistant και πατήσετε Συγχρονισμός με HA.
Βήμα 1

Εγκαταστήστε τέσσερις κάρτες από το HACS

Και οι τέσσερις βρίσκονται στο προεπιλεγμένο κατάστημα του HACS. Στο Home Assistant: HACS › Frontend › Explore & Download Repositories, αναζητήστε το όνομα, πατήστε Download και ανανεώστε τον περιηγητή σας.

ΑναζητήστεΧρησιμεύει γιαΑν το παραλείψετε
MushroomΚάθε πλακίδιο πληροφοριών, κουμπί ελέγχου και πλακίδιο ΣκηνήςΧρησιμοποιήστε μια απλή κάρτα button. Λειτουργεί, αλλά φαίνεται πιο γωνιώδης.
button-cardΤο κεντρικό πλακίδιο, με την ζωντανή ετικέτα τουΧρησιμοποιήστε μια κάρτα entity ή μια κάρτα προτύπου Mushroom με λιγότερες λεπτομέρειες.
card-modΤο φόντο πράσινου γυαλιού, τα περιγράμματα και οι διαβαθμίσειςΌλα εξακολουθούν να λειτουργούν. Απλώς δεν αποκτούν τη λάμψη τους.
mini-graph-cardΤο ιστορικό ωρών λέιζερ κάτω από τη ΣυντήρησηΧρησιμοποιήστε την ενσωματωμένη κάρτα history-graph.
Καμία δεν είναι απαραίτητη για να λειτουργήσει. Κάθε χειριστήριο παρακάτω τρέχει από μια τυπική κάρτα κουμπιού του Home Assistant που δείχνει στο ίδιο script. Οι προσαρμοσμένες κάρτες είναι η εμφάνιση πράσινου γυαλιού, όχι η υποδομή.
Βήμα 2

Βρείτε το entity ID και τον σειριακό αριθμό σας

Κάθε απόσπασμα σε αυτή τη σελίδα χρησιμοποιεί δύο σημεία αναπλήρωσης. Βρείτε τα δικά σας μία φορά και όλα τα υπόλοιπα είναι αντιγραφή και επικόλληση.

  • sensor.YOUR_PROJECTOR → Developer Tools › States στο Home Assistant, με φίλτρο projector_pilot. Κάτι σαν sensor.projector_pilot_epson_qb1000b_qb1000w.
  • YOURSERIAL → ανοίξτε την εφαρμογή, Ρυθμίσεις › Αυτοματισμός Σπιτιού › Home Assistant. Το id που προκύπτει από τον σειριακό εμφανίζεται εκεί, και είναι το μεσαίο τμήμα κάθε συγχρονισμένου script: script.projpilot_YOURSERIAL_power_on, script.projpilot_YOURSERIAL_input_hdmi1 και ούτω καθεξής.

Μπορείτε επίσης να φιλτράρετε το Developer Tools › States με projpilot για να δείτε ολόκληρη τη συγχρονισμένη λίστα χειριστηρίων με μια ματιά, αφού ολοκληρωθούν το Copy block και ο Συγχρονισμός του βήματος 1.

Δεν υπάρχει ακόμη λίστα scripts; Αναμενόμενο πριν επικολλήσετε το Copy block. Ο αισθητήρας υπάρχει και ενημερώνεται· τα scripts εμφανίζονται μόνο αφού εκτελεστεί με επιτυχία ο Συγχρονισμός με HA.
Βήμα 3

Δημιουργήστε την προβολή

  1. Settings › Dashboards › Add Dashboard › New dashboard from scratch. Ονομάστε το Projector Pilot.
  2. Ανοίξτε το και μετά το εικονίδιο μολυβιού πάνω δεξιά για επεξεργασία.
  3. Προσθέστε μια προβολή. Και οι δύο διατάξεις δουλεύουν· ο πραγματικός πίνακας χρησιμοποιεί την προεπιλεγμένη στοίβα καρτών, η μία κάτω από την άλλη, που είναι η πιο απλή για επικόλληση.
  4. Για να επικολλήσετε YAML, χρησιμοποιήστε το μενού με τις τρεις τελείες σε μια κάρτα και επιλέξτε Edit in YAML, ή το μενού με τις τρεις τελείες του πίνακα ελέγχου για Raw configuration editor ώστε να επικολλήσετε μια ολόκληρη προβολή με τη μία.

Οι δικές ρυθμίσεις της προβολής, αν προτιμάτε να τις πληκτρολογήσετε:

title: Projector Pilot
views:
- title: Projector Pilot
  path: projector-pilot
  icon: mdi:projector
  cards: []
Βήμα 4

Προσθέστε ένα ζωντανό πλακίδιο πληροφοριών

Ξεκινήστε με κάτι που μόνο διαβάζει, ώστε να ξέρετε ότι το entity ID σας είναι σωστό πριν αγγίξετε οτιδήποτε στέλνει εντολή. Αυτό είναι ζωντανό μόλις υπάρξει ο αισθητήρας προβολέα, χωρίς Copy block, χωρίς συγχρονισμό. Προσθέστε μια κάρτα, Edit in YAML, επικολλήστε:

type: custom:mushroom-template-card
primary: Brightness
secondary: '{{ state_attr(''sensor.YOUR_PROJECTOR'',''brightness'') }}'
icon: mdi:brightness-6
icon_color: green
layout: vertical
fill_container: true
card_mod:
  style: 'ha-card { background: rgba(18,26,20,0.60); border: 1px solid rgba(61,220,107,0.20);
    border-radius: 16px; box-shadow: 0 6px 22px rgba(0,0,0,0.32); backdrop-filter: blur(8px);
    min-height: 104px; }'

Το ίδιο σχήμα διαβάζει οποιοδήποτε από τα ~80 χαρακτηριστικά που φέρει ο αισθητήρας: αντικαταστήστε το brightness με contrast, gamma, color_temp, hdr_pq, lamp_hours, ό,τι θέλετε στο πλακίδιο.

Αποθηκεύστε το. Αν εμφανιστεί ένας πραγματικός αριθμός ή λέξη, το entity ID σας είναι σωστό και όλα τα παρακάτω θα δουλέψουν. Αν εμφανιστεί κενό, επιστρέψτε στο βήμα 2.

Βήμα 5

Προσθέστε μια πράσινη κεφαλίδα ενότητας

Ένας απλός τίτλος είναι νεκρός χώρος. Αυτή είναι μια κάρτα markdown με φόντο διαβάθμισης από το card-mod, και είναι αυτό που μετατρέπει μια στοίβα πλακιδίων σε ονομασμένες ενότητες. Κάθε ενότητα του πίνακα ανοίγει με μία τέτοια, απλώς με διαφορετική ετικέτα και emoji.

type: markdown
content: '&#128268;  &nbsp; **POWER &amp; SOURCE**'
card_mod:
  style: 'ha-card { background: linear-gradient(135deg, rgba(61,220,107,0.30), rgba(16,120,60,0.30));
    border: 1px solid rgba(61,220,107,0.45); border-radius: 14px; box-shadow: 0 6px 20px rgba(0,0,0,0.3); }
    ha-markdown { padding: 12px 20px !important; } ha-markdown p { margin: 0 !important;
    letter-spacing: 3px; color: #eafff0; font-size: 14px; font-weight: 700; }'

Αλλάξτε τον κωδικό του emoji και το κείμενο της ετικέτας· το μπλοκ card-mod είναι ίδιο σε κάθε ενότητα.

Βήμα 6

Προσθέστε ένα κουμπί ελέγχου

Αυτό στέλνει εντολή αντί να διαβάζει απλώς μια τιμή, γι' αυτό χρειάζεται να υπάρχουν πρώτα τα scripts. Καλεί το script.projpilot_YOURSERIAL_power_on, που η εφαρμογή γράφει μόνο αφού επικολλήσετε το Copy block στο configuration.yaml, κάνετε επανεκκίνηση του Home Assistant και πατήσετε Συγχρονισμός με HA.

type: custom:mushroom-template-card
primary: Power On
icon: mdi:power
icon_color: green
layout: vertical
fill_container: true
tap_action:
  action: call-service
  service: script.projpilot_YOURSERIAL_power_on
card_mod:
  style: 'ha-card { background: linear-gradient(135deg, rgba(61,220,107,0.16), rgba(16,90,46,0.20));
    border: 1px solid rgba(61,220,107,0.34); border-radius: 16px; box-shadow: 0 6px 22px rgba(0,0,0,0.32);
    min-height: 92px; }'

Η ίδια κάρτα για Απενεργοποίηση, Τύφλωση Οθόνης, HDMI 1, HDMI 2, A/V Mute, μια λειτουργία χρώματος ή μια μνήμη φακού: αλλάζουν μόνο η ετικέτα, το εικονίδιο και το service.

Αν φαίνεται σωστό αλλά δεν γίνεται τίποτα όταν το πατάτε, είτε το Copy block δεν έχει επικολληθεί είτε το Home Assistant δεν έχει επανεκκινηθεί από τότε. Εκτελέστε Δοκιμή Σύνδεσης στην εφαρμογή, που ελέγχει ακριβώς αυτό, πριν υποθέσετε ότι φταίει ο πίνακας ελέγχου.
Βήμα 7

Προσθέστε το κεντρικό πλακίδιο

Το κεντρικό πλακίδιο στην κορυφή του πίνακα είναι ένα button-card: μια μεγάλη κατάσταση λειτουργίας, μια σύνοψη μιας γραμμής που χτίζεται από πολλά χαρακτηριστικά ταυτόχρονα, και η εμφάνιση πράσινου γυαλιού σε ολόκληρη την κάρτα και όχι μόνο στο περίγραμμά της.

type: custom:button-card
entity: sensor.YOUR_PROJECTOR
name: Epson QB1000
show_state: true
show_label: true
size: 48px
state_display: '[[[ return entity.state==''on'' ? ''Powered on'' : ''Standby''; ]]]'
label: '[[[ var a=entity.attributes; return (a.input||''-'')+''  •  ''+(a.color_mode||''-'')+
  ''  •  ''+(a.video_range||''-'')+''  •  ''+(a.lamp_hours||0)+''  h''; ]]]'
styles:
  card:
  - height: 176px
  - background: linear-gradient(135deg, rgba(61,220,107,0.32), rgba(11,64,34,0.6))
  - border: 1px solid rgba(61,220,107,0.5)
  - border-radius: 22px
  - box-shadow: 0 12px 36px rgba(0,0,0,0.42)
  - padding: 20px
  state:
  - color: '[[[ return entity.state==''on'' ? ''#3ddc6b'' : ''#8a9'' ]]]'

Περικομμένο στα κομμάτια που αλλάζουν ανά εγκατάσταση. Η πλήρης κάρτα ορίζει επίσης το εικονίδιο, το όνομα και τις θέσεις πλέγματος της ετικέτας· δείτε το αρχείο λήψης στο βήμα 10 για όλα.

Προτιμάτε μια πιο λεπτή λωρίδα; Ένα mushroom-chips-card κάνει την ίδια δουλειά σε μία σειρά μικρών chips: κατάσταση λειτουργίας, είσοδος, λειτουργία χρώματος, εύρος βίντεο και ώρες λυχνίας, το καθένα ένα πρότυπο που διαβάζει state_attr('sensor.YOUR_PROJECTOR', ...). Χρησιμοποιήστε το ένα ή το άλλο, όχι και τα δύο, στην κορυφή του πίνακα.

Βήμα 8

Προσθέστε τις Σκηνές σας

Κάθε Σκηνή που αποθηκεύετε στην εφαρμογή γίνεται ένα script με όνομα script.projpilot_YOURSERIAL_scene_<id> μόλις συγχρονίσετε, και ένα πλακίδιο για μια Σκηνή είναι η ίδια κάρτα κουμπιού ελέγχου από το βήμα 6 με όνομα και εικονίδιο Σκηνής.

type: custom:mushroom-template-card
primary: Movie Night
icon: mdi:movie-open
icon_color: green
layout: vertical
fill_container: true
tap_action:
  action: call-service
  service: script.projpilot_YOURSERIAL_scene_YOURSCENE1
card_mod:
  style: 'ha-card { background: linear-gradient(135deg, rgba(61,220,107,0.16), rgba(16,90,46,0.20));
    border: 1px solid rgba(61,220,107,0.34); border-radius: 16px; box-shadow: 0 6px 22px rgba(0,0,0,0.32);
    min-height: 92px; }'

Αντικαταστήστε το YOURSCENE1 με το id που εμφανίζεται για αυτή τη Σκηνή στη συγχρονισμένη λίστα χειριστηρίων της εφαρμογής. Ένα πλακίδιο ανά Σκηνή, σε ένα horizontal-stack.

Βήμα 9

Προσθέστε ιστορικό ωρών λέιζερ

Ο αισθητήρας προβολέα καταγράφεται από το Home Assistant όπως κάθε άλλος, οπότε το lamp_hours έχει ιστορικό δωρεάν. Χωρίς επιπλέον αισθητήρες, χωρίς βοηθούς, χωρίς καμία προηγούμενη ρύθμιση, κάτω από την ενότητα Συντήρηση.

type: custom:mini-graph-card
entities:
- entity: sensor.YOUR_PROJECTOR
  attribute: lamp_hours
  name: Laser hours
name: Laser hours
icon: mdi:lightbulb-on-outline
line_color: '#3ddc6b'
line_width: 4
hours_to_show: 336
points_per_hour: 0.5
height: 96
animate: true
card_mod:
  style: 'ha-card { background: rgba(18,26,20,0.60); border: 1px solid rgba(61,220,107,0.20);
    border-radius: 16px; box-shadow: 0 6px 22px rgba(0,0,0,0.32); backdrop-filter: blur(8px); }'

Οι 336 ώρες είναι δύο εβδομάδες. Οι ώρες λέιζερ και λυχνίας ανεβαίνουν σταθερά αντί να πηδούν πέρα δώθε, οπότε ένα παράθυρο δύο εβδομάδων συνήθως αρκεί για να φανεί η τάση χωρίς να φαίνεται το γράφημα επίπεδο.

Βήμα 10

Ή πάρτε το σύνολο

Η πλήρης προβολή, κάθε ενότητα και κάθε κάρτα από το στιγμιότυπο στην κορυφή αυτής της σελίδας, με σημεία αναπλήρωσης αντί για entity ID.

  1. Κατεβάστε το YAML της προβολής.
  2. Ανοίξτε το σε οποιονδήποτε επεξεργαστή κειμένου και αντικαταστήστε, παντού όπου εμφανίζονται: το YOUR_PROJECTOR με το entity id του αισθητήρα προβολέα από το βήμα 2, και το YOURSERIAL με το id σας που προκύπτει από τον σειριακό, επίσης από το βήμα 2.
  3. Στην ενότητα Σκηνές προς το τέλος, αντικαταστήστε τα YOURSCENE1, YOURSCENE2 και YOURSCENE3 με τα δικά σας τρία id Σκηνών, ή προσθέστε και αφαιρέστε πλακίδια ώστε να ταιριάζουν με όσες Σκηνές έχετε πραγματικά.
  4. Στο Home Assistant, ανοίξτε τον πίνακα ελέγχου σας, εικονίδιο μολυβιού, μενού με τις τρεις τελείες, Raw configuration editor, και επικολλήστε το ως προβολή.
Τα ονόματα και ο αριθμός των Σκηνών σας δεν θα ταιριάζουν. Το αρχείο περιλαμβάνει τρεις Σκηνές ως παράδειγμα: Movie Night, Gaming, Sports Day. Μετονομάστε τα πλακίδια, κατευθύνετέ τα στα δικά σας id Σκηνών και προσθέστε ή διαγράψτε πλακίδια μέχρι η ενότητα να ταιριάζει με όσες Σκηνές αποθηκεύσατε πραγματικά.
Τα πλακίδια πληροφοριών δουλεύουν αμέσως μετά την επικόλληση. Χρειάζονται μόνο να υπάρχει ο αισθητήρας. Τα κουμπιά ελέγχου και Σκηνών παραμένουν ανενεργά μέχρι να επικολληθεί το Copy block στο configuration.yaml, να γίνει επανεκκίνηση του Home Assistant και να πατήσετε Συγχρονισμός με HA.

Αντιμετώπιση προβλημάτων

Ένα πλακίδιο δείχνει Unknown

Ελέγξτε το όνομα του χαρακτηριστικού με αυτό που φέρει πραγματικά ο αισθητήρας: Developer Tools › States, η οντότητά σας sensor.YOUR_PROJECTOR, και διαβάστε τη λίστα χαρακτηριστικών της. Ορισμένες ενδείξεις, όπως HDR PQ ή HDR HLG, συμπληρώνονται μόνο όσο ο προβολέας λαμβάνει ενεργά αυτό το είδος σήματος, οπότε το Unknown σε αυτές τις δύο μπορεί να είναι σωστό και όχι βλάβη. Αν ολόκληρος ο αισθητήρας φαίνεται φτωχός, ξυπνήστε τον προβολέα: μια μονάδα σε αναμονή δημοσιεύει πολύ λίγα.

Ένα κουμπί δεν κάνει τίποτα

Δεν έχετε επικολλήσει ακόμη το Copy block ή το Home Assistant δεν έχει επανεκκινηθεί από τότε. Τα κουμπιά ελέγχου και Σκηνών καλούν scripts που γράφει η εφαρμογή, και αυτά τα scripts δεν υπάρχουν μέχρι να επικολληθεί το Copy block στο configuration.yaml από το Ρυθμίσεις › Αυτοματισμός Σπιτιού › Home Assistant της εφαρμογής, να γίνει μία επανεκκίνηση του Home Assistant και να πατηθεί Συγχρονισμός με HA. Εκτελέστε πρώτα Δοκιμή Σύνδεσης στην εφαρμογή - σας λέει αν το μπλοκ υπάρχει πριν ψάξετε για λάθος στον πίνακα ελέγχου.

Τα scripts που περιμένω λείπουν από το Developer Tools › States

Φιλτράρετε με projpilot αντί για ολόκληρο τον σειριακό - είναι πιο εύκολο να δείτε ολόκληρη τη λίστα. Αν λείπει ένα χειριστήριο ή μια Σκηνή που προσθέσατε πρόσφατα, πατήστε ξανά Συγχρονισμός με HA· ενημερώνεται επί τόπου χωρίς να απαιτείται νέα ρύθμιση. Αν παλιά, νεκρά scripts γεμίζουν τη λίστα αφού διαγράψατε μια Σκηνή, χρησιμοποιήστε το Κατάργηση ορφανών scripts στην εφαρμογή.
