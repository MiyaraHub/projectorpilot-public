Οδηγός Χρήσης του Projector Pilot

Ό,τι χρειάζεστε για να προσθέσετε τον προβολέα σας και να χρησιμοποιήσετε κάθε οθόνη - τον πίνακα ελέγχου, το πλήρες τηλεχειριστήριο, το ολοκληρωμένο μενού εικόνας, τον μοτοροκίνητο φακό, τις Σκηνές και τον πραγματικό αυτοματισμό σπιτιού. Κάθε οθόνη προσαρμόζεται στο υλικό σας: η εφαρμογή εμφανίζει μόνο τα χειριστήρια που εκθέτει πραγματικά ο προβολέας σας, και κάθε τιμή διαβάζεται πίσω από τον προβολέα, ποτέ δεν μαντεύεται. Έτσι οι οθόνες σας μπορεί να δείχνουν λιγότερες επιλογές από όσες αναφέρει μια σελίδα εδώ, και αυτό είναι η εφαρμογή που είναι ειλικρινής, όχι χαλασμένη.

Περιήγηση στον οδηγό

Κάθε οθόνη, επεξηγημένη

Ξεκινήστε με τα Πρώτα βήματα και μετά βουτήξτε σε οποιαδήποτε οθόνη. Τίποτα εδώ δεν χρειάζεται λογαριασμό cloud - το Projector Pilot μιλά με τον προβολέα σας στο δικό σας δίκτυο μέσω ESC/VP21, PJLink και Epson Web Control, χρησιμοποιώντας όποιο απαντά.
