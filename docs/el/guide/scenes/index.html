Η καρτέλα Σκηνές · Pro

Σκηνές προβολέα: ολόκληρο το δωμάτιό σας, με ένα άγγιγμα

Μια Σκηνή καταγράφει τον προβολέα σας ακριβώς όπως είναι αυτή τη στιγμή και τα επαναφέρει όλα αργότερα με ένα μόνο άγγιγμα. Βραδιά ταινίας, ο μεγάλος αγώνας, μια φωτεινή απογευματινή προβολή της Κυριακής - καθεμία δική της Σκηνή, καθεμία ένα άγγιγμα μακριά. Επιλέγετε ακριβώς ποια μέρη κρατά μια Σκηνή, και προσφέρονται μόνο τα μέρη που αναφέρει πραγματικά ο προβολέας σας.

Οι Σκηνές αποτελούν μέρος του Projector Pilot Pro.

Πώς να αποθηκεύσετε μία

Ρυθμίστε το δωμάτιο και μετά καταγράψτε το

  1. Ρυθμίστε το. Φέρτε τον προβολέα ακριβώς όπως τον θέλετε - την είσοδο, τη λειτουργία χρώματος, την εικόνα, τη μνήμη φακού, τα πάντα.
  2. Αποθήκευση Τρέχουσας. Στην καρτέλα Σκηνές πατήστε Αποθήκευση Τρέχουσας, δώστε όνομα στη Σκηνή και επιλέξτε ποια μέρη να κρατηθούν. Ο επιλογέας προσφέρει μόνο ό,τι αναφέρει ο προβολέας σας, ώστε να μην αποθηκεύετε ποτέ ρύθμιση που το μοντέλο σας δεν έχει.
  3. Ανάκληση. Πατήστε τη Σκηνή για να την εφαρμόσετε. Το Projector Pilot επιβεβαιώνει κάθε ρύθμιση με τον προβολέα καθώς προχωρά και δεν ισχυρίζεται ποτέ μια αλλαγή που δεν πέτυχε.
Τι καταγράφει μια Σκηνή

Όσα ή όσα λίγα επιλέξετε

Μία Σκηνή μπορεί να αποτυπώσει οποιοδήποτε από τα παρακάτω. Η ανάκληση επαναλαμβάνει μόνο τα μέρη που επιλέξατε, ώστε μια Σκηνή «αργής βραδιάς» να μπορεί να χαμηλώσει τη φωτεινή απόδοση και να αφήσει όλα τα άλλα ως έχουν.

Ενεργοποίηση

Η κατάσταση λειτουργίας του προβολέα, ώστε μια Σκηνή να μπορεί να τον ξυπνήσει ή να τον στείλει σε αναμονή ως μέρος της ρύθμισης.

Είσοδος

Η πηγή στην οποία μεταβαίνει η Σκηνή, ώστε το «Movie Night» να καταλήγει στο σωστό HDMI κάθε φορά.

Εικόνα

Η λειτουργία χρώματος και οι τιμές εικόνας, καθεμία στην κλίμακα του μενού του ίδιου του προβολέα.

Σήμα

Οι ρυθμίσεις της πλευράς του σήματος που εκθέτει ο προβολέας σας για το περιεχόμενο που βλέπετε.

Φως

Η απόδοση της πηγής φωτός, ώστε ένα φωτεινό δωμάτιο και ένα σκοτεινό να έχουν τη δική τους ρύθμιση.

Γεωμετρία

Η κατάσταση ευθυγράμμισης και γεωμετρίας που κάδράρει την εικόνα στην οθόνη σας.

Ήχος

Οι ρυθμίσεις ήχου που αναφέρει ο προβολέας, κρατημένες μαζί με τα υπόλοιπα.

Μόνο ό,τι αναφέρεται

Η λίστα επιλογής χτίζεται από όσα απαντά πραγματικά ο προβολέας σας, οπότε τίποτα από όσα αποθηκεύετε δεν είναι εικασία.

Αυτοματισμός

Κάθε Σκηνή γίνεται script του Home Assistant

Επικολλήστε ένα μπλοκ στη διαμόρφωση του Home Assistant σας μία φορά και το Projector Pilot γράφει ένα script για κάθε Σκηνή που έχετε, συν τη λειτουργία, κάθε είσοδο, κάθε λειτουργία χρώματος και κάθε μνήμη φακού που διαθέτει πραγματικά ο προβολέας σας. Ένας αυτοματισμός ή ένας φωνητικός βοηθός μπορεί τότε να εκτελέσει οποιαδήποτε Σκηνή, και η εφαρμογή αφαιρεί τα scripts που έγραψε όταν απενεργοποιείτε τον συγχρονισμό, χωρίς να αγγίξει τίποτα άλλο.

Οι Σκηνές λειτουργούν επίσης μέσω webhooks - η ανάκληση μιας Σκηνής μπορεί να στείλει δεδομένα σε ένα URL δικό σας - και κατοπτρίζονται στο Hubitat μέσω Maker API. Όλα βρίσκονται στον οδηγό Home Assistant.

Κοινόχρηστα προφίλ σκηνών

Ρυθμίσατε μια Σκηνή για την οποία είστε περήφανοι; Εξαγάγετέ την και δώστε την σε έναν φίλο, ή εισαγάγετε μία που μοιράστηκε κάποιος μαζί σας. Τα προφίλ Σκηνών μετακινούνται ανάμεσα σε εγκαταστάσεις, ώστε μια καλή ρύθμιση να μην χρειάζεται να ξαναχτιστεί από το μηδέν σε κάθε προβολέα.
