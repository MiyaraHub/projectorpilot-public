Πρώτα βήματα

Προσθέστε τον προβολέα σας Epson ή PJLink σε περίπου ένα λεπτό

Το Projector Pilot βρίσκει τον προβολέα σας στο δικό σας δίκτυο - χωρίς λογαριασμό cloud, χωρίς κωδικό σύζευξης. Συνδέστε το κινητό σας στο ίδιο Wi-Fi, προσθέστε τον προβολέα μία φορά, και η εφαρμογή σαρώνει τι μπορεί να κάνει και το θυμάται. Ορίστε όλη η διαδικασία.

Πριν ξεκινήσετε

Τι χρειάζεστε

  • Ίδιο δίκτυο. Το κινητό, το tablet ή ο υπολογιστής σας πρέπει να βρίσκεται στο ίδιο Wi-Fi (ή ενσύρματο LAN) με τον προβολέα. Η εφαρμογή μιλά απευθείας με τον προβολέα σε αυτό το δίκτυο.
  • Προβολέας ενεργοποιημένος ή σε αναμονή. Αφήστε τον προβολέα ενεργοποιημένο ή σε αναμονή με ενεργό τον έλεγχο δικτύου - τα περισσότερα μοντέλα Epson απαντούν σε αναμονή, ώστε να τα ενεργοποιείτε από την εφαρμογή.
  • Η διεύθυνση IP του προβολέα (μόνο αν προσθέτετε χειροκίνητα). Βρίσκεται στο μενού δικτύου του ίδιου του προβολέα - δείτε παρακάτω πού να ψάξετε.
Δεν έχετε προβολέα πρόχειρο; Πατήστε Δοκιμή με Λειτουργία Επίδειξης στην πρώτη οθόνη και ολόκληρη η εφαρμογή τρέχει πάνω σε έναν καταγεγραμμένο πραγματικό Epson QB1000 που απαντά ό,τι απαντά ένας πραγματικός προβολέας - ώστε να δοκιμάσετε κάθε οθόνη πριν αγοράσετε οτιδήποτε.
Βήμα προς βήμα

Προσθήκη προβολέα

Ανοίξτε την Προσθήκη Προβολέα και επιλέξτε πώς θέλετε να τον βρείτε. Και οι δύο διαδρομές καταλήγουν στο ίδιο σημείο.

  1. Επιλέξτε Σάρωση δικτύου ή Προσθήκη με IP. Η σάρωση δικτύου ψάχνει στο Wi-Fi ή στο ενσύρματο LAN για οτιδήποτε απαντά ως προβολέας και συμπληρώνει τη διεύθυνση για εσάς. Η Προσθήκη με IP υπάρχει για όταν προτιμάτε να πληκτρολογήσετε εσείς τη διεύθυνση.
  2. Επιλέξτε τον προβολέα σας ή εισαγάγετε την IP του. Από τη σάρωση, πατήστε τον προβολέα στη λίστα. Χειροκίνητα, πληκτρολογήστε τη διεύθυνση IP από το μενού δικτύου του προβολέα και συνεχίστε.
  3. Αφήστε να εκτελεστεί η σάρωση δυνατοτήτων. Στην πρώτη προσθήκη, η εφαρμογή ελέγχει τον προβολέα και εμφανίζει μια γραμμή προόδου, ώστε να βλέπετε πόσο έχει προχωρήσει. Ρωτά τον προβολέα τι υποστηρίζει πραγματικά - ποια πρωτόκολλα απαντούν, ποια χειριστήρια υπάρχουν, τα εύρη φακού και εικόνας - ώστε η εφαρμογή να σας δείχνει μόνο πραγματικά χειριστήρια.
  4. Πατήστε Δοκιμή Σύνδεσης. Η εφαρμογή επιβεβαιώνει ότι φτάνει στον προβολέα και διαβάζει την ταυτότητά του. Αν ο προβολέας ζητά κωδικό Web Control, εισαγάγετέ τον εδώ· η εφαρμογή διαπιστώνει αν χρειάζεται καθόλου κωδικός και σας ενημερώνει είτε χρειάζεται είτε όχι.
  5. Αποθήκευση. Ο προβολέας προστίθεται και η σάρωση δυνατοτήτων του απομνημονεύεται - ανοίξτε ξανά την εφαρμογή και δεν σαρώνει από την αρχή. Μεταφέρεστε στον πίνακα ελέγχου, με ζωντανή ανάγνωση.
Ένας προβολέας σαρώνεται μία φορά και το αποτέλεσμα αποθηκεύεται. Γι' αυτό η δεύτερη εκκίνηση είναι άμεση - η εφαρμογή ξέρει ήδη τι μπορεί να κάνει το υλικό σας.
Εύρεση της διεύθυνσης

Πού βρίσκεται η IP του προβολέα σας

Αν προσθέτετε με IP, χρειάζεστε τη διεύθυνση του προβολέα στο δίκτυό σας. Κάθε Epson την εμφανίζει στο ίδιο σημείο.

  1. Στον προβολέα, ανοίξτε το Μενού στην οθόνη και πηγαίνετε στο Δίκτυο (ή Επέκταση › Δίκτυο σε ορισμένα μοντέλα).
  2. Ανοίξτε το Ρύθμιση Δικτύου › Ενσύρματο LAN ή Ασύρματο LAN και διαβάστε τη Διεύθυνση IP.
  3. Πληκτρολογήστε αυτή τη διεύθυνση στην Προσθήκη με IP. Αξίζει να ορίσετε μια σταθερή ή δεσμευμένη διεύθυνση στον δρομολογητή σας, ώστε να μην αλλάζει κάτω από την εφαρμογή.
Οι ρυθμίσεις δικτύου βρίσκονται στον προβολέα, όχι στην εφαρμογή. Το Projector Pilot φτάνει στον προβολέα μέσω αυτού του δικτύου, γι' αυτό εμφανίζει τη σελίδα δικτύου ως σαφή προβολή μόνο για ανάγνωση - τις διευθύνσεις τις αλλάζετε στη διεπαφή του ίδιου του προβολέα.
Αν δεν συνδέεται

Γρήγορες διορθώσεις

  • Ελέγξτε ξανά το δίκτυο. Ένα κινητό που έπεσε σε Wi-Fi επισκεπτών ή σε δίκτυο κινητής δεν θα δει τον προβολέα. Ίδιο δίκτυο, και στα δύο άκρα.
  • Ξυπνήστε τον προβολέα. Ένα μοντέλο με απενεργοποιημένη αναμονή δικτύου δεν θα απαντήσει μέχρι να ενεργοποιηθεί. Ενεργοποιήστε τον μία φορά και προσθέστε τον.
  • Ζητείται κωδικός; Εισαγάγετε τον κωδικό Web Control (τον μοναδικό που ζητά η ίδια η ιστοσελίδα του προβολέα). Η εφαρμογή διαχειρίζεται τους ξεχωριστούς κωδικούς του προβολέα - δείτε τον οδηγό Τηλεχειριστηρίου.
  • Προβολέας μόνο με PJLink; Είναι μια συνηθισμένη συσκευή. Η εφαρμογή χρησιμοποιεί όποια μέθοδο επικοινωνίας απαντά, οπότε ένας προβολέας χωρίς Web Control λειτουργεί κανονικά.
