Σκηνές

Ένα πάτημα, ολόκληρη η ρύθμιση

Μια σκηνή αποθηκεύει τις τρέχουσες ρυθμίσεις του προβολέα με ένα όνομα, όπως Βραδιά Ταινίας, και τις επαναφέρει όλες με ένα πάτημα. Οι σκηνές ανήκουν σε κάθε προβολέα και είναι μέρος του Pro.

Δημιουργία

Αποθηκεύστε τις τρέχουσες ρυθμίσεις

  1. Ρυθμίστε τον προβολέα όπως τον θέλετε.
  2. Στην καρτέλα Σκηνές, πατήστε Αποθήκευση Τρέχουσας.
  3. Δώστε του ένα Όνομα σκηνής έως 30 χαρακτήρες.
  4. Στο Τι να αποτυπωθεί, επιλέξτε ποιες ομάδες ρυθμίσεων περιέχει η σκηνή.
  5. Αποθηκεύστε. Κάθε προβολέας κρατά έως 20 σκηνές.
Τι περιέχει μια σκηνή

Οι ομάδες αποτύπωσης

Μια σκηνή αποτυπώνει μόνο τις ρυθμίσεις που προσφέρει το μοντέλο σας.

ΟμάδαΚαλύπτει
ΕνεργοποίησηΑν ο προβολέας πρέπει να είναι ενεργός.
Πηγή εισόδουΗ είσοδος στην οποία θα γίνει εναλλαγή.
Λειτουργία χρώματος και εικόναΛειτουργία εικόνας και ρυθμίσεις εικόνας.
Σήμα και HDRΡυθμίσεις σήματος και HDR.
Φωτεινή απόδοσηΡυθμίσεις φωτεινής απόδοσης.
ΓεωμετρίαΗ ρύθμιση αναμορφωτικού.
Εφαρμογή

Πατήστε για εφαρμογή

Ένα πάτημα εφαρμόζει τη σκηνή αμέσως, χωρίς επιβεβαίωση. Μια σκηνή που ενεργοποιεί τον προβολέα περιμένει να προθερμανθεί πριν στείλει τα υπόλοιπα.

Όταν ολοκληρωθεί, μια αναφορά παραθέτει τι έγινε με κάθε ρύθμιση, ώστε μια σκηνή να μην ισχυρίζεται ποτέ περισσότερα από όσα έκανε:

  • Εφαρμόστηκε: ο προβολέας την δέχτηκε.
  • Απορρίφθηκε: ο προβολέας την αρνήθηκε.
  • Ανεπιβεβαίωτη: ο προβολέας δεν την επιβεβαίωσε, επομένως δεν είναι γνωστό αν ίσχυσε.
  • Κρατιέται από άλλη ρύθμιση: μια άλλη ρύθμιση εμποδίζει την εφαρμογή της αυτή τη στιγμή, όπως η Επεξεργασία HDR χωρίς σήμα HDR.
  • Δεν υποστηρίζεται: αυτό το μοντέλο δεν την προσφέρει.
Διαχείριση

Κρατήστε πατημένο ένα πλακίδιο για επιλογές

  • Εφαρμογή, όπως ένα πάτημα.
  • Ενημέρωση με Τρέχουσες Ρυθμίσεις, για να αποθηκευτεί η τρέχουσα κατάσταση του προβολέα στη σκηνή.
  • Μετονομασία και Αλλαγή Εικονιδίου και Χρώματος.
  • Εξαγωγή και Κοινή χρήση, όπως περιγράφεται παρακάτω.
  • Διαγραφή, που ισχύει αμέσως.
  • Σύρετε τα πλακίδια για να τα βάλετε με τη σειρά που θέλετε.
Κοινή χρήση

Αρχεία σκηνών

Η Εξαγωγή και Κοινή χρήση γράφει μια σκηνή ως αρχείο .ppscene, ένα μικρό αρχείο JSON που μπορείτε να στείλετε σε άλλη συσκευή ή σε άλλο άτομο.

  • Τι περιέχει. Τη σκηνή και τις ρυθμίσεις της, με άθροισμα ελέγχου. Χωρίς διεύθυνση, κωδικό πρόσβασης ή διεύθυνση MAC.
  • Εισαγωγή. Ανοίξτε ένα Αρχείο Σκηνής ή Επικολλήστε Κείμενο Σκηνής.
  • Άλλο μοντέλο. Η εισαγωγή δείχνει τι "Ισχύει εδώ" και τι "Παραλείπεται σε αυτό το μοντέλο", ώστε μια σκηνή από διαφορετικό προβολέα να φέρνει μόνο όσα μπορεί να δεχτεί ο δικός σας.
Πέρα από την εφαρμογή

Σκηνές στο έξυπνο σπίτι σας

  • Η κάρτα Σκηνές του πίνακα ελέγχου και το γραφικό στοιχείο Σκηνές Προβολέα εφαρμόζουν μια σκηνή από την πρώτη οθόνη ή από την αρχική οθόνη.
  • Με τον Αυτοματισμό σπιτιού, η ανάκληση μιας σκηνής ενεργοποιεί τον ενεργοποιητή "Ανακαλείται μια σκηνή", για οποιαδήποτε σκηνή ή για συγκεκριμένη.
  • Κάθε αποθηκευμένη σκηνή μπορεί να γίνει σενάριο στο Home Assistant, και ο πίνακας ελέγχου Home Assistant τις εμφανίζει ως κουμπιά.
Οι σκηνές φυλάσσονται μόνο σε αυτή τη συσκευή. Το Αντίγραφο ασφαλείας και επαναφορά δεν τις περιλαμβάνει. Εξαγάγετε όσες θέλετε να κρατήσετε ως αρχεία.
Ιδέες

Σκηνές που αξίζει να αποθηκεύσετε

  • Βραδιά ταινίας. Λειτουργία, η είσοδος που χρησιμοποιεί η συσκευή αναπαραγωγής σας και η λειτουργία εικόνας για ταινίες.
  • Ταινίες HDR. Εικόνα συν την ομάδα Σήμα και HDR, για τις ρυθμίσεις που χρησιμοποιείτε με δίσκους HDR.
  • Θέαση την ημέρα. Μια πιο φωτεινή απόδοση φωτός για δωμάτιο που δεν είναι εντελώς σκοτεινό.
  • Οθόνη Scope. Η ομάδα Γεωμετρία, για τη ρύθμιση αναμορφωτικού, μαζί με μια μνήμη φακού που ανακαλείται από την καρτέλα Φακός ή τον πίνακα ελέγχου.

Κάθε σκηνή περιέχει μόνο τις ομάδες που επιλέγετε, επομένως μια μικρή σκηνή αλλάζει μόνο όσα κατονομάζει.

Ερωτήσεις

Ερωτήσεις για τις σκηνές

Πόσες σκηνές μπορώ να αποθηκεύσω;

Έως 20 για κάθε προβολέα.

Μετακινεί μια σκηνή τον φακό;

Όχι. Μια σκηνή περιέχει τις ομάδες που αναφέρονται παραπάνω. Ανακαλέστε μια μνήμη φακού από την καρτέλα Φακός, την κάρτα Μνήμη Φακού του πίνακα ελέγχου ή ένα σενάριο του Home Assistant.

Τι γίνεται με μια ρύθμιση που ο προβολέας μου αρνείται;

Η αναφορά μετά την εφαρμογή την παραθέτει ως Απορρίφθηκε και η υπόλοιπη σκηνή εφαρμόζεται κανονικά.

Μπορώ να δώσω μια σκηνή σε φίλο με άλλο μοντέλο;

Ναι. Εξαγάγετέ την ως αρχείο .ppscene. Όταν την εισαγάγει, η εφαρμογή δείχνει τι ισχύει στο μοντέλο του και τι παραλείπεται.
