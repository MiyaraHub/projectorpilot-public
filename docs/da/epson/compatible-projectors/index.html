Kompatibilitet

Fjernbetjening til Epson-kompatible projektorer

Projector Pilot er en uafhængig fjernbetjeningsapp, der virker med Epson-projektorer og med enhver PJLink-projektor over dit eget netværk. Her kan du se, hvilke modeller den er kompatibel med, og hvad hver enkelt tilbyder.

Sådan fungerer det

Kompatibel via protokol, ikke via modelliste

Appen leveres ikke med en liste over modelnumre. Den spørger projektoren, hvad den understøtter, og viser de kontroller, den svarer på, så en projektor, der taler PJLink eller Epson Web Control, virker, selv om den ikke er nævnt nedenfor.

  • PJLink (klasse 1 og 2) giver tænd/sluk, kilde, mute og lampe- eller laserstatus på næsten alle netværksforbundne Epson-projektorer.
  • Epson Web Control tilføjer billedindstillinger, objektiv, keystone og HDR på modeller, der understøtter det.
  • ESC/VP21 er projektorens egen kommandoprotokol, som bruges, når projektoren svarer på den.

Før du tilslutter

Slå netværksstyring til

  • Sæt telefonen og projektoren på samme netværk.
  • Aktivér PJLink og Web Control i projektorens netværksmenu.
  • Søg efter projektoren i appen, eller tilføj den med IP-adresse.
