Aloitus

Lisää Epson- tai PJLink-projektorisi noin minuutissa

Projector Pilot löytää projektorisi omasta verkostasi - ei pilvitiliä, ei parituskoodia. Kytke puhelin samaan Wi-Fi-verkkoon, lisää projektori kerran, niin sovellus selvittää sen ominaisuudet ja muistaa ne. Tässä koko kulku.

Ennen aloittamista

Mitä tarvitset

  • Sama verkko. Puhelimesi, tablettisi tai tietokoneesi on oltava samassa Wi-Fi-verkossa (tai kiinteässä LAN-verkossa) kuin projektori. Sovellus keskustelee projektorin kanssa suoraan tässä verkossa.
  • Projektori päällä tai valmiustilassa. Jätä projektori päälle tai valmiustilaan verkko-ohjaus käytössä - useimmat Epson-mallit vastaavat valmiustilassa, joten voit käynnistää ne sovelluksesta.
  • Projektorin IP-osoite (vain jos lisäät käsin). Se löytyy projektorin omasta verkkovalikosta - katso alta, mistä etsiä.
Eikö projektoria ole käsillä? Napauta ensimmäisessä näytössä Tutustu demotilaan, ja koko sovellus toimii tallennettua oikeaa Epson QB1000 -projektoria vastaan, joka vastaa kuten oikea projektori - voit kokeilla jokaista näyttöä ennen kuin ostat mitään.
Vaihe vaiheelta

Projektorin lisääminen

Avaa Lisää projektori ja valitse, miten haluat löytää sen. Molemmat reitit päätyvät samaan paikkaan.

  1. Valitse Etsi verkosta tai Lisää IP-osoitteella. Verkkohaku etsii Wi-Fi- tai kiinteästä LAN-verkostasi kaiken, mikä vastaa projektorina, ja täyttää osoitteen puolestasi. IP-osoitteella lisääminen on olemassa niitä kertoja varten, kun haluat kirjoittaa osoitteen itse.
  2. Valitse projektorisi tai anna sen IP-osoite. Haun jälkeen napauta projektoria luettelossa. Käsin lisättäessä kirjoita IP-osoite projektorin verkkovalikosta ja jatka.
  3. Anna ominaisuuksien tunnistuksen toimia. Ensimmäisellä lisäyskerralla sovellus tutkii projektorin ja näyttää edistymispalkin, jotta näet, kuinka pitkällä se on. Se kysyy projektorilta, mitä se oikeasti tukee - mitkä protokollat vastaavat, mitä säätimiä on, linssin ja kuvan säätöalueet - jotta sovellus näyttää sinulle vain todellisia säätimiä.
  4. Napauta Test Connection. Sovellus varmistaa tavoittavansa projektorin ja lukee sen tunnistetiedot. Jos projektori vaatii Web Control -salasanan, anna se tässä; sovellus selvittää, tarvitaanko salasanaa lainkaan, ja kertoo sinulle kummassakin tapauksessa.
  5. Tallenna. Projektori on lisätty ja sen ominaisuustunnistus muistetaan - avaa sovellus uudelleen, eikä se tunnista uudelleen. Päädyt kojelaudalle, joka lukee tietoja reaaliajassa.
Projektori tunnistetaan kerran ja tulos tallennetaan välimuistiin. Siksi toinen käynnistyskerta on välitön - sovellus tietää jo, mihin laitteesi pystyy.
Osoitteen löytäminen

Mistä projektorisi IP-osoite löytyy

Jos lisäät IP-osoitteella, tarvitset projektorin osoitteen verkossasi. Jokainen Epson näyttää sen samassa paikassa.

  1. Avaa projektorin näyttövalikko Menu ja siirry kohtaan Network (joissakin malleissa Extended › Network).
  2. Avaa Network Configuration › Wired LAN tai Wireless LAN ja lue IP Address.
  3. Kirjoita osoite kohtaan Lisää IP-osoitteella. Reitittimeen kannattaa asettaa kiinteä tai varattu osoite, jottei se muutu sovelluksen alla.
Verkkoasetukset sijaitsevat projektorissa, eivät sovelluksessa. Projector Pilot tavoittaa projektorin tämän verkon kautta, joten se näyttää verkkosivun selkeänä vain luku -näkymänä - osoitteet vaihdetaan projektorin omassa käyttöliittymässä.
Jos yhteys ei muodostu

Pikakorjaukset

  • Tarkista verkko. Puhelin, joka on siirtynyt vieras-Wi-Fi-verkkoon tai mobiilidataan, ei näe projektoria. Sama verkko, molemmissa päissä.
  • Herätä projektori. Malli, jonka verkkovalmiustila on pois päältä, ei vastaa ennen kuin se on käynnistetty. Käynnistä se kerran ja lisää se.
  • Salasanakysely? Anna Web Control -salasana (ainoa, jota projektorin oma verkkosivu kysyy). Sovellus hoitaa projektorin muut salasanat - katso Kaukosäätimen opas.
  • Vain PJLink-projektori? Se on ihan tavallinen laite. Sovellus käyttää mitä tahansa siirtotapaa, joka vastaa, joten projektori ilman Web Controlia toimii silti.
