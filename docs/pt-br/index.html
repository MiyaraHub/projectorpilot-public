FAQ

Perguntas e respostas

  • De qual app eu preciso? O Projector Pilot é para projetores Epson via ESC/VP21 e Web Control, e para qualquer projetor PJLink. O Projector Pilot D-ILA é para projetores JVC D-ILA.
  • Os apps precisam de uma conta ou de um serviço na nuvem? Não. Os dois apps se comunicam com o projetor na sua própria rede local.
  • São assinaturas? Não. Cada app tem uma versão gratuita, e as compras Pro, Home Automation e do pacote são únicas.
