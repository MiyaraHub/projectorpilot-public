Automação residencial

Conecte seu projetor à sua casa

Deixe o resto da casa reagir quando o projetor liga, entra em espera, troca de entrada ou chama uma cena. Três vínculos ficam em Configurações, Automação Residencial: gatilhos de webhook, Hubitat e Home Assistant. Os três exigem o complemento Automação Residencial, vendido separado ou no pacote; o Pro sozinho não o inclui.

Escolha um

Qual vínculo usar

Webhooks

Qualquer sistema que aceite uma requisição web: Node-RED, um servidor doméstico, uma automação na nuvem. O app envia, você decide o que acontece.

Hubitat

Um espelho unidirecional de energia e entrada em um dispositivo do seu hub, pelo Maker API, para o Rule Machine agir.

Home Assistant

Configura a integração JVC Projector do próprio Home Assistant, scripts para as suas cenas e um painel pronto.

Webhooks

Gatilhos de automação

Um gatilho envia uma requisição web a um endereço que você informa quando algo acontece neste projetor. Cada projetor tem a própria lista. Toque em Adicionar gatilho e escolha:

  • Quando: O projetor liga, O projetor entra em espera, A entrada muda (para qualquer entrada ou uma específica) ou Uma cena é chamada (qualquer cena ou uma específica).
  • Método: POST (o padrão), PUT ou GET.
  • Endereço web: um endereço http:// ou https:// com um nome de host.
  • Ativado, para pausar um gatilho sem apagá-lo.
Um endereço que começa com http:// é enviado sem criptografia, e o editor avisa isso. Use https:// quando o seu sistema permitir.
Carga útil

O que a requisição leva

POST e PUT enviam um corpo JSON; GET não envia nenhum. O único cabeçalho que o app adiciona é Content-Type. Um campo que não se aplica ao evento é omitido.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
CampoSignificado
eventpower_on, power_off, input_changed ou scene_recalled.
projectorO nome do projetor no app.
inputA entrada, como hdmi1 ou hdmi2.
scene_id, scene_nameA cena, no caso de uma chamada de cena.
timestampQuando aconteceu, em UTC.
testPresente, e verdadeiro, somente em uma requisição enviada por Enviar teste.
Entrega

Uma tentativa, relatada com honestidade

  • Cada evento é enviado uma vez, com limite de 10 segundos, e os redirecionamentos não são seguidos.
  • O gatilho mostra o último resultado: Entregue em um horário com o código de status, Recusado, Sem resposta, Não foi possível alcançar o endereço, Falha na conexão segura ou Ainda não enviado.
  • Enviar teste envia uma requisição marcada como teste, para você ligar a outra ponta antes que o projetor faça qualquer coisa.
Quando os gatilhos disparam

As regras

  • Somente enquanto o app está aberto e conectado ao projetor. O app observa o estado do projetor; ele não é um serviço em segundo plano.
  • Mudanças, não leituras. A primeira leitura depois que o app se conecta só define o ponto de partida, então abrir o app não dispara “liga” para um projetor que já estava ligado.
  • Nunca a partir do projetor de demonstração. Nada sai do dispositivo enquanto o projetor de demonstração está selecionado ou a Automação Residencial não está desbloqueada.
  • Salvo com segurança. Os endereços dos gatilhos ficam no armazenamento seguro do dispositivo.
Hubitat

Espelhe o projetor no Hubitat

O app espelha este projetor em um dispositivo do seu hub Hubitat pelo Maker API: ligado e em espera, e a entrada como HDMI 1 ou HDMI 2, para o que o dispositivo aceitar. O Rule Machine pode então agir sobre ele.

  1. No Hubitat, adicione o Maker API e anote o id do app (o número nas URLs dele) e o token de acesso.
  2. No app, informe o Endereço do hub, o id do app do Maker API e o Token de acesso.
  3. Toque em Encontrar dispositivo e escolha o dispositivo que representa este projetor. Se nenhum parecer ser ele, adicione no Hubitat um Virtual Switch com o nome do projetor e tente de novo.
  4. Ative Espelhar o estado do projetor. O dispositivo acompanha o projetor sempre que ele muda enquanto o app está aberto e conectado.
Somente em um sentido. Nada é enviado do Hubitat para o projetor. Desvincular remove o vínculo do app.
Home Assistant

O vínculo mais profundo

O app entra no Home Assistant, adiciona o seu projetor à integração JVC Projector dele, publica as suas cenas e controles como scripts e monta um painel. Ele tem páginas próprias: Configuração do Home Assistant e o painel do Home Assistant.
