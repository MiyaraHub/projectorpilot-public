Painel do Home Assistant

Um painel do projetor no Home Assistant

Um toque monta um painel completo para o seu projetor JVC no Home Assistant: energia, status, opções de imagem, suas cenas, entradas, memórias de lente, leituras de sinal e mais. Ele é montado com o que o seu Home Assistant realmente tem e não guarda endereço nem senha. Exige o complemento Automação Residencial.

Antes de enviar

O que ele precisa

  • Home Assistant vinculado, com o projetor adicionado à integração JVC Projector. Veja a configuração do Home Assistant.
  • Scripts sincronizados, se você quiser botões de cena, energia, entrada, memória de lente e controle. O painel usa os scripts que existirem.
  • O sensor de estado ao vivo ativado, para os blocos de status e leituras.
  • Uma conta de administrador no Home Assistant, porque criar um painel exige uma. Sem ela, o Home Assistant recusa e o app avisa.
Duas formas

Enviar ou copiar

  • Enviar painel cria o painel no Home Assistant, na barra lateral, com o nome do seu projetor como título e o ícone de projetor. Envie de novo para atualizá-lo. Sincronizar com o Home Assistant também o envia.
  • Copiar painel não envia nada. Ele copia o painel para você colar no editor de configuração bruta de um novo painel por conta própria e alterá-lo como quiser.
Cada projetor recebe o próprio painel, em um endereço que começa com projector-pilot-jvc-, para que dois projetores nunca sobrescrevam um ao outro.
Layout

O que há nele, de cima para baixo

Uma seção só aparece quando tem algo dentro, então um projetor sem memórias de lente não ganha seção de memória de lente.

CenasUm botão por script de cena.
EnergiaScripts de energia.

Memórias de lenteUm botão por posição de memória de lente que o seu modelo tem.

Visual

Cartões básicos ou o visual estilizado

Básico

Montado somente com os cartões do próprio Home Assistant. Funciona em qualquer Home Assistant, sem nada para instalar.

Estilizado

Usa button-card, card-mod e cartões Mushroom do HACS para um visual mais rico. Usado somente quando os três estão presentes.

Se algum dos três estiver faltando, o app envia a versão básica e informa quais cartões instalar pelo HACS para obter o visual estilizado. Instale-os e envie de novo.

Honesto por princípio

Por que algumas coisas não estão nele

  • Sem medidores. A JVC não informa uma faixa para os níveis que o Home Assistant relata, então o painel não desenha um medidor que teria de adivinhar.
  • Sem endereço nem senha. O painel guarda somente ids de entidades, nomes e rótulos.
  • Sem entidades inventadas. Um bloco só aparece para uma entidade ou script que exista no seu Home Assistant.
Se algo der errado

Mensagens

  • Painel enviado. Abra-o pela barra lateral do Home Assistant.
  • Recusado. O Home Assistant recusou o painel: entre com uma conta de administrador e envie de novo.
  • Login não aceito. Entre novamente e depois envie o painel.
  • Sem resposta. O Home Assistant não respondeu, então o painel não foi confirmado. Verifique a conexão e envie de novo.
  • Não permitido. Nada sai do dispositivo enquanto o projetor de demonstração está selecionado ou a Automação Residencial não está desbloqueada.
O painel controla o projetor pela integração JVC Projector do Home Assistant, que só consegue alcançar o projetor enquanto este app não está conectado a ele. Feche o app antes de usar o painel.
