Home Assistant

Configure seu projetor JVC no Home Assistant a partir do app.

Configuração

Do login ao painel

  • Faça login no Home Assistant com o login OAuth dele.
  • Integração: o app adiciona a integração nativa jvc_projector do Home Assistant, enviando o host, a porta e a senha.
  • Sensor: um sensor mobile_app informa o estado por meio de um webhook.
  • Sincronizar controles avançados cria scripts com o prefixo ppjvc.
  • Painel: um painel Lovelace no estilo nativo ou no estilo HACS.
  • Uma lista de verificação de configuração mostra o que já foi feito e o que falta.
O Home Assistant exige o complemento Home Automation.
