O controle remoto

Um controle remoto de projetor de verdade, sem as pilhas

A aba Controle remoto traz o controle remoto na tela e os controles operacionais, divididos em sub-páginas entre as quais você desliza: Controle remoto, Operação, Dispositivo e Rede. Tudo que o projetor expõe, nenhum dos botões que ele não tem.

Página Controle remoto

Navegue pelos menus do próprio projetor

  • Direcional de navegação com seleção central, mais Menu, Voltar, Início e Fonte - comande os menus na tela do projetor exatamente como o controle de mão faria.
  • Seleção de entrada, para ir direto a uma fonte.
  • Modo de cor, para trocar o modo de imagem na mesma tela.
  • Tela em branco, para esconder a imagem. A energia fica no painel, não aqui, então há um único controle de energia, não três.
Tela em branco não é mudo A/V. Tela em branco esconde a imagem enquanto o projetor continua funcionando e o sinal continua fluindo, então ela volta na hora. Use para uma pausa, não para um desligamento.
Página Operação - geometria

Corrija o formato da imagem

Escolha o método de correção que combina com a sua instalação. O app mostra os métodos que o seu projetor suporta e só uma correção de geometria fica ativa por vez, como o hardware exige.

MétodoUse para
DesligadoSem correção - um projetor alinhado à tela não precisa de nenhuma.
Trapézio H/VCorreção trapezoidal horizontal e vertical independentes para um projetor deslocado para cima/baixo ou esquerda/direita.
Quick CornerArraste cada um dos quatro cantos para o lugar - o ajuste do dia a dia para uma imagem não totalmente reta.
Correção de PontosUma grade de pontos ajustados individualmente, para distorções locais finas.
Superfície CurvaCompense a projeção em uma tela ou parede curva.
Canto de ParedeCorrija a projeção em um canto de sala onde duas paredes se encontram.
Cada valor de geometria é lido de volta do projetor depois que você o altera, então uma correção que o projetor não aplicou nunca é mostrada como se tivesse sido.
Página Dispositivo - senhas

Três senhas, não uma

Um projetor Epson tem três senhas separadas, e elas protegem coisas diferentes. O Projector Pilot sabe a diferença, então digitar uma que você não precisa nunca bloqueia o seu acesso ao app.

SenhaProtege
Web ControlA interface web do projetor e os comandos que passam por ela - incluindo movimentos de lente e leituras de imagem em muitos modelos. É a que a página web do próprio projetor pede.
PJLinkO protocolo PJLink (TCP 4352) usado por sistemas de controle e, no app, como transporte alternativo.
Controle RemotoO canal de controle remoto ESC/VP.net (TCP 3629), o transporte preferido do app.
O app descobre se uma senha é sequer necessária antes de decidir qualquer coisa. Um projetor que responde sem pedir é informado como "nenhuma senha necessária aqui", não sinalizado falsamente como protegido - e nunca confunde "nenhuma definida" com "definida, mas não exigida para este protocolo". Se uma senha salva do Web Control para de funcionar, os controles de lente e imagem não apagam culpando a lente: mostram um aviso de toque para corrigir a atualização da senha.
Página Dispositivo - bloqueios

Bloqueios que o projetor impõe

A página Dispositivo mostra os bloqueios do próprio projetor. Quando um controle fica indisponível porque o projetor o congelou, o app diz qual bloqueio é o responsável em vez de falhar em silêncio.

  • Bloqueio da lente. Com o bloqueio da lente do projetor ativado, deslocamento, foco e zoom ficam travados. O app só informa uma lente como bloqueada quando o projetor realmente recusa o comando - um movimento aceito cuja posição o projetor não consegue confirmar não é tratado como bloqueio, então os controles continuam disponíveis.
  • Bloqueio Infantil. Desativa o botão de energia do próprio projetor para que uma criança não o ligue e fique olhando para a luz. Alterne por aqui.
  • Bloqueio do Painel de Controle. Trava os botões no corpo do projetor para que só o controle remoto (e o app) possam comandá-lo - útil em uma sala pública ou compartilhada.
Página Rede

Uma visualização clara somente leitura

As configurações de rede ficam no projetor, porque o app alcança o projetor por meio dessa rede. A página Rede é uma visualização simples, somente leitura, do endereçamento do projetor com uma nota explicando o motivo - você altera isso na interface do próprio projetor, explicado em Primeiros passos.
