できること

プロジェクターが提供するすべてのコントロールを、ひとつのすっきりしたアプリに。

Projector Pilotは、ESC/VP21、PJLink、Epson Web Controlのすべてでプロジェクターと同時に通信し、応答した方式を使います。そのため、確実に動作する電源、ピクチャー、ジオメトリー、レンズのコントロールが使え、値はプロジェクターから読み取ったもので、推測ではありません。

ダッシュボード

すべてをひと目で、思いどおりのレイアウトで。

  • ライブステータス - 電源、入力、カラーモード、光源の使用時間、信号、ピクチャーの数値を、変化に合わせて更新します。
  • ワンタップの電源と入力を上部に配置。電源ピルはウォームアップと冷却に対応しています。
  • カスタマイズ可能なカード - カードの追加、非表示、並べ替えで、ダッシュボードに必要な情報を表示できます。
  • 投写情報 - ダイナミックレンジ、色空間、ガンマ、レーザー使用時間、シリアル番号、設置方式を、プロジェクターから読み取ります。
リモコン & ピクチャー

充実のリモコンと、ピクチャーメニュー全項目。

  • フルのナビゲーション十字キー、メニュー、ソース、スクリーンブランク。画面上のリモコンを、正しく作りました。
  • 補正方式 - 水平/垂直キーストーン、クイックコーナー、ポイント補正、曲面、コーナーウォール。
  • ピクチャーのフルコントロール - 明るさ、コントラスト、色合い、シャープネス、色温度、ガンマ、HDR、詳細なピクチャーメニューを、それぞれプロジェクター自身のスケールで。
  • HDRと色空間は別物 - BT.2020のSDR信号はそのとおりに表示され、誤ったHDRバッジが付くことはありません。
レンズ

電動レンズのシフト、フォーカス、ズーム、メモリー。

  • 精密なパッドでシフト、フォーカス、ズームを操作でき、ステップ幅も選べるので、位置合わせには細かく、大きな移動には粗くできます。
  • レンズメモリー - プロジェクターが対応する位置を呼び出し、保存できます。
  • 向きに対応 - アプリは天づりやリア投写を含むプロジェクター自身のマッピングに従うので、上はいつでも上です。
  • 正直な表示 - プロジェクターが確認できない位置を、ロックのように見せかけることはありません。
シーン

部屋まるごと、ワンタップで。

  • シーンを保存 - 電源、入力、ピクチャー、信号、光、ジオメトリー、音声を対象に、保存する項目を細かく選べます。
  • ワンタップで適用 - 「映画鑑賞」を呼び出すと、入力、ピクチャーモード、レンズメモリーがまとめて設定されます。
  • すべてのシーンがHome Assistantのスクリプトになるので、オートメーションや音声アシスタントからも実行できます。
  • 共有可能なプロファイル - 調整したシーンをエクスポートして、友だちに渡せます。
ホームオートメーション

Home Assistant、Hubitat、Webhook。本物の連携です。

  • Home Assistant - サインインし、プロジェクターの状態をセンサーとして公開して、HAと同期をタップすると、すべてのシーンとコントロールのスクリプトが手に入ります。
  • 自動で作られるダッシュボード - 同期がHome Assistant内に標準カードで作成し、HACSのカードがあればよりリッチなものにアップグレードします。コアのPJLink連携にも対応しています。
  • セットアップのチェックリストで、完了した手順、足りない手順、次にすべきことがわかります。プロジェクターがオフの間も、読み取り値はHome Assistantに保持されます。
  • Hubitat - Maker API経由でプロジェクターをデバイスにミラーリングし、Rule Machineから操作できます。
  • Webhook - プロジェクターの電源オン、電源オフ、入力変更、シーンの呼び出しのたびに、任意のURLにPOSTします。

さらに

完成度を高める、細部へのこだわり。

どこからでもプロジェクターを切り替え

すべてのプロジェクターページの上部バーにあるプロジェクタースイッチャーで、一覧に戻らずにプロジェクター間を移動できます。

電源オフは先に確認

プロジェクターの電源を切るときは確認が入るので、うっかりタップして映画が終わってしまうことはありません。

即座に反応するコントロール

レンズシフト、フォーカス、ズーム、光出力のステッパーは押した瞬間に動き、アプリはプロジェクターの電源が入ったことを約10秒以内に検知します。

ファームウェアをひと目で

プロジェクターのファームウェアバージョンは、プロジェクターが報告する場合に、ダッシュボード、情報タブ、診断レポートに表示されます。

PJLinkのみ対応のプロジェクターでも入力切替

TW7300やHome Cinema 4040のようにPJLinkでしか入力を一覧表示しないプロジェクターでも入力を切り替えられ、Epson以外のPJLinkプロジェクターでも同様です。

Wi-Fiでプロジェクターを見つける

プロジェクターを追加は、ネットワークをスキャンしてプロジェクターとして応答する機器を探しアドレスを自動入力し、お使いの機種の機能を検出している間はプログレスバーを表示します。

バックアップと復元

アプリの設定をファイルにエクスポートし、あとでインポートし直せます。ファイルは本来の名前のまま共有され、保存済みのプロジェクターとパスワードは含まれません。

ワンステップで不具合を報告

不具合を報告は、関連するすべてのログを1つにまとめ、すぐに送信できる状態にします。

Projector PilotはEpsonが作っているのですか?

Projector Pilotはどのプロジェクターに対応していますか?

ESC/VP21とWeb Control経由のEpsonプロジェクター、およびすべてのPJLinkプロジェクターです。アプリはプロジェクターが応答する方式を使うので、PJLinkのみ対応のプロジェクターも通常の対応デバイスです。

Projector Pilotはサブスクリプションですか?

いいえ。基本的な操作は無料で、Pro、ホームオートメーション、バンドルは買い切りです。サブスクリプションも広告もありません。

Projector Pilotにアカウントやクラウドは必要ですか?

アカウントもクラウドも不要です。アプリはお使いのネットワーク上で、プロジェクターと直接通信します。
