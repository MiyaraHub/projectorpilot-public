はじめに

EpsonまたはPJLinkプロジェクターを約1分で追加

Projector Pilotは、お使いのネットワーク上でプロジェクターを見つけます。クラウドアカウントもペアリングコードも不要です。スマホを同じWi-Fiに接続し、プロジェクターを一度追加するだけで、アプリがその機能をスキャンして記憶します。手順はこれですべてです。

始める前に

必要なもの

  • 同じネットワーク。スマホ、タブレット、パソコンは、プロジェクターと同じWi-Fi(または有線LAN)に接続している必要があります。アプリはそのネットワーク上でプロジェクターと直接通信します。
  • プロジェクターの電源オンまたはスタンバイ。プロジェクターの電源を入れたままにするか、ネットワーク制御を有効にしたスタンバイ状態にしておきます。ほとんどのEpson機種はスタンバイ中も応答するため、アプリから電源を入れられます。
  • プロジェクターのIPアドレス(手動で追加する場合のみ)。プロジェクター自身のネットワークメニューにあります。確認場所は下記をご覧ください。
手元にプロジェクターがない場合は?最初の画面でデモモードを試すをタップしてください。実機のEpson QB1000から取得したデータが、本物のプロジェクターと同じように応答するので、購入前にすべての画面を試せます。
手順

プロジェクターの追加

プロジェクターを追加を開き、探し方を選びます。どちらの方法でも行き着く先は同じです。

  1. ネットワークをスキャンするか、IPで追加するかを選びます。ネットワークのスキャンでは、Wi-Fiまたは有線LAN上でプロジェクターとして応答する機器を探し、アドレスを自動入力します。IPで追加は、自分でアドレスを入力したいときに使います。
  2. プロジェクターを選ぶか、IPを入力します。スキャンした場合は、一覧からプロジェクターをタップします。手動の場合は、プロジェクターのネットワークメニューにあるIPアドレスを入力して進みます。
  3. 機能スキャンを実行します。最初に追加するときは、アプリがプロジェクターを調べ、プログレスバーで進行状況を表示します。どのプロトコルが応答するか、どのコントロールがあるか、レンズやピクチャーの範囲はどうか、といったプロジェクターが実際に対応する内容を問い合わせるので、アプリには実在するコントロールだけが表示されます。
  4. 接続テストをタップします。アプリがプロジェクターに到達できるか確認し、機器情報を読み取ります。プロジェクターがWeb Controlパスワードを求める場合はここで入力してください。アプリはパスワードが必要かどうかを自動で判断し、どちらの場合も結果をお知らせします。
  5. 保存します。プロジェクターが追加され、機能スキャンの結果が記憶されます。次にアプリを開いたときに再スキャンはされません。ダッシュボードに移動し、ライブで読み取りが始まります。
プロジェクターのスキャンは一度だけで、結果はキャッシュされます。そのため2回目以降の起動は一瞬です。お使いのハードウェアに何ができるか、アプリはすでに把握しています。
アドレスを調べる

プロジェクターのIPアドレスの確認場所

IPで追加する場合は、ネットワーク上のプロジェクターのアドレスが必要です。Epsonの機種ならどれも同じ場所に表示されます。

  1. プロジェクターの画面メニューのメニューを開き、ネットワークに進みます(機種によっては「拡張設定」 › 「ネットワーク」)。
  2. ネットワーク設定 › 有線LANまたは無線LANを開き、IPアドレスを確認します。
  3. そのアドレスをIPで追加に入力します。アプリ側で突然変わってしまわないよう、ルーターで固定アドレスまたは予約アドレスを設定しておくのがおすすめです。
ネットワーク設定はアプリではなくプロジェクター側にあります。Projector Pilotはそのネットワーク経由でプロジェクターに接続するため、ネットワークページは読み取り専用で表示します。アドレスの変更は、プロジェクター自身のインターフェースで行ってください。
接続できないときは

かんたん対処法

  • ネットワークを再確認。ゲストWi-Fiやモバイル回線に切り替わったスマホからは、プロジェクターが見えません。両方を同じネットワークに接続してください。
  • プロジェクターを起動する。ネットワークスタンバイがオフの機種は、電源が入るまで応答しません。一度電源を入れてから追加してください。
  • パスワードを求められたら?Web Controlパスワード(プロジェクター自身のWebページで求められる唯一のパスワード)を入力します。プロジェクターの他のパスワードはアプリが処理します。リモコンガイドをご覧ください。
  • PJLinkのみ対応のプロジェクターですか?それも通常のデバイスです。アプリは応答した通信方式に自動的に切り替えるので、Web Controlのないプロジェクターでも動作します。
