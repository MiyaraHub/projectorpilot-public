Home Assistant · Hubitat · Webhook

プロジェクターを、Home AssistantとHubitatへ。

Projector Pilotは、プロジェクターのライブ状態とすべてのコントロールを、Home Assistant、Hubitat、そして任意のWebhookに公開します。一度設定すれば、スマートホームがプロジェクターを自動で動かします。スマホをネットワークに接続する必要も、クラウドを経由する必要もありません。

設定後はサーバー不要シーンがスクリプトにダッシュボードを自動作成セットアップのチェックリスト有料アドオン
概要

ホームオートメーションでできること

ホームオートメーションは、Projector Pilotを手元のリモコンから、家全体が認識できるデバイスに変えます。電源、入力、カラーモード、ピクチャーの各数値、ランプ使用時間といったプロジェクターの動作状況を公開し、アプリで変更できるあらゆる項目のコントロールをスマートホームに提供します。

  • 状態を公開します。プロジェクターは、アプリに表示されるものと同じ読み取り値を持つHome Assistantのセンサー、Hubitatのデバイス、またはWebhookのJSONペイロードとして現れます。
  • コントロールを公開します。保存したすべてのシーンに加え、電源、各入力、各カラーモード、各レンズメモリーが、オートメーションや音声アシスタントから実行できるようになります。
  • サーバー不要で動作します。スクリプトを設定すれば、Home AssistantがプロジェクターのIPアドレスへ直接コマンドを送ります。スマホをネットワークに接続しておく必要はなく、クラウドアカウントを経由することもありません。
ホームオートメーションは有料のアドオンです。Projector Pilot Proとは別の買い切りで、バンドルなら両方をお得にまとめて購入できます。サブスクリプションも、アカウントも、クラウドも不要です。料金をご覧ください。

3つの接続方法、ひとつのハブ

設定 › ホームオートメーションがハブです。お使いのプラットフォーム(Home Assistant、Hubitat、Webhook)を選び、そこで設定します。複数を同時に設定でき、それぞれ独立して動作します。

Home Assistant

Home Assistantを設定する

アプリからサインインし、プロジェクターをセンサーとして公開し、設定ファイルに1つのブロックを貼り付けて同期します。その後は、Home Assistantがプロジェクターを自力で動かします。

  1. 設定 › ホームオートメーション › Home Assistantを開きます。
  2. Home Assistantのアドレス(たとえばhttp://homeassistant.local:8123やそのIPアドレス)を入力し、サインインをタップします。ご自身のインスタンスに対するブラウザーでのサインインなので、トークンを貼り付ける必要はありません。二要素認証も含め、普段のHome Assistantのログインをそのまま使えます。
  3. アプリはプロジェクターをsensor.projector_pilot_epson_qb1000b_qb1000wのようなエンティティを持つセンサーとして公開し、電源、入力、カラーモード、ピクチャーの各数値、ランプ使用時間を保持します。
  4. プロジェクターの状態を送信をオンにすると、アプリを開いている間、変化に合わせてHome Assistant上の読み取り値が更新されます。詳細コントロールを同期をオンにすると、ピクチャーモード、入力、レンズメモリー、電源のスクリプトが公開されます。
  5. 1つのshell_commandブロック(下記)をconfiguration.yamlに貼り付け、Home Assistantを再起動してから、HAと同期をタップします。

shell_commandブロック

これがサーバー不要の仕組みのすべてです。アプリは、Home Assistantがプロジェクターの Web Controlと通信するために実行するコマンドを1つ書き込み、同期されるすべてのスクリプトは、動詞を変えながらそのコマンドを呼び出します。アプリでブロックをコピーをタップし、configuration.yamlに貼り付けてください。以下の例は説明用です。アプリがお使いのプロジェクターのアドレスとコマンド名を自動で入力します。

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

例のみ。アプリは、プロジェクターの実際のIPとシリアル番号から導いた名前で、お使いのものを生成します。

サーバー不要な理由。そのcurlは、スマホではなくHome Assistantの機器上で動作します。Home AssistantはWeb Control経由でプロジェクターのIPに直接アクセスするため、アプリを開いていなくても、スマホが家になくても、オートメーションは実行されます。EPSONWEBのダイジェストユーザーはWeb Controlのログインです。アプリは、プロジェクターに保存済みのWeb Controlパスワードを使用します。

接続テスト、同期、クリーンアップ

  • 接続テストは、アプリがHome Assistantに到達できるか、貼り付けたshell_commandが実際に存在するかを確認します。その上に何かを構築する前に、入力ミスを見つけられます。
  • HAと同期は、シーンとコントロールのスクリプトを書き込みまたは更新し、Projector Pilotのダッシュボードを直接Home Assistant内に作成します。シーンを追加したりコントロールを変更したりしたら、いつでも再実行してください。重複が増えることなく、その場で更新されます。
  • 孤立したスクリプトを削除は、対応するシーンやコントロールがなくなった(たとえばシーンを削除した後の)アプリ作成のスクリプトを見つけ、削除対象を正確に一覧表示して、先に確認します。承認するまで何も削除されません。対象になるのはProjector Pilotが作成したスクリプトだけで、Home Assistantの他の内容には一切影響しません。Home Assistantがスクリプトの一覧を返さない場合は、何も削除されません。
セットアップのチェックリスト

完了していることと足りないことを、アプリが教えます

Home Assistant画面にはセットアップのチェックリストとHome Assistantの状況パネルがあり、どの手順が残っているか迷うことはありません。各行には、完了、未完了、または判定できなかったことと、次にすべきことが表示されます。

  • Home Assistantに接続しました - サインイン済みで応答しています。Home Assistantが応答しない場合は、アドレスの確認と、スマホが同じネットワークにあることの確認を促す表示になります。
  • プロジェクターがHome Assistantに追加済み - Home Assistantにこのプロジェクターがすでにあるかどうかです。ない場合はPJLink連携の追加を案内し、連携の追加手順ではHome Assistantが求めるPJLinkのホストとポートが表示されます。
  • 読み取りセンサーを登録しました - プロジェクターの読み取り値を保持するセンサーです。アプリが初めてプロジェクターを読み取ったときに登録され、何かが妨げている場合は今すぐ登録またはオンにするが表示されます。
  • Home Assistantの状況 - HACS(コミュニティストア)、Epson Projector Link連携、PJLink連携、そしてconfiguration.yaml内のProjector Pilotコマンドです。それぞれ「見つかりました」「未インストール」「判定できませんでした」のいずれかが表示され、必要に応じて「インストール方法」と「HACSで開く」のボタンが付きます。
もう一度確認で、結果がわかります。何かを修正したらもう一度確認をタップしてください。アプリがHome Assistantを再度読み取って結果を報告するので、うまくいったかどうか迷うことがありません。確認できなかった行には判定できませんでしたと表示され、推測で「はい」「いいえ」を示すことはありません。
すでにある環境と連携

コアのPJLink連携に対応し、カードがあればよりリッチに

Projector Pilotは、Home Assistantに何がインストールされているかを調べ、それに合わせて構築します。Home Assistantに標準搭載されているコアのPJLink連携とも連携するので、すでにそこに追加済みのPJLinkプロジェクターもそのまま使えます。

  • まずは標準カードで。コミュニティカードがない場合、同期はHome Assistant標準のカードでダッシュボードを作成し、完了時にその旨をお知らせします。そのままで動作します。
  • HACSカードがあればアップグレード。アプリはコミュニティカード(Mushroom、button-card、card-mod、apexcharts-card)のインストール状況を確認し、ある場合は各カードをよりリッチなものにアップグレードします。フルのグリーングラスの見た目にしたい場合は、手作りダッシュボードガイドがさらに詳しく解説しています。
  • シーンとコントロールには1回の貼り付けが必要です。Home Assistantにプロジェクターへ送信するコマンドがまだない場合でも、ライブの読み取り値付きでダッシュボードは作成され、セットアップを完了カードが手順を案内します。「ブロックをコピー」をタップし、configuration.yamlに貼り付け、Home Assistantを再起動してから、もう一度同期をタップします。
  • 何もインストールされていない場合は、手動で貼り付けます。Home Assistantに何もインストールされていなくても、アプリからすべてをコピーして自分で貼り付けられます。
  • パスワードは明示されます。貼り付けるコマンドブロックには、プロジェクターのパスワードを含む場合にその旨が表示されるので、共有や保存の前に把握できます。
プロジェクターがオフの間

読み取り値を保持

スタンバイ中のプロジェクターはほとんど情報を返さないため、通常ならダッシュボードは空になります。オプションの最終値センサーは、プロジェクターがオフの間も、入力やランプ・レーザー使用時間といったプロジェクターの最後の読み取り値をHome Assistantに保持します。

  • これは追加のオプションブロックです。configuration.yamlの末尾に貼り付けるか(または既存のtemplate:セクションの下にその行だけを追加して)、Home Assistantを再起動してください。アプリにはあるか確認ボタンがあり、Home Assistantにそれが存在するかどうかを教えてくれます。
  • 電源オフは、offとしてHome Assistantに伝わるようになり、ダッシュボードやオートメーションは、プロジェクターがオフのときにオフとして認識します。
シーンをスクリプトに

すべてのシーンがHome Assistantのスクリプトに

同期後は、シーンはアプリの中に閉じ込められません。それぞれのシーンに加え、電源、各入力、各カラーモード、お使いのプロジェクターが実際に持つ各レンズメモリーが、Home Assistantのスクリプトとして書き込まれます。

  • オートメーションから実行できます。「日没時にTVが点いたら、映画鑑賞を実行」といった内容は、シーンがスクリプトになれば、通常のHome Assistantオートメーションです。
  • 音声アシスタントから実行できます。スクリプトをアシスタントに公開すれば、「映画鑑賞をつけて」と言うだけで、入力、ピクチャーモード、レンズメモリーがまとめて設定されます。
  • 実在するコントロールだけが表示されます。アプリは、プロジェクターが報告する各入力、各カラーモード、各レンズメモリーごとにスクリプトを書き込みます。推測で作った汎用の一覧ではありません。
  • 同期を解除してもアプリが書き込んだものだけが削除されます。同期をオフにするか、孤立したスクリプトを削除(一覧を表示して先に確認します)を使うと、Projector Pilotは自分で作成したスクリプトだけを削除し、他には触れません。
スクリプト名は、名前を変えても同じものが更新されるようになっています。スクリプト名はプロジェクターとコントロールから導かれるので、シーンの名前を変更して再同期しても、2つ目のコピーが生まれることなく既存のスクリプトが更新されます。
ダッシュボード

同期がダッシュボードを作成

Lovelaceのビューを手作りする必要はなく、貼り付ける必要もなくなりました。HAと同期をタップすると、アプリはHome Assistant独自のAPI経由で、完全なProjector PilotダッシュボードをHome Assistant内に直接作成します。プロジェクターのライブ状態と、同期したすべてのシーンおよびコントロールのボタンが揃っています。Home AssistantのサイドバーにProjector Pilotとして表示され、開けば完了です。

  1. アプリでHome Assistantにサインインします。
  2. アプリのブロックをコピーをconfiguration.yamlに一度貼り付け、Home Assistantを再起動します(唯一の手動手順です。Home Assistantは、アプリがそのコマンドをリモートで追加することを許可していません)。
  3. HAと同期をタップします。ダッシュボードが作成され、サイドバーにProjector Pilotとして表示されます。
自分で貼り付けたいですか?Home Assistant画面には引き続きダッシュボードをコピーがあります。タップしたら、Home Assistantで設定 › ダッシュボード › ダッシュボードを追加に進み、空のダッシュボードを作成して、3点メニュー › ダッシュボードを編集 › 3点メニュー › 設定の直接編集を開き、コピーしたYAMLを貼り付けます。

作成されても自分で貼り付けても、ダッシュボードは同じです。状態カードと、各コントロールのボタンで構成されます(説明用のスニペット)。

views:
  - title: Projector
    cards:
      - type: entity
        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_power_on
      - type: button
        name: Movie Night
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_scene_movie_night

例のみ。お使いのダッシュボードには、プロジェクター実際のエンティティとご自身のシーンが入ります。

機種を問いません。ダッシュボードは、お使いのプロジェクター自身の機能、つまり実際に報告されたエンティティ、ピクチャーの各数値、入力、カラーモード、レンズメモリー、シーンから作られます。ここのスクリーンショットはQB1000のものなので、お使いの機種では入力、コントロール、読み取り値が異なる場合があります。図のようなフルのグリーングラスのボードにするには、ステップ式ダッシュボードガイドに従うか、完成ビューをダウンロードして2つの文字列を書き換えてください。
もっとリッチな壁面にしたいですか?同じスクリプトで、お好みのカードを動かせます。AVR Maestroをお使いの方には、同じ発想です。1つのセンサーと同期されたスクリプトから、点灯するソースとモードのタイル、ライブヘッダー、履歴を構築します。
Hubitat

Hubitatを設定する

Hubitatでは、Projector PilotがMaker APIを通じてプロジェクターをハブ上のデバイスにミラーリングするので、Rule Machineで電源、ミュート、入力を読み取って動作させられます。

  1. HubitatでMaker APIアプリを有効にし、アクセスURLとトークンを控えて、公開するデバイスを選びます。
  2. Projector Pilotで設定 › ホームオートメーション › Hubitatを開き、ハブのMaker APIの詳細を入力します。
  3. プロジェクターに相当するデバイスを選びます。アプリが有力な候補を提案します。それを選ぶか、ご自身のデバイスを選択してください。
  4. アプリは、そのデバイスが受け付けるコマンドだけを送り、電源、ミュート、入力をミラーリングします。
  5. ほかのデバイスと同じように、そのデバイスに対してRule Machineのルールを作成します。プロジェクターの状態がルールを動かします。
デバイスが受け付けるものだけ。アプリは、選択したデバイスがそのコマンドに対応している場合にだけプロジェクターの値をHubitatに送るので、デバイスが拒否するものを送りつけることはありません。
Webhook

Webhookを設定する

Webhookは万能の連携方法です。プロジェクターの電源オン、電源オフ、入力の変更、シーンの呼び出しのたびに、アプリが指定のURLにPOSTします。Home AssistantのWebhook、Node-RED、IFTTT、JSONを受け取れるものなら何でも使えます。

  1. 設定 › ホームオートメーション › Webhookを開きます。
  2. POST先のURLを入力します。Home AssistantのWebhookはhttp://homeassistant.local:8123/api/webhook/your-idのような形式です。
  3. Webhookを起動するイベント(電源オン、電源オフ、入力の変更、シーンの呼び出し)を選びます。特定の入力やシーンに絞り込むこともできます。
  4. 受信側のサービスが特定の形式を求める場合は、必要に応じてカスタムペイロードを設定します。設定しない場合は、アプリが既定のJSONを送ります。
  5. 保存します。以降、該当するイベントのたびにアプリがPOSTします。

既定のペイロードは、イベント、プロジェクター、変更された値を含むシンプルなJSONです。

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

ペイロードの例。入力変更や電源のイベントには、それに関係するフィールドが含まれます。

再リンクですべて直ります。Home Assistantを新しいアドレスで再リンクすると、アプリはそれを指しているすべてのWebhookを一括で更新するので、インスタンスを移しても1つずつ手作業で編集する必要はありません。

トラブルシューティング

サインインするとログインページに戻される

入力したアドレスが、実際にHome Assistantへアクセスするアドレスと一致していることを、ポート(通常は:8123)も含めて確認してください。サインインはご自身のインスタンスに対する実際のブラウザーログインなので、ユーザー名、パスワード、二要素認証コードがすべて必要です。スマホでは、アプリ内ブラウザーが結果を返しても、ローカルのコールバックが先に返ってきても、サインインは完了します。それでも止まる場合は、シートを閉じてもう一度サインインをタップしてください。

プロジェクターのセンサーがHome Assistantに表示されない

センサーは、アプリを開いていてプロジェクターの状態を送信がオンの間に公開されます。アプリを開いて、そのトグルを確認してください。そのうえで、Home Assistantの開発者ツール › 状態を開き、projector_pilotで絞り込みます。スタンバイ中のプロジェクターはほとんど情報を公開しないため、起動すると読み取り値が埋まります。

同期したスクリプトが見つからない

スクリプトはHAと同期が書き込むもので、shell_commandのブロックをconfiguration.yamlに貼り付け済みで、Home Assistantを一度再起動している必要があります。まず接続テストを実行してください。ブロックが存在するかどうかがわかります。そのうえで、もう一度同期してください。古い不要なスクリプトで一覧が散らかっている場合は、孤立したスクリプトを削除を使ってください。

スマホが外出中だと、アプリではスクリプトが動くのにHome Assistantからは動かない

それこそがshell_commandブロックの役割で、Home Assistantが自力でプロジェクターのIPに届くようにするものです。アプリを開いているときしか動かない場合は、ブロックが貼り付けられていないか、貼り付け後にHome Assistantが再起動されていない可能性が高いです。接続テストで確認し、Home Assistantを再起動して、同期してください。

かんたん回答

Home Assistantのオートメーションを実行するには、スマホをネットワークに接続したままにする必要がありますか?

いいえ。shell_commandのブロックをHome Assistantに一度貼り付けて同期すれば、Home AssistantがプロジェクターのIPアドレスへ直接コマンドを送ります。Projector Pilotは設定用のツールにすぎません。その後は、スマホが家にあってもなくても、Home Assistantが単独でプロジェクターと通信します。

プロジェクターはHome Assistantにどのように表示されますか?

sensor.projector_pilot_epson_qb1000b_qb1000wのようなセンサーとして表示され、電源、入力、カラーモード、ピクチャーの各数値、ランプ使用時間を保持し、アプリを開いている間は変化に合わせて更新されます。「詳細コントロールを同期」をオンにすると、アプリはさらに、すべてのシーン、電源、各入力、各カラーモード、お使いのプロジェクターが持つ各レンズメモリー用のHome Assistantスクリプトも書き込みます。
