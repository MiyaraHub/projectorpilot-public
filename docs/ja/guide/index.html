Projector Pilot ユーザーガイド

プロジェクターの追加から、ダッシュボード、充実のリモコン、ピクチャーメニュー全項目、電動レンズ、シーン、本格的なホームオートメーションまで、すべての画面の使い方を紹介します。どの画面もお使いのハードウェアに合わせて変化します。アプリはプロジェクターが実際に対応しているコントロールだけを表示し、すべての値はプロジェクターから読み取ったもので、推測ではありません。そのため、ここに載っている項目より表示が少ない画面があっても、それはアプリが正直なだけで、故障ではありません。

すべての画面を解説

まずは「はじめに」から、気になる画面へ進んでください。ここで紹介する内容にクラウドアカウントは不要です。Projector Pilotは、ESC/VP21、PJLink、Epson Web Controlのうち応答した方式で、お使いのネットワーク上のプロジェクターと通信します。

はじめに

Projector Pilotを初めてお使いですか?

主な作業は3つの画面でこなせます。

🚀

プロジェクターを追加

ネットワークをスキャンするかIPで追加し、一度だけの機能スキャン、接続テスト、保存まで。同じWi-Fiなら約1分で完了します。
📊

ダッシュボードを見る

電源、入力、カラーモード、投写情報をリアルタイムに表示。カードの追加、非表示、並べ替えで、好みのビューを作れます。
🎭

シーンを保存

電源、入力、ピクチャー、レンズなどを記憶して、部屋の状態をワンタップで再現。Home Assistantにも渡せます。

アプリを入手して試してみましょう

買い切りで、広告もサブスクリプションもクラウドアカウントも不要。お使いのネットワーク上のEpsonまたはPJLinkプロジェクターに接続します。
