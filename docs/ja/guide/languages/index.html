ひとつのプロジェクターアプリを、29言語で

すべての画面、すべての設定、すべてのダイアログを、あなたの言語で。Projector Pilotは英語に加え28言語に対応し、iPhone、iPad、Macの権限リクエストの表示も含めて、初期状態で端末の言語に合わせて表示します。設定から自分で選ぶこともできます。アラビア語とヘブライ語では、レイアウト全体が右から左に反転します。

設定の場所

設定 › 言語

初期状態では、アプリは端末の言語に合わせます。自分で選ぶには、設定を開いて言語をタップしてください。システムの既定を選ぶと、言語の選択が端末に戻ります。その下にはすべての言語がそれぞれの言語名で並んでいるので、別の言語を読まなくても自分の言語を見つけられます。

  • 自動。何も設定せずに、スマホやタブレットの言語に合わせます。
  • お好みの言語。端末の設定を上書きでき、選択は即座に反映され、再起動後も保持されます。
  • 右から左。アラビア語とヘブライ語では、ナビゲーション、カード、リストを含むレイアウト全体が反転します。ただし、プロジェクターから読み取った値は、プロジェクターの表記のまま表示されます。
プロジェクターの言葉は、プロジェクターのまま。入力名、カラーモード、プロジェクターが報告するすべての値は、どの言語でもプロジェクターの表記そのままで表示されます。翻訳されるのはProjector Pilot自身の文言だけです。

よくある質問

言語に関するよくある質問

アプリは端末の言語に自動で合わせますか?
はい。初期状態では端末の言語に合わせます。自分で選ぶには、設定 › 言語を開いてください。「システムの既定」を選ぶと、言語の選択が端末に戻ります。
アラビア語とヘブライ語は右から左のレイアウトになりますか?
はい。ナビゲーション、カード、リストを含むアプリ全体が反転します。ただし、プロジェクターから読み取った値は、プロジェクターの表記のまま表示されます。
入力名が元の言語のままなのはなぜですか?
それはアプリの言葉ではなく、プロジェクター自身の言葉だからです。入力名、カラーモード、プロジェクターが報告するすべての値は、プロジェクターの表記そのままで表示されます。翻訳されるのはProjector Pilot自身の文言だけです。
