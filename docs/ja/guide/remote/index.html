リモコン

電池のいらない、本格的なプロジェクターリモコン

リモコンタブには、画面上のリモコンと操作用のコントロールがあり、スワイプで切り替える複数のサブページに分かれています。リモコン、操作、デバイス、ネットワークです。プロジェクターが提供するものはすべて使え、ないボタンは表示されません。

リモコンページ

プロジェクター自身のメニューを操作

  • 中央に決定ボタンがあるナビゲーション十字キーに加え、メニュー、戻る、ホーム、ソースで、リモコン本体と同じようにプロジェクターの画面メニューを操作できます。
  • 入力の選択で、目的のソースに直接切り替えられます。
  • カラーモードで、同じ画面からピクチャーモードを切り替えられます。
  • スクリーンブランクで、映像を非表示にします。電源はここではなくダッシュボードにあるので、電源コントロールは3つではなく1つだけです。
スクリーンブランクはA/Vミュートとは別物です。スクリーンブランクは、プロジェクターが動作し続け信号も流れ続けたまま映像だけを非表示にするため、即座に復帰します。シャットダウンではなく、一時停止にお使いください。
操作ページ - ジオメトリー

映像の形を補正する

設置状況に合った補正方式を選びます。アプリにはプロジェクターが対応する方式が表示され、ハードウェアの仕様上、有効にできるジオメトリー補正は常に1つだけです。

方式用途
オフ補正なし。スクリーンに正対しているプロジェクターには不要です。
水平/垂直キーストーンプロジェクターが上下または左右にずれている場合に、水平と垂直のキーストーンを個別に補正します。
クイックコーナー4つの角をそれぞれドラッグして合わせます。少しだけ歪んだ映像の、日常的な補正方法です。
ポイント補正格子状のポイントを1つずつ動かして、局所的な細かい歪みを補正します。
曲面曲面のスクリーンや壁への投写を補正します。
コーナーウォール2つの壁が交わる部屋の隅への投写を補正します。
ジオメトリーの値は、変更後にすべてプロジェクターから読み戻されるので、プロジェクターが適用しなかった補正が、適用されたように表示されることはありません。
デバイスページ - パスワード

パスワードは1つではなく3つ

Epsonプロジェクターには3つの独立したパスワードがあり、それぞれ保護する対象が異なります。Projector Pilotはその違いを理解しているので、不要なパスワードを入力してもアプリから締め出されることはありません。

パスワード保護対象
Web ControlプロジェクターのWebインターフェースと、それを介するコマンドです。多くの機種ではレンズの移動や画像の読み取りも含まれます。プロジェクター自身のWebページが求めるのは、このパスワードです。
PJLink制御システムが使用し、アプリでもフォールバック用の通信方式として使うPJLinkプロトコル(TCP 4352)です。
リモコンESC/VP.netのリモコン制御チャンネル(TCP 3629)で、アプリが優先して使う通信方式です。
アプリは、何かを判断する前に、そもそもパスワードが必要かどうかを確認します。要求せずに応答するプロジェクターは「ここではパスワード不要」と報告し、保護されていると誤って判定されることはありません。また「未設定」と、「設定済みだがこのプロトコルでは不要」を混同することもありません。保存済みのWeb Controlパスワードが使えなくなっても、レンズや画像のコントロールがレンズのせいにして使えなくなることはなく、パスワードの更新を促すタップで直せる案内が表示されます。
デバイスページ - ロック

プロジェクターが適用するロック

デバイスページには、プロジェクター自身のロックが表示されます。プロジェクターが固定したためにコントロールが使えない場合、アプリは黙って失敗せず、どのロックが原因かを伝えます。

  • レンズロック。プロジェクターのレンズロックがオンのとき、シフト、フォーカス、ズームは固定されます。アプリは、プロジェクターが実際にコマンドを拒否した場合にだけレンズをロックと報告します。受け付けられた移動で位置が確認できないだけの場合はロックとして扱わないので、コントロールは使えるままです。
  • チャイルドロック。プロジェクター自身の電源ボタンを無効にして、子どもが電源を入れて光を覗き込まないようにします。ここから切り替えられます。
  • 操作パネルロック。プロジェクター本体のボタンをロックし、リモコン(とアプリ)だけで操作できるようにします。公共の場や共用の部屋で便利です。
ネットワークページ

分かりやすい読み取り専用表示

アプリはそのネットワーク経由でプロジェクターに接続するため、ネットワーク設定はプロジェクター側にあります。ネットワークページはプロジェクターのアドレス情報を読み取り専用で表示し、その理由の注記が付いています。変更はプロジェクター自身のインターフェースで行います。詳しくははじめにをご覧ください。
