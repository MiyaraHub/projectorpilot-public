設定

Projector Pilotの設定: 自分仕様に

設定では、プロジェクターの管理、アプリのアンロック、テーマの変更、取得間隔の調整、そして全体のバックアップができます。デバイスコントロール、購入、外観、リンクがそれぞれ分かりやすい場所に整理されています。広告もサブスクリプションもクラウドアカウントもなく、本当に必要なスイッチだけを用意しています。

プロジェクター

追加、編集、接続

  • プロジェクターの追加は2通り。Wi-Fiまたは有線ネットワークをスキャンして、プロジェクターとして応答する機器を探しアドレスを自動入力するか、IPを手入力します。新しく追加したプロジェクターは、機能のスキャン中にプログレスバーを表示し、結果は記憶されるので、次回アプリを開いても再スキャンされません。
  • 編集、確認、削除。保存済みのプロジェクターごとに、編集の鉛筆アイコン、詳細接続ビュー、情報パネル、削除があります。詳細設定には、プロジェクターごとのポートと3つのパスワードがあります。
  • 3つの独立したパスワード。プロジェクターには最大3つ(Web Control、PJLink、リモート)あります。プロトコルごとに別のパスワードで、プロジェクターごとに保存されます。アプリは保護されていると決めつけず、プロジェクターが実際にどれを求めているかを判断します。
アプリのアンロック

Pro、ホームオートメーション、そしてバンドル

Projector Pilotは、買い切りの2つに分けて販売されています。Proは高機能なアプリ本体、ホームオートメーションは別売りで、バンドルは両方をまとめて購入できます。分割前にProを購入された方は、Proにあったすべての機能をそのままお使いいただけます。

  • Projector Pilot Pro - シーン、複数のプロジェクター、ピクチャーのフルコントロール、レンズとジオメトリー、メンテナンス、ウィジェット、テストパターン、共有可能なプロファイル。
  • ホームオートメーション - Home Assistant、Hubitat、Webhook。
  • バンドル - 両方を1回の購入で。
  • 復元 - このストアアカウントで購入済みの内容を再付与します。ストアが「すでに所有している」と返した場合、アプリはエラーを表示せずに付与するので、購入した機能が使えなくなることはありません。
価格は常にストアの表示価格で、確定前にお使いの通貨で表示されます。アプリが勝手な数字を作ることはありません。ストアのないプラットフォームでは、誰も支払えない課金の壁を出さず、すべての機能を含めて提供します。詳しい内訳は料金をご覧ください。

テーマとカラーテーマ

  • ライト - すっきりした白いテーマ。
  • ダーク - 標準的なダークの配色。

よくある質問

設定のよくある質問

プロジェクターはどうやって追加しますか?
設定のプロジェクターを追加を開きます。アプリにネットワークをスキャンさせてアドレスを自動入力するか、IPを手入力してください。新しいプロジェクターは、機能を一度だけプログレスバー付きでスキャンされ、その結果が記憶されます。
ポートとパスワードはどこにありますか?
保存済みのプロジェクターの詳細接続ビューを開いてください。プロジェクターごとのポートと、3つの独立したパスワード(Web Control、PJLink、リモート)はそこにあります。
すでにProを購入済みですが、ホームオートメーションも買う必要がありますか?
いいえ。アプリが2つに分かれる前にProを購入された方は、Proにあったすべての機能をそのままお使いいただけます。アンロック済みのものが失われることはありません。
パスワードはバックアップに含まれますか?
いいえ。バックアップと復元の対象はアプリの設定です。保存済みのプロジェクターとそのパスワードは暗号化されたセキュアストレージに残り、バックアップファイルには含まれません。
プロジェクターへの問い合わせ頻度は変更できますか?
はい。ステータス取得間隔でライブ状態の更新頻度を設定できます。変更は即座に反映され、スライダーをドラッグしている間に問い合わせが集中することはありません。
