対応状況

Epson対応プロジェクターのリモコン

Projector Pilotは、Epsonプロジェクターと、あらゆるPJLinkプロジェクターを自宅のネットワーク経由で操作できる独立系のリモコンアプリです。対応モデルと、各モデルで使える機能を紹介します。

使い方

モデル一覧ではなく、プロトコルで対応

このアプリには型番のリストは含まれていません。プロジェクターに対応機能を問い合わせ、返ってきた操作だけを表示します。そのため、PJLinkまたはEpson Web Controlに対応したプロジェクターなら、下記に載っていなくても使えます。

  • PJLink(クラス1と2)により、ネットワーク対応のほぼすべてのEpsonプロジェクターで、電源、入力、ミュート、ランプまたはレーザーの状態を操作・確認できます。
  • Epson Web Controlに対応するモデルでは、画質設定、レンズ、台形補正、HDRも操作できます。
  • ESC/VP21はプロジェクター独自のコマンドプロトコルで、プロジェクターが応答する場合に使われます。

接続する前に

ネットワーク制御をオンにする

  • スマートフォンとプロジェクターを同じネットワークに接続します。
  • プロジェクターのネットワークメニューで、PJLinkとWeb Controlを有効にします。
  • アプリでプロジェクターを検索するか、IPアドレスで追加します。

設定手順ははじめにとヘルプ & FAQをご覧ください。JVCプロジェクターをお使いの場合は、Projector Pilot D-ILAをご覧ください。
