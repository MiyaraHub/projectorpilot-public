Home Assistantダッシュボード

Home Assistantのプロジェクターダッシュボード

ワンタップで、Home AssistantにJVCプロジェクターの完全なダッシュボードを作成します。電源、ステータス、映像のオプション、シーン、入力、レンズメモリー、信号の読み取り値などが含まれます。お使いのHome Assistantに実際にあるものから作成され、アドレスもパスワードも含まれません。ホームオートメーションのアドオンが必要です。

送信する前に

必要なもの

  • Home Assistantと連携済みで、プロジェクターがJVC Projector連携に追加されていること。Home Assistantのセットアップをご覧ください。
  • シーン、電源、入力、レンズメモリー、操作のボタンが必要な場合は、スクリプトを同期済みであること。ダッシュボードは、存在するスクリプトを使います。
  • ステータスと読み取り値のタイルのために、リアルタイム状態センサーがオンになっていること。
  • ダッシュボードの作成には管理者権限が必要なため、Home Assistantの管理者アカウントであること。管理者でない場合、Home Assistantが拒否し、アプリがその旨を表示します。
2つの方法

送信またはコピー

  • ダッシュボードを送信すると、Home Assistantのサイドバーに、プロジェクターの名前とプロジェクターのアイコンが付いたダッシュボードが作成されます。もう一度送信すると更新されます。Home Assistantと同期した場合も送信されます。
  • ダッシュボードをコピーでは何も送信されません。ダッシュボードをコピーするので、新しいダッシュボードのRAW設定エディターに自分で貼り付けて、好きなように変更できます。
プロジェクターごとに専用のダッシュボードが作成され、アドレスはprojector-pilot-jvc-で始まるため、2台のプロジェクターが互いに上書きされることはありません。
レイアウト

上から順に何があるか

セクションは中身があるときだけ表示されるため、レンズメモリーのないプロジェクターにはレンズメモリーのセクションがありません。

セクション内容
ヘッダープロジェクターの名前、状態が最後に更新された時刻、電源、ステータス、光源使用時間。
ピクチャー入力と、Home Assistantがそのプロジェクターに提供する映像のオプション。たとえば、ピクチャーモード、光源パワー、ダイナミックコントロール、クリアモーションドライブ、アナモーフィック、HDR処理、設置モードなどで、お使いのモデルが対応し、有効になっているものが対象です。
シーンシーンのスクリプトごとに1つのボタン。
電源電源のスクリプト。
入力入力のスクリプト。
レンズメモリーお使いのモデルにあるレンズメモリーのスロットごとに1つのボタン。
操作ピクチャーモードやハイドなど、その他の操作スクリプト。
信号Home Assistantが報告する解像度、色深度、色空間、カラリメトリー、HDR。
読み取り値リアルタイム状態センサーから取得した、アプリが読み取った設定。
見た目

標準カードまたはスタイル付き

標準

Home Assistant標準のカードだけで作成されます。どのHome Assistantでも動作し、インストールするものはありません。

スタイル付き

HACSのbutton-card、card-mod、Mushroomカードを使って、より豊かな見た目にします。3つすべてが揃っている場合にのみ使用されます。

3つのうち1つでも欠けている場合、アプリは標準版を送信し、スタイル付きの見た目にするためにHACSからインストールするカードを知らせます。インストールしてから、もう一度送信してください。

正直な設計

表示されないものがある理由

  • ゲージはありません。JVCはHome Assistantが報告するレベルの範囲を提供していないため、ダッシュボードは推測が必要になるゲージを描画しません。
  • アドレスもパスワードもありません。ダッシュボードに含まれるのは、エンティティID、名前、ラベルだけです。
  • 架空のエンティティはありません。タイルは、お使いのHome Assistantに存在するエンティティまたはスクリプトにだけ表示されます。
うまくいかないとき

メッセージ

  • ダッシュボードを送信しました。Home Assistantのサイドバーから開いてください。
  • 拒否されました。Home Assistantがダッシュボードを拒否しました。管理者アカウントでサインインしてから、もう一度送信してください。
  • サインインが受け付けられませんでした。もう一度サインインしてから、ダッシュボードを送信してください。
  • 応答なし。Home Assistantから応答がなかったため、ダッシュボードは確認されていません。接続を確認して、もう一度送信してください。
  • 許可されていません。デモプロジェクターが選択されているとき、またはホームオートメーションが解放されていないときは、デバイスから何も送信されません。
ダッシュボードは、Home AssistantのJVC Projector連携を通じてプロジェクターを操作します。この連携がプロジェクターに接続できるのは、このアプリが接続していない間だけです。ダッシュボードを使う前に、アプリを閉じてください。
