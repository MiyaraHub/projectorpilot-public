ピクチャー

プロジェクターから読み取る映像設定

ピクチャータブには、お使いのモデルが記載している映像設定が、ピクチャー、信号、表示の3つのページにまとめられています。すべての値はプロジェクターから読み取られ、変更はすべて読み戻されます。すべてProに含まれます。

画質画面

映像そのもの

  • ピクチャーモードと、ピクチャーモード名の編集(対応するモデルのみ)。
  • 色：カラープロファイル、補正付きの色温度、赤・緑・青のゲインとオフセット、ガンマ補正付きのガンマ。
  • HDR：コンテンツタイプ、HDR処理、HDRレベル、オートトーンマッピング、マッピングレベル。
  • 光：レーザーパワー(ランプモデルではランプパワー)、LD電流値、ダイナミックコントロール、ディープブラック、インテリジェントレンズアパーチャー。
  • モーションと遅延：クリアモーションドライブ、モーションエンハンス、低遅延。
  • 調整：コントラスト、明るさ、色の濃さ、色合い、ピクチャートーン、明部レベルと暗部レベル、NR、エンハンス、スムージングなど。
どの設定が表示されるかはモデルによって異なります。2024年のモデルと2018年のモデルでは記載されている設定が異なり、アプリは各モデルに、そのモデル専用の一覧を表示します。
カラーマネジメント

カラーアクシス(ISFキャリブレーション)

対応するモデルでは、カラーアクシスカードにカラーマネジメントがあり、6色それぞれについて、軸位置、色相、彩度、明るさが含まれます。

信号ページ

入力の読み取り方

  • HDMI入力レベルとHDMI色空間。
  • 信号ごとのピクチャーモード：HDR10ピクチャーモード、SDR(2D)ピクチャーモード、SDR(3D)ピクチャーモード、HLGピクチャーモード。信号の種類ごとに、選んだモードで開きます。
  • FILMMAKER MODE設定とALLM(自動低遅延モード)。
  • 3D設定を含む3Dカード。
表示ページ

画角とメニュー

  • アスペクト、マスク、画面位置(水平と垂直)。
  • マスク端：上、下、左、右。
  • オンスクリーンメニュー：バックカラー、メニュー位置、入力表示、ロゴ、言語、OSDダークモード、OSD明るさ同期。
  • パネルアライメントと画素調整。
値を変更する

リスト、ボタン、スライダー

  • ピクチャーモードやガンマなどの選択肢には、お使いのモデルが記載している値が表示されます。
  • レベルにはマイナスとプラスのボタンを使います。ボタンを押し続けると繰り返され、400ミリ秒後に始まり、その後300ミリ秒ごとにステップします。
  • スライダーは、JVCが範囲を定めている項目にのみ表示されます。現在は、0から100パーセントのLD電流値です。
連動する設定

別の設定が操作を制限するとき

設定には、特定の条件でのみ適用されるものがあります。アプリはそのルールに従うため、効果を持たない操作は無効になり、「現在の低遅延設定では利用できません」のように、制限している設定が表示されます。何も送信されません。

設定変更できる条件
HDR処理入力信号がHDR、HDR10+、HLG、またはST2084であること。
ダイナミックコントロール低遅延がオフであること。
クリアモーションドライブ(リモコンキーを含む)低遅延がオフであること。
マスク端マスクがオンであること。
操作を制限する設定をアプリがまだ読み取っていない場合は、何も制限されません。
正直な読み取り

メッセージの意味

  • 「このプロジェクターはこの設定に応答しません。」電源が入っている間ずっとプロジェクターが応答しなかったため、操作は無効になっています。
  • 「プロジェクターはこの設定を報告しません。」設定はできますが、プロジェクターは現在の値を知らせません。
  • 「プロジェクターがそのコマンドを受理しませんでした。反映されたかどうかは不明です。」この場合、アプリは設定をもう一度読み取るので、画面にはプロジェクターが実際に保持している値が表示されます。
  • 先に確認を求める値は、そのカード自身からのみ、確認したあとに送信されます。
  • スタンバイ。ほとんどの映像設定は、プロジェクターの電源が入ると表示されます。
保存する

気に入った映像を残す

シーンは、ピクチャーモードと、お使いのモデルが提供するその他の映像設定を記録し、1回のタップで元に戻します。
