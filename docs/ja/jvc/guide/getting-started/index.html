はじめに

プロジェクターを追加

アプリは同じネットワーク上のJVC D-ILAプロジェクターを見つけ、TCPポート20554で直接通信します。セットアップに必要なのは、スキャンまたはIPアドレスと、プロジェクターにネットワークパスワードがある場合はそのパスワードです。

初回起動

ウェルカム画面

  1. Projector Pilot D-ILAへようこそ。無料の機能、Proで追加される機能、サポートの受け方(Discordに参加、またはログをメールで送る)を簡単に紹介します。
  2. アナリティクス。匿名の利用状況データの送信を許可するかどうかを確認します。許可しない限りオフで、あとから設定のAboutで変更できます。
  3. 開始する前に。チェックリストです。スマートフォンとプロジェクターが同じローカルネットワークにあること、プロジェクターがLANポートで接続されていてネットワークパスワードがある場合はそれを用意すること、プロジェクターのネットワーク設定に表示されるIPアドレスを控えておくこと。
  4. プロジェクターを追加。ネットワークをスキャン、IPアドレスでプロジェクターを追加、デモモードを体験のいずれかを選びます。
方法1

ネットワークをスキャンする

  • 検索範囲。お使いのデバイスが接続しているプライベートアドレスの範囲ごとに、その/24サブネットのアドレス1から254を、ポート20554で調べます。
  • 判定の仕組み。JVCプロジェクターは新しい接続にあいさつを返します。スキャンでは、あいさつを返したデバイスを「準備完了」または「別のコントローラーが使用中」として一覧に表示します。進行状況には、全体のうち何件のアドレスを確認したかが表示されます。
  • 応答がないとき。「このネットワークでJVCプロジェクターから応答がありませんでした。」Home Assistantなど別のコントローラーがすでに接続しているプロジェクターはスキャンに応答しないため、そのプロジェクターはアドレスを指定して追加してください。
  • Wi-Fiがないとき。デバイスがローカルネットワークに接続されていない場合、スキャンには「ローカルネットワークが見つかりません。Wi-Fiに接続してから、もう一度スキャンしてください。」と表示されます。
方法2

IPアドレスで追加する

スキャンでプロジェクターが見つからない場合や、プロジェクターが別のサブネットにあってもデバイスから到達できる場合に使います。

  1. プロジェクターに名前を付けます。たとえば、設置している部屋の名前にします。
  2. IPアドレス：プロジェクター自身のネットワークメニューに表示されるIPv4アドレスです。ホスト名は使用できません。
  3. ネットワークパスワード：プロジェクターに設定したパスワードです。プロジェクターにネットワークパスワードがない場合は空のままにします。
  4. 接続をテスト。テストに成功すると、「接続しました」と、プロジェクターが報告したモデルが表示されます。
  5. 保存。プロジェクターがダッシュボードに表示されます。同じプロジェクターを2回保存しようとすると、「このプロジェクターはすでに保存されています。」と表示されて拒否されます。
追加画面では標準のポート20554を使います。別のポートを使う場合は、下のガイド付きセットアップを実行してください。コントロールポートの欄に入力したポートが追加画面に引き継がれます。
方法3

ガイド付きセットアップと診断

「接続できませんか? ガイド付き診断を実行」をタップすると、プロジェクターをセットアップが開きます。プロジェクターのIPアドレスとコントロールポート(変更していなければ20554)を入力し、接続を診断をタップします。

チェック確認できること
プロジェクターと同じネットワークお使いのデバイスとプロジェクターが同じサブネットにあり、互いに通信できます。
コントロールポートに到達可能コントロールポートで接続を受け付けるものがあります。
プロジェクターのハンドシェイクとパスワードJVCプロジェクターとして応答し、パスワードがある場合はそれが受け付けられます。

3つすべてに合格すると、結果は「接続できます」となり、このプロジェクターを追加ボタンが表示されます。1つでも失敗すると、画面にその項目が示され、「何が起きているか」と「対処方法」が表示されます。プロジェクターがパスワードを要求している場合は、ネットワークパスワードの欄とパスワードを試すボタンがその場に表示されます。診断結果の一覧はヘルプページにあります。

パスワード

ネットワークパスワード

  • どのパスワードか。プロジェクター自身のネットワークメニューで設定したネットワークパスワードです。アプリ独自のアカウントはありません。
  • 2024年と2025年のモデルは8から10文字で、アプリは送信前に文字数を確認します。最初にSHA-256形式を試し、次にそのままの形式を試します。
  • 2018年と2021年のモデルには、プロジェクターが要求したときだけパスワードを送信します。それより前のモデルには送信しません。
  • 保存場所。このデバイスのセキュアストレージにのみ保存され、バックアップには含まれません。
  • 変更方法。ダッシュボードでプロジェクターのメニューを開き、パスワードを変更を選びます。
コントローラーは1つだけ

同時に使えるアプリは1つだけ

JVCプロジェクターは、同時に1つのネットワークコントローラーにしか対応しません。Projector Pilot D-ILAが接続している間は、Home Assistant、制御システム、別のスマートフォンからはプロジェクターに接続できず、逆の場合も同様です。

  • 2024年と2025年のモデルは接続を開いたままにします。それより古いモデルは、コマンドごとに接続します。
  • アプリがバックグラウンドに移ると、プロジェクターとの接続を解放するので、別のコントローラーが接続できます。
  • 接続が切れた場合は、3秒後、5秒後、8秒後、その後は10秒ごとに再試行し、ネットワークが復帰したときはすぐに再試行します。パスワードが誤っていた場合は再試行しません。
新しいアドレス

プロジェクターのアドレスが変わったとき

アプリは接続時にプロジェクターのMACアドレスを記憶します。3回連続でどこにも到達できなかった場合、ステータスは「ネットワークを検索中」となり、アプリはそのMACアドレスを求めてサブネット全体を最大3回探します。一致するプロジェクターがちょうど1台だった場合は、保存されたアドレスをそこに更新して再接続します。アドレスを自分で設定するには、プロジェクターのメニューから接続を編集を選びます。

手元にプロジェクターがない場合

デモプロジェクター

  • デモモードを体験すると、デバイス上でシミュレートされるデモプロジェクターが追加されます。DEMOと「このデバイス上でシミュレート、ハードウェアなし」と表示されます。
  • デモプロジェクターは2024年のモデルとして応答し、短いウォームアップと冷却の時間も再現するので、ステータスカードは実機と同じように動作します。
  • すべての機能が解放されており、ナビゲーション操作の回数は数えられません。
  • オートメーショントリガー、Hubitat、Home Assistantには何も送信せず、ネットワークのスキャンも行いません。
  • メニューまたは設定からデモを終了を選ぶと削除されます。
