はじめに

プロジェクターを追加

アプリは、お使いのネットワーク上のJVC D-ILAプロジェクターを見つけて、直接通信します。

プロジェクターの追加

スキャンするか、アドレスを入力する

  • ネットワークスキャンは、お使いの/24サブネット内でプロジェクターを探します。
  • スキャンで見つからない場合は、IPアドレスで追加します。デフォルトのポートは20554です。
  • ネットワークパスワード: プロジェクター側で設定したパスワードです。この端末のセキュアストレージにのみ保存され、バックアップには含まれません。
  • 世代に応じたハンドシェイク: 2024年モデルでは、まずSHA-256を試し、次にパスワードなしの方式を試します。
  • 移動したプロジェクターは、3回接続に失敗するとMACアドレスで再び見つけます。
手元にプロジェクターがない場合

デモプロジェクター

  • デモプロジェクターは端末内でシミュレートされるため、ハードウェアがなくてもすべての画面を試せます。
  • デモプロジェクターでは、すべての機能が利用できます。オートメーションのトリガーは、デモプロジェクターからは実行されません。
