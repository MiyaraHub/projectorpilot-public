ダッシュボード

プロジェクターの状態をひと目で確認

ダッシュボードには、選択中のプロジェクターについて、接続されているか、電源が入っているか、何を映しているか、そしてお好みのカードが表示されます。表示される内容はすべてプロジェクターから読み取った値で、推測ではありません。

ステータスカード

接続と電源

  • 名前とモデル。プロジェクターの名前、アドレス、報告されたモデルが表示されます。デモプロジェクターにはDEMOバッジが付きます。
  • 電源の表示。プロジェクターから電源オンまたはスタンバイの報告があると表示されます。電源操作はどのプロジェクターでも無料です。
  • 電源状態がまだわからないときのステータスラベル：接続中、切断、接続できません、パスワードの問題、ネットワークを検索中のほか、電源: スタンバイ、電源: ウォームアップ中などの電源状態が表示されます。
  • ウォームアップと冷却の間は、進行バー、「ウォームアップ中...」または「冷却中...」が表示されます。アプリはこの間2秒ごと、それ以外は15秒ごとにプロジェクターを読み取ります。
電源

電源を切る前に確認が表示されます

プロジェクターの電源を切るときは、「プロジェクターの電源を切りますか?」と表示され、視聴中の全員の映像が消えることが注意書きとして示されます。電源を入れるときは確認されません。レーザーまたはランプのプロジェクターは、スタンバイになる前に独自の冷却を行い、カードもそれに追従します。

カード

レイアウト

ダッシュボードをカスタマイズ

  1. 上部バーのカスタマイズをタップします。
  2. カードをドラッグして移動するか、カードのマイナスをタップして削除します。
  3. 追加をタップすると「カードを追加」から削除したカードを戻せます。RESETをタップすると既定のレイアウトに戻ります。
  4. 完了をタップします。
レイアウトはアプリ全体で1つの設定です。そのため、どのプロジェクターでも、モデルが対応していないカードを除いて、同じカードが同じ順序で表示されます。
複数のプロジェクター

プロジェクターの切り替え

  • プロジェクターを複数保存している場合は、名前のチップが並んで表示され、タップすると選択できます。上部バーのタイトルをタップしても切り替えられます。
  • プロジェクターを追加ボタンで、いつでもプロジェクターを追加できます。
  • プロジェクターメニューには、名前を変更、接続を編集、パスワードを変更、削除があります。削除すると、プロジェクターと保存されたパスワードがこのデバイスから消去されます。デモプロジェクターでは、メニューの項目はデモを終了のみです。
  • 下に引いて更新します。アプリがカードを再度読み取り、接続されていない場合は再接続します。
メッセージ

カードがないとき

ダッシュボードが空のときは理由が表示されるので、何も表示されないままになることはありません。

  • 未接続：「このプロジェクターに接続されていないため、操作を表示できません。」
  • スタンバイ：「プロジェクターはスタンバイ中です。電源を入れると操作が表示されます。」
  • ウォームアップ中または冷却中：プロジェクターが安定すると操作が戻ります。
  • すべてのカードを削除した場合：カスタマイズから戻せます。
  • パスワードの誤り：「プロジェクターがネットワークパスワードを拒否しました。タップして入力し直してください。」
  • オフライン：「このアドレスのポート20554から応答がありませんでした。」のように、失敗の内容が平易な言葉で表示されます。それぞれの意味はヘルプページで説明しています。
ホーム画面

ウィジェット

Proでは、AndroidとiOSで、5つのウィジェットをホーム画面に置いてプロジェクターを操作できます。ウィジェットはそれぞれ1台のプロジェクター用に設定します。

プロジェクタークイックコントロール

電源、入力、ピクチャーモード、ハイド。

プロジェクターステータス

電源、接続、光源使用時間。

プロジェクターシーン

1回のタップで保存したシーンを適用します。

プロジェクター情報

電源、入力、ピクチャーモード、光源。

プロジェクター入力

1回のタップで入力を切り替えます。

ウィジェット自体がプロジェクターと通信することはありません。タップするとアプリが開き、アプリがダッシュボードと同じ確認を経てコマンドを送信します。アプリが30秒以内に接続できなかった場合、そのタップは破棄されます。ウィジェットにはアドレスもパスワードも保存されません。
