ホームオートメーション

プロジェクターをスマートホームに接続

プロジェクターの電源オン、スタンバイ、入力切替、シーンの呼び出しに合わせて、家の他の機器を反応させられます。設定のホームオートメーションの下に、Webhookトリガー、Hubitat、Home Assistantの3つの連携があります。3つすべてにホームオートメーションのアドオンが必要で、単品でもバンドルでも購入できます。Proだけには含まれません。

1つ選ぶ

使う連携の選び方

Webhook

Node-RED、ホームサーバー、クラウドの自動化など、Webリクエストを受け付けるあらゆるシステム向けです。送信はアプリが行い、何が起きるかはお客様が決めます。

Hubitat

Maker APIを通じて、電源と入力をハブ上のデバイスに一方向でミラーリングし、Rule Machineで処理できるようにします。

Home Assistant

Home Assistant標準のJVC Projector連携、シーン用のスクリプト、既成のダッシュボードをセットアップします。

Webhook

オートメーショントリガー

トリガーは、このプロジェクターで何かが起きたときに、入力したアドレスにWebリクエストを送信します。トリガーの一覧はプロジェクターごとに別々です。トリガーを追加をタップして、次を選びます。

  • 条件：プロジェクターの電源がオンになった時、プロジェクターがスタンバイになった時、入力切替(任意の入力または特定の入力へ)、シーンが呼び出された時(任意のシーンまたは特定のシーン)。
  • メソッド：POST(既定)、PUT、GET。
  • ウェブアドレス：ホスト名を含むhttp://またはhttps://のアドレス。
  • 有効：トリガーを削除せずに一時停止できます。
http://で始まるアドレスは暗号化なしで送信され、エディターにもその旨が表示されます。お使いのシステムが対応している場合は、https://を使ってください。
ペイロード

リクエストに含まれる内容

POSTとPUTはJSONの本文を送信し、GETは本文を送信しません。アプリが追加するヘッダーはContent-Typeだけです。イベントに該当しないフィールドは含まれません。

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
項目内容
eventpower_on、power_off、input_changed、またはscene_recalled。
projectorアプリ内のプロジェクターの名前。
inputhdmi1やhdmi2などの入力。
scene_id, scene_nameシーンの呼び出しの場合は、そのシーン。
timestamp発生した時刻(UTC)。
testテスト送信で送られたリクエストにのみ、trueとして含まれます。
配信

送信は1回、結果は正直に報告

  • 各イベントは10秒の制限付きで1回だけ送信され、リダイレクトには従いません。
  • トリガーには最後の結果が表示されます。ステータスコード付きの「配信済み」と時刻、「拒否されました」、「応答なし」、「アドレスに到達できませんでした」、「セキュア接続に失敗しました」、「未送信」のいずれかです。
  • テスト送信はテスト用と明記したリクエストを送信するので、プロジェクターが何かを行う前に、受信側の設定を済ませられます。
トリガーが動作するとき

ルール

  • アプリが開いていて、プロジェクターに接続している間だけ動作します。アプリはプロジェクターの状態を監視しており、バックグラウンドサービスではありません。
  • 変化だけが対象で、読み取り値そのものは対象外です。アプリが接続した後の最初の読み取りは基準点を設定するだけなので、すでに電源が入っていたプロジェクターについて、アプリを開いたときに「電源がオンになった時」のトリガーが動作することはありません。
  • デモプロジェクターからは決して送信されません。デモプロジェクターが選択されているとき、またはホームオートメーションが解放されていないときは、デバイスから何も送信されません。
  • 安全に保存されます。トリガーのアドレスは、デバイスのセキュアストレージに保存されます。
Hubitat

プロジェクターをHubitatにミラーリングする

アプリは、Maker APIを通じて、このプロジェクターの状態をお使いのHubitatハブのデバイスにミラーリングします。オンとスタンバイ、そして入力(HDMI 1またはHDMI 2)のうち、そのデバイスが受け付けるものが対象です。Rule Machineでその状態に応じた処理ができます。

  1. Hubitatで、Maker APIを追加し、そのアプリID(URLに含まれる番号)とアクセストークンを控えます。
  2. アプリで、ハブアドレス、Maker APIのアプリID、アクセストークンを入力します。
  3. デバイスを検索をタップして、このプロジェクターに対応するデバイスを選びます。該当するものがない場合は、Hubitatでプロジェクターの名前を付けた仮想スイッチを追加して、もう一度試してください。
  4. プロジェクターの状態をミラーリングをオンにします。アプリが開いて接続している間にプロジェクターが変化するたびに、デバイスもそれに追従します。
一方向のみ。Hubitatからプロジェクターには何も送信されません。連携を解除すると、アプリ側の連携が削除されます。
Home Assistant

最も深い連携

アプリがHome Assistantにサインインし、プロジェクターをJVC Projector連携に追加し、シーンと操作をスクリプトとして公開し、ダッシュボードを作成します。専用のページがあります：Home AssistantのセットアップとHome Assistantのダッシュボード。
