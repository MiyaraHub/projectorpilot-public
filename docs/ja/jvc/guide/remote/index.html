リモコン

スマートフォンで使うリモコン

リモコンタブは、プロジェクター自身のメニューを操作し、お使いのモデルが記載しているすべてのリモコンキーを備えています。スワイプで切り替える4つのページがあります：リモコン、操作、デバイス、ネットワーク。

リモコンページ

プロジェクターのメニューを操作する

  • ナビゲーション。上、下、左、右、OKの丸いナビゲーションパッドと、JVCのリモコンと同じメニューと戻るがあります。
  • 入力。キー表に含まれるモデルでは、入力キーで入力を順に切り替えます。Proのキーです。
  • 入力ソース。HDMI 1やHDMI 2など、お使いのモデルが提供する入力ごとに1つのボタンがあります。HDMI 1は無料で、それ以外はProが必要です。
  • その他の操作。ピクチャーモード、ハイド、その他すべてのリモコンキーが、専用のページにあります。
  • 更新。上部バーの更新ボタンで、プロジェクターのステータスをもう一度読み取ります。
無料版

無料のナビゲーション操作

Proがない場合、ナビゲーションパッドのキー(上、下、左、右、OK、戻る、メニュー)は回数が数えられます。インストール後の累計で20回使え、その後は1日3回です。Proでは回数制限がなくなります。

  • ナビゲーションパッドの下のカウンターには、「無料のナビゲーション操作 残り18回」と表示され、最初の20回を使い切ると「本日の無料のナビゲーション操作 残り3回」と表示されます。
  • 1日の始まり。1日の回数枠は、最後に操作してから24時間後ではなく、現地時間の午前0時にリセットされます。最初の20回を使い切った日も、その日の3回は残っています。
  • 数えられるもの。操作は、アプリが送信した時点で数えられます。その後プロジェクターが受理しなかった場合も同様です。アプリが接続していないとき、デモプロジェクター、またはProの場合は数えられません。
  • 使い切ったとき。ナビゲーションパッドは画面に表示されたまま、何も送信せず、「本日の無料のナビゲーション操作は使い切りました。明日になるとまた使えます。無制限に使うにはProを解放してください。」と表示します。
再インストールすると回数はリセットされますか?

iOSとmacOSではリセットされません。Keychainにコピーが保存されており、多い方の回数が採用されます。Androidでは、Android自身のバックアップでアプリのデータが復元されない限り、再インストール後に回数が最初からになります。Windowsでは、再インストール後に最初からになります。

その他の操作

その他すべてのリモコンキー

その他の操作はProのページです。お使いのモデルで設定できる場合は最初にピクチャーモードのカード、次にハイド、その後に機能別にまとめたリモコンキーが続きます。お使いのモデルの表に記載されているキーだけが表示されます。

モデルごとの違い

お使いのモデルで使えるキー

JVCの世代ごとに独自のキー表があり、アプリはプロジェクターが報告するモデルコードからそれを選びます。お使いのモデルにないキーは表示されません。万一、そのキーがないモデルにキーが届いた場合は、アプリは何も送信せず、操作とモデルの名前を示して、「何も送信されませんでした。」で終わります。アプリが一覧に載せていないモデルでも、電源、入力、リモコンキーは使えます。

操作ページ

プロジェクターの動作

操作ページには、対応するモデルで、オフタイマー、エコモード、トリガー、ハイドエコ、Control4があります。すべてProです。

エコモードとネットワーク。エコモードがオンの場合、プロジェクターはスタンバイ中にネットワーク上で応答しなくなることがあり、アプリから電源を入れ直せなくなる場合があります。オンにする前にアプリが警告します。JVCのコマンド資料にはどちらとも記載がないため、警告には「場合があります」と表示されます。
デバイスページ

プロジェクターが報告する自身の情報

デバイスページ(Pro)には2つのセクションがあります。プロジェクターには、モデルコードと、お使いのモデルが報告するその他の読み取り値が表示されます。信号には、プロジェクターが報告する入力信号の情報が表示され、信号がないときは表示されません。設定でプロジェクターをタップすると、デバイス情報として同じ詳細が開きます。

ネットワークページ

ネットワークの読み取り専用表示

ネットワークページ(Pro)には、プロジェクターの有線LAN設定が表示されます。DHCP、IPアドレス、サブネット、ゲートウェイ、ポート、MACアドレスで、お使いのモデルが報告する範囲です。意図的に読み取り専用になっています。アプリは同じネットワークでプロジェクターに接続しているため、ここからアドレスを変更すると、アプリ自身の接続が切れてしまうからです。変更はプロジェクターのオンスクリーンメニューで行い、そのあと再接続してください。アドレスが変わったプロジェクターについては、はじめにで説明しています。

よくある質問

リモコンに関するご質問

無料の操作回数に数えられるキーはどれですか?

上、下、左、右、OK、戻る、メニューで、接続中のプロジェクターに操作が送信された場合のみです。電源とHDMI 1は常に無料です。

キーが表示されないのはなぜですか?

アプリには、お使いのモデルのコマンド表に記載されているキーが表示されます。お使いのモデルが記載していないキーは表示されません。

デモプロジェクターでもリモコンは使えますか?

はい。デモでの操作は数えられません。
