設定

アプリの環境設定、バックアップ、診断、サポート。

設定画面

設定の内容

  • テーマと表示サイズ。
  • バックアップと復元は、アプリの設定をファイルに書き出します。プロジェクター、パスワード、シーン、メンテナンス情報、購入情報は書き出されません。
  • 診断: お使いのプロジェクターの対応機能と、読み取り専用のプロトコルプローブ。
  • フィードバックを送信すると、診断ログが添付されます。
  • アプリ情報: バージョン、ウェブサイト、プライバシーポリシー、利用規約、クラッシュレポートのスイッチ。
