Home Assistant

Home AssistantでJVCプロジェクターをセットアップする

アプリがHome Assistantにサインインし、プロジェクターをHome Assistant標準のJVC Projector連携に追加し、シーンと操作をスクリプトとして公開し、ダッシュボードを作成します。トークンを貼り付けたりYAMLを書いたりする必要はありません。ホームオートメーションのアドオンが必要です。

最初にお読みください

コントローラーは同時に1つだけ

JVCプロジェクターは、同時に1つのネットワークコントローラーにしか対応しません。このアプリが開いてプロジェクターに接続している間は、Home Assistantからプロジェクターに接続できません。アプリを閉じている間は、Home Assistantのプロジェクター操作とスクリプトが動作します。アプリはバックグラウンドに移るとプロジェクターとの接続を解放します。

ステップ 1

サインイン

  1. 設定、ホームオートメーション、Home Assistantの順に開きます。
  2. http://またはhttps://で始まるHome Assistantのアドレスを入力します。
  3. サインインをタップします。Home Assistant自身のサインインページがブラウザーで開くので、そこでサインインしてからアプリに戻ります。
  4. 接続をテストをタップして確認します。
Home Assistantに接続できない場合は、アドレスと、このデバイスがHome Assistantと同じネットワークにあるかどうかを確認してください。
ステップ 2

Home Assistantの状況

パネルがHome Assistantを読み取り、各項目を「見つかりました」「インストールされていません」「判定できませんでした」のいずれかで表示します。もう一度確認をタップすると再度読み取ります。

項目必要な用途
Mobile App連携リアルタイム状態センサー。
JVC Projector連携Home Assistantからこのプロジェクターを操作すること。
HACSダッシュボードのスタイル付き表示のみ。
ステップ 3

セットアップのチェックリスト

  1. Home Assistantにサインインします。
  2. このプロジェクターをHome AssistantのJVC Projector連携に追加します。追加をタップします。アプリは、確認を求めたうえで、プロジェクターのアドレス、ポート、ネットワークパスワードをHome AssistantのJVC Projector連携に送信します。
  3. スクリプトに必要なエンティティを有効にします。JVC Projectorのエンティティの一部はHome Assistantで無効の状態から始まります。各エンティティの横にある有効にするをタップしてください。表示されるまでに、Home Assistantの再読み込みまたは再起動が必要な場合があります。
  4. リアルタイム状態センサー。プロジェクターの状態を送信をオンにします。センサーは、アプリが接続中に次にプロジェクターの状態を送信したときに作成されます。
パスワードについて。プロジェクターを追加すると、そのネットワークパスワードがお使いのHome Assistantに送信され、JVC Projectorのエントリー内に保存されます。アプリがそれ以外の場所に送信することはありません。Home Assistantがプロジェクターに接続する間、アプリはプロジェクターとの接続を解放し、その後に再接続します。
どのエントリー?

アプリがHome Assistant内のプロジェクターを見つける方法

アプリは、プロジェクターのMACアドレスでJVC Projectorのエントリーを照合します。そのため、先に少なくとも1回プロジェクターに接続してください。そのMACアドレスのエントリーがHome Assistantにない場合や、複数ある場合は、チェックリストにその旨と対処方法が表示されます。プロジェクターのアドレスが変わった場合は、新しいアドレスをHome Assistantに送信するかどうかをアプリが確認します。

センサー

リアルタイム状態

センサーの状態は、アプリが最後に読み取った電源状態で、属性は入力、モデル、アプリが読み取った設定です。Mobile App連携を経由し、プロジェクターには何も送信しません。アプリが開いて接続している間に状態が変わると、そのたびに更新されます。

スクリプト

シーンと操作

保存した各シーンは、JVC Projectorのエンティティを通じて実行されるスクリプトとしてHome Assistantに登録されます。スクリプトにアドレスやパスワードは含まれません。スクリプトのIDはppjvcで始まります。

  • Sync With HAはシーンをスクリプトとして書き込み、各スクリプトのステップ数と、除外された内容とその理由を表示します。
  • Sync Advanced Controlsは、電源、入力、ピクチャーモード、レンズメモリー、ハイドのスクリプトを公開します。
  • 結果は件数で表示されます。同期されたスクリプトの数、Home Assistantが拒否した数、再読み込みが確認されたかどうかです。
  • 孤立したスクリプトを削除は、このアプリが作成したスクリプトのうち、どのシーンでも使われなくなったものを削除します。削除前に一覧が表示され、確認が求められます。
同期が依存する情報が読み取れていない場合、何も書き込まれず、変更も削除もされません。同期が推測で途中まで実行されることはありません。
ダッシュボード

既成のダッシュボード

ダッシュボードを送信は、JVC Projectorのエンティティ、スクリプト、センサーから、プロジェクター用のダッシュボードをお使いのHome Assistantに作成します。ダッシュボードをコピーは、代わりにダッシュボードをコピーするので、新しいダッシュボードに自分で貼り付けられます。詳しくはHome Assistantのダッシュボードのページをご覧ください。

ルール

アプリが決して行わないこと

  • デモプロジェクターが選択されているとき、またはホームオートメーションが解放されていないときは、デバイスから何も送信されません。
  • 連携を解除すると、このアプリ側の連携だけが削除されます。プロジェクターのデバイスとエンティティは、Home Assistant側で削除するまで残ります。
  • Home Assistantがサインインを受け付けなくなった場合は、アプリがその旨を表示し、再度のサインインを求めます。
