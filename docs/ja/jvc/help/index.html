よくある質問

よくある質問

  • アプリがプロジェクターを見つけられない、または接続できない スマートフォンとプロジェクターを、同じネットワークかつ同じサブネットに接続してください。ゲストネットワークや分離されたVLANでは、互いに通信できません。スキャンは、お使いの/24サブネットを対象にします。スキャンで見つからない場合は、IPアドレスで追加してください。ネットワーク制御にはTCPポート20554を使い、新しいモデルでは、プロジェクターに設定したネットワークパスワードが必要です。
  • アプリが求めるパスワードはどれですか？ プロジェクター本体に設定したネットワークパスワードです。アプリはこのパスワードを、この端末のセキュアストレージにのみ保存し、バックアップには含めません。
  • プロジェクターのIPアドレスが変わった 3回接続に失敗すると、アプリはMACアドレスでネットワーク上のプロジェクターを探し、新しいアドレスに再接続します。
  • お使いのモデルが一覧にない 一覧にないD-ILAプロジェクターでも、電源、入力、リモコンキーは利用できます。モデルのコマンド表に含まれない設定は、手探りで送信せず、表示しません。
  • 買い切りですか？ はい。Pro、Home Automation、バンドルはいずれも買い切りで、サブスクリプションも広告もありません。購入を確定する前に、ストアにお使いの通貨での価格が表示されます。
  • アプリはデータを収集しますか？ AndroidとiOSでは、クラッシュレポートが初期設定でオンになっており、設定の「アプリ情報」でオフにできます。利用状況の分析は、同意するまでオフで、プロジェクターの名前、アドレス、MAC、パスワードは含まれません。
対応モデル

モデルファミリー

  • LAN対応の旧モデル: DLA-X7、X9、RS50、RS60、X30、RS45、X70R、X90R、RS55、RS65。
  • 2018年: DLA-NX5、NX7、NX9、およびRS1000、RS2000、RS3000、N5、N6、N8、N11、V5、V7、V9Rの各名称。
  • 2021年: DLA-NZ7、NZ8、NZ9、NP5、およびRS1100、RS2100、RS3100、RS4100、N88、N98、V50、V70R、V80R、V90Rの各名称。
  • 2024年: DLA-NZ500、NZ700、およびRS1200、RS2200、N700、N788、N799、N800、N888、N899、Z5、Z7の各名称。
  • 2025年: DLA-NZ800、NZ900。
  • DLA-HD350、HD550、HD750、HD950、HD990、X3、RS10、RS15、RS20、RS25、RS35、RS40などのLAN非対応の旧モデルは、ネットワーク経由では操作できません。
