JVC D-ILAプロジェクター

JVC D-ILAプロジェクター用のネットワークリモコン。

JVC D-ILAプロジェクターの電源、入力、画質メニュー、レンズ操作、設置モード、シーン、メンテナンス情報を、お使いのネットワーク経由で操作できます。アカウント、クラウド、サブスクリプションは不要です。

29言語 Android · iOS · macOS · Windows 買い切り ローカルネットワークのみ
TCP 20554DLA-XDLA-NXDLA-NZHome AssistantHubitat

近日公開 Projector Pilot D-ILAは、Android、iOS、macOS、Windows向けに、Google Play、App Store、Microsoft Storeで公開に向けて準備中です。現時点ではどのストアにも公開されていないため、ダウンロードできません。

できること

D-ILAプロジェクターの操作を、スマートフォンで。

各モデルには、そのモデル自身のJVCコマンド表に記載された機能が提供されます。アプリは、お使いのプロジェクターが対応する機能を表示し、対応しない機能は表示しません。

電源と入力

電源のオンとスタンバイ、HDMI 1とHDMI 2。プロジェクターのウォームアップの状況もリアルタイムで表示されます。

リモコン

メニュー操作、ピクチャーモード、コンテンツタイプ、HDRレベル、ガンマ、色温度、カラープロファイル、モーション、ハイド、メニューショートカット。

レンズと設置

レンズ絞り、押し続けて動かすシフト、フォーカス、ズーム、レンズメモリー、設置モード、アスペクト、アナモフィック。

シーン

設定一式を保存して、ワンタップで適用できます。シーンは.ppsceneファイルとして共有でき、インポート時は、モデルが対応する設定だけが取り込まれます。

メンテナンス

光源の使用時間と定格寿命の比較、1時間あたりのコスト、任意で有効にできるリマインダー、エクスポートできる使用時間レポート。

ホームオートメーション

電源、入力、シーンのイベントに対するWebhook、Maker API経由のHubitat、すぐに使えるダッシュボード付きのHome Assistant。

対応プロジェクター

DLA-Xから2025年のNZシリーズまで

  • 43のモデルプロファイルが64のDLAモデル名をカバーし、そのうち52がネットワーク制御に対応しています。
  • 2018年のNXシリーズ: DLA-NX5、NX7、NX9、およびRSと各地域向けの名称。
  • 2021年のNZシリーズ: DLA-NZ7、NZ8、NZ9、DLA-NP5、およびRSと各地域向けの名称。
  • 2024年と2025年のNZシリーズ: DLA-NZ500、NZ700、NZ800、NZ900。
  • DLA-X7、X9、X30、X70R、X90RなどのLAN対応の旧モデル。
  • 一覧にないD-ILAプロジェクターでも、電源、入力、リモコンキーは利用できます。
よくある質問

よくある質問と回答

  • Projector Pilot D-ILAは、どのJVCプロジェクターに対応していますか？ ネットワーク制御に対応したJVC D-ILAプロジェクターに対応します。LANポートを備えたDLA-XおよびDLA-RSモデルから、2018年のNXシリーズ、2021年、2024年、2025年のNZシリーズまでが対象です。アプリには43のモデルプロファイルがあり、64のDLAモデル名をカバーし、そのうち52がネットワーク制御に対応しています。一覧にないD-ILAプロジェクターでも、電源、入力、リモコンキーは利用できます。
  • アカウントやクラウドサービスは必要ですか？ いいえ。アプリは、お使いのローカルネットワーク上でTCPポート20554を使い、プロジェクター自身のネットワークパスワードで、プロジェクターと直接通信します。アカウントもクラウドサービスも不要です。
  • サブスクリプションですか？ いいえ。電源、HDMI 1、一定回数のリモコン操作は無料です。Pro、Home Automationアドオン、バンドルは買い切りです。
  • いつダウンロードできますか？ Projector Pilot D-ILAは、Google Play、App Store、Microsoft Storeで近日公開です。現時点では、どのストアにも公開されていません。
