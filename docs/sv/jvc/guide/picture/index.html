Bild

Bildmenyn

Tre flikar: Bild, Signal och Skärm.

Sidan Bild

Inställningar som din modell dokumenterar

  • Bild: bildläge, gamma, färgtemperatur, färgprofil och de andra bildinställningar som din modell erbjuder.
  • Signal och Skärm: innehållstyp, HDR-nivå, rörelse, bildformat och tillhörande inställningar för din modell.
  • Varje inställning kommer från modellens JVC-kommandotabell, så varje modell ser det den stöder.
  • En inställning som projektorn inte rapporterar tillbaka visas som skickad, inte som avläst.
Bildinställningar kräver Pro.
