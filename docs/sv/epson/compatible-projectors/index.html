Kompatibilitet

Fjärrkontroll för Epson-kompatibla projektorer

Projector Pilot är en oberoende fjärrkontrollsapp som fungerar med Epson-projektorer och alla PJLink-projektorer via ditt eget nätverk. Här ser du vilka modeller den är kompatibel med och vad var och en erbjuder.

Så fungerar det

Kompatibel per protokoll, inte per modelllista

Appen levereras inte med någon lista över modellnummer. Den frågar projektorn vad den stöder och visar de kontroller som projektorn svarar med, så en projektor som talar PJLink eller Epson Web Control fungerar även om den inte nämns nedan.

  • PJLink (klass 1 och 2) ger ström, ingång, tystning och lamp- eller laserstatus på nästan alla nätverksanslutna Epson-projektorer.
  • Epson Web Control lägger till bildinställningar, objektiv, keystone och HDR på modeller som har det.
  • ESC/VP21 är projektorns eget kommandoprotokoll, som används när projektorn svarar på det.

Innan du ansluter

Slå på nätverksstyrning

  • Sätt telefonen och projektorn på samma nätverk.
  • Aktivera PJLink och Web Control i projektorns nätverksmeny.
  • Sök efter projektorn i appen eller lägg till den med IP-adress.
