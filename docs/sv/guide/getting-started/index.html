Kom igång

Lägg till din Epson- eller PJLink-projektor på ungefär en minut

Projector Pilot hittar din projektor på ditt eget nätverk - inget molnkonto, ingen parkopplingskod. Sätt telefonen på samma Wi-Fi, lägg till projektorn en gång, så skannar appen vad den kan och minns det. Här är hela flödet.

Innan du börjar

Vad du behöver

  • Samma nätverk. Din telefon, surfplatta eller dator måste vara på samma Wi-Fi (eller kabelanslutna LAN) som projektorn. Appen pratar direkt med projektorn på det nätverket.
  • Projektorn påslagen eller i standby. Låt projektorn vara på, eller i standby med nätverksstyrning aktiverad - de flesta Epson-modeller svarar i standby så att du kan slå på dem från appen.
  • Projektorns IP-adress (bara om du lägger till för hand). Den finns i projektorns egen nätverksmeny - se nedan var du hittar den.
Ingen projektor till hands? Tryck på Utforska demoläge på första skärmen så körs hela appen mot en inspelad riktig Epson QB1000 som svarar som en riktig projektor - så du kan prova varje skärm innan du köper något.
Steg för steg

Lägga till en projektor

Öppna Lägg till projektor och välj hur du vill hitta den. Båda vägarna slutar på samma ställe.

  1. Välj Sök i nätverket eller Lägg till via IP. Sök i nätverket letar över ditt Wi-Fi eller kabelanslutna LAN efter allt som svarar som en projektor och fyller i adressen åt dig. Lägg till via IP finns för de gånger du hellre skriver adressen själv.
  2. Välj din projektor, eller ange dess IP. Vid en sökning trycker du på projektorn i listan. För hand skriver du IP-adressen från projektorns nätverksmeny och fortsätter.
  3. Låt funktionsskanningen köra. Vid första tillägget undersöker appen projektorn och visar en förloppsindikator så att du ser hur långt den har kommit. Den frågar projektorn vad den faktiskt stöder - vilka protokoll som svarar, vilka kontroller som finns, objektivets och bildens omfång - så att appen bara visar riktiga kontroller.
  4. Tryck på Testa anslutning. Appen bekräftar att den når projektorn och läser tillbaka dess identitet. Om projektorn vill ha ett lösenord för Web Control anger du det här; appen avgör om ett lösenord alls behövs och talar om det oavsett.
  5. Spara. Projektorn läggs till och dess funktionsskanning sparas - öppna appen igen så skannar den inte om. Du hamnar på instrumentpanelen, med live-avläsning.
En projektor skannas en gång och resultatet cachas. Därför går den andra starten på ett ögonblick - appen vet redan vad din hårdvara kan.
Hitta adressen

Var din projektors IP finns

Om du lägger till via IP behöver du projektorns adress på nätverket. Varje Epson visar den på samma ställe.

  1. Öppna Menu på projektorns skärm och gå till Network (eller Extended › Network på vissa modeller).
  2. Öppna Network Configuration › Wired LAN eller Wireless LAN och läs av IP Address.
  3. Skriv in adressen i Lägg till via IP. Det lönar sig att ställa in en fast eller reserverad adress i routern så att den aldrig ändras under appen.
Nätverksinställningar finns på projektorn, inte i appen. Projector Pilot når projektorn över det nätverket, så nätverkssidan visas som en tydlig skrivskyddad vy - du ändrar adresser i projektorns eget gränssnitt.
Om den inte vill ansluta

Snabba lösningar

  • Dubbelkolla nätverket. En telefon som hamnat på gäst-Wi-Fi eller mobilnät ser inte projektorn. Samma nätverk, i båda ändar.
  • Väck projektorn. En modell med nätverksstandby avstängd svarar inte förrän den är på. Slå på den en gång och lägg till den.
  • Lösenordsfråga? Ange lösenordet för Web Control (det enda som projektorns egen webbsida frågar efter). Appen hanterar projektorns övriga lösenord - se fjärrkontrollguiden.
  • Projektor med bara PJLink? Det är en helt vanlig enhet. Appen faller tillbaka på den transport som svarar, så en projektor utan Web Control fungerar ändå.
