The Scenes tab · Pro

Your whole room, in one tap

A Scene captures your projector exactly how it is right now and brings it all back later with a single tap. Movie night, the big game, a bright Sunday matinee - each its own Scene, each one a tap away. You pick precisely which parts a Scene keeps, and only the parts your projector actually reports are on offer.

Scenes are part of Projector Pilot Pro.

How to save one

Set the room, then capture it

  1. Set it up. Get the projector exactly how you want it - the input, the color mode, the picture, the lens memory, the lot.
  2. Save Current. On the Scenes tab tap Save Current, give the Scene a name, and tick which parts to keep. The picker only offers what your projector reports, so you never save a setting your model does not have.
  3. Recall. Tap the Scene to apply it. Projector Pilot confirms each setting against the projector as it goes and never claims a change that did not land.
What a Scene captures

As much or as little as you tick

A single Scene can snapshot any of the following. Recall replays only the parts you ticked, so a "late show" Scene can drop the light output and leave everything else alone.

Power

The projector's power state, so a Scene can wake it or send it to standby as part of the setup.

Input

The source the Scene switches to, so "Movie Night" lands on the right HDMI every time.

Picture

Color mode and the picture values, each on the projector's own menu scale.

Signal

The signal-side settings your projector exposes for the content you are watching.

Light

Light-source output, so a bright room and a dark one get their own setting.

Geometry

The alignment and geometry state that frames the image on your screen.

Audio

The audio settings the projector reports, kept alongside the rest.

Only what is reported

The tick list is built from what your projector actually answers, so nothing you save is a guess.

Automation

Every Scene becomes a Home Assistant script

Paste one block into your Home Assistant configuration once and Projector Pilot writes a script for every Scene you have, plus power, each input, each color mode and each lens memory your projector actually holds. An automation or a voice assistant can then run any Scene, and the app removes the scripts it wrote when you turn the sync off, touching nothing else.

Scenes also work through webhooks - recalling a Scene can post to a URL of yours - and mirror onto Hubitat through Maker API. It is all in the Home Assistant guide.
Share your work

Shareable scene profiles

Tuned a Scene you are proud of? Export it and hand it to a friend, or import one someone shared with you. Scene profiles move between installs so a good setup does not have to be rebuilt from scratch on every projector.
