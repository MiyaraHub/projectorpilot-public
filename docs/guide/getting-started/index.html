Getting started

Add your projector in about a minute

Projector Pilot finds your projector on your own network - no cloud account, no pairing code. Put your phone on the same Wi-Fi, add the projector once, and the app scans what it can do and remembers it. Here is the whole flow.

Before you start

What you need

  • Same network. Your phone, tablet or computer must be on the same Wi-Fi (or wired LAN) as the projector. The app talks to the projector directly on that network.
  • Projector powered or on standby. Leave the projector on, or on standby with network control enabled - most Epson models answer on standby so you can power them on from the app.
  • The projector's IP address (only if you add by hand). It lives in the projector's own network menu - see below for where to look.
No projector handy? Tap Explore Demo Mode on the first screen and the whole app runs against a captured real Epson QB1000 that answers what a real projector answers - so you can try every screen before you buy anything.
Step by step

Adding a projector

Open Add Projector and pick how you want to find it. Both routes end at the same place.

  1. Choose Scan network or Add by IP. Scan network looks across your Wi-Fi or wired LAN for anything answering as a projector and fills the address in for you. Add by IP is there for the times you would rather type the address yourself.
  2. Pick your projector, or enter its IP. From a scan, tap the projector in the list. By hand, type the IP address from the projector's network menu and continue.
  3. Let the capability scan run. On a first add, the app probes the projector and shows a progress bar so you can see how far along it is. It is asking the projector what it actually supports - which protocols answer, which controls exist, the lens and picture ranges - so the app only ever shows you real controls.
  4. Tap Test Connection. The app confirms it can reach the projector and reads back its identity. If the projector wants a Web Control password, enter it here; the app works out whether a password is needed at all and tells you either way.
  5. Save. The projector is added and its capability scan is remembered - open the app again and it does not re-scan. You land on the dashboard, reading live.
A projector is scanned once and the result is cached. That is why the second launch is instant - the app already knows what your hardware can do.
Finding the address

Where your projector's IP lives

If you add by IP, you need the projector's address on your network. Every Epson exposes it in the same place.

  1. On the projector, open the on-screen Menu and go to Network (or Extended › Network on some models).
  2. Open Network Configuration › Wired LAN or Wireless LAN and read the IP Address.
  3. Type that address into Add by IP. A fixed or reserved address is worth setting on your router so it never changes under the app.
Network settings live on the projector, not in the app. Projector Pilot reaches the projector over that network, so it shows the network page as a clear read-only view - you change addresses on the projector's own interface.
If it will not connect

Quick fixes

  • Double-check the network. A phone that dropped onto guest Wi-Fi or cellular will not see the projector. Same network, both ends.
  • Wake the projector. A model with network standby switched off will not answer until it is on. Turn it on once and add it.
  • Password prompt? Enter the Web Control password (the only one the projector's own web page asks for). The app handles the projector's separate passwords - see the Remote guide.
  • PJLink-only projector? That is an ordinary device. The app falls back to whatever transport answers, so a projector without Web Control still works.
