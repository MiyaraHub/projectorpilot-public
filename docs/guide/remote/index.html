The remote

A real remote, without the batteries

The Remote tab carries the on-screen remote and the operational controls, split across sub-pages you swipe between: Remote, Operation, Device and Network. Everything the projector exposes, none of the buttons it does not.

Remote page

Navigate the projector's own menus

  • Navigation D-pad with a center select, plus Menu, Back, Home and Source - drive the projector's on-screen menus exactly as the handset would.
  • Input selection, to jump straight to a source.
  • Color mode, to switch the picture mode from the same screen.
  • Screen blank, to hide the picture. Power lives on the dashboard, not here, so there is one power control, not three.
Screen blank is not A/V mute. Screen blank hides the image while the projector keeps running and the signal keeps flowing, so it comes back instantly. Use it for a pause, not a shutdown.
Operation page - geometry

Correct the shape of the image

Pick the correction method that matches your install. The app shows the methods your projector supports and only one geometry correction is active at a time, as the hardware requires.

MethodUse it for
OffNo correction - a projector squared to the screen needs none.
H/V KeystoneIndependent horizontal and vertical keystone for a projector offset up/down or left/right.
Quick CornerDrag each of the four corners into place - the everyday fix for a not-quite-square image.
Point CorrectionA grid of points nudged individually, for fine local distortion.
Curved SurfaceCompensate for projection onto a curved screen or wall.
Corner WallCorrect for projecting into a room corner where two walls meet.
Every geometry value is read back from the projector after you change it, so a correction the projector did not apply is never shown as if it did.
Device page - passwords

Three passwords, not one

An Epson projector has three separate passwords, and they protect different things. Projector Pilot knows the difference, so entering one you do not need never locks you out of the app.

PasswordProtects
Web ControlThe projector's web interface and the commands that ride on it - including lens moves and image reads on many models. This is the one the projector's own web page asks for.
PJLinkThe PJLink protocol (TCP 4352) used by control systems and, in the app, as a fallback transport.
RemoteThe ESC/VP.net remote-control channel (TCP 3629), the app's preferred transport.
The app works out whether a password is even wanted before deciding anything. A projector that answers without asking is reported as "no password needed here", not falsely flagged as protected - and it never confuses "none set" with "set but not required for this protocol". If a saved Web Control password stops working, lens and image controls do not go dark blaming the lens: they show a tap-to-fix nudge to update the password.
Device page - locks

Locks the projector enforces

The Device page surfaces the projector's own locks. When a control is unavailable because the projector froze it, the app says which lock is responsible instead of failing silently.

  • Lens lock. When the projector's lens lock is on, shift, focus and zoom are held. The app only reports a lens as locked when the projector actually refuses the command - an accepted move whose position the projector cannot confirm is not treated as a lock, so the controls stay available.
  • Child lock. Disables the projector's own power button so a child cannot switch it on and stare into the light. Toggle it from here.
  • Control panel lock. Locks the buttons on the projector body so only the remote (and the app) can drive it - handy in a public or shared room.
Network page

A clear read-only view

Network settings live on the projector, because the app reaches the projector over that network. The Network page is a plain read-only view of the projector's addressing with a note explaining why - you change these on the projector's own interface, covered in Getting started.
