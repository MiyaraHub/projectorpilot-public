The picture menu

Projector picture settings, on the projector's own scale

Everything the projector's picture menu holds, in one screen - brightness through frame interpolation. Every value is the number your projector's own menu shows, not its internal byte, and every change is read back from the projector afterwards so you always see the figure the hardware actually kept.

The basics

Brightness, contrast, tint, sharpness

  • Brightness and Contrast - the black floor and white ceiling, on the projector's own 0-100 (or model) scale.
  • Tint and Saturation - color balance and intensity.
  • Sharpness - edge definition, on the range your model uses.

Each control shows the exact menu figure. Where the projector has declared the range a control uses, the app converts precisely as the projector does; where it has not, the number is shown as sent and the control says wire value rather than printing a guess.

Color

Color temperature and gamma

Two controls that behave differently depending on the mode - and the app follows the projector rather than flattening them.

  • Color temperature is fourteen steps, not a slider - numbered, or shown in Kelvin in the picture modes that report a Kelvin figure. It is a stepped setting, so the app presents it as steps, never as a 0-100 range that would misread it.
  • Gamma is per picture mode. The options differ by mode - Dynamic offers steps across a range, Cinema offers curve values, Custom is different again. The app resolves which set is valid from the current picture mode before it offers you the choices, so you never see a gamma option the current mode cannot take.
  • RGB gain and offset - the white-balance controls, each on the projector's own scale, for tuning the grayscale.
Color temperature reads as the step the menu shows (for example 0 to 13), or the Kelvin figure in the modes that show one - not a byte, and not a re-converted value.

Only the controls your model actually exposes appear, with the ranges it reports. A control your projector does not have is simply not shown - the app never invents one.
The honesty rule

HDR and color space stay separate

A signal's dynamic range and its color space are two different things, and the app keeps them that way. BT.2020 does not mean HDR, and SDR does not mean BT.709.

  • Dynamic range (SDR or HDR) and color space (BT.2020, BT.709 and so on) are shown as separate fields.
  • A BT.2020 SDR signal - common with an external tone-mapper like MadVR - reads as exactly that, never as a false HDR10 badge.
  • Every picture value is read back from the projector after you set it, so a value the projector kept, or did not confirm, is said plainly rather than assumed.
Picture memory

Save, recall and rename your picture memories

The Picture screen lists the memories your projector actually holds, by the names you gave them on its menu. Save the current picture into a slot, rename it, or erase it - saving over a slot that already holds a memory asks first.
