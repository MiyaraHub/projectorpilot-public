Imagem

O menu de imagem

Três separadores: Imagem, Sinal e Ecrã.

Página de imagem

Definições que o teu modelo documenta

  • Imagem: modo de imagem, gama, temperatura de cor, perfil de cor e as restantes definições de imagem que o teu modelo oferece.
  • Sinal e Ecrã: tipo de conteúdo, nível HDR, movimento, formato e as definições relacionadas para o teu modelo.
  • Cada definição vem da tabela de comandos JVC desse modelo, por isso cada modelo vê o que suporta.
  • Uma definição que o projetor não devolve é mostrada como enviada, não como lida.
As definições de imagem requerem Pro.
