FAQ

Perguntas e respostas

  • Que aplicação preciso? O Projector Pilot é para projetores Epson através de ESC/VP21 e Web Control, e para qualquer projetor PJLink. O Projector Pilot D-ILA é para projetores JVC D-ILA.
  • As aplicações precisam de uma conta ou de um serviço na nuvem? Não. As duas aplicações comunicam com o projetor na tua própria rede local.
  • São subscrições? Não. Cada aplicação tem um nível gratuito, e as compras Pro, Home Automation e do pacote são pagamentos únicos.
