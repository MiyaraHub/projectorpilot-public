O telecomando

Um comando de projetor a sério, sem as pilhas

O separador Comando reúne o comando no ecrã e os controlos de funcionamento, repartidos por subpáginas entre as quais desliza: Comando, Funcionamento, Aparelho e Rede. Tudo o que o projetor expõe, nenhum dos botões que não tem.

Página Comando

Navegue nos menus do próprio projetor

  • Teclado direcional de navegação com seleção central, mais Menu, Voltar, Início e Fonte - comande os menus no ecrã do projetor exatamente como faria o comando físico.
  • Seleção de entrada, para saltar diretamente para uma fonte.
  • Modo de cor, para mudar o modo de imagem a partir do mesmo ecrã.
  • Ecrã em branco, para esconder a imagem. A energia fica no painel, não aqui, por isso há um só controlo de energia, não três.
Ecrã em branco não é A/V mute. O ecrã em branco esconde a imagem enquanto o projetor continua a funcionar e o sinal continua a fluir, por isso volta instantaneamente. Use-o para uma pausa, não para desligar.
Página Funcionamento - geometria

Corrija a forma da imagem

Escolha o método de correção que corresponde à sua instalação. A app mostra os métodos que o seu projetor suporta e só uma correção de geometria está ativa de cada vez, como o equipamento exige.

MétodoUse-o para
DesligadoSem correção - um projetor alinhado com o ecrã não precisa de nenhuma.
Keystone H/VKeystone horizontal e vertical independentes, para um projetor deslocado para cima/baixo ou para a esquerda/direita.
Quick CornerArraste cada um dos quatro cantos para o sítio - a correção do dia a dia para uma imagem que não está bem alinhada.
Correção de pontosUma grelha de pontos movidos individualmente, para distorções locais finas.
Superfície curvaCompense a projeção num ecrã ou parede curvos.
Canto de paredeCorrija a projeção num canto de uma sala onde duas paredes se encontram.
Cada valor de geometria é lido de volta do projetor depois de o alterar, por isso uma correção que o projetor não aplicou nunca é mostrada como se tivesse sido.
Página Aparelho - palavras-passe

Três palavras-passe, não uma

Um projetor Epson tem três palavras-passe separadas, e protegem coisas diferentes. O Projector Pilot conhece a diferença, por isso introduzir uma de que não precisa nunca o deixa bloqueado fora da app.

Palavra-passeProtege
Web ControlA interface web do projetor e os comandos que passam por ela - incluindo os movimentos da lente e as leituras de imagem em muitos modelos. É a que a própria página web do projetor pede.
PJLinkO protocolo PJLink (TCP 4352) usado por sistemas de controlo e, na app, como transporte alternativo.
ComandoO canal de controlo remoto ESC/VP.net (TCP 3629), o transporte preferido da app.
A app descobre se é sequer pedida uma palavra-passe antes de decidir seja o que for. Um projetor que responde sem pedir é comunicado como "aqui não é preciso palavra-passe", não falsamente assinalado como protegido - e nunca confunde "nenhuma definida" com "definida mas não exigida para este protocolo". Se uma palavra-passe do Web Control guardada deixa de funcionar, os controlos de lente e imagem não ficam inativos a culpar a lente: mostram um aviso de toque para corrigir, a pedir a atualização da palavra-passe.
Página Aparelho - bloqueios

Bloqueios que o projetor impõe

A página Aparelho mostra os bloqueios do próprio projetor. Quando um controlo está indisponível porque o projetor o congelou, a app diz que bloqueio é o responsável em vez de falhar em silêncio.

  • Bloqueio da lente. Quando o bloqueio da lente do projetor está ligado, a deslocação, o foco e o zoom ficam retidos. A app só comunica uma lente como bloqueada quando o projetor recusa mesmo o comando - um movimento aceite cuja posição o projetor não consegue confirmar não é tratado como bloqueio, por isso os controlos continuam disponíveis.
  • Bloqueio de crianças. Desativa o botão de energia do próprio projetor, para que uma criança não o ligue e fique a olhar para a luz. Ative-o a partir daqui.
  • Bloqueio do painel de controlo. Bloqueia os botões do corpo do projetor para que só o comando (e a app) o possam comandar - útil numa sala pública ou partilhada.
Página Rede

Uma vista clara só de leitura

As definições de rede ficam no projetor, porque a app chega ao projetor através dessa rede. A página Rede é uma vista simples só de leitura do endereçamento do projetor, com uma nota a explicar porquê - altera-as na interface do próprio projetor, explicada em Primeiros passos.
