相容 Epson 的投影機遙控器

Projector Pilot 是一款獨立的遙控應用程式，可透過您自己的網路控制 Epson 投影機以及任何支援 PJLink 的投影機。以下列出它相容的機型，以及各機型提供的功能。

運作方式

依通訊協定相容，而非依機型清單

應用程式不內建機型清單。它會詢問投影機支援哪些功能，並顯示投影機回應的控制項，因此只要投影機支援 PJLink 或 Epson Web Control，即使下方沒有列出也能使用。

  • PJLink（第 1 類和第 2 類）幾乎適用於所有連網的 Epson 投影機，提供電源、輸入、靜音以及燈泡或雷射狀態。
  • Epson Web Control 在提供該功能的機型上增加畫面設定、鏡頭、梯形校正和 HDR。
  • ESC/VP21 是投影機自有的指令通訊協定，在投影機透過該協定回應時使用。

連線之前

開啟網路控制

  • 讓手機和投影機連上同一個網路。
  • 在投影機的網路選單中啟用 PJLink 和 Web Control。
  • 在應用程式中掃描投影機，或透過 IP 位址新增。

設定步驟請見指南和說明 & FAQ。使用的是 JVC 投影機？請參閱 Projector Pilot D-ILA。
