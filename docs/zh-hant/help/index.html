Projector Pilot 說明& FAQ

如何連線、哪些投影機可用、購買與還原的運作方式，以及 App 如何對待您的隱私。還是卡關？歡迎到社群聯絡開發者，或在 App 中點選傳送意見回饋。

連線

完成連線

Projector Pilot 直接在您的網路上與投影機通訊。只要做到三件事就能連線，其中一件常讓大多數人卡關。

同一個 Wi-Fi，同一個子網路

手機與投影機必須位於同一個網路與子網路。訪客網路、IoT VLAN 與部分 Mesh 設定會把裝置彼此隔離，因此位於「IoT」SSID 上的投影機，無法從連在主要網路的手機存取。請把兩者放在同一個網路。

在投影機上啟用 PJLink 與 Web Control

網路控制必須在投影機上開啟。請在投影機的網路選單中啟用 PJLink 與 Web Control（Epson 稱後者為網頁遙控／Web Control）。網路控制關閉時，投影機就是不會回應。

找出投影機的 IP 位址

App 會掃描您的網路來尋找投影機，您也可以用 IP 新增。要找出 IP，請在投影機自己的選單中開啟網路資訊畫面，那裡會列出目前的位址。如果掃描沒有結果，就手動新增該 IP。

投影機的三組密碼

Epson 投影機有三組獨立的密碼：Web Control、PJLink 與遙控器。它們不是同一個欄位，而一台投影機可能需要其中一組、數組，或完全不需要。請輸入您的投影機要求的那些；App 會判斷投影機實際需要哪些，並在任一情況下都能連線，診斷會告訴您使用了哪條路徑。如果投影機不需要密碼就有回應，App 會說明此處不需要已儲存的密碼，而不是宣稱沒有設定密碼。

相容性

支援的投影機

  • 透過 ESC/VP21 與 Web Control 連線的 Epson 投影機：兩者並用，即可取得電源、完整畫質選單、幾何校正與電動鏡頭控制。
  • 任何 PJLink 投影機：透過 PJLink 標準取得電源、輸入與狀態，因此非 Epson 或僅支援 PJLink 的 Epson 都是一般的受支援裝置。
  • 使用哪種傳輸方式取決於它有回應，而不是事先設定好。App 偏好 ESC/VP21，其次是 PJLink，再來是 Web Control，但會退而使用投影機實際有回應的方式。沒有 Web Control 的投影機仍可透過 PJLink 運作；傳輸方式拒絕的數值會被視為未知，而不是不支援。
不確定您的機型？App 的「關於」畫面會從機型資料庫列出支援的投影機，並註明各機型是在硬體上驗證，還是推斷而得。如果投影機自己的網頁和網路控制都能運作，Projector Pilot 應該也能連上它。
購買 & 還原

購買，以及找回購買項目

是一次性購買嗎？

是的。Pro、居家自動化附加功能與組合包都是一次性購買。沒有訂閱、沒有廣告、沒有帳號。請參閱價格。

如何在新裝置上還原？

登入您購買時使用的同一個商店帳號，並在 App 中使用「還原購買項目」。一次購買即可在您擁有的所有平台上解鎖：Android、iOS、Windows 與 macOS，並與該商店帳號綁定。

我已經擁有它，但 App 顯示錯誤

這不應該發生，而較新的版本正是修正了這個問題。如果商店回報 Pro、居家自動化或組合包已擁有，App 會直接授予並悄悄重新整理您的購買項目，因此購買或還原您已擁有的項目一定會解鎖。

為什麼價格和我在網路上看到的不一樣？

App 會在您確認之前，以您自己的貨幣顯示商店的價格。各地區的定價不同，而且 App 絕不會退回使用寫死的數字；如果商店尚未回應，它會直接說明，而不是自創一個數字。

隱私權

您的資料屬於您

Projector Pilot 是本機 App。它在您的網路上與投影機通訊，沒有任何需要註冊的項目。

  • 沒有帳號，沒有雲端。您不需要建立帳號，投影機的資料也不會傳送到我們的任何伺服器。
  • 透過 Crashlytics 的當機診斷。當 App 當機時，會傳送診斷報告以便修正錯誤。這是標準的當機回報，不是追蹤。
  • 選用、需主動加入的分析。使用分析預設為關閉。App 在第一次啟動時會詢問一次，之後您隨時可以在設定 › 關於中開啟或關閉。除非您開啟，否則不會收集或傳送任何內容。
  • 我們不販售資料。您的資料不會賣給任何人，就是這樣。

FAQ

快速解答

Projector Pilot 找不到或無法連線到我的投影機

請確認手機與投影機位於同一個 Wi-Fi 網路與子網路；訪客網路與 IoT VLAN 可能會把它們隔離。在投影機上，請於其網路選單中啟用網路控制（PJLink 和／或 Web Control）。到投影機自己的網路資訊畫面找出它的 IP，若掃描找不到，就手動新增。

Projector Pilot 支援哪些投影機？

透過 ESC/VP21 與 Web Control 連線的 Epson 投影機，以及任何 PJLink 投影機。使用哪種傳輸方式取決於它有回應，而不是事先設定好；App 會退而使用投影機有回應的方式，因此只支援 PJLink 的投影機也是一般的受支援裝置。

Projector Pilot 需要帳號，或會把我的資料傳到雲端嗎？

沒有帳號，也沒有雲端。App 在您的網路上與投影機通訊。它透過 Crashlytics 使用當機診斷，另有選用的使用分析，預設為關閉，可在設定 > 關於中關閉。我們不會販售任何資料。
