功能

投影機提供的每項控制，盡在一個簡潔的 App。

Projector Pilot 同時透過 ESC/VP21、PJLink 與 Epson Web Control 與投影機通訊，並使用有回應的那一種，因此您得到真正好用的電源、畫質、幾何校正與鏡頭控制，而且數值都是從投影機讀回，絕不憑空猜測。

儀表板

一切一目了然，依您的喜好打造。

  • 即時狀態：電源、輸入、色彩模式、光源使用時數、訊號與畫質數值，隨變化即時更新。
  • 一鍵電源與輸入，就在最上方，電源按鈕還能感知暖機與冷卻。
  • 可自訂的卡片：新增、隱藏與重新排列卡片，讓儀表板顯示您在意的內容。
  • 投影資訊：動態範圍、色彩空間、伽瑪、雷射使用時數、序號與安裝方式，直接從投影機讀取。
遙控器 & 畫質

功能完整的遙控器，以及完整的畫質選單。

  • 完整的方向鍵、選單、訊號源與螢幕遮蔽：把螢幕遙控器做到位。
  • 校正方式：水平／垂直梯形校正、快速角落、點校正、曲面與牆角。
  • 完整畫質控制：亮度、對比、色調、銳利度、色溫、伽瑪、HDR 與深入的畫質選單，各自採用投影機自己的刻度。
  • HDR 與色彩空間分開呈現：BT.2020 SDR 訊號會如實顯示，絕不會出現錯誤的 HDR 標章。
鏡頭

電動鏡頭的偏移、對焦、變焦與記憶。

  • 透過精準的方向鍵進行偏移、對焦與變焦，並有您自選的步進大小：精細用於取景，粗略用於大幅移動。
  • 鏡頭記憶：叫出並儲存投影機支援的位置。
  • 感知方向：App 遵循投影機自己的對應方式，不論吊裝或背投，上永遠是上。
  • 如實的讀數：投影機無法確認的位置，絕不會被偽裝成鎖定。
情境

整個空間，一鍵搞定。

  • 儲存場景：電源、輸入、畫質、訊號、光源、幾何校正與音訊，並可精確選擇要保留哪些部分。
  • 一鍵套用：「電影之夜」會同時設定輸入、畫面模式與鏡頭記憶。
  • 每個場景都會成為 Home Assistant 指令碼，因此自動化或語音助理也能執行它。
  • 可分享的設定檔：匯出調校好的場景，交給朋友。
居家自動化

Home Assistant、Hubitat 與 Webhook，貨真價實。

  • Home Assistant：登入、將投影機狀態發布為感測器，並點選與 HA 同步，為每個場景與控制項取得一個指令碼。
  • 為您建立的儀表板：同步會在 Home Assistant 中建立它，使用內建卡片，並在您安裝了更豐富的 HACS 卡片時自動升級。它也能搭配核心 PJLink 整合。
  • 設定檢查清單會顯示哪些已完成、哪些還缺，以及接下來該做什麼，而且在投影機關機期間，您的讀數仍會保留在 Home Assistant 中。
  • Hubitat：透過 Maker API 將投影機鏡像到裝置，讓 Rule Machine 能據此動作。
  • Webhook：當投影機開機、關機、切換輸入或叫出場景時，向任何 URL發送請求。

隨處切換投影機

每個投影機頁面的頂端列都有投影機切換器，不必回到清單就能在投影機之間切換。

關機前會先詢問

關閉投影機時會要求您確認，因此不小心點到也不會讓電影中斷。

立即回應的控制

鏡頭偏移、對焦、變焦與光輸出調整鈕在您按下的瞬間就會移動，投影機開機後約十秒內，App 就會偵測到。

韌體一目了然

只要投影機有回報，投影機的韌體版本就會顯示在儀表板與資訊分頁，以及診斷報告中。

在僅支援 PJLink 的投影機上切換輸入

只透過 PJLink 列出輸入的投影機（例如 TW7300 與 Home Cinema 4040）可以切換輸入，非 Epson 的 PJLink 投影機也可以。

在 Wi-Fi 上找到您的投影機

新增投影機會掃描您的網路，找出任何以投影機身分回應的裝置並填入位址，探索您機型的功能時還會顯示進度列。

備份與還原

將您的 App 設定匯出為檔案，也能再次匯入。檔案會以其真實名稱分享，已儲存的投影機與密碼絕不會隨檔案帶走。

一個步驟回報問題

回報問題會建立一個包含所有相關紀錄的檔案包，隨時可以傳送。

FAQ

大家最先會問的問題

Projector Pilot 是 Epson 開發的嗎？

不是。Projector Pilot 是 MiyaraHub Technologies LLC 開發的獨立 App，與 Epson、PJLink 標準組織、Home Assistant 或 Hubitat 並無關聯，亦未獲其背書或贊助。這些名稱為其各自所有者的商標，出現在此處僅用於說明本 App 可搭配哪些投影機與智慧家庭系統。

Projector Pilot 支援哪些投影機？

透過 ESC/VP21 與 Web Control 連線的 Epson 投影機，以及任何 PJLink 投影機。App 會使用投影機有回應的任一方式，因此只支援 PJLink 的投影機也是一般的受支援裝置。

Projector Pilot 是訂閱制嗎？

不是。基本控制免費，Pro、居家自動化與組合包皆為一次性購買。沒有訂閱，沒有廣告。

Projector Pilot 需要帳號或雲端嗎？

沒有帳號，也沒有雲端。App 直接在您自己的網路上與投影機通訊。
