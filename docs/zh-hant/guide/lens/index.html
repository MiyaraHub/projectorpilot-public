鏡頭分頁

鏡頭偏移、對焦與變焦，精準到位

透過精準的方向鍵，對投影機的電動鏡頭進行偏移、對焦與變焦，叫出並儲存投影機支援的鏡頭記憶，並從機身讀回確切的位置。每個數值都來自投影機，無法確認的位置會顯示為未知，絕不會偽裝成已鎖定。

鏡頭分頁有兩個子分頁：鏡頭用於日常的偏移、對焦、變焦與記憶控制，安裝則用於一次性的設定調整。

鏡頭偏移

方向鍵，加上您自選的步進大小

偏移方向鍵可將鏡頭上移、下移、左移與右移。讓它從玩具變成工具的，是下方的步進大小選擇器：您可以選擇一次點按讓鏡頭移動多遠，從精細的取景到粗略的大幅移位都行。

步驟 1

最精細的移動。一次輕推一點點，讓畫面邊緣對準螢幕的邊框。

步驟 5

適中的設定，在已經接近目標位置時，用來把畫面調整到定位。

步驟 10

快速移動，適合還在粗略抓位置的階段。

步進 25

最粗的移動，只要點幾下就能讓鏡頭橫越很大一段行程。

您選擇的步進大小同時適用於偏移、對焦與變焦，因此一個設定就決定了每個鏡頭控制項每次點按移動的幅度。先用大步進抓到大致位置，再降到 1 完成取景。
對焦 & 變焦

銳利度與畫面大小，同樣的操作方式

  • 對焦：以減號與加號按鈕驅動對焦馬達，每次點按依您設定的步進大小移動。目前的對焦馬達位置顯示在按鈕上方，方便您回到已知的數值。
  • 變焦：同樣以減號與加號按鈕驅動變焦馬達，一樣依您選擇的步進大小，並在旁邊顯示即時的變焦馬達位置。
  • 讀回而非猜測：對焦與變焦的數值是投影機回報的馬達位置，因此您看到的就是鏡頭的實際位置，而不是 App 期望它到達的位置。
鏡頭記憶

叫出已儲存的設定，或儲存目前的設定

具備鏡頭記憶的投影機，會把完整的偏移、對焦與變焦位置儲存在具名的欄位中。Projector Pilot 會列出您的投影機實際支援的欄位，讓您點一下就能叫出，或把目前的位置儲存進去。

  • 叫出：點選一個記憶，鏡頭就會移到該儲存的偏移、對焦與變焦位置，正是變形寬螢幕或不同畫面比例所需要的設定。
  • 儲存：把目前的鏡頭位置存入一個欄位，以便日後回到這個位置。
  • 只顯示真實的欄位：App 顯示的是投影機回報擁有的記憶欄位，而不是假設每個機型都具備的固定清單。
鏡頭記憶與場景搭配得很好：場景可以把鏡頭記憶與輸入和畫面模式一起儲存，因此只要點一下，就能為寬螢幕電影或 16:9 節目設定好整個空間。
位置讀數

繪製出來的偏移範圍

鏡頭分頁頂端以兩種方式顯示目前的鏡頭位置：數值與圖表。

  • V-Shift 與 H-Shift 數值：垂直與水平偏移的位置，各以目前數值相對於投影機完整行程顯示（例如 1023 中的 595），讓您隨時知道鏡頭抵達極限前還剩多少空間。
  • 範圍圖：一個方框，將鏡頭位置繪製為投影機偏移範圍內的一個點（垂直對水平），讓您一眼就看出鏡頭是置中，還是偏向行程的某個角落。
方向是投影機的事，App 予以尊重。不論是吊裝、背投或正投，上就是上：App 遵循投影機自己的對應方式，絕不會為了揣測您的安裝方式而反轉方向鍵。點上，畫面就往上，不管投影機被固定在什麼位置。
預設就誠實

未確認的位置是未知，不是鎖定

有些投影機會接受鏡頭移動指令並執行，但回報的位置不會隨馬達同步更新。在 QB1000 這類機型上，這種延遲很容易被誤認為鏡頭卡住。

  • 指令已被接受但位置未確認時，控制項仍可使用。App 不再僅僅因為回報的數值沒有變動，就把控制項反灰，或指向鏡頭鎖定；指令既然已被接受，控制項就保持可用。
  • 只有真正被拒絕才會回報為鎖定。只有在投影機確實拒絕指令時，App 才會告訴您鏡頭已鎖定，而且不論有沒有 Web Control 密碼都適用。
  • 登入被拒是未知，不是鎖定。如果鏡頭移動是透過 Web Control 進行，而該登入被拒，App 會把鏡頭視為未知，並顯示點一下即可修正的提示，請您更新 Web Control 密碼，而不是怪到鏡頭頭上。
安裝子分頁

一次性的設定調整

安裝子分頁收納了投影機安裝時只需設定一次、之後很少再動的幾何與安裝人員控制項，與鏡頭子分頁上日常的鏡頭移動相互對應。

安裝人員控制項只會在投影機支援時出現，並從機身讀回，因此您看到的就是您的確切機型所提供的內容，而不是假設的一套。
