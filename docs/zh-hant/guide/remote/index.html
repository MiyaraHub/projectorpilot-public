遙控器

真正的投影機遙控器，不用電池

遙控器分頁包含螢幕遙控器與各項操作控制，分成幾個可左右滑動切換的子頁面：遙控器、操作、裝置與網路。投影機提供什麼，這裡就有什麼，沒有的按鈕就不會出現。

遙控器頁面

操作投影機自己的選單

  • 方向鍵加上中央選取鍵，以及選單、返回、首頁與訊號源：就像使用實體遙控器一樣操作投影機的螢幕選單。
  • 輸入選擇，直接跳到某個訊號源。
  • 色彩模式，在同一個畫面切換畫面模式。
  • 螢幕遮蔽，隱藏畫面。電源控制在儀表板上，不在這裡，因此只有一個電源控制，而不是三個。
螢幕遮蔽不等於 A/V 靜音。螢幕遮蔽會在投影機持續運作、訊號持續傳送的情況下隱藏畫面，所以能瞬間恢復。它適合暫停，而不是關機。
操作頁面：幾何校正

修正畫面的形狀

選擇符合您安裝方式的校正方式。App 會顯示您的投影機支援的方式，而且依硬體要求，同一時間只能啟用一種幾何校正。

方式適用於
關閉不校正：與螢幕完全對正的投影機不需要校正。
水平／垂直梯形校正獨立的水平與垂直梯形校正，適用於上下或左右偏移擺放的投影機。
快速角落將四個角落分別拖曳到定位，是修正不太方正的畫面的日常做法。
點校正以網格上的點個別微調，用於細緻的局部變形。
曲面補償投影在曲面螢幕或牆面上的變形。
牆角修正投影到兩面牆交會的房間牆角時的變形。
每個幾何數值在您變更後都會從投影機讀回，因此投影機沒有套用的校正，絕不會被顯示成已套用。
裝置頁面：密碼

三組密碼，不是一組

Epson 投影機有三組各自獨立的密碼，保護的對象也不同。Projector Pilot 清楚其中的差異，因此輸入了不需要的密碼也絕不會把您鎖在 App 之外。

密碼保護對象
Web Control投影機的網頁介面，以及透過它傳送的指令，在許多機型上包括鏡頭移動與影像讀取。這就是投影機自己的網頁會要求的那一組。
PJLink控制系統使用的 PJLink 通訊協定（TCP 4352），在 App 中也作為備援傳輸方式。
遙控器ESC/VP.net 遙控通道（TCP 3629），App 偏好的傳輸方式。
App 會先判斷是否真的需要密碼，再做任何決定。不需詢問就有回應的投影機，會被回報為「此處不需要密碼」，而不會被錯誤地標示為受保護；它也絕不會把「未設定」與「已設定但此通訊協定不需要」混為一談。如果已儲存的 Web Control 密碼失效，鏡頭與影像控制項不會因此變暗並怪罪鏡頭，而是會顯示點一下即可修正的提示，請您更新密碼。
裝置頁面：鎖定

投影機強制執行的鎖定

裝置頁面會顯示投影機自己的鎖定。當某個控制項因為投影機將其凍結而無法使用時，App 會說明是哪一個鎖定造成的，而不是默默失敗。

  • 鏡頭鎖定。投影機的鏡頭鎖定開啟時，偏移、對焦與變焦都會被鎖住。只有當投影機確實拒絕指令時，App 才會回報鏡頭已鎖定；若指令已被接受、只是投影機無法確認位置，則不會視為鎖定，控制項仍可使用。
  • 兒童鎖。停用投影機本身的電源按鈕，避免孩子開機後直視光源。可在這裡切換。
  • 控制面板鎖定。鎖住投影機機身上的按鈕，只有遙控器（與 App）能操作，適合公共或共用的空間。
網路頁面

清楚的唯讀檢視

網路設定在投影機上，因為 App 是透過該網路連到投影機。網路頁面是投影機位址資訊的單純唯讀檢視，並附上說明原因的註記；若要變更，請在投影機自己的介面上進行，詳見開始使用。
