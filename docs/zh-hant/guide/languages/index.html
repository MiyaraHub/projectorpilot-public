一個投影機 App，29 種語言

每個畫面、每項設定、每個對話框，都以您的語言呈現。Projector Pilot 支援英文加上另外 28 種語言，包括 iPhone、iPad 與 Mac 上的權限提示，預設會跟隨您的裝置，也可以在設定中自行選擇。阿拉伯文與希伯來文則會將整個版面由右至左鏡像。

在哪裡設定

設定 › 語言

App 預設會跟隨裝置語言。若要自行選擇，請開啟設定並點選語言。系統預設會把選擇權交還給裝置；其下以各語言自己的名稱列出所有語言，因此您不必先讀懂另一種語言就能找到自己的語言。

  • 自動。配合手機或平板，無需任何設定。
  • 自行選擇。覆寫裝置語言，選擇會立即生效，且重新啟動後仍會保留。
  • 由右至左。阿拉伯文與希伯來文會把整個版面翻轉過來，包括導覽、卡片與清單的鏡像，而從投影機讀取的數值仍維持投影機的書寫方式。
投影機自己的用詞仍屬於投影機。輸入名稱、色彩模式，以及投影機回報的每個數值，都會以它的原文顯示，不論使用何種語言。只有 Projector Pilot 自己的文字會被翻譯。

常見問題

語言常見問題

App 會自動跟隨我的裝置語言嗎？
會。預設就會跟隨裝置。若要自行選擇，請開啟設定 › 語言；「系統預設」會把選擇權交還給裝置。
阿拉伯文與希伯來文是由右至左排版嗎？
是的。整個 App 都會鏡像，包括導覽、卡片與清單，而從投影機讀取的數值仍維持投影機的書寫方式。
為什麼我的輸入名稱還是原本的語言？
因為那是投影機自己的用詞，不是 App 的。輸入名稱、色彩模式，以及投影機回報的每個數值，都會以它的原文顯示。只有 Projector Pilot 自己的文字會被翻譯。
