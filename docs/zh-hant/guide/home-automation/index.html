Home Assistant · Hubitat · Webhook

您的投影機，在 Home Assistant 與 Hubitat 中。

Projector Pilot 會把投影機的即時狀態與每一項控制發布到 Home Assistant、Hubitat 以及您想用的任何 Webhook。設定一次後，您的智慧家庭就能自行驅動投影機：手機不必在網路上，中間也沒有雲端。

居家自動化能做什麼

居家自動化讓 Projector Pilot 從您手中的遙控器，變成整個家都看得到的裝置。它會公開投影機的運作狀況，包括電源、輸入、色彩模式、畫質數值與燈泡使用時數，並為智慧家庭提供 App 能變更的每一項事物的控制。

  • 它會發布狀態。投影機會以 Home Assistant 感測器、Hubitat 裝置，或您 Webhook 上的 JSON 內容形式出現，帶有與 App 顯示相同的讀數。
  • 它會發布控制。您儲存的每個場景，加上電源、每個輸入、每個色彩模式與每個鏡頭記憶，都會變成自動化或語音助理可以執行的項目。
  • 它不需要伺服器。指令碼設定完成後，Home Assistant 會直接把指令傳送到投影機的 IP 位址。您的手機不必在網路上，也沒有任何內容會經過雲端帳號。
居家自動化是付費的附加功能。它是一次性購買，與 Projector Pilot Pro 分開計價，購買組合包可同時取得兩者並享有優惠。沒有訂閱、沒有帳號、沒有雲端。請參閱價格。

三種接入方式，一個中樞

設定 › 居家自動化就是中樞。選擇您使用的平台：Home Assistant、Hubitat 或 Webhook，並在那裡設定。您可以同時接上多個，它們彼此獨立。

Home Assistant

設定 Home Assistant

從 App 登入，把投影機發布為感測器，將一段區塊貼入您的設定檔，然後同步。從此 Home Assistant 就能自行驅動投影機。

  1. 開啟設定 › 居家自動化 › Home Assistant。
  2. 輸入您的 Home Assistant 位址（例如 http://homeassistant.local:8123 或其 IP），然後點選登入。這是針對您自己的執行個體所做的瀏覽器登入，不需要貼上權杖。請使用您平常的 Home Assistant 登入方式，包括雙重驗證。
  3. App 會把投影機發布為感測器，實體類似 sensor.projector_pilot_epson_qb1000b_qb1000w，帶有電源、輸入、色彩模式、畫質數值與燈泡使用時數。
  4. 開啟傳送投影機狀態，讓這些讀數在 App 開啟期間，隨變化即時更新到 Home Assistant；並開啟同步進階控制，以發布畫質模式、輸入、鏡頭記憶與電源的指令碼。
  5. 把這一段 shell_command 區塊（見下方）貼入您的 configuration.yaml，重新啟動 Home Assistant，然後點選與 HA 同步。

shell_command 區塊

這就是無需伺服器的全部祕訣。App 會寫入一個讓 Home Assistant 執行、用來與投影機的 Web Control 通訊的指令，而它同步的每個指令碼都以不同的動詞呼叫該指令。在 App 中點選複製區塊，並貼入 configuration.yaml。下方範例僅供說明，App 會填入您投影機自己的位址與指令名稱：

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

僅為範例。App 會產生您自己的版本，內含投影機真實的 IP，以及由序號衍生的名稱。

為什麼無需伺服器。該 curl 是在 Home Assistant 主機上執行，而不是在您的手機上。Home Assistant 會透過 Web Control 直接連到投影機的 IP，因此不論 App 是否開啟、您的手機是否在家，自動化都會觸發。EPSONWEB 摘要使用者就是 Web Control 登入帳號；App 會使用已為該投影機儲存的 Web Control 密碼。

測試連線、同步與清理

  • 測試連線會檢查 App 能否連到您的 Home Assistant，以及貼上的 shell_command 是否真的存在，讓您在建立任何內容之前就能發現打錯字。
  • 與 HA 同步會寫入或更新您的場景與控制項的指令碼，並直接在 Home Assistant 中建立現成的 Projector Pilot 儀表板。每當您新增場景或變更控制項時都可以再執行一次，它會就地更新，而不是產生一堆重複項目。
  • 移除孤立指令碼會找出 App 寫入、但已沒有對應場景或控制項的指令碼，例如刪除場景之後，並列出確切會移除哪些項目，且事先詢問。在您確認之前不會刪除任何東西。它只會動到 Projector Pilot 建立的指令碼，Home Assistant 中的其他內容完全不受影響；如果 Home Assistant 無法列出它的指令碼，就不會移除任何項目。
設定檢查清單

App 會告訴您哪些已完成、哪些還缺

Home Assistant 畫面中有設定檢查清單與您的 Home Assistant 現有內容面板，讓您不必猜測還剩哪一步。每一列都會說明該項目已完成、缺少，或無法判斷，並告訴您下一步該怎麼做。

  • 已連線到 Home Assistant：已登入並有回應。如果 Home Assistant 沒有回應，該列會提示您檢查位址，以及手機是否在同一個網路上。
  • 投影機已加入 Home Assistant：Home Assistant 是否已有這台投影機。若沒有，該列會引導您新增 PJLink 整合，且新增整合的步驟會顯示 Home Assistant 要求的 PJLink 主機與連接埠。
  • 讀數感測器已註冊：承載投影機讀數的感測器。它會在 App 第一次讀取投影機時註冊，若有狀況阻礙註冊，該列會提供立即註冊或開啟。
  • 您的 Home Assistant 現有內容：HACS（社群商店）、Epson Projector Link 整合、PJLink 整合，以及 configuration.yaml 中的 Projector Pilot 指令。每一項都會顯示「已找到」、「未安裝」或「無法確定」，並在有幫助的地方附上「安裝方式」與「在 HACS 中開啟」按鈕。
重新檢查會告訴您找到了什麼。修正問題後點選重新檢查，App 就會重新讀取您的 Home Assistant 並回報結果，而不是讓您自己猜是否成功。無法檢查的項目會顯示無法確定，絕不會隨便猜一個是或否。
與您現有的設備搭配運作

支援核心 PJLink 整合，有更豐富的卡片時則升級

Projector Pilot 會查出您的 Home Assistant 安裝了什麼，並據此建立。它能搭配 Home Assistant 內建的核心 PJLink 整合運作，因此您已在那裡新增的 PJLink 投影機，也是一等公民。

  • 優先使用內建卡片。如果您沒有安裝社群卡片，同步會以 Home Assistant 的內建卡片建立儀表板，並在完成時告知。開箱即用。
  • 安裝 HACS 卡片後自動升級。App 會檢查社群卡片（Mushroom、button-card、card-mod、apexcharts-card）中安裝了哪些，並在有的地方把每張卡片升級成更豐富的版本。如果您想要完整的綠色玻璃質感外觀，手工打造儀表板指南會帶您更進一步。
  • 場景與控制項需要貼上一次。如果 Home Assistant 還沒有傳送給投影機的指令，儀表板仍會以即時讀數建立，並由完成設定卡片帶您完成：點選複製區塊，貼入 configuration.yaml，重新啟動 Home Assistant，然後再次點選同步。
  • 什麼都沒安裝？手動貼上。如果 Home Assistant 中什麼都沒安裝，您仍然可以從 App 複製所有內容，自己貼上。
  • 會標明密碼。您貼上的指令區塊會註明是否包含投影機密碼，讓您在分享或儲存之前就知道。
投影機關機時

保留不變的讀數

待機中的投影機幾乎不回報任何資料，因此儀表板通常會變成一片空白。選用的最後已知感測器會在投影機關機期間，把投影機最後的讀數（輸入、燈泡或雷射使用時數）保留在 Home Assistant 中。

  • 它是另一個選用區塊：貼在 configuration.yaml 的結尾（或只把它的行加到現有的 template: 區段下），然後重新啟動 Home Assistant。App 有一個檢查是否存在按鈕，會告訴您 Home Assistant 是否已有它。
  • 關機現在會以關閉的狀態傳到 Home Assistant，因此儀表板與您的自動化會在投影機關機時，將它視為關閉。
場景變成指令碼

每個場景都變成 Home Assistant 指令碼

同步之後，您的場景不再被困在 App 裡。每一個場景，加上電源、每個輸入、每個色彩模式，以及投影機實際擁有的每個鏡頭記憶，都會寫成 Home Assistant 指令碼。

  • 自動化可以執行它們。「日落時，如果TV開啟，就執行電影之夜」，一旦場景成為指令碼，這就是一般的 Home Assistant 自動化。
  • 語音助理可以執行它們。把指令碼公開給您的助理，說「開啟電影之夜」就能同時設定輸入、畫面模式與鏡頭記憶。
  • 只會出現您真正有的控制項。App 會為投影機回報的每個輸入、色彩模式與鏡頭記憶寫入指令碼，而不是猜測的通用清單。
  • 移除同步只會移除 App 所寫入的內容。關閉同步，或使用「移除孤立指令碼」（會列出並先詢問），Projector Pilot 就只會刪除它自己建立的指令碼，其餘一概不動。
指令碼的命名方式讓重新命名後仍會更新同一個。指令碼名稱由投影機與控制項衍生，因此重新命名場景後再次同步，會更新既有的指令碼，而不是分岔出第二份副本。
儀表板

同步會為您建立儀表板

您不必再手動建立 Lovelace 檢視，也不必再自己貼上。當您點選與 HA 同步時，App 會透過 Home Assistant 自己的 API，直接在其中建立完整的 Projector Pilot 儀表板：包含投影機的即時狀態，以及每個已同步場景與控制項各一顆按鈕。它會以Projector Pilot 的名稱出現在 Home Assistant 側邊欄，開啟即完成。

  1. 在 App 中登入 Home Assistant。
  2. 將 App 的複製區塊貼入 configuration.yaml 一次，並重新啟動 Home Assistant（這是唯一需要手動的步驟，因為 Home Assistant 不允許 App 遠端新增該指令）。
  3. 點選與 HA 同步。儀表板會自動為您建立，並以Projector Pilot 的名稱出現在側邊欄。
想自己貼上？Home Assistant 畫面上仍保留複製儀表板。點選它，然後在 Home Assistant 中前往設定 › 儀表板 › 新增儀表板，建立空白儀表板，開啟其三點選單 › 編輯儀表板 › 三點選單 › 原始設定編輯器，並貼上複製的 YAML。

不論是自動建立還是自己貼上，儀表板都是一樣的：一張狀態卡片，加上每個控制項各一顆按鈕（示意片段）：

views:
  - title: Projector
    cards:
      - type: entity
        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_power_on
      - type: button
        name: Movie Night
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_scene_movie_night

僅為範例。您的儀表板會帶有您投影機的真實實體與您自己的場景。

不限機型。儀表板是依您的投影機自身的功能建立：它實際回報的實體、畫質數值、輸入、色彩模式、鏡頭記憶與場景。此處的截圖是 QB1000；您的機型可能會顯示不同的輸入、控制項與讀數。若要打造如圖中那樣完整的綠色玻璃質感面板，請依照逐步儀表板指南，或下載完整檢視並改兩個字串。
想要更豐富的牆面？同樣的指令碼可以驅動您喜歡的任何卡片。如果您用過 AVR Maestro，做法完全相同：以同一個感測器和已同步的指令碼，打造亮起的訊號源與模式方塊、即時標題與歷程。
Hubitat

設定 Hubitat

在 Hubitat 上，Projector Pilot 會透過 Maker API 把投影機鏡像到您中樞上的裝置，讓 Rule Machine 能讀取電源、靜音與輸入並據此動作。

  1. 在 Hubitat 中啟用 Maker API 應用程式，記下它的存取 URL與權杖，並選擇它要公開哪些裝置。
  2. 在 Projector Pilot 中開啟設定 › 居家自動化 › Hubitat，並輸入您中樞的 Maker API 詳細資料。
  3. 選擇代表投影機的裝置。App 會建議最可能的那一個；您可以直接選用，或自行選擇。
  4. App 會把電源、靜音與輸入鏡像到該裝置，並且只傳送該裝置接受的指令。
  5. 像處理其他裝置一樣，針對該裝置建立 Rule Machine 規則，由投影機的狀態來驅動它們。
只傳送裝置接受的內容。只有在所選裝置支援該指令時，App 才會把投影機的值傳送到 Hubitat，因此絕不會推送裝置會拒絕的內容。
Webhook

設定 Webhook

Webhook 是萬用的做法。當投影機開機、關機、切換輸入或叫出場景時，App 會向您的 URL發送 POST 請求：可以是 Home Assistant 的 Webhook、Node-RED、IFTTT，或任何接受 JSON 的服務。

  1. 開啟設定 › 居家自動化 › Webhook。
  2. 輸入要發送請求的URL。Home Assistant 的 Webhook 看起來像 http://homeassistant.local:8123/api/webhook/your-id。
  3. 選擇哪些事件會觸發 Webhook：開機、關機、輸入變更、叫出場景，也可以選擇性地篩選特定的輸入或場景。
  4. 如果接收的服務需要特定格式，可選擇性地設定自訂 Payload；否則 App 會傳送預設的 JSON。
  5. 儲存。從此每個符合條件的事件，App 都會發送請求。

預設的 Payload 是單純的 JSON，包含事件、投影機，以及變更的值：

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

範例 Payload。輸入變更或電源事件會帶有與其相關的欄位。

重新連結即可全部修復。如果您把 Home Assistant 重新連結到新位址，App 會一次更新所有指向它的 Webhook，因此搬移執行個體並不代表要逐一手動編輯。

疑難排解

登入後又跳回登入頁面

請確認您輸入的位址，就是實際連到 Home Assistant 的位址，包括連接埠（通常是 :8123）。登入是針對您的執行個體所做的真實瀏覽器登入，因此您的使用者名稱、密碼與雙重驗證碼都適用。在手機上，不論 App 內建瀏覽器先交回結果，還是本機回呼先返回，登入都會完成；如果仍然卡住，請關閉該視窗，再點選一次登入。

Home Assistant 中沒有出現投影機感測器

感測器是在 App 開啟且傳送投影機狀態已開啟的期間發布，因此請開啟 App 並確認該開關。接著到 Home Assistant 的開發者工具 › 狀態，以 projector_pilot 篩選。待機中的投影機幾乎不發布資料；喚醒它，讀數就會出現。

缺少已同步的指令碼

指令碼是由與 HA 同步寫入的，它需要 shell_command 區塊已貼入 configuration.yaml 且 Home Assistant 已重新啟動一次。請先執行測試連線，它會告訴您區塊是否存在。然後再同步一次。如果舊的失效指令碼讓清單變得雜亂，請使用移除孤立指令碼。

手機不在身邊時，指令碼在 App 中可以執行，但從 Home Assistant 卻不行

這正是 shell_command 區塊的用途：它讓 Home Assistant 能自行連到投影機的 IP。如果只有在 App 開啟時才能用，很可能是區塊沒有貼上，或貼上後沒有重新啟動 Home Assistant。請以測試連線確認、重新啟動 Home Assistant，然後同步。

FAQ

快速解答

我的手機需要一直連在網路上，Home Assistant 自動化才能執行嗎？

不需要。只要您把那個 shell_command 區塊貼入 Home Assistant 並同步，Home Assistant 就會直接把指令傳送到投影機的 IP 位址。Projector Pilot 只是設定工具；之後 Home Assistant 會自行與投影機通訊，不管您的手機在不在家。

投影機在 Home Assistant 中是如何呈現的？

以感測器的形式呈現，例如 sensor.projector_pilot_epson_qb1000b_qb1000w，內含電源、輸入、色彩模式、畫質數值與燈泡使用時數，並在 App 開啟期間，隨變化即時更新。若開啟「同步進階控制」，App 還會為每個場景，以及投影機具備的電源、每個輸入、每個色彩模式與每個鏡頭記憶，各寫入一個 Home Assistant 指令碼。

居家自動化是免費的嗎？

居家自動化是付費的附加功能，一次性購買，與 Projector Pilot Pro 分開計價。購買組合包可同時取得兩者，並享有優惠。請參閱價格頁面。
