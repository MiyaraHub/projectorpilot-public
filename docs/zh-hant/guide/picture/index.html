畫質選單

投影機畫質設定，採用投影機自己的刻度

投影機畫質選單中的所有內容，集中在一個畫面：從亮度到畫面插補。每個數值都是您投影機選單所顯示的數字，而不是它內部的位元組；每次變更後也會從投影機讀回，讓您永遠看到硬體實際保留的數值。

基本項目

亮度、對比、色調、銳利度

  • 亮度與對比：黑位與白位，採用投影機自己的 0-100（或機型專屬）刻度。
  • 色調與飽和度：色彩的平衡與強度。
  • 銳利度：邊緣的清晰度，採用您機型所使用的範圍。

每個控制項都會顯示確切的選單數字。若投影機已宣告某個控制項使用的範圍，App 就會與投影機完全一致地換算；若沒有，則照送出的數字顯示，且該控制項會標示為原始數值，而不是印出一個猜測值。

色彩

色溫與伽瑪

這兩個控制項的行為會依模式而不同，而 App 會遵循投影機，不會把它們一視同仁。

  • 色溫是十四個級距，而不是滑桿：以編號顯示，或在會回報 Kelvin 數值的畫面模式中以 Kelvin 顯示。它是分級設定，因此 App 以級距呈現，絕不會用 0-100 的範圍造成誤解。
  • 伽瑪依畫面模式而定。各模式的選項不同：動態模式提供一個範圍內的級距，電影院模式提供曲線值，自訂模式又不一樣。App 會先根據目前的畫面模式判斷哪一組有效，再提供選項，因此您絕不會看到目前模式無法使用的伽瑪選項。
  • RGB 增益與偏移：白平衡控制項，各自採用投影機自己的刻度，用來調校灰階。
色溫會顯示為選單所顯示的級距（例如 0 到 13），或在顯示 Kelvin 的模式中顯示 Kelvin 數值，而不是位元組，也不是重新換算的值。
進階

影像處理控制項

控制項功能
降噪平滑訊號源的雜訊，採用投影機自己的刻度。
超解析度Epson 的細節增強處理，能讓模糊的訊號源更清晰，又不會產生振鈴效應。
畫面插補在畫面之間進行動態平滑，級別依您的機型支援而定。
RGB 增益／偏移各色彩通道的白平衡，用於校準灰階。
只會顯示您的機型實際提供的控制項，並採用它回報的範圍。投影機沒有的控制項就不顯示，App 絕不會憑空捏造。
誠實原則

HDR 與色彩空間分開呈現

訊號的動態範圍與色彩空間是兩回事，App 也將它們分開看待。BT.2020 不代表 HDR，SDR 也不代表 BT.709。

  • 動態範圍（SDR 或 HDR）與色彩空間（BT.2020、BT.709 等）以不同的欄位顯示。
  • BT.2020 SDR 訊號（在使用 MadVR 等外接色調對應器時很常見）會如實顯示，絕不會被誤標成 HDR10。
  • 每個畫質數值在設定後都會從投影機讀回，因此投影機保留了、或沒有確認的數值，都會直接說明，而不是假設。
畫質記憶

儲存、叫出與重新命名您的畫質記憶

畫質畫面會列出投影機實際擁有的記憶，沿用您在投影機選單上取的名稱。您可以將目前的畫質儲存到某個欄位、重新命名或清除它；若要覆寫已有記憶的欄位，會先詢問。
