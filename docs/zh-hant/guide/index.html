Projector Pilot 使用指南

新增投影機與使用每個畫面所需的一切：儀表板、功能完整的遙控器、完整畫質選單、電動鏡頭、場景，以及真正的居家自動化。每個畫面都會配合您的硬體：App 只顯示您的投影機實際提供的控制項，且每個數值都是從投影機讀回，絕不憑空猜測。因此您的畫面上可能比這裡列出的選項更少，這是 App 在誠實以對，而不是故障。

瀏覽指南

每個畫面，逐一說明

先從「開始使用」著手，再深入任何畫面。這裡的一切都不需要雲端帳號：Projector Pilot 在您自己的網路上，透過 ESC/VP21、PJLink 與 Epson Web Control 與投影機通訊，並使用任何有回應的那一種。

新增您的投影機

掃描網路或以 IP 新增，執行一次性的功能偵測，測試連線並儲存。只要在同一個 Wi-Fi 下，約一分鐘即可完成。

閱讀儀表板

即時顯示電源、輸入、色彩模式與投影資訊，卡片可自行新增、隱藏與重新排序，打造您想要的檢視。
