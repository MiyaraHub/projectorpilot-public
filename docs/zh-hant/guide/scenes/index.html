投影機場景：整個空間，一鍵到位

場景會依投影機此刻的樣子精確擷取，之後只要點一下就能全部還原。電影之夜、重要賽事、明亮的週日午場，各有各的場景，各自一鍵即達。您可以精確選擇場景要保留哪些部分，而且只會提供您的投影機實際回報的部分。

場景屬於 Projector Pilot Pro 的一部分。

如何儲存場景

先設定好空間，再擷取

  1. 先設定好。把投影機調整成您想要的樣子：輸入、色彩模式、畫質、鏡頭記憶，全部都包括。
  2. 儲存目前設定。在場景分頁點選儲存目前設定，替場景取個名字，並勾選要保留哪些部分。選擇器只會提供您的投影機回報的內容，因此您絕不會儲存機型沒有的設定。
  3. 叫出。點選場景即可套用。Projector Pilot 會邊執行邊向投影機確認每項設定，絕不會宣稱某項沒有生效的變更已完成。
場景會擷取什麼

您勾選多少就保留多少

單一場景可以擷取以下任何內容。叫出時只會重現您勾選的部分，因此「深夜場」場景可以降低光輸出，其他一概不動。

電源

投影機的電源狀態，讓場景可以把它喚醒，或在設定過程中送它進入待機。

輸入

場景要切換到的訊號源，讓「電影之夜」每次都落在正確的 HDMI。

畫質

色彩模式與畫質數值，各自採用投影機自己的選單刻度。

訊號

您的投影機針對所觀看內容所提供的訊號端設定。

光源

光源輸出，讓明亮的房間與昏暗的房間各有各的設定。

幾何校正

讓畫面在螢幕上正確取景的對齊與幾何狀態。

音訊

投影機回報的音訊設定，與其他設定一併保存。

只保留有回報的內容

勾選清單是依據您的投影機實際回應的內容建立，因此您儲存的一切都不是猜測。

自動化

每個場景都變成 Home Assistant 指令碼

只要把一段區塊貼入您的 Home Assistant 設定一次，Projector Pilot 就會為您擁有的每個場景寫入一個指令碼，並為投影機實際具備的電源、每個輸入、每個色彩模式與每個鏡頭記憶也各寫一個。之後自動化或語音助理就能執行任何場景；當您關閉同步時，App 會移除它所寫入的指令碼，其他一概不動。

場景也能透過 Webhook 運作：叫出場景時可以向您的 URL發送請求；並透過 Maker API 鏡像到 Hubitat。全都收錄在 Home Assistant 指南中。
