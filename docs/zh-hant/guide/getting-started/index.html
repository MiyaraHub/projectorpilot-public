入門指南

約一分鐘，新增您的 Epson 或 PJLink 投影機

Projector Pilot 直接在您自己的網路上找到投影機，不需要雲端帳號，也不用配對碼。讓手機連上同一個 Wi-Fi，新增一次投影機，App 就會掃描它的功能並記住。完整流程如下。

開始之前

您需要準備的東西

  • 同一個網路。您的手機、平板或電腦必須與投影機位於同一個 Wi-Fi（或有線 LAN）。App 會在該網路上直接與投影機通訊。
  • 投影機已開機或處於待機。請讓投影機保持開機，或在已啟用網路控制的情況下待機。大多數 Epson 機型在待機時仍會回應，因此您可以從 App 開機。
  • 投影機的 IP 位址（僅在手動新增時需要）。它位於投影機自己的網路選單中，查詢位置請見下方說明。
手邊沒有投影機？在第一個畫面點選探索示範模式，整個 App 就會對著一台擷取自真實 Epson QB1000 的投影機運作，它的回應就和真機一樣，讓您在購買前就能試用每個畫面。
逐步說明

新增投影機

開啟新增投影機，選擇您想用的尋找方式。兩種方式最後都會到同一個地方。

  1. 選擇掃描網路或以 IP 新增。掃描網路會在您的 Wi-Fi 或有線 LAN中尋找任何以投影機身分回應的裝置，並自動填入位址。如果您想自己輸入位址，就選以 IP 新增。
  2. 選擇您的投影機，或輸入它的 IP。掃描後，從清單中點選投影機即可。手動新增時，輸入投影機網路選單中顯示的 IP 位址後繼續。
  3. 讓功能偵測跑完。第一次新增時，App 會探測投影機，並顯示進度列讓您看到進度。它是在詢問投影機實際支援什麼：哪些通訊協定有回應、有哪些控制項、鏡頭與畫質的範圍，因此 App 只會顯示真正可用的控制項。
  4. 點選測試連線。App 會確認能否連上投影機，並讀回它的身分資訊。如果投影機需要 Web Control 密碼，請在此輸入；App 會自行判斷是否真的需要密碼，並告訴您結果。
  5. 儲存。投影機就新增完成，且功能偵測結果會被記住，下次再開啟 App 時不會重新掃描。您會進入儀表板，看到即時讀取的資料。
每台投影機只會掃描一次，結果會被快取。這就是第二次啟動如此快速的原因：App 已經知道您的硬體能做什麼。
尋找位址

投影機的 IP 在哪裡

如果以 IP 新增，您需要投影機在網路上的位址。所有 Epson 機型都把它放在相同的位置。

  1. 在投影機上開啟螢幕選單，前往網路（部分機型為「擴充設定」 › 「網路」）。
  2. 開啟網路設定 › 有線 LAN或無線 LAN，查看IP 位址。
  3. 把該位址輸入到以 IP 新增。建議在路由器上為它設定固定或保留的位址，這樣位址就不會在 App 不知情的情況下改變。
網路設定在投影機上，不在 App 裡。Projector Pilot 是透過該網路連到投影機，因此網路頁面會以清楚的唯讀檢視呈現；若要變更位址，請在投影機自己的介面上操作。
如果無法連線

快速排解

  • 再確認一次網路。手機如果切換到訪客 Wi-Fi 或行動網路，就看不到投影機。兩端必須在同一個網路。
  • 喚醒投影機。網路待機功能關閉的機型，在開機前不會有回應。請先開機一次，再新增它。
  • 出現密碼提示？請輸入 Web Control 密碼（也就是投影機自己的網頁會要求的那一個）。投影機另外的密碼由 App 處理，請參閱遙控器指南。
  • 只支援 PJLink 的投影機？那只是一般的裝置。App 會退而使用任何有回應的傳輸方式，因此沒有 Web Control 的投影機一樣能用。
