Home Assistant 儀表板

Home Assistant 中的投影機儀表板

輕點一下，就能在 Home Assistant 中為您的 JVC 投影機建立完整的儀表板:電源、狀態、畫質選項、您的情境、輸入、鏡頭記憶、訊號讀數等。它是根據您的 Home Assistant 實際擁有的內容建立，且不保存任何位址或密碼。此功能需要家庭自動化附加元件。

傳送之前

需求

  • 已連結 Home Assistant，且投影機已加入 JVC Projector 整合。請參閱 Home Assistant 設定。
  • 已同步指令碼，如果您想要情境、電源、輸入、鏡頭記憶與控制按鈕。儀表板會使用已存在的指令碼。
  • 已開啟即時狀態感測器，以顯示狀態與讀數方塊。
  • Home Assistant 中的管理員帳號，因為建立儀表板需要管理員權限。沒有的話，Home Assistant 會拒絕，App 也會告知。
兩種方式

傳送或複製

  • 傳送儀表板會在 Home Assistant 的側邊欄中建立儀表板，標題為您的投影機名稱，並使用投影機圖示。再次傳送即可更新。與 Home Assistant 同步時也會一併傳送。
  • 複製儀表板不會傳送任何內容。它會複製儀表板，讓您自行貼到新儀表板的原始設定編輯器中，並隨意修改。
每台投影機都有自己的儀表板，其位址以 projector-pilot-jvc- 開頭，因此兩台投影機絕不會互相覆寫。
版面配置

上面有什麼，由上到下

區段只有在有內容時才會出現，因此沒有鏡頭記憶的投影機就不會有鏡頭記憶區段。

區塊內容
標頭投影機的名稱、狀態最近一次更新的時間、電源、狀態與光源使用時數。
畫質輸入，以及 Home Assistant 為投影機提供的畫質選項，例如畫面模式、光源功率、動態控制、Clear Motion Drive、變形、HDR 處理與安裝模式，前提是您的機型提供且已啟用。
場景每個情境指令碼一個按鈕。
電源電源指令碼。
輸入輸入指令碼。
鏡頭記憶您的機型所擁有的每個鏡頭記憶欄位各一個按鈕。
控制其他控制指令碼，例如畫面模式與隱藏。
訊號解析度、色彩深度、色彩空間、色度測定與 HDR，依 Home Assistant 回報的內容顯示。
讀數App 已讀取的設定，來自即時狀態感測器。
外觀

核心卡片或樣式化外觀

核心

僅使用 Home Assistant 自己的卡片建立。可在任何 Home Assistant 上運作，不需安裝任何東西。

樣式化

使用來自 HACS 的 button-card、card-mod 與 Mushroom 卡片，呈現更豐富的外觀。只有在三者都存在時才會使用。

若三者中缺少任何一個，App 會傳送核心版本，並告訴您為了樣式化外觀要從 HACS 安裝哪些卡片。安裝後再傳送一次即可。

刻意保持誠實

為什麼有些東西不在上面

  • 沒有儀表。JVC 並未提供 Home Assistant 所回報數值的範圍，因此儀表板不會繪製需要憑猜測的儀表。
  • 沒有位址或密碼。儀表板只保存實體 id、名稱與標籤。
  • 沒有憑空捏造的實體。只有在您的 Home Assistant 中真的存在該實體或指令碼時，才會出現對應的方塊。
出問題時

訊息

  • 儀表板已傳送。請從 Home Assistant 側邊欄開啟它。
  • 被拒絕。Home Assistant 拒絕了儀表板:請使用管理員帳號登入，然後再傳送一次。
  • 登入不被接受。請重新登入，然後傳送儀表板。
  • 無回應。Home Assistant 沒有回應，因此儀表板未獲確認。請檢查連線，然後再傳送一次。
  • 不允許。選取示範投影機，或尚未解鎖家庭自動化時，不會有任何內容離開裝置。
儀表板是透過 Home Assistant 的 JVC Projector 整合來控制投影機，而該整合只有在此 App 未連線到投影機時才能連上它。使用儀表板之前，請先關閉 App。
