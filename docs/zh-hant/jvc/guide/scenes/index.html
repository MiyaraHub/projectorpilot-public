場景

輕點一下，整套設定到位

情境會以名稱(例如「電影之夜」)儲存投影機目前的設定，並能輕點一下就全部還原。情境屬於各台投影機，且屬於 Pro。

建立

儲存目前的設定

  1. 把投影機調整成您想要的樣子。
  2. 在「情境」分頁中，點選儲存目前設定。
  3. 為它取一個最多 30 個字元的情境名稱。
  4. 在要擷取的內容下，選擇情境要包含哪幾組設定。
  5. 儲存。每台投影機最多可保存 20 個情境。
情境包含什麼

擷取的分組

情境只會擷取您的機型提供的設定。

群組涵蓋
電源投影機是否應該開機。
輸入來源要切換到的輸入。
色彩模式與畫質畫面模式與畫質設定。
訊號與 HDR訊號與 HDR 設定。
光輸出量光輸出量設定。
幾何校正變形鏡頭設定。
套用

輕點即套用

輕點一下就會立即套用情境，不需確認。會讓投影機開機的情境，會先等投影機暖機完成，再傳送其餘設定。

完成後，報告會列出每項設定的結果，因此情境絕不會謊報它做到的事:

  • 已套用:投影機已接受。
  • 被拒絕:投影機拒絕了它。
  • 未確認:投影機沒有確認，因此不確定是否已生效。
  • 被另一項設定限制:另一項設定使它目前無法套用，例如沒有 HDR 訊號時的 HDR 處理。
  • 不支援:此機型不提供它。
管理

按住方塊以查看選項

  • 套用，與輕點的效果相同。
  • 以目前設定更新，把投影機目前的狀態儲存到情境中。
  • 重新命名與變更圖示與顏色。
  • 匯出與分享，說明如下。
  • 刪除，會立即生效。
  • 拖曳方塊即可排成您想要的順序。
分享

情境檔案

「匯出與分享」會把情境寫成 .ppscene 檔案，這是一個小型 JSON 檔，可以傳送到另一台裝置或給另一個人。

  • 內容。情境及其設定，以及檢查碼。不含位址、密碼或 MAC 位址。
  • 匯入。開啟情境檔案，或貼上情境文字。
  • 另一個機型。匯入時會顯示哪些「可在此套用」，哪些「在此機型上略過」，因此來自不同投影機的情境，只會帶入您的投影機能接受的部分。
應用程式之外

智慧家庭中的情境

  • 儀表板的「情境」卡片與「投影機情境」小工具，可從第一個畫面或主畫面套用情境。
  • 搭配家庭自動化時，套用情境會觸發「套用某個情境時」觸發，可針對任何情境或特定情境。
  • 每個儲存的情境都可以成為 Home Assistant 中的指令碼，而 Home Assistant 儀表板會把它們顯示為按鈕。
情境只保存在此裝置上。備份與還原不包含它們；請把想保留的情境匯出為檔案。
點子

值得儲存的情境

  • 電影之夜。電源、播放器使用的輸入，以及您的電影畫面模式。
  • HDR 電影。畫質加上「訊號與 HDR」組，用於您觀看 HDR 光碟時的設定。
  • 白天觀看。針對不是完全黑暗的房間，提高光輸出量。
  • 寬螢幕。幾何組，用於變形鏡頭設定，並搭配從鏡頭分頁或儀表板呼叫的鏡頭記憶。

每個情境只包含您勾選的組別，因此小型情境只會變更它所指名的內容。

常見問題

情境相關問題

我可以儲存多少個情境?

每台投影機最多 20 個。

情境會移動鏡頭嗎?

不會。情境包含上方列出的組別。請從鏡頭分頁、儀表板的「鏡頭記憶」卡片或 Home Assistant 指令碼呼叫鏡頭記憶。

投影機拒絕某項設定時會怎樣?

套用後的報告會把它列為「被拒絕」，情境的其餘部分仍會套用。

我可以把情境分享給使用其他機型的朋友嗎?

可以。把它匯出為 .ppscene 檔案。對方匯入時，App 會顯示哪些適用於他們的機型，哪些被略過。
