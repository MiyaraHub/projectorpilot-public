畫質

畫質設定，從投影機讀取

畫質分頁包含您的機型所記載的影像設定，分為三個頁面:畫質、訊號與顯示。每個數值都是從投影機讀取，每次變更也都會讀回確認。這一切都屬於 Pro。

畫質頁面

影像本身

  • 畫面模式，以及在支援的機型上編輯畫面模式名稱。
  • 色彩:色彩設定檔、色溫及其校正、紅綠藍的增益與偏移，以及伽瑪與伽瑪校正。
  • HDR:內容類型、HDR 處理、HDR 等級、自動色調對應與對應等級。
  • 光源:雷射功率(燈泡機型為燈泡功率)、LD 電流值、動態控制、深黑與智慧鏡頭光圈。
  • 動態與延遲:Clear Motion Drive、動態增強與低延遲。
  • 調整:對比、亮度、色彩、色調、畫面色調、亮部位準與暗部位準、NR、增強、平滑等。
您會看到哪些項目取決於機型。2024 機型與 2018 機型所記載的設定不同，App 會為每個機型顯示它自己的清單。
色彩管理

色彩軸(ISF 校色)

在支援的機型上，色彩軸卡片包含色彩管理，以及六種顏色各自的軸位置、色相、飽和度與亮度。

訊號頁面

輸入的讀取方式

  • HDMI 輸入位準與 HDMI 色彩空間。
  • 依訊號設定畫面模式:HDR10 畫面模式、SDR(2D) 畫面模式、SDR(3D) 畫面模式與 HLG 畫面模式，讓每種訊號都以您選擇的模式開啟。
  • FILMMAKER MODE 設定與 ALLM(自動低延遲模式)。
  • 含 3D 設定的 3D 卡片。
顯示頁面

取景與選單

  • 長寬比、遮罩與畫面位置，包含水平與垂直。
  • 遮罩邊緣:上、下、左、右。
  • 螢幕選單:背景色、選單位置、來源顯示、Logo、語言、OSD 深色模式與 OSD 亮度同步。
  • 面板對齊與像素調整。
變更數值

清單、按鈕與滑桿

  • 選項，例如畫面模式或伽瑪，提供您的機型為它所記載的數值。
  • 位準使用減號與加號按鈕。按住按鈕即可重複:400 ms 後開始，之後每 300 ms 步進一次。
  • 滑桿只出現在 JVC 宣告了範圍的地方。目前只有 LD 電流值，範圍為 0 到 100%。
連動的設定

當另一項設定限制某個控制項時

有些設定只在特定條件下適用。App 會遵循這些規則，因此無法生效的控制項會被停用，並顯示「在目前的低延遲設定下無法使用」，或是限制它的任何設定。不會傳送任何內容。

設定可變更的條件
HDR 處理輸入訊號為 HDR、HDR10+、HLG 或 ST2084。
動態控制低延遲為關閉。
Clear Motion Drive，包括其遙控按鍵低延遲為關閉。
遮罩邊緣遮罩為開啟。
若 App 尚未讀取會限制某個控制項的設定，就不會封鎖任何內容。
如實的讀數

訊息的意思

  • 「此投影機不回應此設定。」投影機在開機時持續不回應，因此該控制項被停用。
  • 「投影機不回報此設定。」可以設定，但投影機不會告知目前的數值。
  • 「投影機未確認該指令。不確定是否已生效。」App 隨後會再次讀取該設定，讓畫面顯示投影機實際保有的值。
  • 需要您先確認的數值只會從它自己的卡片、在您確認之後才傳送。
  • 待機。大多數畫質設定會在投影機開機後才出現。
儲存起來

保留您喜歡的畫面效果

情境會擷取畫面模式與您的機型提供的其他畫質設定，並能輕點一下就還原。
