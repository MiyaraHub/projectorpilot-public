畫質

畫質選單

三個分頁：畫質、訊號與顯示。

畫質頁面

您的機型所記載的設定

  • 畫質：畫面模式、伽瑪、色溫、色彩設定檔，以及您的機型提供的其他畫質設定。
  • 訊號與顯示：內容類型、HDR 等級、動態、長寬比，以及您的機型相關的設定。
  • 每項設定都來自該機型的 JVC 指令表，因此每個機型只會看到它所支援的項目。
  • 投影機不會回報的設定，會顯示為已傳送，而非已讀取。
畫質設定需要 Pro。
