入門指南

新增您的投影機

App 會在您自己的網路上尋找 JVC D-ILA 投影機，並透過 TCP 連接埠 20554 直接與它們通訊。設定時需要掃描或輸入 IP 位址，若投影機設有網路密碼，也需要輸入密碼。

首次啟動

歡迎畫面

  1. 歡迎使用 Projector Pilot D-ILA。簡短導覽免費版有哪些功能、Pro 增加了什麼，以及哪裡可以取得協助:加入 Discord，或透過郵件寄送記錄檔。
  2. 分析。App 會詢問是否可以傳送匿名使用分析。除非您同意，否則一律關閉，之後也能在設定的「關於」中變更。
  3. 開始之前。檢查清單:手機與投影機位於同一個區域網路；投影機以 LAN 連接埠連線，若設有網路密碼也請備妥；以及投影機的 IP 位址，可在其網路設定中查看。
  4. 新增投影機。選擇「掃描網路」、「以 IP 新增投影機」或「探索示範模式」。
選項 1

掃描網路

  • 搜尋範圍。您的裝置所在的每個私有位址範圍，即該 /24 子網路的位址 1 到 254，連接埠為 20554。
  • 判斷方式。JVC 投影機會對新的連線打招呼；掃描會把有回應的裝置列為就緒，或列為正由其他控制器使用。進度會顯示已檢查的位址數與總數。
  • 沒有任何回應時。「此網路上沒有 JVC 投影機回應。」若投影機已被其他控制器(例如 Home Assistant)連線，就不會回應掃描，請改以位址新增該投影機。
  • 沒有 Wi-Fi。若裝置沒有區域網路，掃描會顯示「找不到區域網路。請連線到 Wi-Fi 後再掃描一次。」
選項 2

以 IP 位址新增

當掃描找不到投影機，或投影機位於您的裝置仍可連到的另一個子網路時，請使用此方式。

  1. 名稱:為投影機命名，例如以它所在的房間命名。
  2. IP 位址:投影機的 IPv4 位址，可在其自身的網路選單中找到。不接受主機名稱。
  3. 網路密碼:投影機上設定的密碼。若投影機沒有設定網路密碼，請留空。
  4. 測試連線。測試成功時會顯示「已連線。」以及投影機回報的機型。
  5. 儲存。投影機會出現在儀表板上。重複儲存同一台投影機會被拒絕，並顯示「此投影機已經儲存。」
新增畫面使用標準連接埠 20554。若要使用其他連接埠，請執行下方的引導式設定:其中的「控制連接埠」欄位會把連接埠帶入新增畫面。
選項 3

引導式設定與診斷

「連線有問題?執行引導式診斷」會開啟「設定投影機」。輸入投影機 IP 位址與控制連接埠(除非您更改過，否則為 20554)，然後選擇「診斷連線」。

檢查項目證明了什麼
與投影機位於同一網路您的裝置與投影機位於同一個子網路，可以互相看見。
控制連接埠可連通控制連接埠上有東西接受連線。
投影機交握與密碼它的回應與 JVC 投影機相同，而且密碼(若有)已被接受。

三項全部通過時，結果為「連線正常」，並附有「新增此投影機」按鈕。若有一項失敗，畫面會指出是哪一項，並顯示「發生了什麼事」與「如何解決」。若投影機需要密碼，會就地出現網路密碼欄位與「嘗試密碼」按鈕。每一種診斷結果都列在說明頁面。

密碼

網路密碼

  • 是哪一個。在投影機自身網路選單中設定的網路密碼。App 本身沒有帳號。
  • 2024 與 2025 機型使用 8 到 10 個字元；App 會在傳送任何內容之前先檢查長度。它會先嘗試 SHA-256 形式，再嘗試純文字形式。
  • 2018 與 2021 機型只有在投影機要求時才會送出密碼。更早的機型則一律不送。
  • 保存位置。存放在裝置的安全儲存空間中，僅限此裝置，且不會納入備份。
  • 變更密碼。在儀表板上開啟投影機的選單，然後選擇「變更密碼」。
單一控制器

一次只能一個 App

JVC 投影機一次只服務一個網路控制器。當 Projector Pilot D-ILA 連線時，Home Assistant、控制系統或另一支手機就無法連上它，反之亦然。

  • 2024 與 2025 機型會保持一條連線；較舊的機型則是每個指令各連線一次。
  • App 進入背景時會釋放投影機，讓其他控制器可以接手。
  • 連線中斷時，它會在 3、5、8 秒後重試，之後每 10 秒重試一次，網路恢復時則立即重試。密碼錯誤後不會重試。
新位址

投影機換位址時

App 在連線時會記住投影機的 MAC 位址。若連續三次連線都沒有連到任何裝置，狀態會顯示「正在搜尋網路」，App 會在子網路中尋找該 MAC 位址，最多三次。若恰好只有一台投影機符合，就會把儲存的位址移到那裡並重新連線。若要自行設定位址，請從投影機的選單中選擇「編輯連線」。

手邊沒有投影機

示範投影機

  • 「探索示範模式」會新增一台示範投影機，它在裝置本身上模擬，標有「示範」與「在此裝置上模擬，沒有硬體」。
  • 它會自稱為 2024 機型，並執行很短的暖機與冷卻時間，因此狀態卡片的行為就和真實投影機一樣。
  • 它的所有功能都已解鎖，而且不會計算方向鍵的按壓次數。
  • 它絕不會向自動化觸發、Hubitat 或 Home Assistant 傳送任何內容，也絕不會掃描網路。
  • 請從其選單或設定中，使用「關閉示範」將它移除。
