入門指南

新增您的投影機

App 會在您自己的網路上找出 JVC D-ILA 投影機，並直接與其通訊。

新增投影機

掃描或輸入位址

  • 網路掃描會在您自己的 /24 子網路中尋找投影機。
  • 掃描找不到時，可以 IP 位址新增。預設連接埠為 20554。
  • 網路密碼：即投影機上設定的密碼。密碼儲存在裝置的安全儲存空間中，僅限本裝置使用，且不會包含在備份內。
  • 依世代調整的交握方式：2024 年機型會先嘗試 SHA-256，再嘗試一般方式。
  • 投影機位址變動時，連續三次連線失敗後，會依 MAC 位址重新找到它。
手邊沒有投影機

示範投影機

  • 示範投影機是在裝置上模擬的，因此不需要任何硬體，也能試用每個畫面。
  • 示範投影機上的所有功能皆已解鎖。自動化觸發不會從示範投影機發出。
