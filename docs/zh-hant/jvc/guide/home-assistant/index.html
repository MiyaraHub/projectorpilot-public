Home Assistant

在 Home Assistant 中設定您的 JVC 投影機

App 會登入您的 Home Assistant，將投影機加入 Home Assistant 自己的 JVC Projector 整合，把您的情境與控制項發布為指令碼，並建立儀表板。您完全不需要貼上權杖或撰寫 YAML。此功能需要家庭自動化附加元件。

一次只能一個控制器

JVC 投影機一次只服務一個網路控制器。當此 App 開啟並連線到投影機時，Home Assistant 就無法連上它。在 App 關閉時，Home Assistant 的投影機控制項與指令碼才能運作，而 App 進入背景時會釋放投影機。

步驟 1

登入

  1. 開啟設定、家庭自動化、Home Assistant。
  2. 輸入您的 Home Assistant 位址，以 http:// 或 https:// 開頭。
  3. 點選登入。Home Assistant 自己的登入頁面會在瀏覽器中開啟；請在該頁面登入後再回來。
  4. 點選測試連線加以確認。
若無法連上 Home Assistant，請檢查位址，並確認此裝置與 Home Assistant 位於同一個網路。
步驟 2

您的 Home Assistant 有什麼

面板會讀取您的 Home Assistant，並將每個部分標示為「已找到」、「未安裝」或「無法確定」。按「重新檢查」會再讀取一次。

部分用途
Mobile App 整合即時狀態感測器。
JVC Projector 整合從 Home Assistant 控制這台投影機。
HACS僅用於儀表板的樣式化外觀。
步驟 3

設定清單

  1. 登入 Home Assistant。
  2. 將此投影機新增至 Home Assistant 的 JVC Projector 整合。點選「新增」。App 會在先詢問您之後，將投影機的位址、連接埠與網路密碼傳送給 Home Assistant 的 JVC Projector 整合。
  3. 啟用指令碼所需的實體。部分 JVC Projector 實體在 Home Assistant 中預設為停用；請點選每一項旁的「啟用」。Home Assistant 可能需要重新載入或重新啟動，實體才會出現。
  4. 即時狀態感測器。開啟「傳送投影機狀態」。下次 App 在連線期間傳送投影機狀態時，就會建立該感測器。
關於密碼。新增投影機時，其網路密碼會傳送到您的 Home Assistant，並儲存在它的 JVC Projector 項目中。App 不會把它傳送到其他任何地方。Home Assistant 連線到投影機期間，App 會釋放投影機，之後再重新連線。
是哪個項目?

App 如何在 Home Assistant 中找到您的投影機

App 會以投影機的 MAC 位址比對 JVC Projector 項目，因此請先至少連線到投影機一次。若 Home Assistant 中沒有該 MAC 的項目，或有多個，檢查清單會說明並告訴您該怎麼做。若投影機換了位址，App 會提議將新位址傳送給 Home Assistant。

感測器

即時狀態

感測器的狀態是 App 最近一次讀取的電源狀態，其屬性則是輸入、機型，以及 App 已讀取的設定。它透過 Mobile App 整合運作，不會向投影機傳送任何內容。只要 App 開啟且已連線，狀態一有變更就會更新。

指令碼

情境與控制

每個儲存的情境都會成為 Home Assistant 中的一個指令碼，透過 JVC Projector 實體執行。指令碼不保存任何位址或密碼。指令碼 id 以 ppjvc 開頭。

  • 與 HA 同步會將您的情境寫成指令碼，並顯示每個指令碼包含幾個步驟，以及有哪些內容被略過與原因。
  • 同步進階控制會發布電源、輸入、畫面模式、鏡頭記憶與隱藏的指令碼。
  • 結果會加以統計:有多少指令碼已同步、有多少被 Home Assistant 拒絕，以及它是否確認已重新載入這些指令碼。
  • 移除孤立的指令碼會刪除此 App 建立、但已沒有任何情境使用的指令碼。它會先列出這些指令碼並詢問您。
若同步所依賴的某項資料尚未讀取，就不會寫入、變更或移除任何內容。同步絕不會憑猜測執行到一半。
儀表板

現成的儀表板

傳送儀表板會根據 JVC Projector 實體、指令碼與感測器，在您的 Home Assistant 中建立投影機儀表板。複製儀表板則改為複製它，讓您自行貼到新的儀表板中。關於它的一切都在Home Assistant 儀表板頁面。

規則

App 絕不會做的事

  • 選取示範投影機，或尚未解鎖家庭自動化時，不會有任何內容離開裝置。
  • 取消連結只會從此 App 移除連結。投影機的裝置與實體仍會留在 Home Assistant 中，直到您在那裡刪除為止。
  • 若 Home Assistant 不再接受登入，App 會告知，並請您重新登入。
