居家自動化

將投影機連接到您的智慧家庭

讓家中其他裝置在投影機開機、進入待機、變更輸入或套用情境時做出反應。設定、家庭自動化底下有三種連結:Webhook 觸發、Hubitat 與 Home Assistant。三者都需要家庭自動化附加元件，可單獨購買或透過組合包取得；單獨的 Pro 不包含它。

擇一使用

該使用哪一種連結

Webhook

任何接受網路請求的系統:Node-RED、家用伺服器、雲端自動化。App 負責傳送，由您決定接下來發生什麼。

Hubitat

透過 Maker API，將電源與輸入單向鏡像到您 Hub 中的某個裝置，供 Rule Machine 據以動作。

Home Assistant

設定 Home Assistant 自己的 JVC Projector 整合、您的情境指令碼，以及現成的儀表板。

Webhook

自動化觸發

當這台投影機發生某件事時，觸發會向您輸入的位址傳送網路請求。每台投影機都有自己的清單。點選新增觸發，然後選擇:

  • 條件:投影機開機、投影機進入待機、輸入變更(變更為任何輸入或特定輸入)，或套用某個情境時(任何情境或特定情境)。
  • 方法:POST(預設)、PUT 或 GET。
  • 網址:含有主機名稱、以 http:// 或 https:// 開頭的位址。
  • 已啟用，可在不刪除觸發的情況下暫停它。
以 http:// 開頭的位址會未經加密傳送，編輯器也會這麼提醒。若您的系統支援，請使用 https://。
內容

請求帶有什麼

POST 與 PUT 會傳送 JSON 本文；GET 則不傳送。App 唯一加入的標頭是 Content-Type。不適用於該事件的欄位會被省略。

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
欄位說明
eventpower_on、power_off、input_changed 或 scene_recalled。
projector投影機在 App 中的名稱。
input輸入，例如 hdmi1 或 hdmi2。
scene_id, scene_name情境，用於套用情境時。
timestamp事件發生的時間，以 UTC 表示。
test只會出現在由「傳送測試」所送出的請求中，且值為 true。
傳送

只嘗試一次，如實回報

  • 每個事件只會傳送一次，限時 10 秒，且不會跟隨重新導向。
  • 觸發會顯示它最近一次的結果:已於某個時間送達並附上狀態碼、被拒絕、無回應、無法連到該位址、安全連線失敗，或尚未傳送。
  • 傳送測試會傳送標示為測試的請求，讓您在投影機執行任何動作之前，就能先接好另一端。
觸發何時啟動

規則

  • 只有在 App 開啟並連線到投影機時才會觸發。App 監看的是投影機的狀態；它不是背景服務。
  • 只看變化，不看讀數。App 連線後的第一次讀取只會設定起始點，因此開啟 App 時，不會對原本就已開機的投影機觸發「開機」。
  • 絕不來自示範投影機。選取示範投影機，或尚未解鎖家庭自動化時，不會有任何內容離開裝置。
  • 安全儲存。觸發位址存放在裝置的安全儲存空間中。
Hubitat

將投影機鏡像到 Hubitat

App 會透過 Maker API，將這台投影機鏡像到您 Hubitat Hub 中的某個裝置:開機與待機，以及輸入(HDMI 1 或 HDMI 2)，以該裝置接受的為準。Rule Machine 之後便能據以動作。

  1. 在 Hubitat 中新增 Maker API，並記下它的 App id(其網址中的數字)與存取權杖。
  2. 在 App 中輸入 Hub 位址、Maker API App id 與存取權杖。
  3. 點選尋找裝置，並挑選代表這台投影機的裝置。若沒有看起來像的，請在 Hubitat 中新增一個以投影機命名的 Virtual Switch，然後再試一次。
  4. 開啟鏡像投影機狀態。只要 App 開啟且已連線，裝置就會在投影機每次變更時跟著變化。
僅限單向。不會從 Hubitat 向投影機傳送任何內容。取消連結會從 App 移除該連結。
Home Assistant

最深入的連結

App 會登入 Home Assistant，將您的投影機加入其 JVC Projector 整合，把您的情境與控制項發布為指令碼，並建立儀表板。它有各自的頁面:Home Assistant 設定與 Home Assistant 儀表板。
