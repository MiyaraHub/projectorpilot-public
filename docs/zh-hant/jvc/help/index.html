FAQ

常見問題

  • App 找不到投影機或無法連線請讓手機與投影機位於同一個網路與子網路；訪客網路與隔離的 VLAN 會讓兩者無法互通。掃描只會檢查您自己的 /24 子網路。若掃描找不到投影機，請以 IP 位址新增。網路控制使用 TCP 連接埠 20554，較新的機型需要使用投影機上設定的網路密碼。
  • App 要求輸入的是哪個密碼？是投影機本身設定的網路密碼。App 會將它儲存在裝置的安全儲存空間中，僅限本裝置使用，且不會包含在備份內。
  • 我的投影機 IP 位址變了連續三次連線失敗後，App 會依 MAC 位址在您的網路上尋找投影機，並重新連線到它的新位址。
  • 我的機型不在清單中清單中沒有的 D-ILA 投影機，仍可使用電源、輸入與遙控按鍵。機型指令表未提供的設定不會顯示，也不會盲目傳送。
  • 是一次性購買嗎？是的。Pro、Home Automation 與組合包皆為一次性購買，無需訂閱，也沒有廣告。您確認前，商店會以您當地的貨幣顯示價格。
  • App 會收集資料嗎？Android 與 iOS 上的當機報告預設為開啟，可在「設定」中的「關於」關閉。使用分析在您同意前保持關閉，且絕不包含投影機的名稱、位址、MAC 或密碼。
支援的機型

機型系列

  • 支援 LAN 的早期機型：DLA-X7、X9、RS50、RS60、X30、RS45、X70R、X90R、RS55 與 RS65。
  • 2018 年：DLA-NX5、NX7、NX9，以及 RS1000、RS2000、RS3000、N5、N6、N8、N11、V5、V7 與 V9R 等型號名稱。
  • 2021 年：DLA-NZ7、NZ8、NZ9、NP5，以及 RS1100、RS2100、RS3100、RS4100、N88、N98、V50、V70R、V80R 與 V90R 等型號名稱。
  • 2024 年：DLA-NZ500、NZ700，以及 RS1200、RS2200、N700、N788、N799、N800、N888、N899、Z5 與 Z7 等型號名稱。
  • 2025 年：DLA-NZ800 與 NZ900。
  • 不支援 LAN 的早期機型，例如 DLA-HD350、HD550、HD750、HD950、HD990、X3、RS10、RS15、RS20、RS25、RS35 與 RS40，無法透過網路控制。
