Projector Pilot 亮點

Projector Pilot 首個正式版本的亮點，依您使用 App 的目的分類。這裡的每一項，今天的 App 都已具備。App 已在 Google Play 上架，其他商店正在等待審核。

Home Assistant

會自動建立並持續運作的 Home Assistant

閱讀 Home Assistant 指南。

  • 與 HA 同步建立的是您的整個儀表板，而不只是指令碼。Home Assistant 畫面上的逐步指南，會帶您完成 Home Assistant 仍要求您自行完成的那一個設定步驟。
  • 可搭配您已有的整合，包括核心 PJLink 整合。安裝了更豐富的 HACS 卡片時，卡片會自動升級。
  • 設定檢查清單會顯示哪些步驟已完成、哪些還缺，以及接下來該做什麼，而重新檢查會告訴您找到了什麼。
  • 最後已知感測器會在投影機關機期間，把您的讀數保留在 Home Assistant 中，而關機也會以關閉的狀態傳到 Home Assistant。
  • 指令區塊會註明是否包含投影機密碼，而新增整合的步驟會顯示 PJLink 的主機與連接埠。什麼都沒安裝？全部手動貼上即可。
  • 移除孤立指令碼會列出將移除的項目，並先詢問。
  • 複製儀表板會依您自己投影機的控制項建立面板，並配合標示燈泡或雷射使用時數。
  • App 內建瀏覽器的登入可以順利完成，並可在您自己的網路上透過一般 HTTP 運作。
日常操作

更快、更穩，也更不容易誤觸

請參閱儀表板指南與鏡頭指南。

  • 每個投影機頁面的頂端列都有投影機切換器，不必回到清單就能在投影機之間切換。
  • 關閉投影機前會先詢問。
  • 鏡頭偏移、對焦、變焦與光輸出調整鈕在您按下的瞬間就會回應，不會閃爍。如果前一個指令還在傳送時又按了一次，該次按壓會被捨棄，而不是排隊等候。
  • 投影機開機後約十秒內，App 就會偵測到，且重新開啟時會顯示「檢查中」，而不是錯誤地顯示「關機」。
  • 只要投影機有回報，韌體版本就會顯示在儀表板與資訊分頁，以及診斷報告中。
  • 鏡頭頁面新增從精細到粗略的步進大小選擇器。鏡頭控制項不會再在沒有鎖定時顯示為已鎖定。
  • 輸入切換現在適用於只透過 PJLink 列出輸入的投影機（例如 TW7300 與 Home Cinema 4040），以及非 Epson 的 PJLink 投影機。
  • 場景可透過 PJLink 喚醒待機中的投影機，並等待其回應後再進行下一步。儲存場景時，可勾選要保留哪些部分。
新增投影機

找到它、新增它、看著它學會您的機型

  • 新增投影機會先掃描您的 Wi-Fi 或有線網路，找出任何以投影機身分回應的裝置，並填入位址。手動輸入 IP 依然可用。
  • 在探索您機型的功能時，進度列會從 0% 爬升到 100%。每台投影機只會掃描一次，並被記住。
  • 新增後，色彩模式、亮度與對比會立即顯示真實的數值。
  • TW7300、Home Cinema 4040 與 5050UB 皆已獲得辨識。
語言與平台

29 種語言，四個平台

  • 英文加上 28 種翻譯，提供語言設定，並為阿拉伯文與希伯來文提供由右至左的版面。iPhone、iPad 與 Mac 上的權限提示也會以您的語言顯示。請參閱語言清單。
  • Android、iOS、Windows 與 macOS。
  • 在 iPad 上也能分享紀錄、報告、場景或備份，且備份檔會以其真實名稱分享。
  • 回報問題會建立一個包含所有相關紀錄的檔案包，隨時可以傳送。
隱私權與密碼

您的資料，由您決定

  • 選用的使用分析預設為關閉。App 只會詢問一次，之後您隨時可在設定 › 隱私權中變更。
  • 三組投影機密碼（Web Control、PJLink 與遙控器）已針對真實投影機在傳輸線路上驗證過，而且當投影機只是不需要密碼時，診斷訊息不會再宣稱它沒有密碼。
