Compatibility

Epson-compatible projector remote

Projector Pilot is an independent remote app that works with Epson projectors and with any PJLink projector, over your own network. Here is which models it is compatible with and what each one exposes.

How it works

Compatible by protocol, not by model list

The app does not ship a list of model numbers. It asks the projector what it supports and shows the controls it answers, so a projector that speaks PJLink or Epson Web Control works even if it is not named below.

  • PJLink (class 1 and 2) gives power, input, mute and lamp or laser status on almost every networked Epson projector.
  • Epson Web Control adds picture settings, lens, keystone and HDR on models that provide it.
  • ESC/VP21 is the projector's own command protocol, used when the projector answers on it.

Before you connect

Turn network control on

  • Put the phone and projector on the same network.
  • Enable PJLink and Web Control in the projector's network menu.
  • Scan for the projector in the app, or add it by IP address.

Setup steps are in Getting Started and Help & FAQ. Using a JVC projector instead? See Projector Pilot D-ILA.
