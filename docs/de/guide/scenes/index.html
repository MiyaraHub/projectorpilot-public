Der Tab Szenen · Pro

Projektor-Szenen: dein ganzer Raum, mit einem Tipp

Eine Szene hält deinen Projektor genau so fest, wie er gerade ist, und holt alles später mit einem einzigen Tipp zurück. Filmabend, das große Spiel, eine helle Sonntagsmatinee - jedes seine eigene Szene, jede einen Tipp entfernt. Du wählst genau, welche Teile eine Szene behält, und es werden nur die Teile angeboten, die dein Projektor tatsächlich meldet.

Szenen sind Teil von Projector Pilot Pro.

So speicherst du eine

Den Raum einstellen, dann festhalten

  1. Einstellen. Bringe den Projektor genau in den gewünschten Zustand - Eingang, Farbmodus, Bild, Objektivspeicher, alles.
  2. Aktuelle speichern. Tippe im Tab Szenen auf Aktuelle speichern, gib der Szene einen Namen und hake an, welche Teile erhalten bleiben sollen. Die Auswahl bietet nur an, was dein Projektor meldet, daher speicherst du nie eine Einstellung, die dein Modell nicht hat.
  3. Abrufen. Tippe die Szene an, um sie anzuwenden. Projector Pilot bestätigt unterwegs jede Einstellung am Projektor und behauptet nie eine Änderung, die nicht angekommen ist.
Was eine Szene festhält

So viel oder so wenig, wie du ankreuzt

Eine einzelne Szene kann jedes der folgenden Dinge festhalten. Beim Abrufen werden nur die angekreuzten Teile wiedergegeben, daher kann eine „Spätvorstellung“-Szene die Lichtleistung senken und alles andere in Ruhe lassen.

Power

Der Betriebszustand des Projektors, damit eine Szene ihn als Teil des Setups aufwecken oder in den Standby schicken kann.

Eingang

Die Quelle, auf die die Szene umschaltet, damit „Filmabend“ jedes Mal auf dem richtigen HDMI landet.

Bild

Farbmodus und die Bildwerte, jeweils auf der Menüskala des Projektors.

Signal

Die signalseitigen Einstellungen, die dein Projektor für den Inhalt bereitstellt, den du ansiehst.

Licht

Ausgabe der Lichtquelle, damit ein heller und ein dunkler Raum je ihre eigene Einstellung bekommen.

Geometrie

Der Ausrichtungs- und Geometriezustand, der das Bild auf deiner Leinwand einrahmt.

Audio

Die Audioeinstellungen, die der Projektor meldet, zusammen mit dem Rest gespeichert.

Nur, was gemeldet wird

Die Ankreuzliste wird aus dem aufgebaut, was dein Projektor tatsächlich beantwortet, daher ist nichts, was du speicherst, geraten.

Automation

Jede Szene wird zu einem Home Assistant Skript

Füge einmal einen Block in deine Home Assistant Konfiguration ein, und Projector Pilot schreibt ein Skript für jede Szene, die du hast, sowie für Ein/Aus, jeden Eingang, jeden Farbmodus und jeden Objektivspeicher, den dein Projektor tatsächlich hat. Eine Automation oder ein Sprachassistent kann dann jede Szene ausführen, und die App entfernt die Skripte, die sie geschrieben hat, wenn du die Synchronisierung ausschaltest, und berührt sonst nichts.

Szenen funktionieren auch über Webhooks - das Abrufen einer Szene kann an eine URL von dir senden - und werden über die Maker API auf Hubitat gespiegelt. Alles steht in der Home Assistant Anleitung.
Teile deine Arbeit

Teilbare Szenenprofile

Eine Szene abgestimmt, auf die du stolz bist? Exportiere sie und gib sie einem Freund, oder importiere eine, die jemand mit dir geteilt hat. Szenenprofile wandern zwischen Installationen, sodass ein gutes Setup nicht auf jedem Projektor von null neu aufgebaut werden muss.
