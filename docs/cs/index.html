Projector Pilot

Pro projektory Epson přes ESC/VP21 a Epson Web Control a pro libovolný projektor PJLink. Android, iOS, Windows a macOS.

  • Napájení, vstup a kompletní nabídka obrazu
  • Motorizovaný posun objektivu, zaostření, zoom a paměti objektivu
  • Scény, přehledy údržby a widgety
  • Home Assistant, Hubitat a webhooky

Projector Pilot D-ILA

Pro projektory JVC D-ILA přes síť, od řady DLA-X po řadu NZ z roku 2025. Android, iOS, macOS a Windows.

FAQ

Otázky a odpovědi

  • Kterou aplikaci potřebuji? Aplikace Projector Pilot je určena pro projektory Epson přes ESC/VP21 a Web Control a pro libovolný projektor PJLink. Aplikace Projector Pilot D-ILA je určena pro projektory JVC D-ILA.
  • Potřebují aplikace účet nebo cloudovou službu? Ne. Obě aplikace komunikují s projektorem ve vaší vlastní místní síti.
  • Jsou to předplatná? Ne. Každá aplikace má bezplatnou verzi a nákupy Pro, Home Automation a balíčku jsou jednorázové.
