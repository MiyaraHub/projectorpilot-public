Projector Pilot 亮点

Projector Pilot 首个正式版本的亮点，按您使用应用时的操作分组。这里的每一条在应用中现已可用。应用已在 Google Play 上架，其他应用商店正在等待审核。

Home Assistant

能自动构建并持续运行的 Home Assistant

阅读 Home Assistant 指南。

  • 与 HA 同步构建的是您的整个仪表盘，而不仅仅是脚本。Home Assistant 界面上的分步指南会告诉您 Home Assistant 仍要求您自己完成的那一个设置步骤。
  • 可与您已有的集成协同工作，包括核心 PJLink 集成。安装了更丰富的 HACS 卡片时，卡片会自动升级。
  • 设置清单会显示哪些步骤已完成、哪些缺失以及下一步该做什么，重新检查则会告诉您它找到了什么。
  • 最近已知传感器会在投影机关机期间，把您的读数保留在 Home Assistant 中，而关机操作也会作为关闭状态传到 Home Assistant。
  • 命令代码块会在包含投影机密码时明确说明，添加集成的步骤会显示 PJLink 主机和端口。什么都没安装？全部手动粘贴即可。
  • 移除孤立脚本会列出它将移除的内容，并先征求您的同意。
  • 复制仪表盘会为您自己投影机的控件构建一个面板，并相应标注灯泡或激光使用时间。
  • 来自应用内浏览器的登录可以顺利完成，并且在您自己的网络中通过普通 HTTP 也能使用。
日常控制

更快、更稳、更不易误触

请参阅仪表盘指南和镜头指南。

  • 每个投影机页面顶栏中的投影机切换器，让您无需返回列表就能在多台投影机之间切换。
  • 关闭投影机前会先确认。
  • 镜头位移、对焦、变焦和光输出步进器在您按下的瞬间就会响应，毫无闪烁。如果上一次发送还没完成时又按了一次，这次按键会被丢弃，而不是排队等待。
  • 应用能在大约十秒内发现投影机已开机，并且重新打开时会提示正在检查，而不是错误地显示关闭。
  • 只要投影机上报，固件版本就会显示在仪表盘和信息标签页中，也会出现在诊断报告里。
  • 镜头页面上的步长选择器，从精细到粗略均可选择。镜头控件不再在未锁定时显示为已锁定。
  • 对于只通过 PJLink 列出信号源的投影机（如 TW7300 和 Home Cinema 4040），以及非 Epson 的 PJLink 投影机，信号源切换同样可用。
  • 场景可通过 PJLink 唤醒待机中的投影机，并在进行下一步之前等待其响应。保存场景时，您可以勾选要保留的部分。
添加投影机

找到它，添加它，看它学习您的机型

  • “添加投影机”首先会扫描您的 Wi-Fi 或有线网络，查找所有以投影机身份响应的设备，并填入地址。手动输入 IP 地址依然可用。
  • 在检测您机型的功能期间，进度条会从 0 爬升到 100%。投影机只会被扫描一次，然后被记住。
  • 添加后，色彩模式、亮度和对比度会立即显示真实数值。
  • TW7300、Home Cinema 4040 和 5050UB 均已能被识别。
语言与平台

29 种语言，四个平台

  • 英语加 28 种翻译，提供语言设置，并为阿拉伯语和希伯来语提供从右到左的布局。iPhone、iPad 和 Mac 上的权限提示也会以您的语言显示。请查看语言列表。
  • Android、iOS、Windows 和 macOS。
  • 在 iPad 上也可以分享日志、报告、场景或备份，备份文件会以其真实名称分享。
  • 报告问题会生成一个包含所有相关日志的压缩包，可直接发送。
隐私与密码

您的数据，由您做主

  • 可选的使用数据分析默认关闭。应用只会询问一次，您可以随时在“设置” › “隐私”中更改。
  • 三个投影机密码（Web Control、PJLink 和遥控）都已在真实投影机上通过线路验证，并且诊断信息不再在投影机只是无需密码时，错误地声称它没有密码。
