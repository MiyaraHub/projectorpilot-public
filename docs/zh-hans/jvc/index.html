功能

您的 D-ILA 投影机所提供的控制功能，尽在手机上。

每个机型都会获得其自身 JVC 指令表中记载的功能。应用会显示您的投影机支持的功能，并隐藏不支持的功能。

电源和信号源

开机和待机、HDMI 1 和 HDMI 2，并实时显示投影机的预热过程。

遥控器

菜单导航、画面模式、内容类型、HDR 级别、伽玛、色温、色彩配置、运动、隐藏和菜单快捷键。

镜头与安装

镜头光圈、长按驱动的位移、对焦和变焦、镜头记忆、安装模式、宽高比和变形。

场景

保存一组设置，一键应用。将场景以 .ppscene 文件分享；导入时会保留机型所提供的设置。

维护

光源使用时间与额定寿命对比、每小时成本、可选择开启的提醒，以及可导出的时长报告。

家庭自动化

针对电源、信号源和场景事件的 Webhook，通过 Maker API 接入 Hubitat，以及带现成仪表盘的 Home Assistant。

支持的投影机

从 DLA-X 到 2025 年的 NZ 系列

  • 43 个机型配置涵盖 64 个 DLA 型号名称，其中 52 个可通过网络控制。
  • 2018 年 NX 系列：DLA-NX5、NX7、NX9，及其 RS 和地区型号名称。
  • 2021 年 NZ 系列：DLA-NZ7、NZ8、NZ9 和 DLA-NP5，及其 RS 和地区型号名称。
  • 2024 年和 2025 年 NZ 系列：DLA-NZ500、NZ700、NZ800 和 NZ900。
  • 早期 LAN 机型，例如 DLA-X7、X9、X30、X70R 和 X90R。
  • 不在列表中的 D-ILA 投影机仍可使用电源、信号源和遥控按键。
常见问题

常见问题解答

  • Projector Pilot D-ILA 支持哪些 JVC 投影机？支持网络控制的 JVC D-ILA 投影机，涵盖带 LAN 接口的 DLA-X 和 DLA-RS 机型、2018 年的 NX 系列，以及 2021、2024 和 2025 年的 NZ 系列。应用包含 43 个机型配置，涵盖 64 个 DLA 型号名称，其中 52 个可通过网络控制。不在列表中的 D-ILA 投影机仍可使用电源、信号源和遥控按键。
  • 我需要账号或云服务吗？不需要。应用通过 TCP 端口 20554，使用投影机自身的网络密码，在您的本地网络中直接与投影机通信。没有账号，也没有云服务。
  • 是订阅制吗？不是。电源、HDMI 1 和一定次数的遥控按键是免费的。Pro、家庭自动化附加包和套装均为一次性购买。
  • 什么时候可以下载？Projector Pilot D-ILA 即将登陆 Google Play、App Store 和 Microsoft Store。目前尚未在任何商店上架。
