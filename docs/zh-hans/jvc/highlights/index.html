连接

找到您的投影机，找不到时说明原因

  • 扫描网络可发现在控制端口上作出响应的 JVC 投影机。
  • 扫描没有发现时，可通过 IP 地址添加。
  • 引导式设置会逐一检查网络、端口和密码，指出第一个失败的环节以及解决办法。
  • 投影机更换到新地址后，应用会通过 MAC 地址重新找到它。
如实的控制

只提供您的型号具有的功能

只有当您的型号命令表列出某个控制项时，应用才会显示它，因此您绝不会点按投影机无法接受的设置。投影机不接受的更改会被报告为未被接受，而不是显示为已完成。“设置”、“关于”、“支持的投影机”列出了应用已知的每个型号，以及应用能控制其中多少。

日常使用

遥控、画面和镜头

  • 遥控：方向键、菜单键、信号源、宽高比和隐藏。参见遥控。
  • 画面：画面模式、HDR、色彩、动态以及您的型号其余的画面设置。参见画面。
  • 镜头：按住时驱动位移、对焦和变焦，并调用镜头记忆。参见镜头。
  • 仪表盘：一目了然地查看电源、信号源、状态和快捷操作。参见仪表盘。
您的家

家庭自动化

投影机开机、进入待机、切换信号源或调用场景时触发 Webhook；通过 Maker API 实现 Hubitat 镜像；以及 Home Assistant 设置：登录、把投影机添加到 Home Assistant 自带的集成、把您的场景发布为脚本并生成仪表盘。参见家庭自动化和 Home Assistant 仪表盘。

无需账户。投影机密码保存在设备的安全存储中，不包含在备份内。使用数据分析在您同意之前保持关闭。诊断报告会省略地址、端口、MAC 地址和密码。参见隐私页面。
