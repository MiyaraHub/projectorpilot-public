帮助 & FAQ

连接、保持连接、支持的型号、购买项目和隐私。大多数连接问题归结为三点：同一网络、投影机处于待机并连着 LAN 网线，以及没有其他控制器占用投影机。

从这里开始

快速检查清单

  1. 投影机已开机，或处于待机状态并连着 LAN 网线。
  2. 手机、平板或电脑与投影机位于同一网络和同一子网，而不是访客网络。
  3. 没有其他设备连接到投影机：Home Assistant、控制系统或本应用的另一份副本。
  4. 如果投影机设有网络密码，请把它准备好。
  5. 从“设置”运行引导式设置。它会逐一检查以上各项，并指出是哪一项失败。
常见问题

常见问题

应用找不到或无法连接我的投影机

请让手机和投影机处于同一网络和同一子网；访客网络、隔离的 VLAN 和客户端隔离会使它们互相无法访问。扫描只查看您自己的 /24 子网。如果扫描没有发现投影机，请通过 IP 地址添加。网络控制使用 TCP 端口 20554，较新的型号需要在投影机上设置的网络密码。

应用要求输入哪个密码？

这是在投影机自身上设置的网络密码，而不是 Wi-Fi 密码。较新的型号使用 8 至 10 个字符。应用把它保存在设备的安全存储中，仅限此设备，并且不包含在备份内。

投影机处于待机状态，应用无法访问它

完全断电的投影机无法响应。请让它保持待机状态，并连着 LAN 网线。在某些型号上，节能待机设置（例如节能模式）会使网络在待机时不再响应；请检查投影机自身的网络和待机设置。

提示另一个控制器已连接

JVC 投影机同一时间只服务一个网络控制器。如果 Home Assistant、控制系统或另一个应用已连接，本应用在其释放之前无法连接，反之亦然。本应用转入后台时会释放投影机。

我的投影机更换了 IP 地址

连续三次尝试失败后，应用会通过 MAC 地址在您的网络中查找投影机，并重新连接到其新地址。这要求之前至少连接过一次，以便知道 MAC 地址。您也可以在“设置”中通过“编辑连接”更改地址。

我的机型不在列表中

未列出的 D-ILA 投影机仍然具备电源、信号源和遥控按键。型号命令表中没有提供的设置不会显示，而不是盲目发送。“设置”、“关于”、“支持的投影机”列出了应用已知的每个型号及其支持级别。

为什么我的投影机上缺少某个控制项？

只有当您的型号命令表列出某个控制项，并且投影机对其作出响应时，应用才会显示它。投影机处于待机或预热期间，控制项也会等待，开机后才会出现。

是一次性购买吗？

是的。Pro、家庭自动化和套装均为一次性购买，无需订阅，也没有广告。确认购买前，商店会以您所在地区的货币显示价格。

如何在新设备上找回我的购买项目？

登录同一个商店账户，然后点按“设置”中 Pro 卡片上的“恢复”。购买项目属于商店账户，而不属于设备。如果没有找到，应用会如实告知。

应用会收集数据吗？

Android 和 iOS 上的崩溃报告默认开启，可在“设置”的“关于”中关闭。使用数据分析在您同意之前保持关闭，并且绝不包含投影机的名称、地址、MAC 地址或密码。

应用在真实的 JVC 投影机上测试过吗？

测试过，在 DLA-NZ500 上：使用网络密码连接、读取其状态并更改设置。其他型号依据 JVC 公布的命令表提供支持，应用只提供每个型号的命令表所列的内容。

故障排除

连接检查告诉您什么

引导式设置和添加界面会检查您输入的地址，并指出第一个失败的环节。每个结果都附有下一步该怎么做。

结果含义怎么做
网络不同手机和投影机位于不同的子网。请让手机与投影机位于同一网络（而不是访客网络），或允许 VLAN 之间的流量。
该地址没有设备该地址没有任何响应。请在投影机的网络设置中核对 IP，并确认它处于待机状态且连着 LAN 网线。
控制端口被拒绝该地址上有设备，但拒绝了控制端口。请检查端口。JVC D-ILA 投影机默认使用 20554。
控制端口无回复端口超时，没有任何回应。投影机可能已完全关闭，可能有其他控制器已连接，或者网络可能阻止设备之间的流量（客户端隔离或 AP 隔离）。
需要密码投影机要求输入网络密码。请输入在投影机上设置的网络密码。
密码未被接受投影机拒绝了该密码。请核对投影机上的密码，然后重新输入。
投影机忙碌另一个控制器已连接。请关闭其他控制投影机的应用或系统，等待几秒后重新检查。
不是 JVC 的回复有设备作出回应，但没有完成 JVC 握手。请检查地址：该端口可能属于另一台设备。
连接期间

您可能看到的提示

  • 此地址的端口 20554 上没有任何响应。投影机不在网络中，或位于另一个地址。
  • 投影机未接受端口 20554 上的连接。要么它不在网络中，要么另一个控制器（例如 Home Assistant）已连接到它。
  • 投影机关闭了连接。投影机结束了会话；应用会自动重新连接。
  • 无法从安全存储中读取已保存的密码。请在“设置”中通过“更改密码”重新设置。
