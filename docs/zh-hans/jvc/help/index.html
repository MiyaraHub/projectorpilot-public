常见问题

常见问题

  • 应用找不到或无法连接我的投影机请让手机和投影机处于同一网络和同一子网；访客网络和隔离的 VLAN 会使两者无法互通。扫描只会查找您自己的 /24 子网。如果扫描找不到投影机，请通过 IP 地址添加。网络控制使用 TCP 端口 20554，较新的机型还需要使用在投影机上设置的网络密码。
  • 应用要求输入哪个密码？即在投影机本机上配置的网络密码。应用将其保存在设备的安全存储中，仅限本设备，且不会包含在备份中。
  • 我的投影机更换了 IP 地址连续三次连接失败后，应用会通过 MAC 地址在您的网络中查找该投影机，并重新连接到它的新地址。
  • 我的机型不在列表中不在列表中的 D-ILA 投影机仍可使用电源、信号源和遥控按键。机型指令表中没有提供的设置不会显示，也不会盲目发送。
  • 是一次性购买吗？是的。Pro、家庭自动化和套装均为一次性购买，无需订阅，也没有广告。确认购买前，商店会以您所在地区的货币显示价格。
  • 应用会收集数据吗？Android 和 iOS 上的崩溃报告默认开启，可在设置的“关于”中关闭。使用数据分析在您同意之前保持关闭，且绝不包含您的投影机名称、地址、MAC 或密码。
