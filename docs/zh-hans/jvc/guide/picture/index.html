画面

画面菜单

三个标签页：画面、信号和显示。

画面页面

您的机型文档中记载的设置

  • 画面：画面模式、伽玛、色温、色彩配置，以及您的机型提供的其他画面设置。
  • 信号和显示：内容类型、HDR 级别、运动、宽高比，以及您的机型的相关设置。
  • 每项设置都来自该机型的 JVC 指令表，因此每个机型只会看到它所支持的设置。
  • 投影机不回报的设置会显示为“已发送”，而不是“已读取”。
画面设置需要 Pro。
