画面

画面设置，读取自投影机

“画面”标签页包含您的型号有文档记载的图像设置，分为三个页面：画面、信号和显示。每个数值都读取自投影机，每次更改都会读回确认。全部属于 Pro。

画面页面

图像本身

  • 画面模式，以及在支持的型号上编辑画面模式名称。
  • 色彩：色彩配置、色温及其校正、红绿蓝的增益和偏移，以及伽玛和伽玛校正。
  • HDR：内容类型、HDR 处理、HDR 级别、自动色调映射和映射级别。
  • 光：激光功率（灯泡型号为灯泡功率）、LD 电流值、动态控制、深黑和智能镜头光圈。
  • 动态与延迟：Clear Motion Drive、运动增强和低延迟。
  • 调整：对比度、亮度、色彩、色调、画面色调、亮电平和暗电平、降噪、增强、平滑等。
您看到哪些内容取决于型号。2024 年款型号和 2018 年款型号所记载的设置不同，应用会为每个型号显示其各自的列表。
色彩管理

色彩轴（ISF 校准）

在支持的型号上，“色彩轴”卡片包含色彩管理，以及六种颜色各自的轴位置、色相、饱和度和亮度。

信号页面

如何读取信号源

  • HDMI 输入电平和 HDMI 色彩空间。
  • 按信号设置画面模式：HDR10 画面模式、SDR(2D) 画面模式、SDR(3D) 画面模式和 HLG 画面模式，让每种信号都以您选择的模式打开。
  • FILMMAKER MODE 设置和 ALLM（自动低延迟模式）。
  • 含 3D 设置的 3D 卡片。
显示页面

取景和菜单

  • 宽高比、遮罩和画面位置，含水平和垂直方向。
  • 遮罩边缘：上、下、左、右。
  • 屏幕菜单：背景色、菜单位置、信号源显示、Logo、语言、OSD 深色模式和 OSD 亮度同步。
  • 面板对齐和像素调整。
更改数值

列表、按钮和滑块

  • 选项，例如画面模式或伽玛，提供您的型号有文档记载的数值。
  • 级别使用减号和加号按钮。按住按钮可重复：400 毫秒后开始，之后每 300 毫秒一步。
  • 滑块只在 JVC 声明了范围的地方出现。目前只有 LD 电流值，范围为 0 至 100%。
关联设置

当另一项设置限制某个控制项时

有些设置只在特定条件下适用。应用遵循这些规则，因此无法生效的控制项会被禁用，并提示“当前低延迟设置下不可用”，或其他正在限制它的设置。不会发送任何内容。

设置可更改的条件
HDR 处理输入信号为 HDR、HDR10+、HLG 或 ST2084。
动态控制低延迟为关。
Clear Motion Drive，含其遥控键低延迟为关。
遮罩边缘遮罩为开。
如果应用尚未读取会限制某个控制项的那项设置，则不会阻止任何操作。
如实读数

各条提示的含义

  • “此投影机不响应此设置。”投影机开机时一直不响应它，因此该控制项被禁用。
  • “投影机不上报此设置。”可以设置，但投影机不会告知其当前值。
  • “投影机未确认该命令。是否已生效未知。”随后应用会再次读取该设置，因此屏幕上显示的是投影机实际保存的值。
  • 需要先确认的数值只会从其自己的卡片发送，并且在您确认之后。
  • 待机。大多数画面设置在投影机开机后才会出现。
保存

留住喜欢的效果

场景会记录画面模式和您的型号提供的其他画面设置，并一键恢复。
