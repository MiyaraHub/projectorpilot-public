家庭自动化

将您的投影机接入智能家居

让家里的其他设备在投影机开机、进入待机、切换信号源或调用场景时做出反应。“设置”的“家庭自动化”下有三种关联：Webhook 触发器、Hubitat 和 Home Assistant。三者都需要家庭自动化附加包，该附加包可单独购买或随捆绑包购买；仅有 Pro 并不包含它。

任选其一

该用哪种关联

Webhook

任何能接收网络请求的系统：Node-RED、家庭服务器、云端自动化。应用负责发送，由您决定接下来发生什么。

Hubitat

通过 Maker API，把电源和信号源单向镜像到您的 Hub 中的某个设备上，供 Rule Machine 据此执行操作。

Home Assistant

设置 Home Assistant 自带的 JVC Projector 集成、您的场景脚本和现成的仪表盘。

Webhook

自动化触发器

此投影机上发生某件事时，触发器会向您输入的地址发送网络请求。每台投影机都有各自的列表。点按添加触发器，然后选择：

  • 触发条件：投影机开机、投影机进入待机、信号源变更（变为任意信号源或某个指定信号源），或调用某个场景（任意场景或某个指定场景）。
  • 方法：POST（默认）、PUT 或 GET。
  • 网址：带有主机名的 http:// 或 https:// 地址。
  • 已启用，可暂停触发器而不必删除。
以 http:// 开头的地址会不加密发送，编辑器也会提示这一点。系统支持时请使用 https://。
载荷

请求携带的内容

POST 和 PUT 发送 JSON 正文；GET 不发送。应用添加的唯一请求头是 Content-Type。不适用于该事件的字段会被省略。

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
字段含义
eventpower_on、power_off、input_changed 或 scene_recalled。
projector投影机在应用中的名称。
input信号源，例如 hdmi1 或 hdmi2。
scene_id, scene_name场景，用于场景调用。
timestamp事件发生的时间，采用 UTC。
test仅在由“发送测试”发出的请求中出现，且值为 true。
发送

只尝试一次，如实报告

  • 每个事件只发送一次，限时 10 秒，且不跟随重定向。
  • 触发器会显示其最近一次结果：已送达（附时间和状态码）、被拒绝、无响应、无法访问该地址、安全连接失败，或尚未发送。
  • 发送测试会发送标记为测试的请求，让您在投影机有任何动作之前就能先把另一端接好。
触发器何时触发

规则

  • 仅在应用已打开并已连接投影机时。应用监视投影机的状态；它不是后台服务。
  • 针对变化，而非读数。应用连接后的第一次读数只用来设定起点，因此打开应用不会对已经开机的投影机触发“开机”。
  • 绝不来自演示投影机。选中演示投影机或家庭自动化未解锁时，任何内容都不会离开设备。
  • 安全保存。触发器地址保存在设备的安全存储中。
Hubitat

把投影机镜像到 Hubitat

应用通过 Maker API，把此投影机镜像到您的 Hubitat Hub 中的某个设备上：开机和待机，以及信号源（HDMI 1 或 HDMI 2，取决于该设备接受哪些）。之后 Rule Machine 即可据此执行操作。

  1. 在 Hubitat 中添加 Maker API，并记下其应用 ID（其 URL 中的数字）和访问令牌。
  2. 在应用中输入 Hub 地址、Maker API 应用 ID 和访问令牌。
  3. 点按查找设备，选择代表此投影机的设备。如果没有合适的，请在 Hubitat 中添加一个以该投影机命名的虚拟开关，然后重试。
  4. 打开镜像投影机状态。应用打开并连接期间，投影机一有变化，该设备就会随之更新。
仅限单向。Hubitat 不会向投影机发送任何内容。“取消关联”会移除应用中的关联。
Home Assistant

最深入的关联

应用会登录 Home Assistant，把您的投影机添加到其 JVC Projector 集成中，把您的场景和控制发布为脚本，并生成仪表盘。它有专门的页面：Home Assistant 设置和Home Assistant 仪表盘。
