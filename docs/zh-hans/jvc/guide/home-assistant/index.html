Home Assistant

Home Assistant

在应用中为 Home Assistant 设置您的 JVC 投影机。

设置

从登录到仪表盘

  • 通过 Home Assistant 自带的 OAuth 登录方式，登录 Home Assistant。
  • 集成：应用会添加 Home Assistant 的核心 jvc_projector 集成，并发送主机、端口和密码。
  • 传感器：mobile_app 传感器通过 Webhook 上报数据。
  • 同步高级控制会创建带有 ppjvc 前缀的脚本。
  • 仪表盘：核心样式或 HACS 样式的 Lovelace 仪表盘。
  • 设置清单会显示已完成和待完成的事项。
Home Assistant 功能需要家庭自动化附加包。
