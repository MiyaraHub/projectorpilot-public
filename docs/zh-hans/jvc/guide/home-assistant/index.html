Home Assistant

在 Home Assistant 中设置您的 JVC 投影机

应用会登录您的 Home Assistant，把投影机添加到 Home Assistant 自带的 JVC Projector 集成中，把您的场景和控制发布为脚本，并生成仪表盘。您无需粘贴令牌，也无需编写 YAML。此功能需要家庭自动化附加包。

请先阅读

同一时间只有一个控制器

JVC 投影机同一时间只服务一个网络控制器。本应用处于打开状态并连接投影机期间，Home Assistant 无法访问它。应用关闭后，Home Assistant 的投影机控制和脚本才可使用，并且应用转入后台时会释放投影机。

第 1 步

登录

  1. 打开“设置”，“家庭自动化”，Home Assistant。
  2. 输入您的 Home Assistant 地址，以 http:// 或 https:// 开头。
  3. 点按登录。Home Assistant 自带的登录页面会在浏览器中打开；在那里登录后返回应用。
  4. 点按测试连接进行确认。
如果无法访问 Home Assistant，请检查地址，并确认此设备与 Home Assistant 位于同一网络。
第 2 步

您的 Home Assistant 已具备什么

一个面板会读取您的 Home Assistant，并把每个部分标记为已找到、未安装或无法确定。“重新检查”会重新读取。

部分用途
Mobile App 集成实时状态传感器。
JVC Projector 集成从 Home Assistant 控制此投影机。
HACS仅用于仪表盘的样式外观。
第 3 步

设置清单

  1. 登录 Home Assistant。
  2. 把此投影机添加到 Home Assistant 的 JVC Projector 集成。点按“添加”。应用会在征得您同意后，把投影机的地址、端口和网络密码发送给 Home Assistant 的 JVC Projector 集成。
  3. 启用脚本所需的实体。部分 JVC Projector 实体在 Home Assistant 中默认处于禁用状态；点按每个实体旁的“启用”。Home Assistant 可能需要重新加载或重启后，该实体才会出现。
  4. 实时状态传感器。打开“发送投影机状态”。传感器会在应用下一次于连接状态下发送投影机状态时创建。
关于密码。添加投影机时，其网络密码会发送到您的 Home Assistant，并保存在其 JVC Projector 条目中。应用不会把它发送到其他任何地方。Home Assistant 连接投影机期间，应用会释放投影机，随后再重新连接。
哪个条目？

应用如何在 Home Assistant 中找到您的投影机

应用通过投影机的 MAC 地址匹配 JVC Projector 条目，因此请先至少连接一次投影机。如果 Home Assistant 中没有该 MAC 地址的条目，或有多个，清单会说明情况和处理方法。如果投影机更换了地址，应用会提示把新地址发送给 Home Assistant。

传感器

实时状态

传感器的状态是应用最近一次读取到的电源状态，其属性包括信号源、型号以及应用已读取的设置。它通过 Mobile App 集成工作，不会向投影机发送任何内容。应用打开并连接期间，状态一有变化就会更新。

脚本

场景和控制

每个已保存的场景都会成为 Home Assistant 中的一个脚本，通过 JVC Projector 实体运行。脚本不保存地址和密码。脚本 ID 以 ppjvc 开头。

  • 与 HA 同步会把您的场景写成脚本，并显示每个脚本包含多少步骤，以及哪些内容被省略及原因。
  • 同步高级控制会发布电源、信号源、画面模式、镜头记忆和隐藏的脚本。
  • 结果会计数：同步了多少个脚本、Home Assistant 拒绝了多少个，以及它是否确认已重新加载这些脚本。
  • 移除孤立脚本会删除由本应用创建、且已没有任何场景使用的脚本。它会先列出这些脚本并征求您的确认。
如果同步所依赖的某项内容尚未读取，则不会写入、更改或移除任何内容。同步绝不会凭猜测只执行一半。
仪表盘

现成的仪表盘

发送控制台会根据 JVC Projector 实体、脚本和传感器，在您的 Home Assistant 中生成投影机仪表盘。复制仪表盘则改为复制它，供您自行粘贴到新的仪表盘中。关于它的全部内容见Home Assistant 仪表盘页面。

规则

应用绝不会做的事

  • 选中演示投影机或家庭自动化未解锁时，任何内容都不会离开设备。
  • 取消关联只会移除本应用中的关联。投影机的设备和实体会保留在 Home Assistant 中，直到您在那里删除。
  • 如果 Home Assistant 不再接受登录，应用会告知并请您重新登录。
