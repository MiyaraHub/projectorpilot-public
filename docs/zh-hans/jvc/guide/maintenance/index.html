维护

维护与统计

了解光源的工作强度。“维护”界面会从投影机读取使用时间，根据您输入的数值推算预计寿命和运行成本，并在额定寿命临近时提醒您。它属于 Pro，位于“设置”的“维护与统计”中。

使用时间

只读，来自投影机

  • 光源使用时间。激光或灯泡累计运行的总小时数，读取自投影机。标签会随您的型号上报的光源而变化。
  • 自添加以来。在您设定下面的基准值后，自您标记此投影机已安装以来的运行小时数。
  • 还没有使用时间？请连接并开启投影机，应用才能读取。
此界面上的任何内容都不会写回投影机。应用不会重置或更改投影机自身的小时数。
统计

预计寿命和每小时成本

应用不知道任何型号的额定寿命，因此绝不会自行编造。请输入投影机文档或经销商提供的数值，统计信息就会自动填充。

统计项您输入的内容显示内容
预计寿命额定寿命，以小时计，例如 20000。额定寿命的剩余小时数和已用百分比。
每小时成本更换光源或光源组件的费用，例如 3500。每运行一小时的成本。不添加货币符号，因此适用于任何币种。
安装基准值点按“立即标记”，或手动编辑小时数。“清除”可将其移除。上面的“自添加以来”数值。
提醒

维护提醒

提醒默认关闭，需要您主动开启。请打开“维护通知”，再打开“光源寿命预警”。

  • 时机。达到您输入的额定寿命的 90% 时提醒，之后每 100 小时提醒一次。
  • 方式。标题为“光源使用时间”的通知。检查在应用打开并连接投影机期间运行。
  • 前提。已在“统计”中填写额定寿命，并已授予通知权限。如果系统拒绝通知，则提醒保持关闭，直到您允许为止。
  • 适用平台。Android、iOS 和 macOS。Windows 不提供提醒。
无论应用设置为何种语言，提醒文字都是英语。
记录

导出时长报告

“导出时长报告”会保存一个小型文本文件：应用版本、型号、应用读取的光源使用时间、时间，以及 SHA-256 校验和。

它是应用在那一刻所读取内容的快照，可作为投影机使用情况的记录。它由应用自行证明，并非由 JVC 认证。

您的数据

数据保存在哪里

  • 额定寿命、单价和基准值保存在此设备上。
  • “备份与恢复”不包含它们。
  • 使用时间本身始终来自投影机，因此无论您从哪台设备连接，数值都是正确的。
  • 仪表盘上的“光源使用时间”标签和“投影机状态”小组件显示的是同一读数；参见仪表盘。
示例

一个计算示例

假设您的投影机已运行 4000 小时，您输入的额定寿命为 20000 小时，更换成本为 3500。

数值结果算法
剩余小时数16000额定寿命减去已运行小时数。
已用寿命20%已运行小时数除以额定寿命。
每小时成本0.875更换成本除以目前已运行的小时数。
首次提醒在 18000 小时时额定寿命的 90%，之后每 100 小时一次。

光源运行得越久，每小时成本越低，因为同样的成本被分摊到更多小时上。

首页上的使用时间

无需打开此界面就能看到使用时间。仪表盘上的“光源使用时间”标签和“投影机状态”小组件显示的是投影机上报的同一读数。参见仪表盘。

常见问题

维护相关问题

为什么应用不替我填写额定寿命？

应用没有任何型号的额定寿命，也绝不会自行编造。请输入投影机文档或经销商提供的数值。

应用能重置投影机的使用时间吗？

不能。此界面上的任何内容都不会写入投影机。安装基准值是应用自己的方式，用来统计自您选定的日期以来的使用时间。

Windows 上提醒能用吗？

不能。提醒适用于 Android、iOS 和 macOS，且需在应用打开并连接投影机期间。
