入门指南

添加您的投影机

应用会在您自己的网络中查找 JVC D-ILA 投影机，并通过 TCP 端口 20554 直接与其通信。设置只需要扫描或输入 IP 地址，以及投影机的网络密码（如果有的话）。

首次启动

欢迎界面

  1. 欢迎使用 Projector Pilot D-ILA。简要介绍免费功能、Pro 增加的功能，以及获取帮助的途径：加入 Discord，或通过邮件发送日志。
  2. 数据分析。应用会询问是否允许发送匿名使用数据分析。除非您同意，否则保持关闭，之后也可以在“设置”的“关于”中更改。
  3. 开始之前。一份清单：手机和投影机位于同一局域网；投影机通过 LAN 端口连接，如有网络密码则一并准备；以及投影机的 IP 地址，可在其网络设置中查看。
  4. 添加投影机。选择扫描网络、通过 IP 地址添加投影机，或体验演示模式。
方式 1

扫描网络

  • 扫描范围。您的设备所在的每个私有地址段，即该 /24 子网的 1 至 254 号地址，端口为 20554。
  • 判断方式。JVC 投影机会对新连接作出问候；扫描会把作出问候的设备列为就绪，或列为正被其他控制器占用。进度会显示已检查的地址数和总数。
  • 没有响应时。“此网络中没有 JVC 投影机响应。”已被其他控制器（例如 Home Assistant）连接的投影机不会响应扫描，请改为通过地址添加。
  • 没有 Wi-Fi。如果设备没有局域网，扫描会提示“未找到局域网。请连接 Wi-Fi 后重新扫描。”
方式 2

通过 IP 地址添加

扫描找不到投影机，或投影机位于您的设备仍可访问的另一个子网时，请使用此方式。

  1. 为投影机命名，例如以所在房间命名。
  2. IP 地址：投影机的 IPv4 地址，可在其自身的网络菜单中查看。不接受主机名。
  3. 网络密码：在投影机上设置的密码。如果投影机没有网络密码，请留空。
  4. 测试连接。测试成功会显示“已连接”以及投影机上报的型号。
  5. 保存。投影机会出现在仪表盘上。重复保存同一台投影机会被拒绝，并提示“此投影机已保存。”
添加界面使用标准端口 20554。如需使用其他端口，请运行下面的引导式设置：其中的控制端口字段会把端口带入添加界面。
方式 3

引导式设置和诊断

“连接遇到问题？运行引导式诊断”会打开“设置投影机”。输入投影机 IP 地址和控制端口（除非您改过，否则为 20554），然后点按“诊断连接”。

检查项验证内容
与投影机位于同一网络您的设备与投影机处于同一子网，因此可以互相访问。
控制端口可访问控制端口上有设备接受连接。
投影机握手和密码它像 JVC 投影机一样作出应答，并且密码（如果有）被接受。

三项全部通过时，结果为“连接正常”，并显示“添加此投影机”按钮。有一项失败时，屏幕会指出是哪一项，并显示“发生了什么”和“如何解决”。如果投影机需要密码，会就地出现“网络密码”字段和“尝试密码”按钮。每种诊断结果都列在帮助页面中。

密码

网络密码

  • 是哪一个。在投影机自身网络菜单中设置的网络密码。应用没有自己的账户。
  • 2024 和 2025 年款型号的密码为 8 至 10 个字符；应用在发送任何内容之前会先检查长度。它先尝试 SHA-256 形式，再尝试明文形式。
  • 2018 和 2021 年款型号仅在投影机要求密码时才会发送密码。更早的型号从不发送。
  • 保存位置。保存在设备的安全存储中，仅限此设备，不包含在备份内。
  • 更改方法。在仪表盘上打开投影机的菜单，选择“更改密码”。
一个控制器

同一时间只能有一个应用

JVC 投影机同一时间只服务一个网络控制器。Projector Pilot D-ILA 连接期间，Home Assistant、控制系统或另一部手机都无法访问它，反之亦然。

  • 2024 和 2025 年款型号保持一个连接常开；较早的型号则每条命令连接一次。
  • 应用转入后台时会释放投影机，以便其他控制器接管。
  • 连接断开后，会在 3、5、8 秒，之后每 10 秒重试，网络恢复时会立即重试。密码错误后不会重试。
新地址

投影机更换地址时

应用在连接时会记下投影机的 MAC 地址。如果连续三次连接都没有任何结果，状态会显示“正在搜索网络”，应用会在子网内查找该 MAC 地址，最多三次。恰好有一台投影机匹配时，会把保存的地址改为新地址并重新连接。如需自行设置地址，请在投影机菜单中选择“编辑连接”。

手边没有投影机

演示投影机

  • 体验演示模式会添加一台演示投影机，它在设备本机上模拟，标有 DEMO 和“在此设备上模拟，无硬件”。
  • 它自称为 2024 年款型号，并运行较短的预热和冷却过程，因此状态卡片的表现与真实投影机一致。
  • 它的所有功能均已解锁，也不会统计导航按键次数。
  • 它从不向自动化触发器、Hubitat 或 Home Assistant 发送任何内容，也从不扫描网络。
  • 通过其菜单或“设置”中的“关闭演示”即可将其移除。
