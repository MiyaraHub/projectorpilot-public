隐私

Projector Pilot D-ILA 发送哪些数据，发送到哪里。完整政策请参阅 MiyaraHub Technologies 隐私政策：miyarahub.com/privacy.html。

数据

哪些数据会离开您的设备

  • 无需账号，没有广告。
  • 您的投影机：指令会发送到您本地网络中的投影机。
  • 应用商店，用于购买和恢复购买。
  • 崩溃报告（Firebase Crashlytics），仅限 Android 和 iOS。默认开启，可在设置的“关于”中关闭。消息文本中的地址、主机名、MAC 地址、URL 和令牌会被删除；堆栈跟踪包含代码位置。
  • 使用数据分析（Firebase）在您同意之前保持关闭，且绝不包含您的投影机名称、地址、MAC 或密码，也不包含任何 Home Assistant、Hubitat、令牌或触发器地址。
  • 仅在使用家庭自动化时，且绝不会来自演示投影机：向您输入的触发器地址、Hubitat 和 Home Assistant 发送的请求。
  • 投影机密码保存在设备的安全存储中，仅限本设备，且不会包含在备份中。
