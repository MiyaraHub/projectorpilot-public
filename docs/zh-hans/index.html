功能

投影机提供的每一项控制，尽在一款简洁的应用中。

Projector Pilot 同时通过 ESC/VP21、PJLink 和 Epson Web Control 与投影机通信，哪个有响应就用哪个，因此您获得的电源、画面、几何校正和镜头控制真正好用，所有数值都读回自投影机，绝不猜测。

仪表盘

一切尽收眼底，按您的喜好打造。

  • 实时状态：电源、信号源、色彩模式、光源使用时间、信号和画面数值，随变化即时更新。
  • 顶部即可一键切换电源和信号源，电源按钮还能感知预热和冷却。
  • 可自定义的卡片：添加、隐藏和重新排列卡片，让仪表盘显示您关心的内容。
  • 投影信息：动态范围、色彩空间、伽玛、激光使用时间、序列号和安装方式，读取自投影机。
遥控器 & 画面

深度遥控器和完整的画面菜单。

  • 完整的导航方向键、菜单、信号源和画面遮蔽：把屏幕遥控器做到位。
  • 校正方式：水平／垂直梯形校正、快速角点校正、点校正、曲面校正和墙角校正。
  • 完整的画面控制：亮度、对比度、色调、锐度、色温、伽玛、HDR 以及深层画面菜单，每项都使用投影机自己的刻度。
  • HDR 与色彩空间是分开的：BT.2020 SDR 信号会如实显示为 BT.2020 SDR，绝不会被错误标成 HDR。
镜头

电动镜头位移、对焦、变焦与记忆。

  • 通过精确的方向键进行位移、对焦和变焦，步长由您选择：精细用于取景，粗略用于大幅移动。
  • 镜头记忆：调用和保存投影机支持的位置。
  • 感知安装方向：应用遵循投影机自己的映射，无论是吊装还是背投，向上始终是向上。
  • 如实的读数：投影机无法确认的位置，绝不会被伪装成已锁定。
场景

整个房间，一键搞定。

  • 保存场景：电源、信号源、画面、信号、光源、几何校正和音频，并精确选择要保留的部分。
  • 一键应用：“观影之夜”会一并设置信号源、画面模式和镜头记忆。
  • 每个场景都会变成 Home Assistant 脚本，所以自动化或语音助手也能运行它。
  • 可分享的配置：导出调校好的场景，交给朋友。
家庭自动化

Home Assistant、Hubitat 和 Webhook，货真价实。

  • Home Assistant：登录，把投影机的状态发布为传感器，然后轻点与 HA 同步，即可为每个场景和控件获得一个脚本。
  • 为您构建的仪表盘：同步会在 Home Assistant 中使用内置卡片构建，并在您安装了更丰富的 HACS 卡片时自动升级。它同样适用于核心 PJLink 集成。
  • 设置清单会显示哪些已完成、哪些缺失以及下一步该做什么，投影机关机期间，您的读数也会保留在 Home Assistant 中。
  • Hubitat：通过 Maker API 把投影机镜像到一台设备上，这样 Rule Machine 就能据此执行操作。
  • Webhook：当投影机开机、关机、切换信号源或调用场景时，向任意 URL 发送请求。

更多功能

让它显得完成度十足的细节。

随处切换投影机

每个投影机页面顶栏中的投影机切换器，让您无需返回列表就能在多台投影机之间切换。

关机前先确认

关闭投影机时会请您确认，避免误触而中断电影。

即时响应的控件

镜头位移、对焦、变焦和光输出步进器在您按下的瞬间就会移动，应用也能在大约十秒内发现投影机已开机。

固件一目了然

只要投影机上报，它的固件版本就会显示在仪表盘和信息标签页中，也会出现在诊断报告里。

只支持 PJLink 的投影机也能切换信号源

对于只通过 PJLink 列出信号源的投影机（如 TW7300 和 Home Cinema 4040），信号源切换同样可用，非 Epson 的 PJLink 投影机也可以。

在 Wi-Fi 中找到您的投影机

“添加投影机”会扫描您的网络，查找所有以投影机身份响应的设备并填入地址，在检测您机型的功能期间还会显示进度条。

备份与恢复

将应用设置导出为文件，再导入回来。文件会以其真实名称分享，已保存的投影机和密码绝不会包含在内。

一步报告问题

“报告问题”会生成一个包含所有相关日志的压缩包，可直接发送。

常见问题

大家最先会问的问题

Projector Pilot 是 Epson 开发的吗？

不是。Projector Pilot 是 MiyaraHub Technologies LLC 开发的独立应用，与 Epson、PJLink 标准机构、Home Assistant 或 Hubitat 没有任何关联，也未获得其认可或赞助。这些名称是其各自所有者的商标，在此出现仅用于说明本应用适用于哪些投影机和智能家居系统。

Projector Pilot 支持哪些投影机？

支持通过 ESC/VP21 和 Web Control 连接的 Epson 投影机，以及任何 PJLink 投影机。应用会使用投影机有响应的任何方式，所以只支持 PJLink 的投影机也是普通的受支持设备。

Projector Pilot 是订阅制吗？

不是。基础控制免费，Pro、家庭自动化和捆绑包均为一次性购买。没有订阅，没有广告。

Projector Pilot 需要账号或云端吗？

没有账号，也没有云端。应用直接在您自己的网络中与投影机通信。
