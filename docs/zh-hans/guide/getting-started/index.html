入门指南

大约一分钟，添加您的 Epson 或 PJLink 投影机

Projector Pilot 直接在您自己的网络中找到投影机，无需云账号，也无需配对码。让手机连上同一个 Wi-Fi，添加一次投影机，应用就会扫描它的功能并记住。完整流程如下。

开始之前

您需要准备

  • 同一网络。您的手机、平板或电脑必须与投影机处于同一个 Wi-Fi（或有线 LAN）中。应用会在该网络内直接与投影机通信。
  • 投影机已开机或处于待机。让投影机保持开机，或在启用网络控制的情况下处于待机。大多数 Epson 机型在待机时也能响应，因此您可以从应用中开机。
  • 投影机的 IP 地址（仅在手动添加时需要）。它位于投影机自己的网络菜单中，具体位置见下文。
手边没有投影机？在第一个界面轻点体验演示模式，整个应用就会连接到一台捕获自真实 Epson QB1000 的演示设备，它的响应与真实投影机一致，这样您在购买之前就能试用每一个界面。
分步操作

添加投影机

打开“添加投影机”，选择您想用的查找方式。两种方式最终殊途同归。

  1. 选择扫描网络或通过 IP 地址添加。扫描网络会在您的 Wi-Fi 或有线 LAN中查找所有以投影机身份响应的设备，并自动填入地址。如果您更想自己输入地址，也可以选择通过 IP 地址添加。
  2. 选择您的投影机，或输入它的 IP 地址。扫描时，在列表中轻点投影机即可。手动添加时，输入投影机网络菜单中的 IP 地址，然后继续。
  3. 让功能扫描运行。首次添加时，应用会探测投影机并显示进度条，让您看到进展。它会询问投影机究竟支持什么：哪些协议有响应、有哪些控件、镜头和画面的调节范围，所以应用只会向您显示真实存在的控件。
  4. 轻点测试连接。应用会确认能否连上投影机，并读回它的身份信息。如果投影机需要 Web Control 密码，请在此输入；应用会判断究竟是否需要密码，并无论哪种情况都告诉您结果。
  5. 保存。投影机就添加好了，它的功能扫描结果也会被记住，再次打开应用不会重新扫描。您将进入仪表盘，实时读取数据。
投影机只会被扫描一次，结果会被缓存。这就是第二次启动瞬间完成的原因：应用已经知道您的硬件能做什么。
查找地址

投影机的 IP 地址在哪里

如果通过 IP 地址添加，您需要知道投影机在网络中的地址。所有 Epson 投影机都把它放在同一个位置。

  1. 在投影机上打开屏幕菜单，进入网络（部分机型为“扩展”›“网络”）。
  2. 打开网络配置 › 有线 LAN或无线 LAN，查看IP 地址。
  3. 把该地址输入到“通过 IP 地址添加”中。建议在路由器上为它设置固定或保留的地址，这样地址就不会在应用背后悄悄变化。
网络设置在投影机上，而不在应用里。Projector Pilot 是通过该网络连接投影机的，所以网络页面只是一个清晰的只读视图，要更改地址，请在投影机自己的界面上操作。
如果无法连接

快速排查

  • 再确认一下网络。手机如果切到了访客 Wi-Fi 或蜂窝网络，就看不到投影机。两端必须在同一网络。
  • 唤醒投影机。关闭了网络待机的机型，在开机之前不会响应。先开机一次，再添加它。
  • 提示输入密码？请输入 Web Control 密码（也就是投影机自己的网页所要求的那个密码）。投影机另外几个密码由应用来处理，详见遥控器指南。
  • 只支持 PJLink 的投影机？它同样是普通设备。应用会退而使用任何有响应的传输方式，所以没有 Web Control 的投影机也能正常工作。
