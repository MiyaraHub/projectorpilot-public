画面菜单

投影机画面设置，使用投影机自己的刻度

投影机画面菜单中的所有内容，集中在一个界面里：从亮度到帧插值。每个数值都是投影机自身菜单显示的数字，而不是它内部的字节值，每次更改之后也都会从投影机读回，所以您看到的始终是硬件实际保留下来的数值。

基础设置

亮度、对比度、色调、锐度

  • 亮度和对比度：黑位和白位，使用投影机自己的 0-100（或机型对应的）刻度。
  • 色调和饱和度：色彩平衡与浓度。
  • 锐度：边缘清晰度，使用您的机型采用的范围。

每个控件都会显示精确的菜单数值。如果投影机已声明某个控件所用的范围，应用会和投影机一样精确换算；如果没有声明，则按发送的数值显示，并且控件会标注原始数值，而不是显示一个猜测的数字。

色彩

色温与伽玛

两个控件在不同模式下表现不同，应用会跟随投影机，而不是把它们一概而论。

  • 色温是十四个档位，而不是滑块：用编号表示，或者在会上报开尔文数值的画面模式中以开尔文显示。它是分档设置，所以应用以档位呈现，绝不会显示成会让人误解的 0-100 范围。
  • 伽玛因画面模式而异。各模式的选项不同：动态模式提供一个范围内的档位，影院模式提供曲线值，自定义模式又有所不同。应用会先根据当前画面模式判断哪一组有效，再向您提供选择，所以您永远不会看到当前模式无法使用的伽玛选项。
  • RGB 增益和偏移：白平衡控件，各自使用投影机自己的刻度，用于调校灰阶。
色温显示为菜单中的档位（例如 0 到 13），或者在会显示开尔文的模式中显示开尔文数值，不是字节值，也不是重新换算后的值。

如实原则

HDR 与色彩空间保持分离

信号的动态范围与色彩空间是两回事，应用也如此对待。BT.2020 不代表 HDR，SDR 也不代表 BT.709。

  • 动态范围（SDR 或 HDR）与色彩空间（BT.2020、BT.709 等）作为独立字段显示。
  • 使用 MadVR 等外部色调映射器时常见的 BT.2020 SDR 信号，会如实显示为 BT.2020 SDR，绝不会被错误标成 HDR10。
  • 您设置的每个画面数值都会在设置后从投影机读回，所以投影机保留了或未能确认的数值，都会被直接说明，而不是想当然。
画面记忆

保存、调用和重命名您的画面记忆

画面界面会列出您的投影机实际拥有的记忆，使用您在其菜单上为它们起的名字。您可以把当前画面保存到某个存储位、重命名或擦除；覆盖已有记忆的存储位时会先征求您的确认。
