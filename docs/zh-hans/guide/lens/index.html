镜头标签页

镜头位移、对焦与变焦，精准到位

通过精确的方向键对投影机的电动镜头进行位移、对焦和变焦，调用和保存投影机支持的镜头记忆，并从机身读回精确位置。每个数值都来自投影机，对于它无法确认的位置，会显示为未知，而不是伪装成已锁定。

镜头标签页包含两个子标签页：镜头用于日常的位移、对焦、变焦和记忆控制，安装用于一次性的设置调整。

镜头位移

一个方向键，加上由您选择的步长

位移方向键可将镜头上移、下移、左移和右移。真正让它从玩具变成工具的，是下方的步长选择器：您可以选择轻点一次让镜头移动多远，从精细取景到大幅调整位置均可。

第 1 步

最精细的移动。一点一点地微调画面，让边缘与屏幕边框对齐。

第 5 步

适中的设置，适合在已经接近目标位置时把画面调到位。

第 10 步

在初步确定位置时快速移动。

步长 25

最粗的移动，几次轻点就能让镜头移过大部分行程。

您选择的步长同样适用于位移、对焦和变焦，所以一个设置就决定了每个镜头控件每次轻点移动多远。先用较大的步长大致到位，再降到 1 完成取景。
对焦 & 变焦

清晰度与画面大小，同样的方式

  • 对焦：一个减号和一个加号按钮驱动对焦电机，每次轻点按您设置的步长移动。当前对焦电机位置显示在按钮上方，方便您回到已知的数值。
  • 变焦：同样的减号和加号按钮驱动变焦电机，同样按您选择的步长移动，旁边显示实时的变焦电机位置。
  • 读回，而非猜测：对焦和变焦数值是投影机上报的电机位置，所以您看到的就是镜头实际所在的位置，而不是应用希望它到达的位置。
镜头记忆

调用已保存的设置，或保存当前设置

支持镜头记忆的投影机会在命名的存储位中保存完整的位移、对焦和变焦位置。Projector Pilot 会列出您的投影机实际支持的存储位，让您轻点一下就能调用，或把当前位置保存进去。

  • 调用：轻点一个记忆，镜头就会移动到所存储的位移、对焦和变焦位置，正如变形宽银幕或其他画幅比例的设置所需要的那样。
  • 保存：把当前镜头位置存入存储位，方便以后回到这里。
  • 只有真实的存储位：应用显示的是投影机上报拥有的记忆存储位，而不是假定每个机型都具备的固定列表。
镜头记忆与场景搭配得很好：场景可以把镜头记忆与信号源和画面模式一并保存，轻点一下，就能为宽银幕电影或 16:9 节目设置好整个房间。
位置读数

位移范围，绘制成图

在镜头标签页顶部，当前镜头位置以两种方式显示：数值和示意图。

  • 垂直位移和水平位移数值：垂直和水平位移位置，各自显示为当前值占投影机完整行程的比例（例如 1023 中的 595），让您始终知道镜头距离极限还有多少余量。
  • 范围示意图：一个方框，把镜头位置绘制为投影机位移范围内的一个点，纵向对应垂直，横向对应水平，让您一眼看出镜头是居中还是偏向行程的某个角落。
方向由投影机决定，应用予以尊重。无论是吊装、背投还是正投，向上就是向上：应用遵循投影机自己的映射，绝不会为了揣测您的安装方式而反转方向键。轻点向上，画面就上移，无论投影机是怎么固定的。
默认如实呈现

未确认的位置是未知，而不是已锁定

有些投影机会接受并执行镜头移动，但它读回的位置并不会随电机同步变化。在 QB1000 等机型上，这种滞后很容易被误认为镜头卡住了。

  • 已接受移动但位置未确认时，控件仍然可用。应用不再仅仅因为上报的数值没有变化，就让控件变灰或引导您去看镜头锁定；既然命令已被接受，控件就保持可用。
  • 只有真正的拒绝才会被报告为锁定。只有当投影机确实拒绝命令时，应用才会告诉您镜头已锁定，并且无论有没有 Web Control 密码都是如此。
  • 登录被拒绝是未知，而不是锁定。如果镜头移动通过 Web Control 进行，而该登录被拒绝，应用会将镜头视为未知，并显示一条轻点即可修复的提示，让您更新 Web Control 密码，而不是怪罪镜头。
安装子标签页

一次性设置调整

安装子标签页包含几何校正和安装人员控件，这些是投影机安装时设置一次、之后很少再动的内容，与镜头子标签页中的日常镜头移动相对应。

安装人员控件只在投影机支持时才会出现，并读回自机身，所以您看到的就是您的具体机型所提供的内容，而不是假定的一套功能。
