遥控器

真正的投影机遥控器，无需电池

遥控器标签页包含屏幕遥控器和操作控件，分布在可以滑动切换的子页面中：遥控器、操作、设备和网络。投影机提供的一切都在，它没有的按键则一个不多。

遥控器页面

浏览投影机自己的菜单

  • 导航方向键配有中央确认键，另有菜单、返回、主页和信号源，操作投影机的屏幕菜单，与手持遥控器完全一致。
  • 信号源选择，可直接跳转到某个信号源。
  • 色彩模式，可在同一界面切换画面模式。
  • 画面遮蔽，用于隐藏画面。电源控制在仪表盘上，不在这里，所以只有一个电源控件，而不是三个。
画面遮蔽不是 A/V 静音。画面遮蔽会在投影机继续运行、信号持续输入的情况下隐藏图像，所以能立即恢复。把它用于暂停，而不是关机。
操作页面：几何校正

校正图像的形状

选择与您的安装方式相符的校正方式。应用会显示您的投影机支持的方式，并且按硬件要求，同一时间只有一种几何校正生效。

方式适用场景
关闭不校正：与屏幕端正对齐的投影机不需要校正。
水平／垂直梯形校正独立的水平和垂直梯形校正，适用于上下或左右偏置的投影机。
快速角点校正把四个角分别拖到位，这是应对画面不太方正时的常用校正方式。
点校正逐个微调网格中的点，用于精细的局部畸变。
曲面校正补偿投射到弧形屏幕或墙面时产生的变形。
墙角校正用于投射到两面墙交汇的房间墙角时的校正。
每个几何校正数值在您更改后都会从投影机读回，所以投影机未应用的校正绝不会显示得好像已经应用。
设备页面：密码

三个密码，而不是一个

Epson 投影机有三个相互独立的密码，各自保护不同的内容。Projector Pilot 清楚其中的区别，所以输入了您并不需要的密码，也绝不会把您锁在应用之外。

密码保护对象
Web Control投影机的网页界面及其承载的命令，在许多机型上包括镜头移动和图像读取。这就是投影机自己的网页所要求输入的那个密码。
PJLinkPJLink 协议（TCP 4352），供控制系统使用，在应用中则作为备用传输方式。
遥控ESC/VP.net 遥控通道（TCP 3629），是应用优先使用的传输方式。
应用会先判断究竟是否需要密码，再做出任何决定。如果投影机无需询问就有响应，会被报告为“此处无需密码”，而不会被错误地标记为受保护，并且应用绝不会把“未设置”与“已设置但此协议不需要”混为一谈。如果已保存的 Web Control 密码失效，镜头和图像控件不会一片灰暗、归咎于镜头，而是会显示一条轻点即可修复的提示，让您更新密码。
设备页面：锁定

投影机实施的锁定

设备页面会显示投影机自己的锁定。当某个控件因为投影机将其冻结而不可用时，应用会说明是哪个锁定造成的，而不是悄无声息地失败。

  • 镜头锁定。当投影机的镜头锁定开启时，位移、对焦和变焦都会被锁住。只有当投影机确实拒绝命令时，应用才会报告镜头已锁定；对于已被接受、但位置无法由投影机确认的移动，不会视为锁定，所以控件保持可用。
  • 童锁。禁用投影机自身的电源按钮，防止孩子把它打开并直视光线。可在这里切换。
  • 控制面板锁定。锁定投影机机身上的按键，只有遥控器（和应用）才能操作它，在公共或共用的房间里很方便。
网络页面

清晰的只读视图

网络设置在投影机上，因为应用是通过该网络连接投影机的。网络页面是投影机寻址信息的纯只读视图，并附有说明原因的提示；要更改这些设置，请在投影机自己的界面上操作，详见快速入门。
