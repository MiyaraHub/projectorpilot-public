一款投影机应用，29 种语言

每个界面、每项设置、每个对话框，都使用您的语言。Projector Pilot 支持英语以及另外 28 种语言，包括 iPhone、iPad 和 Mac 上的权限提示，开箱即用地跟随您的设备，也允许您在设置中自行选择。阿拉伯语和希伯来语会把整个布局从右到左镜像显示。

在哪里设置

设置 › 语言

开箱即用时，应用会跟随设备语言。要自己选择，请打开设置并轻点语言。系统默认会把选择权交还给设备；其下每种语言都以自己的名称列出，所以您无需先读懂另一种语言就能找到自己的。

  • 自动。与手机或平板保持一致，无需设置。
  • 您来选。覆盖设备语言，选择会立即生效，并在重启后保留。
  • 从右到左。阿拉伯语和希伯来语会把整个布局翻转：导航、卡片和列表都会镜像，而从投影机读取的数值仍按投影机的书写方式显示。
投影机自己的文字仍归投影机所有。信号源名称、色彩模式以及投影机上报的每个数值，无论使用哪种语言，都完全按它的原样显示。只有 Projector Pilot 自己的文案才会被翻译。

常见问题

语言常见问题

应用会自动跟随我的设备语言吗？
会。开箱即用时它就会跟随设备。要自己选择，请打开“设置” › “语言”；“系统默认”会把选择权交还给设备。
阿拉伯语和希伯来语是从右到左排版的吗？
是的。整个应用都会镜像，包括导航、卡片和列表，而从投影机读取的数值仍按投影机的书写方式显示。
为什么我的信号源名称仍然是原来的语言？
因为它们是投影机自己的文字，而不是应用的。信号源名称、色彩模式以及投影机上报的每个数值，都完全按它的原样显示。只有 Projector Pilot 自己的文案才会被翻译。
