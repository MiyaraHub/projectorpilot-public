仪表盘

您的投影机仪表盘，按您的喜好打造

仪表盘是您的大本营。顶部是实时状态，下方是投影机各个部分对应的卡片，还有自定义模式，让您添加、隐藏和重新排列这些卡片，让屏幕只显示您关心的内容。每一个数值都读取自投影机，并随变化即时刷新。

实时状态

顶部显示电源、信号源和色彩模式

  • 电源按钮。轻点一下即可开机或关机，并且能感知预热和冷却过程：它会如实显示投影机正在预热或冷却，而不是假装状态瞬间切换。
  • 输入信号源。当前信号源一目了然，轻点即可切换。
  • 色彩模式。当前的画面模式（动态、影院、自然等），读取自投影机。
  • 画面遮蔽。在不中断信号的情况下遮蔽画面，仪表盘与遥控器保持一致：遮蔽状态在两处都显示为已启用。
仪表盘周边

切换投影机、关机、固件

  • 投影机切换器。每个投影机页面的顶栏都有切换投影仪控件，无需返回列表就能在多台投影机之间切换。多台投影机属于 Pro 功能。
  • 关机前先确认。关闭投影机时会询问关闭投影仪？并等待您确认。开机则不会询问。
  • 固件。只要投影机上报了固件版本，就会显示在仪表盘、信息标签页和诊断报告中。如果投影机没有上报，就什么都不显示，而不是随便猜一个。
  • 即时控制。镜头位移、对焦、变焦和光输出步进器在您按下的瞬间就会响应，并最终以投影机确认的数值为准。如果上一次发送还没完成时又按了一次，这次按键会被丢弃，而不是排队等待。
  • 如实的电源状态。重新打开应用时，它会显示正在检查，而不是错误地显示“关闭”，并且能在大约十秒内发现投影机已开机。
投影信息

投影机此刻的真实状态

投影信息卡片直接从机身读取真实的信号和安装细节，这里没有任何内容是推测出来的。

字段显示内容
动态范围SDR 或 HDR，与色彩空间分开显示，确保信号不会被错误标注。
色彩空间输入信号的色域，例如 BT.2020 或 BT.709，单独上报，不会混入 HDR 徽标。
伽玛投影机上报的当前伽玛。
激光使用时间光源已运行的小时数，方便您掌握面板或激光的寿命。灯泡机型则显示灯泡使用时长。
序列号投影机自身的序列号，读取自机身。
安装方式吊装或背投，以投影机上的设置为准。
色彩空间和动态范围是两个独立字段，这是有意为之。例如使用 MadVR 等外部色调映射器时常见的 BT.2020 SDR 信号，就会如实显示为 BT.2020 SDR，绝不会被错误标成 HDR10。
摘要卡片

画面和镜头，一眼看清

  • 画面摘要。关键画面数值：亮度、对比度、色调、锐度和色温，采用投影机自身菜单的刻度显示，轻点即可进入完整的画面页面。
  • 镜头摘要。显示当前镜头状态，并可直接跳转到镜头页面，进行位移、对焦、变焦和记忆设置。
  • 信号、光源和运行卡片。添加您关心的卡片，例如信号详情、光输出和节能／运行，让仪表盘想繁则繁，想简则简。
打造专属风格

添加、隐藏和重新排列卡片

轻点自定义，仪表盘就变为可编辑状态。从选择器中添加卡片，拖动调整顺序，或隐藏您从不查看的卡片。

  1. 在仪表盘上轻点自定义。
  2. 从选择器中添加卡片：电源、信号源、色彩模式、画面遮蔽、画面、镜头、信号和节能／运行都可添加，完整选择器里还有更多卡片类型。
  3. 拖动排序，把最常用的控件放在最上面。
  4. 隐藏不需要的内容。完成后，布局就是您的了，并且会一直保留。
只会提供您的投影机实际支持的控件对应的卡片。如果您的机型没有电动镜头，就不会有镜头卡片可添加：应用绝不会显示硬件无法响应的控件。
