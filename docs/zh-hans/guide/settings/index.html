设置

Projector Pilot 设置：打造专属于您的应用

在设置中，您可以管理投影机、解锁应用、设置主题、调整轮询方式，并备份所有内容。它的组织方式让设备控制、购买、外观和链接各自位于清晰的位置。没有广告，没有订阅，不需要云账号，只有真正重要的开关。

投影机

添加、编辑和连接

  • 两种方式添加投影机。扫描您的 Wi-Fi 或有线网络，查找所有以投影机身份响应的设备并让应用填入地址，或手动输入 IP 地址。新添加的投影机在扫描其功能时会显示进度条，结果会被记住，所以再次打开应用时不会重新扫描。
  • 编辑、查看或删除。每台已保存的投影机都有编辑铅笔、高级连接视图、信息面板和删除选项。高级中是每台投影机的端口，以及三个密码。
  • 三个独立的密码。一台投影机最多有三个密码：Web Control、PJLink 和遥控。它们是用于不同协议的不同密码，按投影机分别保存，应用会判断某台投影机实际需要哪一个，而不是假定它受到保护。
解锁应用

Pro、家庭自动化和捆绑包

Projector Pilot 分为两部分，均为一次性购买。Pro 是高级应用；家庭自动化是单独的购买项；捆绑包则同时包含两者。在拆分之前购买过 Pro 的用户，保留 Pro 原有的一切。

  • Projector Pilot Pro：场景、多台投影机、完整的画面控制、镜头与几何校正、维护、小组件、测试图案和可分享的配置。
  • 家庭自动化：Home Assistant、Hubitat 和 Webhook。
  • 捆绑包：两者合一，一次购买。
  • 恢复：重新授予您在此商店账号下已购买的内容。如果商店报告某个项目已拥有，应用会直接授予它，而不是显示错误，所以您付费购买的功能绝不会把您拒之门外。
价格始终由应用商店提供，在您确认之前以您自己的货币显示，应用绝不会编造数字。在没有应用商店的平台上，应用会包含全部功能，而不是显示一个没人能付款的付费墙。详细对比请见价格。
外观

主题与配色主题

  • 浅色：清爽的白色主题。
  • 深色：标准的深色界面。
  • AMOLED：适用于 OLED 屏幕的纯黑。
  • 品牌色：应用标志性的森林绿。

常见问题

设置常见问题解答

如何添加投影机？
进入“设置”，选择“添加投影机”。可以让应用扫描您的网络并填入地址，也可以手动输入 IP 地址。新投影机会被扫描一次以获取其功能，并显示进度条，结果会被记住。
端口和密码在哪里？
打开已保存投影机的高级连接视图。每台投影机的端口和三个独立的密码（Web Control、PJLink 和遥控）都在那里。
我已经购买了 Pro，还需要购买家庭自动化吗？
不需要。在应用拆分为两部分之前购买过 Pro 的用户，保留 Pro 原有的一切。任何已解锁的内容都不会被收回。
我的密码会进入备份吗？
不会。备份与恢复只涵盖您的应用设置；已保存的投影机及其密码保留在加密的安全存储中，绝不会随备份文件一起传输。
我可以更改轮询投影机的频率吗？
可以。“状态轮询间隔”决定实时状态多久刷新一次，更改会立即生效，拖动滑块时不会突然产生大量查询。
