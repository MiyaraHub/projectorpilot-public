兼容 Epson 的投影机遥控器

Projector Pilot 是一款独立的遥控应用，可通过您自己的网络控制 Epson 投影机以及任何支持 PJLink 的投影机。下面列出了它兼容的型号，以及各型号提供的功能。

工作方式

按协议兼容，而非按型号列表

应用不内置型号列表。它会询问投影机支持哪些功能，并显示投影机回应的控制项，因此只要投影机支持 PJLink 或 Epson Web Control，即使下方没有列出也能使用。

  • PJLink（第 1 类和第 2 类）几乎适用于所有联网的 Epson 投影机，提供电源、输入、静音以及灯泡或激光状态。
  • Epson Web Control 在提供该功能的型号上增加画面设置、镜头、梯形校正和 HDR。
  • ESC/VP21 是投影机自有的命令协议，在投影机通过该协议应答时使用。

连接之前

开启网络控制

  • 让手机和投影机连接到同一网络。
  • 在投影机的网络菜单中启用 PJLink 和 Web Control。
  • 在应用中扫描投影机，或通过 IP 地址添加。

设置步骤请见指南和帮助 & FAQ。使用的是 JVC 投影机？请查看 Projector Pilot D-ILA。
