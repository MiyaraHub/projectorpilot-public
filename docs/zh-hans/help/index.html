Projector Pilot 帮助& FAQ

如何连接、哪些投影机可用、购买与恢复如何运作，以及应用如何对待您的隐私。仍然遇到问题？请在社区中联系开发者，或在应用中轻点“发送反馈”。

连接

建立连接

Projector Pilot 直接在您的网络中与投影机通信。三件事就能让您连上，而其中一件是大多数人容易栽跟头的地方。

同一个 Wi-Fi，同一个子网

手机和投影机必须处于同一个网络和子网。访客网络、IoT VLAN 和某些 Mesh 组网会让设备彼此隔离，所以连在“IoT”SSID 上的投影机，无法被连在主网络上的手机访问到。请让两者连入同一个网络。

在投影机上启用 PJLink 和 Web Control

必须在投影机上开启网络控制。在投影机的网络菜单中，启用 PJLink 和 Web Control（Epson 将后者称为网页遥控／Web Control）。网络控制关闭时，投影机根本不会响应。

查找投影机的 IP 地址

应用会在您的网络中扫描投影机，您也可以通过 IP 地址添加。要查找 IP 地址，请在投影机自己的菜单中打开网络信息界面，其中会列出当前地址。如果扫描结果为空，就手动添加该 IP 地址。

投影机的三个密码

Epson 投影机有三个相互独立的密码：Web Control、PJLink 和遥控。它们不是同一个字段，一台投影机可能需要其中一个、几个，或者一个都不需要。请输入您的投影机要求的密码；应用会判断投影机实际需要哪些，并在两种情况下都完成连接，诊断功能会告诉您用的是哪条路径。如果投影机无需密码就有响应，应用会说明已保存的密码在此处并未用到，而不是声称没有设置密码。

兼容性

支持的投影机

  • 通过 ESC/VP21 和 Web Control 连接的 Epson 投影机：两者结合，即可提供电源、完整的画面菜单、几何校正和电动镜头控制。
  • 任何 PJLink 投影机：通过 PJLink 标准提供电源、信号源和状态，所以非 Epson 投影机或只支持 PJLink 的 Epson 投影机也是普通的受支持设备。
  • 使用某种传输方式是因为它有响应，而绝不是因为它被配置过。应用优先使用 ESC/VP21，其次是 PJLink，再次是 Web Control，但它会退而使用投影机实际有响应的任何方式。没有 Web Control 的投影机通过 PJLink 依然正常工作；某种传输方式拒绝的数值，会被视为未知，而不是不支持。
不确定您的机型？应用的“关于”界面会根据其机型数据库列出它支持的投影机，并说明每款是在硬件上验证过，还是推断得出。如果投影机自己的网页和网络控制可以正常使用，Projector Pilot 应该也能连上它。
购买 & 恢复

购买，以及找回购买项

是一次性购买吗？

是的。Pro、家庭自动化附加组件和捆绑包都是一次性购买。没有订阅，没有广告，没有账号。请查看价格。

如何在新设备上恢复购买？

登录您购买时使用的同一个商店账号，并在应用中使用“恢复购买”。一次购买即可在您拥有的所有平台上解锁，包括 Android、iOS、Windows 和 macOS，并与该商店账号绑定。

我已经拥有了，但应用显示错误

不应该这样，较新的版本正是修复了这个问题。如果商店报告 Pro、家庭自动化或捆绑包已被拥有，应用会直接授予，并悄悄刷新您的购买项，所以购买或恢复您已拥有的内容总能将其解锁。

为什么价格与我在网上看到的不同？

应用会在您确认之前，以您自己的货币显示商店的价格。各地区定价不同，应用绝不会退而使用写死的数字：如果商店尚未响应，它会如实告知，而不是编造一个数字。

隐私

您的数据始终属于您

Projector Pilot 是一款本地应用。它在您的网络中与投影机通信，无需注册任何内容。

  • 没有账号，没有云端。您无需创建账号，投影机的数据也不会发送到我们的任何服务器。
  • 通过 Crashlytics 进行崩溃诊断。应用崩溃时，会发送一份诊断报告以便修复问题。这是标准的崩溃报告，而不是跟踪。
  • 可选、需主动开启的使用数据分析。使用数据分析默认关闭。应用会在首次启动时询问一次，您可以随时在设置 › 关于中开启或关闭。除非您开启，否则不会收集或发送任何内容。
  • 不会出售任何数据。您的数据不会出售给任何人，就这么简单。

FAQ

快速解答

Projector Pilot 找不到或无法连接我的投影机

请确保手机和投影机处于同一个 Wi-Fi 网络和子网中，访客网络和 IoT VLAN 可能会将它们隔离。在投影机上，于其网络菜单中启用网络控制（PJLink 和／或 Web Control）。在投影机自己的网络信息界面中查找它的 IP 地址，如果扫描没有发现它，就手动添加。

Projector Pilot 支持哪些投影机？

支持通过 ESC/VP21 和 Web Control 连接的 Epson 投影机，以及任何 PJLink 投影机。使用某种传输方式是因为它有响应，而不是因为它被配置过：应用会退而使用投影机有响应的任何方式，所以只支持 PJLink 的投影机也是普通的受支持设备。

Projector Pilot 需要账号，或者会把我的数据发送到云端吗？

没有账号，也没有云端。应用在您的网络中与投影机通信。它通过 Crashlytics 使用崩溃诊断，并提供可选的使用数据分析，默认关闭，可在“设置”>“关于”中关闭。不会出售任何数据。
