أتمتة المنزل

اربط جهاز العرض ببيتك

دع بقية المنزل يتفاعل عندما يعمل جهاز العرض أو ينتقل إلى وضع الاستعداد أو يغيّر المدخل أو يستدعي مشهدًا. توجد ثلاثة روابط ضمن الإعدادات، أتمتة المنزل: مشغلات webhook وHubitat وHome Assistant. تتطلب الثلاثة إضافة أتمتة المنزل، التي تُباع منفردة أو ضمن الحزمة؛ ولا يشملها Pro وحده.

اختر واحدًا

أي رابط تستخدم

Webhooks

أي نظام يقبل طلب ويب: Node-RED أو خادم منزلي أو أتمتة سحابية. التطبيق يرسل وأنت تقرر ما يحدث.

Hubitat

مرآة باتجاه واحد للتشغيل والمدخل على جهاز في المركز الخاص بك، عبر Maker API، ليتصرف بناءً عليها Rule Machine.

Home Assistant

يُعدّ تكامل JVC Projector الخاص بـ Home Assistant نفسه، ونصوصًا برمجية لمشاهدك، ولوحة معلومات جاهزة.

مشغلات الأتمتة

يرسل المشغل طلب ويب إلى عنوان تدخله عندما يحدث شيء على جهاز العرض هذا. لكل جهاز عرض قائمته الخاصة. انقر على إضافة مشغل، ثم اختر:

  • عندما: يتم تشغيل جهاز العرض، أو ينتقل جهاز العرض إلى وضع الاستعداد، أو يتغير المدخل (إلى أي مدخل أو إلى مدخل محدد)، أو يتم استدعاء مشهد (أي مشهد أو مشهد محدد).
  • الطريقة: POST (الافتراضية) أو PUT أو GET.
  • عنوان الويب: عنوان http:// أو https:// مع اسم مضيف.
  • مفعّل، لإيقاف مشغل مؤقتًا دون حذفه.
يُرسَل العنوان الذي يبدأ بـ http:// دون تشفير، ويقول المحرر ذلك. استخدم https:// عندما يدعمه نظامك.
الحمولة

ما الذي يحمله الطلب

يرسل POST وPUT جسمًا بصيغة JSON؛ أما GET فلا يرسل جسمًا. والترويسة الوحيدة التي يضيفها التطبيق هي Content-Type. ويُترك أي حقل لا ينطبق على الحدث.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
الحقلالمعنى
eventpower_on أو power_off أو input_changed أو scene_recalled.
projectorاسم جهاز العرض في التطبيق.
inputالمدخل، مثل hdmi1 أو hdmi2.
scene_id, scene_nameالمشهد، عند استدعاء مشهد.
timestampوقت حدوثه، بالتوقيت UTC.
testموجود، وقيمته true، فقط في الطلب المرسل عبر إرسال اختبار.
التسليم

محاولة واحدة، يُبلَّغ عنها بصدق

  • يُرسَل كل حدث مرة واحدة، بمهلة 10 ثوانٍ، ولا تُتبع عمليات إعادة التوجيه.
  • يعرض المشغل آخر نتيجة له: تم التسليم في وقت معين مع رمز الحالة، أو مرفوض، أو لا توجد استجابة، أو تعذر الوصول إلى العنوان، أو فشل الاتصال الآمن، أو لم يُرسل بعد.
  • إرسال اختبار يرسل طلبًا معلَّمًا على أنه اختبار، لتتمكن من تجهيز الطرف الآخر قبل أن يفعل جهاز العرض أي شيء.
متى تعمل المشغلات

القواعد

  • فقط ما دام التطبيق مفتوحًا ومتصلًا بجهاز العرض. يراقب التطبيق حالة جهاز العرض؛ وهو ليس خدمة تعمل في الخلفية.
  • التغيّرات، لا القراءات. القراءة الأولى بعد اتصال التطبيق تحدد نقطة البداية فقط، لذلك لا يؤدي فتح التطبيق إلى تشغيل "يتم تشغيل" لجهاز عرض كان يعمل أصلًا.
  • لا شيء من جهاز العرض التجريبي أبدًا. لا يغادر شيء الجهاز ما دام جهاز العرض التجريبي محددًا أو أتمتة المنزل غير مفتوحة.
  • محفوظة بأمان. تُحفظ عناوين المشغلات في التخزين الآمن للجهاز.
Hubitat

اعكس جهاز العرض في Hubitat

يعكس التطبيق جهاز العرض هذا على جهاز في مركز Hubitat الخاص بك عبر Maker API: التشغيل والاستعداد، والمدخل بصيغة HDMI 1 أو HDMI 2، لأي من هذين يقبله الجهاز. وبعدها يستطيع Rule Machine التصرف بناءً عليه.

  1. في Hubitat، أضف Maker API ودوّن معرّف تطبيقه (الرقم الظاهر في روابطه) ورمز الوصول الخاص به.
  2. في التطبيق، أدخل عنوان المركز ومعرّف تطبيق Maker API ورمز الوصول.
  3. انقر على البحث عن جهاز واختر الجهاز الذي يمثل جهاز العرض هذا. إذا لم يبدُ أي جهاز مناسبًا، فأضف في Hubitat مفتاحًا افتراضيًا (Virtual Switch) باسم جهاز العرض وحاول مرة أخرى.
  4. فعّل عرض حالة جهاز العرض مطابقة. يتبع الجهاز جهاز العرض كلما تغير والتطبيق مفتوح ومتصل.
اتجاه واحد فقط. لا يُرسل شيء من Hubitat إلى جهاز العرض. يزيل إلغاء الربط الربط من التطبيق.
Home Assistant

أعمق رابط

يسجّل التطبيق الدخول إلى Home Assistant ويضيف جهاز العرض إلى تكامل JVC Projector فيه، وينشر مشاهدك وعناصر التحكم نصوصًا برمجية، ويبني لوحة معلومات. وله صفحاته الخاصة: إعداد Home Assistant ولوحة Home Assistant.
