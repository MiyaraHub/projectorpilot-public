جهاز تحكم عن بعد لأجهزة عرض Epson المتوافقة

Projector Pilot تطبيق تحكم عن بعد مستقل يعمل مع أجهزة عرض Epson ومع أي جهاز عرض يدعم PJLink عبر شبكتك الخاصة. ستعرف هنا الطرازات المتوافقة معه وما يوفره كل طراز.

كيف يعمل

التوافق حسب البروتوكول، لا حسب قائمة الطرازات

لا يحمل التطبيق قائمة بأرقام الطرازات. فهو يسأل جهاز العرض عمّا يدعمه ويعرض عناصر التحكم التي يستجيب لها، لذا يعمل أي جهاز عرض يتحدث PJLink أو Epson Web Control حتى لو لم يُذكر أدناه.

  • يوفر PJLink (الفئة 1 و2) التشغيل والمدخل وكتم الصوت وحالة المصباح أو الليزر على معظم أجهزة عرض Epson المتصلة بالشبكة.
  • يضيف Epson Web Control إعدادات الصورة والعدسة وتصحيح الميل وHDR في الطرازات التي توفرها.
  • ESC/VP21 هو بروتوكول الأوامر الخاص بجهاز العرض، ويُستخدم عندما يستجيب له جهاز العرض.
