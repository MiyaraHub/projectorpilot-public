Epson & PJLink

Projector Pilot

Pentru proiectoare Epson prin ESC/VP21 și Epson Web Control, și pentru orice proiector PJLink. Android, iOS, Windows și macOS.

  • Alimentare, intrare și meniul complet de imagine
  • Deplasare motorizată a obiectivului, focalizare, zoom și memorii de obiectiv
  • Scene, informații de întreținere și widgeturi
  • Home Assistant, Hubitat și webhookuri

JVC D-ILA

Projector Pilot D-ILA

Pentru proiectoare JVC D-ILA prin rețea, de la DLA-X până la seria NZ din 2025. Android, iOS, macOS și Windows.

  • Alimentare, intrări HDMI și setările de imagine documentate pentru fiecare model
  • Deplasare obiectiv, focalizare, zoom, memorie obiectiv și moduri de instalare
  • Scene, valori de întreținere și widgeturi
  • Home Assistant, Hubitat și webhookuri

  • Projector Pilot (Epson & PJLink): Google Play, App Store (iPhone, iPad și Mac) și Microsoft Store.

Întrebări frecvente

Întrebări și răspunsuri

  • De ce aplicație am nevoie? Projector Pilot este pentru proiectoare Epson prin ESC/VP21 și Web Control, și pentru orice proiector PJLink. Projector Pilot D-ILA este pentru proiectoare JVC D-ILA.
  • Au aplicațiile nevoie de un cont sau de un serviciu în cloud? Nu. Ambele aplicații comunică cu proiectorul în propria ta rețea locală.
  • Sunt abonamente? Nu. Fiecare aplicație are un nivel gratuit, iar achizițiile Pro, Home Automation și pachetul sunt plăți unice.
