Automatizarea casei

Conectează proiectorul la locuința ta

Lasă restul casei să reacționeze când proiectorul pornește, trece în standby, schimbă intrarea sau reapelează o scenă. Trei legături se află în Setări, Automatizare Locuință: declanșatoare webhook, Hubitat și Home Assistant. Toate trei necesită suplimentul Automatizare Locuință, vândut separat sau în pachet; Pro singur nu îl include.

Alege una

Ce legătură să folosești

Webhooks

Orice sistem care acceptă o cerere web: Node-RED, un server de acasă, o automatizare în cloud. Aplicația trimite, tu decizi ce se întâmplă.

Hubitat

O oglindă unidirecțională a alimentării și intrării pe un dispozitiv din hubul tău, prin Maker API, pentru ca Rule Machine să acționeze.

Home Assistant

Configurează integrarea JVC Projector proprie a Home Assistant, scripturi pentru scenele tale și un tablou de bord gata făcut.

Webhooks

Declanșatoare de automatizare

Un declanșator trimite o cerere web la o adresă introdusă de tine când se întâmplă ceva pe acest proiector. Fiecare proiector are propria listă. Atinge Adaugă declanșator, apoi alege:

  • Când: Proiectorul pornește, Proiectorul trece în standby, Intrarea se schimbă (la orice intrare sau la una anume) sau O scenă este reapelată (orice scenă sau una anume).
  • Metodă: POST (implicit), PUT sau GET.
  • Adresă web: o adresă http:// sau https:// cu un nume de gazdă.
  • Activat, ca să oprești temporar un declanșator fără să-l ștergi.
O adresă care începe cu http:// este trimisă necriptat, iar editorul spune asta. Folosește https:// când sistemul tău o acceptă.
Conținut

Ce transportă cererea

POST și PUT trimit un corp JSON; GET nu trimite niciunul. Singurul antet adăugat de aplicație este Content-Type. Un câmp care nu se aplică evenimentului este omis.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
CâmpSemnificație
eventpower_on, power_off, input_changed sau scene_recalled.
projectorNumele proiectorului din aplicație.
inputIntrarea, de exemplu hdmi1 sau hdmi2.
scene_id, scene_nameScena, pentru reapelarea unei scene.
timestampCând s-a întâmplat, în UTC.
testPrezent, și adevărat, doar într-o cerere trimisă prin Trimite test.
Livrare

O singură încercare, raportată sincer

  • Fiecare eveniment este trimis o singură dată, cu o limită de 10 secunde, iar redirecționările nu sunt urmate.
  • Declanșatorul își arată ultimul rezultat: Livrat la o oră cu codul de stare, Refuzat, Fără răspuns, Adresa nu a putut fi accesată, Conexiunea securizată a eșuat sau Încă netrimis.
  • Trimite test trimite o cerere marcată ca test, ca să poți configura celălalt capăt înainte ca proiectorul să facă ceva.
Când se declanșează

Regulile

  • Doar cât timp aplicația este deschisă și conectată la proiector. Aplicația urmărește starea proiectorului; nu este un serviciu de fundal.
  • Schimbări, nu citiri. Prima citire după conectarea aplicației stabilește doar punctul de pornire, așa că deschiderea aplicației nu declanșează "pornește" pentru un proiector care era deja pornit.
  • Niciodată de pe proiectorul demo. Nimic nu părăsește dispozitivul cât timp este selectat proiectorul demo sau Automatizare Locuință nu este deblocată.
  • Salvate securizat. Adresele declanșatoarelor sunt păstrate în stocarea securizată a dispozitivului.
Hubitat

Oglindește proiectorul în Hubitat

Aplicația oglindește acest proiector pe un dispozitiv din hubul tău Hubitat prin Maker API: pornit și standby, iar intrarea ca HDMI 1 sau HDMI 2, pentru oricare dintre acestea pe care le acceptă dispozitivul. Rule Machine poate apoi să acționeze pe baza lor.

  1. În Hubitat, adaugă Maker API și notează ID-ul aplicației (numărul din URL-urile ei) și tokenul de acces.
  2. În aplicație, introdu Adresa hub-ului, ID-ul aplicației Maker API și Tokenul de acces.
  3. Atinge Găsește dispozitivul și alege dispozitivul care reprezintă acest proiector. Dacă niciunul nu seamănă, adaugă în Hubitat un Virtual Switch cu numele proiectorului și încearcă din nou.
  4. Activează Oglindește starea proiectorului. Dispozitivul urmărește proiectorul ori de câte ori acesta se schimbă cât timp aplicația este deschisă și conectată.
Doar într-o direcție. Nimic nu este trimis din Hubitat către proiector. Deconectarea legăturii o elimină din aplicație.
