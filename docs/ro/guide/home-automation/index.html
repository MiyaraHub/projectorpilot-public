Proiectorul tău, în Home Assistant și Hubitat.

Projector Pilot publică starea live a proiectorului și fiecare comandă în Home Assistant, Hubitat și în orice webhook dorești. Îl configurezi o dată, iar casa ta inteligentă conduce singură proiectorul - fără telefon în rețea, fără cloud la mijloc.

Prezentare generală

Ce face Home Automation

Home Automation transformă Projector Pilot dintr-o telecomandă din mâna ta într-un dispozitiv pe care îl vede toată casa. Expune ce face proiectorul - alimentare, intrare, mod de culoare, valorile imaginii, orele lămpii - și oferă casei tale inteligente un control pentru tot ce poate schimba aplicația.

  • Publică starea. Proiectorul apare ca senzor Home Assistant, ca dispozitiv Hubitat sau ca payload JSON pe webhook-ul tău, cu aceleași valori pe care ți le arată aplicația.
  • Publică comenzile. Fiecare Scenă salvată, plus alimentarea, fiecare intrare, fiecare mod de culoare și fiecare memorie de obiectiv devine ceva ce o automatizare sau un asistent vocal poate rula.
  • Rulează fără server. După ce scripturile sunt configurate, Home Assistant trimite comenzile direct la adresa IP a proiectorului. Telefonul tău nu trebuie să fie în rețea și nimic nu trece printr-un cont în cloud.
Home Automation este un supliment plătit. Este o achiziție unică, separată de Projector Pilot Pro, iar un pachet le cumpără pe amândouă împreună, cu reducere. Fără abonament, fără cont, fără cloud. Vezi prețurile.

Trei căi de acces, un singur hub

Settings › Home Automation este hubul. Alege platforma pe care o rulezi - Home Assistant, Hubitat sau Webhooks - și configureaz-o acolo. Poți conecta mai multe deodată; sunt independente.

Home Assistant

Configurează Home Assistant

Conectează-te din aplicație, publică proiectorul ca senzor, lipește un bloc în configurația ta și sincronizează. De atunci, Home Assistant conduce singur proiectorul.

  1. Deschide Settings › Home Automation › Home Assistant.
  2. Scrie adresa Home Assistant (de exemplu http://homeassistant.local:8123 sau IP-ul lui), apoi atinge Sign in. Este o autentificare în browser pe propria ta instanță - nu ai niciun token de lipit. Folosește autentificarea ta obișnuită Home Assistant, inclusiv autentificarea în doi pași.
  3. Aplicația publică proiectorul ca senzor, cu o entitate de forma sensor.projector_pilot_epson_qb1000b_qb1000w, care conține alimentarea, intrarea, modul de culoare, valorile imaginii și orele lămpii.
  4. Activează Trimite starea proiectorului, ca aceste valori să se actualizeze în Home Assistant ori de câte ori se schimbă cât timp aplicația este deschisă, și activează Sync Advanced Controls pentru a publica scripturi pentru moduri de imagine, intrări, memorii de obiectiv și alimentare.
  5. Lipește blocul shell_command (de mai jos) în configuration.yaml, repornește Home Assistant, apoi atinge Sincronizează cu HA.

Blocul shell_command

Acesta este tot trucul fără server. Aplicația scrie o comandă pe care Home Assistant o rulează pentru a vorbi cu Web Control al proiectorului, iar fiecare script sincronizat apelează acea comandă cu un alt verb. Atinge Copy block în aplicație și lipește-l în configuration.yaml. Exemplul de mai jos este ilustrativ - aplicația completează adresa și numele de comandă ale proiectorului tău:

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

Doar exemplu. Aplicația îl generează pe al tău cu IP-ul real al proiectorului și un nume derivat din seria acestuia.

De ce fără server. Acel curl rulează pe dispozitivul Home Assistant, nu pe telefonul tău. Home Assistant ajunge direct la IP-ul proiectorului prin Web Control, așa că o automatizare pornește indiferent dacă aplicația este deschisă sau dacă telefonul tău e măcar acasă. Utilizatorul digest EPSONWEB este autentificarea Web Control; aplicația folosește parola Web Control deja salvată pentru proiector.

Testează conexiunea, Sincronizează și curățenia

  • Testează conexiunea verifică dacă aplicația poate ajunge la Home Assistant și dacă shell_command lipit este într-adevăr acolo, ca să găsești o greșeală de tastare înainte de a construi ceva peste ea.
  • Sincronizează cu HA scrie sau actualizează scripturile pentru Scenele și comenzile tale și construiește direct în Home Assistant un tablou de bord Projector Pilot gata făcut. Rulează-l din nou oricând adaugi o Scenă sau schimbi o comandă - se actualizează pe loc, fără să acumuleze duplicate.
  • Elimină scripturile orfane găsește scripturile scrise de aplicație care nu mai au o Scenă sau o comandă corespunzătoare - de exemplu după ce ștergi o Scenă - listează exact pe care le va elimina și întreabă mai întâi. Nu se șterge nimic până nu confirmi. Atinge doar scripturile create de Projector Pilot; nimic altceva din Home Assistant nu este deranjat, iar dacă Home Assistant nu își listează scripturile, nu se elimină nimic.
Listă de verificare pentru configurare

Aplicația îți spune ce este făcut și ce lipsește

Ecranul Home Assistant conține o Listă de verificare pentru configurare și un panou Ce are Home Assistant-ul tău, așa că nu mai ghicești niciodată ce pas a mai rămas. Fiecare rând spune dacă este făcut, lipsește sau nu s-a putut stabili și îți spune ce să faci în continuare.

  • Conectat la Home Assistant - autentificat și răspunde. Dacă Home Assistant nu răspunde, rândul îți spune să verifici adresa și că telefonul este în aceeași rețea.
  • Proiector adăugat în Home Assistant - dacă Home Assistant are deja acest proiector. Dacă nu, rândul te trimite să adaugi integrarea PJLink, iar pasul de adăugare a integrării afișează hostul și portul PJLink pe care le cere Home Assistant.
  • Senzorul de valori a fost înregistrat - senzorul care conține valorile proiectorului tău. Se înregistrează prima dată când aplicația citește proiectorul, iar rândul oferă Înregistrează acum sau Activează când ceva îl blochează.
  • Ce are Home Assistant-ul tău - HACS (magazinul comunității), integrarea Epson Projector Link, integrarea PJLink și comenzile Projector Pilot din configuration.yaml. Fiecare arată Găsit, Neinstalat sau Nu s-a putut stabili, cu butoanele Cum se instalează și Deschide în HACS acolo unde ajută.
Verifică din nou îți spune ce a găsit. Atinge Verifică din nou după ce repari ceva, iar aplicația citește din nou Home Assistant-ul tău și raportează rezultatul, în loc să te lase să te întrebi dacă a funcționat. Un rând care nu a putut fi verificat spune Nu s-a putut stabili, niciodată un da sau un nu ghicit.
Funcționează cu ce ai deja

Suport pentru integrarea PJLink de bază și carduri mai bogate când le ai

Projector Pilot află ce are instalat Home Assistant-ul tău și se adaptează. Funcționează cu integrarea PJLink de bază pe care Home Assistant o include deja, așa că un proiector PJLink pe care l-ai adăugat deja acolo este un cetățean de rangul întâi.

  • Mai întâi cardurile încorporate. Dacă nu ai carduri ale comunității, Sincronizarea îți construiește tabloul de bord cu cardurile încorporate ale Home Assistant și spune asta când termină. Funcționează din prima.
  • Îmbunătățit când sunt instalate cardurile HACS. Aplicația verifică care dintre cardurile comunității (Mushroom, button-card, card-mod, apexcharts-card) sunt instalate și trece fiecare card pe varianta mai bogată acolo unde o ai. Ghidul tabloului construit manual merge mai departe dacă vrei aspectul complet de sticlă verde.
  • Scenele și comenzile au nevoie de o singură lipire. Dacă Home Assistant nu are încă o comandă pentru trimiterea către proiector, tabloul de bord este construit oricum, cu valori live, iar un card Finalizează configurarea te ghidează: atinge Copy block, lipește-l în configuration.yaml, repornește Home Assistant, apoi atinge din nou Sincronizează.
  • Nu e nimic instalat? Lipește manual. Dacă nu e nimic instalat în Home Assistant, poți copia totul din aplicație și îl poți lipi singur.
  • O parolă este semnalată. Blocul de comandă pe care îl lipești spune când conține o parolă de proiector, ca să știi înainte să-l distribui sau să-l stochezi.
Cât timp proiectorul este oprit

Valori care rămân la locul lor

Un proiector în standby raportează foarte puține, așa că un tablou de bord ar rămâne de obicei gol. Senzorul ultimei valori cunoscute, opțional, păstrează în Home Assistant ultimele valori ale proiectorului - intrarea, orele lămpii sau ale laserului - cât timp proiectorul este oprit.

  • Este încă un bloc opțional: lipește-l la finalul configuration.yaml (sau adaugă doar liniile lui sub o secțiune template: existentă) și repornește Home Assistant. Aplicația are un buton Verifică dacă există care îți spune dacă Home Assistant îl are.
  • O oprire ajunge acum în Home Assistant ca off, așa că tabloul de bord și automatizările tale văd proiectorul ca oprit când este oprit.
Scene ca scripturi

Fiecare Scenă devine un script Home Assistant

După o sincronizare, Scenele tale nu rămân blocate în aplicație. Fiecare, plus alimentarea, fiecare intrare, fiecare mod de culoare și fiecare memorie de obiectiv pe care o are proiectorul tău, este scrisă ca script Home Assistant.

  • Automatizările le pot rula. „La apus, dacă TV-ul pornește, rulează Movie Night” este o automatizare Home Assistant obișnuită, odată ce Scena este un script.
  • Asistenții vocali le pot rula. Expune un script asistentului tău, iar „pornește Movie Night” setează împreună intrarea, modul de imagine și memoria de obiectiv.
  • Apar doar comenzile tale reale. Aplicația scrie un script pentru fiecare intrare, mod de culoare și memorie de obiectiv pe care le raportează proiectorul - nu o listă generică ghicită.
  • Oprirea sincronizării elimină doar ce a scris aplicația. Dezactivează sincronizarea sau folosește Elimină scripturile orfane (care le listează și întreabă mai întâi), iar Projector Pilot șterge scripturile create de el și nimic altceva.
Scripturile sunt denumite astfel încât o redenumire să actualizeze același script. Numele scripturilor derivă din proiector și din comandă, așa că re-sincronizarea după ce redenumești o Scenă actualizează scriptul existent, în loc să creeze o a doua copie.
Tabloul de bord

Sincronizarea construiește tabloul de bord pentru tine

Nu trebuie să construiești manual o vizualizare Lovelace și nici măcar să o mai lipești. Când atingi Sincronizează cu HA, aplicația construiește un tablou de bord Projector Pilot complet direct în Home Assistant, prin API-ul acestuia: starea live a proiectorului și un buton pentru fiecare Scenă și comandă sincronizată. Apare în bara laterală Home Assistant ca Projector Pilot - îl deschizi și gata.

  1. Conectează-te la Home Assistant în aplicație.
  2. Lipește Copy block al aplicației în configuration.yaml o singură dată și repornește Home Assistant (singurul pas manual - Home Assistant nu permite aplicațiilor să adauge de la distanță acea comandă).
  3. Atinge Sincronizează cu HA. Tabloul de bord este construit pentru tine și apare în bara laterală ca Projector Pilot.
Preferi să-l lipești singur? Copiază dashboardul este în continuare pe ecranul Home Assistant. Atinge-l, apoi în Home Assistant mergi la Settings › Dashboards › Add Dashboard, creează un tablou gol, deschide meniul lui cu trei puncte › Edit dashboard › meniul cu trei puncte › Raw configuration editor și lipește YAML-ul copiat.

Fie că este construit pentru tine, fie că îl lipești, tabloul de bord este același - un card de stare plus un buton pentru fiecare comandă (fragment ilustrativ):

views:
  - title: Projector
    cards:
      - type: entity
        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_power_on
      - type: button
        name: Movie Night
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_scene_movie_night

Doar exemplu. Tabloul tău de bord conține entitatea reală a proiectorului tău și propriile tale Scene.

Independent de model. Tabloul de bord este construit din capabilitățile proiectorului tău - entitatea, valorile imaginii, intrările, modurile de culoare, memoriile de obiectiv și Scenele pe care le-a raportat efectiv. Capturile de ecran de aici sunt de la un QB1000; modelul tău poate arăta alte intrări, comenzi și valori. Pentru un tablou complet în stil sticlă verde, ca cel din imagine, urmează ghidul pas cu pas al tabloului de bord sau descarcă vizualizarea completă și schimbă două șiruri de text.
Vrei un perete mai bogat? Aceleași scripturi conduc orice carduri dorești. Dacă ai folosit AVR Maestro, abordarea este identică - construiește plăci luminate pentru sursă și mod, antete live și istoric dintr-un singur senzor și din scripturile sincronizate.
Hubitat

Configurează Hubitat

Pe Hubitat, Projector Pilot oglindește proiectorul pe un dispozitiv din hubul tău prin Maker API, ca Rule Machine să poată citi și acționa asupra alimentării, mute-ului și intrării.

  1. În Hubitat, activează aplicația Maker API, notează URL-ul de acces și tokenul și alege ce dispozitive expune.
  2. În Projector Pilot, deschide Settings › Home Automation › Hubitat și introdu detaliile Maker API ale hubului tău.
  3. Alege dispozitivul care reprezintă proiectorul. Aplicația îl sugerează pe cel probabil; alege-l sau selectează-l pe al tău.
  4. Aplicația oglindește alimentarea, mute-ul și intrarea pe acel dispozitiv, trimițând doar comenzile pe care dispozitivul le acceptă.
  5. Construiește reguli Rule Machine pentru acel dispozitiv așa cum ai face pentru oricare altul - starea proiectorului le conduce.
Doar ce acceptă dispozitivul. Aplicația trimite o valoare a proiectorului către Hubitat doar când dispozitivul ales suportă acea comandă, așa că nu trimite niciodată ceva ce dispozitivul ar respinge.
Webhooks

Configurează Webhooks

Webhook-urile sunt soluția universală. Aplicația trimite un POST către un URL al tău când proiectorul pornește, se oprește, schimbă intrarea sau reapelează o Scenă - un webhook Home Assistant, Node-RED, IFTTT sau orice acceptă JSON.

  1. Deschide Settings › Home Automation › Webhooks.
  2. Introdu URL-ul către care se trimite. Un webhook Home Assistant arată ca http://homeassistant.local:8123/api/webhook/your-id.
  3. Alege ce evenimente declanșează webhook-ul: pornire, oprire, schimbarea intrării, reapelarea unei Scene - și, opțional, filtrează după o anumită intrare sau Scenă.
  4. Opțional, setează un payload personalizat dacă serviciul receptor vrea o anumită structură; altfel aplicația trimite JSON-ul ei implicit.
  5. Salvează. De atunci, aplicația trimite la fiecare eveniment potrivit.

Payload-ul implicit este JSON simplu - un eveniment, proiectorul și valoarea care s-a schimbat:

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

Payload exemplu. Un eveniment de schimbare a intrării sau de alimentare conține câmpurile relevante pentru el.

Reconectarea le repară pe toate. Dacă reconectezi Home Assistant la o adresă nouă, aplicația actualizează dintr-odată toate webhook-urile care îl vizează, așa că mutarea instanței nu înseamnă să editezi fiecare webhook manual.

Depanare

Autentificarea te aruncă înapoi la pagina de conectare

Asigură-te că adresa introdusă este cea la care ajungi de fapt la Home Assistant, inclusiv portul (de obicei :8123). Autentificarea este o conectare reală în browser pe instanța ta, așa că se aplică numele de utilizator, parola și codul de autentificare în doi pași. Pe telefon, autentificarea se finalizează fie că browserul din aplicație returnează rezultatul, fie că apelul local ajunge primul; dacă tot se blochează, închide fereastra și atinge din nou Sign in.

Senzorul proiectorului nu apare în Home Assistant

Senzorul este publicat cât timp aplicația este deschisă și Trimite starea proiectorului este activat, așa că deschide aplicația și confirmă acel comutator. Apoi verifică Developer Tools › States în Home Assistant și filtrează după projector_pilot. Un proiector în standby publică foarte puține; trezește-l și valorile se completează.

Scripturile sincronizate lipsesc

Scripturile sunt scrise de Sincronizează cu HA, care are nevoie ca blocul shell_command să fie deja lipit în configuration.yaml și Home Assistant repornit o dată. Rulează mai întâi Testează conexiunea - îți spune dacă blocul este prezent. Apoi Sincronizează din nou. Dacă scripturi vechi, moarte, aglomerează lista, folosește Elimină scripturile orfane.

Un script rulează în aplicație, dar nu din Home Assistant când telefonul meu e plecat

Exact despre asta este blocul shell_command - el permite Home Assistant să ajungă singur la IP-ul proiectorului. Dacă funcționează doar cu aplicația deschisă, probabil blocul nu e lipit sau Home Assistant nu a fost repornit după lipire. Confirmă cu Testează conexiunea, repornește Home Assistant și Sincronizează.

Întrebări frecvente

Răspunsuri rapide

Trebuie ca telefonul meu să rămână în rețea pentru ca automatizările Home Assistant să ruleze?

Nu. După ce lipești blocul shell_command în Home Assistant și sincronizezi, Home Assistant trimite comenzile direct la adresa IP a proiectorului. Projector Pilot este doar instrumentul de configurare; după aceea, Home Assistant vorbește singur cu proiectorul, indiferent dacă telefonul tău e acasă sau nu.

Cum apare proiectorul în Home Assistant?

Ca senzor, de exemplu sensor.projector_pilot_epson_qb1000b_qb1000w, care conține alimentarea, intrarea, modul de culoare, valorile imaginii și orele lămpii, actualizat ori de câte ori se schimbă, cât timp aplicația este deschisă. Activează Sync Advanced Controls și aplicația scrie în Home Assistant și un script pentru fiecare Scenă, plus alimentare, fiecare intrare, fiecare mod de culoare și fiecare memorie de obiectiv pe care o are proiectorul tău.
