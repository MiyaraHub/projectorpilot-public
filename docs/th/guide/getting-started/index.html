เริ่มต้นใช้งาน

เพิ่มโปรเจกเตอร์ Epson หรือ PJLink ของคุณในประมาณหนึ่งนาที

Projector Pilot ค้นหาโปรเจกเตอร์ของคุณในเครือข่ายของคุณเอง ไม่ต้องมีบัญชีคลาวด์ ไม่ต้องใช้รหัสจับคู่ เพียงต่อโทรศัพท์เข้ากับ Wi-Fi เดียวกัน เพิ่มโปรเจกเตอร์ครั้งเดียว แล้วแอปจะสแกนว่าเครื่องทำอะไรได้บ้างและจดจำไว้ นี่คือขั้นตอนทั้งหมด

ก่อนเริ่มต้น

สิ่งที่คุณต้องมี

  • เครือข่ายเดียวกัน โทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์ของคุณต้องอยู่ใน Wi-Fi (หรือ LAN แบบสาย) เดียวกับโปรเจกเตอร์ แอปคุยกับโปรเจกเตอร์โดยตรงบนเครือข่ายนั้น
  • โปรเจกเตอร์เปิดอยู่หรืออยู่ในโหมดสแตนด์บาย เปิดโปรเจกเตอร์ทิ้งไว้ หรือให้อยู่ในโหมดสแตนด์บายโดยเปิดการควบคุมผ่านเครือข่าย โปรเจกเตอร์ Epson ส่วนใหญ่ตอบสนองได้ในโหมดสแตนด์บาย คุณจึงเปิดเครื่องจากแอปได้
  • ที่อยู่ IP ของโปรเจกเตอร์ (เฉพาะเมื่อคุณเพิ่มด้วยตนเอง) อยู่ในเมนูเครือข่ายของโปรเจกเตอร์เอง ดูด้านล่างว่าต้องหาที่ไหน
ยังไม่มีโปรเจกเตอร์อยู่ใกล้ตัว? แตะ ลองโหมดสาธิต ในหน้าจอแรก แล้วทั้งแอปจะทำงานกับ Epson QB1000 ตัวจริงที่บันทึกไว้ ซึ่งตอบสนองเหมือนโปรเจกเตอร์จริง คุณจึงลองได้ทุกหน้าจอก่อนซื้ออะไรเลย
ทีละขั้นตอน

การเพิ่มโปรเจกเตอร์

เปิด เพิ่มโปรเจกเตอร์ แล้วเลือกวิธีค้นหา ทั้งสองทางไปจบที่เดียวกัน

  1. เลือกสแกนเครือข่ายหรือเพิ่มด้วย IP การสแกนเครือข่ายจะค้นหาอุปกรณ์ที่ตอบสนองเป็นโปรเจกเตอร์ทั่ว Wi-Fi หรือ LAN แบบสายของคุณ แล้วกรอกที่อยู่ให้ ส่วนเพิ่มด้วย IP เหมาะสำหรับตอนที่คุณอยากพิมพ์ที่อยู่เอง
  2. เลือกโปรเจกเตอร์ของคุณ หรือป้อน IP หากสแกน ให้แตะโปรเจกเตอร์ในรายการ หากทำเอง ให้พิมพ์ที่อยู่ IP จากเมนูเครือข่ายของโปรเจกเตอร์แล้วไปต่อ
  3. ปล่อยให้การสแกนความสามารถทำงาน เมื่อเพิ่มครั้งแรก แอปจะตรวจสอบโปรเจกเตอร์และแสดงแถบความคืบหน้า ให้คุณเห็นว่าถึงไหนแล้ว แอปกำลังถามโปรเจกเตอร์ว่ารองรับอะไรจริงๆ ทั้งโพรโทคอลที่ตอบสนอง ตัวควบคุมที่มี และช่วงของเลนส์และภาพ เพื่อให้แอปแสดงเฉพาะตัวควบคุมจริงเท่านั้น
  4. แตะทดสอบการเชื่อมต่อ แอปจะยืนยันว่าเข้าถึงโปรเจกเตอร์ได้และอ่านข้อมูลระบุตัวตนกลับมา หากโปรเจกเตอร์ต้องการรหัสผ่าน Web Control ให้ป้อนที่นี่ แอปจะตรวจสอบเองว่าต้องใช้รหัสผ่านหรือไม่ และบอกคุณไม่ว่าจะเป็นกรณีใด
  5. บันทึก เพิ่มโปรเจกเตอร์แล้ว และผลการสแกนความสามารถถูกจดจำไว้ เปิดแอปอีกครั้งก็ไม่ต้องสแกนซ้ำ คุณจะไปอยู่ที่แดชบอร์ดที่อ่านค่าสดๆ
โปรเจกเตอร์จะถูกสแกนครั้งเดียวและแคชผลไว้ นั่นคือเหตุผลที่การเปิดแอปครั้งที่สองเร็วทันใจ เพราะแอปรู้อยู่แล้วว่าฮาร์ดแวร์ของคุณทำอะไรได้บ้าง
การหาที่อยู่

ที่อยู่ IP ของโปรเจกเตอร์อยู่ตรงไหน

หากเพิ่มด้วย IP คุณต้องใช้ที่อยู่ของโปรเจกเตอร์ในเครือข่าย Epson ทุกเครื่องแสดงที่อยู่นี้ในที่เดียวกัน

  1. บนโปรเจกเตอร์ เปิดเมนูบนหน้าจอ แล้วไปที่ เครือข่าย (หรือ ขยาย › เครือข่าย ในบางรุ่น)
  2. เปิด การกำหนดค่าเครือข่าย › LAN แบบสาย หรือ LAN ไร้สาย แล้วอ่านที่อยู่ IP
  3. พิมพ์ที่อยู่นั้นลงในช่อง เพิ่มด้วย IP ควรตั้งที่อยู่คงที่หรือจองไว้ในเราเตอร์ เพื่อไม่ให้เปลี่ยนไปจนแอปหาไม่เจอ
การตั้งค่าเครือข่ายอยู่บนโปรเจกเตอร์ ไม่ใช่ในแอป Projector Pilot เข้าถึงโปรเจกเตอร์ผ่านเครือข่ายนั้น จึงแสดงหน้าเครือข่ายเป็นมุมมองแบบอ่านอย่างเดียวที่ชัดเจน คุณเปลี่ยนที่อยู่ได้ที่อินเทอร์เฟซของโปรเจกเตอร์เอง
หากเชื่อมต่อไม่ได้

วิธีแก้เบื้องต้น

  • ตรวจสอบเครือข่ายอีกครั้ง โทรศัพท์ที่หลุดไปเชื่อม Wi-Fi สำหรับแขกหรือเครือข่ายมือถือจะมองไม่เห็นโปรเจกเตอร์ ต้องเป็นเครือข่ายเดียวกันทั้งสองฝั่ง
  • ปลุกโปรเจกเตอร์ รุ่นที่ปิดสแตนด์บายเครือข่ายไว้จะไม่ตอบสนองจนกว่าจะเปิดเครื่อง เปิดเครื่องสักครั้งแล้วค่อยเพิ่ม
  • ขอรหัสผ่าน? ป้อนรหัสผ่าน Web Control (รหัสเดียวที่หน้าเว็บของโปรเจกเตอร์ขอ) แอปจัดการรหัสผ่านอื่นๆ ของโปรเจกเตอร์ให้ ดูคู่มือรีโมต
  • โปรเจกเตอร์ที่ใช้ PJLink อย่างเดียว? ถือเป็นอุปกรณ์ปกติ แอปจะใช้ช่องทางใดก็ได้ที่ตอบสนอง โปรเจกเตอร์ที่ไม่มี Web Control จึงยังใช้งานได้
