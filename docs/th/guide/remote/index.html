รีโมท

รีโมตโปรเจกเตอร์ตัวจริง ไม่ต้องใช้ถ่าน

แท็บรีโมตมีรีโมตบนหน้าจอและตัวควบคุมการทำงาน แบ่งเป็นหน้าย่อยที่ปัดสลับได้: รีโมต, การทำงาน, อุปกรณ์ และ เครือข่าย ทุกอย่างที่โปรเจกเตอร์มี และไม่มีปุ่มที่มันไม่มี

หน้ารีโมต

ไล่ดูเมนูของโปรเจกเตอร์เอง

  • D-pad นำทางพร้อมปุ่มเลือกตรงกลาง รวมถึง Menu, Back, Home และ Source ควบคุมเมนูบนหน้าจอของโปรเจกเตอร์ได้เหมือนรีโมตจริงทุกประการ
  • การเลือกอินพุต เพื่อข้ามไปยังแหล่งสัญญาณได้ทันที
  • โหมดสี เพื่อสลับโหมดภาพจากหน้าจอเดียวกัน
  • ปิดภาพหน้าจอ เพื่อซ่อนภาพ ปุ่มเปิดปิดอยู่บนแดชบอร์ด ไม่อยู่ที่นี่ จึงมีตัวควบคุมเปิดปิดเพียงตัวเดียว ไม่ใช่สามตัว
ปิดภาพหน้าจอไม่ใช่ปิดเสียง/ภาพ ปิดภาพหน้าจอซ่อนภาพขณะที่โปรเจกเตอร์ยังทำงานและสัญญาณยังไหลอยู่ ภาพจึงกลับมาทันที ใช้สำหรับพักชั่วคราว ไม่ใช่ปิดเครื่อง
หน้าการทำงาน - รูปทรง

แก้ไขรูปร่างของภาพ

เลือกวิธีแก้ไขที่ตรงกับการติดตั้งของคุณ แอปแสดงวิธีที่โปรเจกเตอร์รองรับ และใช้การแก้ไขรูปทรงได้ครั้งละหนึ่งอย่างตามที่ฮาร์ดแวร์กำหนด

วิธีใช้สำหรับ
ปิดไม่แก้ไข โปรเจกเตอร์ที่ตั้งตรงกับจอไม่ต้องใช้
H/V-Keystoneคีย์สโตนแนวนอนและแนวตั้งแยกอิสระ สำหรับโปรเจกเตอร์ที่ตั้งเยื้องขึ้นลงหรือซ้ายขวา
Quick Cornerลากแต่ละมุมทั้งสี่เข้าที่ เป็นวิธีแก้ประจำวันสำหรับภาพที่เกือบตรง
Point Correctionตารางจุดที่ขยับทีละจุด สำหรับความเพี้ยนเฉพาะที่แบบละเอียด
Curved Surfaceชดเชยการฉายลงบนจอหรือผนังโค้ง
Corner Wallแก้ไขเมื่อฉายเข้ามุมห้องที่ผนังสองด้านมาบรรจบกัน
ทุกค่าของรูปทรงจะถูกอ่านกลับจากโปรเจกเตอร์หลังจากที่คุณเปลี่ยน การแก้ไขที่โปรเจกเตอร์ไม่ได้ใช้จึงไม่ถูกแสดงเหมือนว่าใช้แล้ว
หน้าอุปกรณ์ - รหัสผ่าน

สามรหัสผ่าน ไม่ใช่หนึ่ง

โปรเจกเตอร์ Epson มีรหัสผ่านสามรหัสแยกกัน และปกป้องคนละส่วน Projector Pilot รู้ความแตกต่าง การป้อนรหัสที่คุณไม่ต้องใช้จึงไม่ทำให้คุณถูกล็อกออกจากแอป

รหัสผ่านปกป้อง
Web Controlหน้าเว็บของโปรเจกเตอร์และคำสั่งที่ทำงานผ่านหน้านั้น รวมถึงการเลื่อนเลนส์และการอ่านภาพในหลายรุ่น นี่คือรหัสที่หน้าเว็บของโปรเจกเตอร์เองขอ
PJLinkโพรโทคอล PJLink (TCP 4352) ที่ระบบควบคุมใช้ และในแอปใช้เป็นช่องทางสำรอง
รีโมทช่องทางควบคุมระยะไกล ESC/VP.net (TCP 3629) ซึ่งเป็นช่องทางที่แอปเลือกใช้เป็นอันดับแรก
แอปตรวจสอบก่อนว่าต้องใช้รหัสผ่านหรือไม่ก่อนตัดสินใจอะไร โปรเจกเตอร์ที่ตอบโดยไม่ขอรหัสจะถูกรายงานว่า “ไม่ต้องใช้รหัสผ่านที่นี่” ไม่ถูกติดป้ายว่าป้องกันไว้อย่างผิดๆ และไม่เคยสับสนระหว่าง “ไม่ได้ตั้ง” กับ “ตั้งไว้แต่โพรโทคอลนี้ไม่ต้องใช้” หากรหัสผ่าน Web Control ที่บันทึกไว้ใช้ไม่ได้ ตัวควบคุมเลนส์และภาพจะไม่ดับแล้วโทษเลนส์ แต่จะแสดงข้อความให้แตะเพื่อแก้ไขโดยอัปเดตรหัสผ่าน
หน้าอุปกรณ์ - ล็อก

ล็อกที่โปรเจกเตอร์บังคับใช้

หน้าอุปกรณ์แสดงล็อกของโปรเจกเตอร์เอง เมื่อตัวควบคุมใช้ไม่ได้เพราะโปรเจกเตอร์ล็อกไว้ แอปจะบอกว่าล็อกใดเป็นสาเหตุ แทนที่จะล้มเหลวเงียบๆ

  • ล็อกเลนส์ เมื่อล็อกเลนส์ของโปรเจกเตอร์เปิดอยู่ การเลื่อน โฟกัส และซูมจะถูกล็อกไว้ แอปรายงานว่าเลนส์ล็อกก็ต่อเมื่อโปรเจกเตอร์ปฏิเสธคำสั่งจริงๆ การเลื่อนที่ถูกรับแต่โปรเจกเตอร์ยืนยันตำแหน่งไม่ได้ไม่ถือว่าเป็นล็อก ตัวควบคุมจึงยังใช้งานได้
  • ล็อกป้องกันเด็ก ปิดใช้งานปุ่มเปิดปิดบนตัวโปรเจกเตอร์ เพื่อไม่ให้เด็กเปิดเครื่องแล้วจ้องแสง สลับได้จากที่นี่
  • ล็อกแผงควบคุม ล็อกปุ่มบนตัวโปรเจกเตอร์ ให้มีเพียงรีโมต (และแอป) เท่านั้นที่สั่งได้ สะดวกในห้องสาธารณะหรือห้องที่ใช้ร่วมกัน
หน้าเครือข่าย

มุมมองแบบอ่านอย่างเดียวที่ชัดเจน

การตั้งค่าเครือข่ายอยู่บนโปรเจกเตอร์ เพราะแอปเข้าถึงโปรเจกเตอร์ผ่านเครือข่ายนั้น หน้าเครือข่ายเป็นมุมมองแบบอ่านอย่างเดียวธรรมดาของที่อยู่ของโปรเจกเตอร์ พร้อมหมายเหตุอธิบายเหตุผล คุณเปลี่ยนค่าเหล่านี้ที่อินเทอร์เฟซของโปรเจกเตอร์เอง ดูในเริ่มต้นใช้งาน
