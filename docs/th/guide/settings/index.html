การตั้งค่า

การตั้งค่า Projector Pilot: ทำให้เป็นของคุณ

การตั้งค่าคือที่ที่คุณจัดการโปรเจกเตอร์ ปลดล็อกแอป ตั้งธีม ปรับความถี่ในการอัปเดตสถานะ และสำรองข้อมูลทั้งหมด จัดไว้ให้ตัวควบคุมอุปกรณ์ การซื้อ รูปลักษณ์ และลิงก์ อยู่ในที่ชัดเจนที่เดียวกัน ไม่มีโฆษณา ไม่มีค่าสมาชิก ไม่ต้องมีบัญชีคลาวด์ มีแค่สวิตช์ที่สำคัญ

โปรเจกเตอร์โปรเจกเตอร์ที่บันทึกไว้ของคุณ แต่ละเครื่องมีแก้ไข การเชื่อมต่อขั้นสูง ข้อมูล และลบ เพิ่มโปรเจกเตอร์จะสแกนเครือข่ายหาสิ่งที่ตอบสนองเป็นโปรเจกเตอร์ หรือรับที่อยู่ IP ที่ป้อนเอง ขั้นสูงเก็บพอร์ตของแต่ละโปรเจกเตอร์และรหัสผ่านสามรหัสแยกกัน (Web Control, PJLink และรีโมต)
Projector Pilot Proซื้อPro, Home Automation หรือชุดรวม และกู้คืนการซื้อ ราคาเป็นราคาของสโตร์ แสดงเป็นสกุลเงินของคุณก่อนยืนยัน การซื้อที่สโตร์แจ้งว่าคุณเป็นเจ้าของอยู่แล้วจะได้รับสิทธิ์ ไม่ถูกปฏิเสธ

แพตเทิร์นทดสอบแสดงตารางจัดแนวในตัวของโปรเจกเตอร์เองเป็นตัวควบคุมเปิดปิดที่ตรงไปตรงมา สำหรับจัดภาพให้พอดีกับจอของคุณ
ธีมสว่าง มืด AMOLED (ดำสนิท) หรือ Brand (สีเขียวป่าอันเป็นเอกลักษณ์) พร้อมธีมสี เลือกค่าที่ตั้งไว้ล่วงหน้าหรือสีเน้นของคุณเอง แล้วแอปจะสร้างจานสีใหม่รอบสีนั้น
ปรับแต่งแท็บ & มุมมองจัดเรียงแท็บด้านล่างใหม่และซ่อนแท็บที่คุณไม่ใช้ รวมถึงซ่อนมุมมองย่อยภายในแท็บ (ภาพ / สัญญาณ / การแสดงผล, เลนส์ / การติดตั้ง, รีโมต / การทำงาน, การตั้งค่า / เครือข่าย / อุปกรณ์)
ความถี่ในการอัปเดตสถานะแอปรีเฟรชสถานะสดของโปรเจกเตอร์บ่อยแค่ไหน การเปลี่ยนแปลงมีผลทันที โดยไม่มีคำสั่งสอบถามพรั่งพรูขณะที่คุณลากแถบเลื่อน

โปรเจกเตอร์

เพิ่ม แก้ไข และเชื่อมต่อ

  • เพิ่มโปรเจกเตอร์ได้สองวิธี สแกน Wi-Fi หรือเครือข่ายแบบสายหาสิ่งที่ตอบสนองเป็นโปรเจกเตอร์แล้วให้แอปกรอกที่อยู่ให้ หรือพิมพ์ IP เอง โปรเจกเตอร์ที่เพิ่งเพิ่มจะแสดงแถบความคืบหน้าขณะสแกนความสามารถ และผลจะถูกจดจำ เปิดแอปอีกครั้งจึงไม่ต้องสแกนซ้ำ
  • แก้ไข ตรวจดู หรือลบ โปรเจกเตอร์ที่บันทึกไว้แต่ละเครื่องมีดินสอแก้ไข มุมมองการเชื่อมต่อขั้นสูง แผงข้อมูล และปุ่มลบ ขั้นสูงคือที่ที่พอร์ตของแต่ละโปรเจกเตอร์อยู่ ควบคู่กับรหัสผ่านทั้งสาม
  • สามรหัสผ่านแยกกัน โปรเจกเตอร์มีได้สูงสุดสามรหัส: Web Control, PJLink และรีโมต เป็นรหัสผ่านต่างกันสำหรับโพรโทคอลต่างกัน บันทึกแยกตามโปรเจกเตอร์ และแอปตรวจสอบว่าโปรเจกเตอร์ต้องการรหัสไหนจริง แทนที่จะสมมติว่าป้องกันไว้
การปลดล็อกแอป

Pro, Home Automation และชุดรวม

Projector Pilot ขายเป็นสองส่วน ซื้อครั้งเดียวทั้งคู่ Pro คือแอปขั้นสูง Home Automation เป็นการซื้ออีกชิ้นหนึ่ง ส่วนชุดรวมซื้อทั้งสองอย่าง ผู้ที่ซื้อ Pro ก่อนแยกส่วนจะยังได้ทุกอย่างที่ Pro เคยมี

  • Projector Pilot Pro ฉาก หลายโปรเจกเตอร์ ควบคุมภาพเต็มรูปแบบ เลนส์และรูปทรง การบำรุงรักษา วิดเจ็ต แพตเทิร์นทดสอบ และโปรไฟล์ที่แชร์ได้
  • Home Automation Home Assistant, Hubitat และ webhooks
  • ชุดรวม ทั้งสองอย่างในการซื้อครั้งเดียว
  • กู้คืน ให้สิทธิ์สิ่งที่คุณซื้อไว้แล้วในบัญชีสโตร์นี้อีกครั้ง หากสโตร์รายงานว่ามีสิ่งนั้นอยู่แล้ว แอปจะให้สิทธิ์แทนที่จะแสดงข้อผิดพลาด ฟีเจอร์ที่คุณจ่ายเงินแล้วจึงไม่มีวันล็อกคุณออก
ราคาเป็นราคาของสโตร์เสมอ แสดงเป็นสกุลเงินของคุณก่อนยืนยัน แอปไม่แต่งตัวเลขขึ้นเอง บนแพลตฟอร์มที่ไม่มีสโตร์ แอปรวมทุกอย่างไว้ แทนที่จะแสดงเพย์วอลล์ที่ไม่มีใครจ่ายได้ ดูรายละเอียดทั้งหมดที่ราคา
รูปลักษณ์

ธีมและธีมสี

  • สว่าง ธีมสีขาวสะอาดตา
  • มืด พื้นผิวสีเข้มมาตรฐาน
  • AMOLED สีดำสนิทสำหรับหน้าจอ OLED
  • Brand สีเขียวป่าอันเป็นเอกลักษณ์ของแอป
  • ธีมสี เลือกสีเน้นที่ตั้งไว้ล่วงหน้าหรือสีของคุณเอง แล้วแอปจะสร้างจานสีทั้งหมดใหม่รอบสีนั้น
คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการตั้งค่า

ฉันจะเพิ่มโปรเจกเตอร์ได้อย่างไร
ไปที่การตั้งค่า เพิ่มโปรเจกเตอร์ ให้แอปสแกนเครือข่ายและกรอกที่อยู่ให้ หรือพิมพ์ IP เอง โปรเจกเตอร์ใหม่จะถูกสแกนความสามารถครั้งเดียวพร้อมแถบความคืบหน้า และผลจะถูกจดจำไว้
พอร์ตและรหัสผ่านอยู่ที่ไหน
เปิดมุมมองการเชื่อมต่อขั้นสูงของโปรเจกเตอร์ที่บันทึกไว้ พอร์ตของแต่ละโปรเจกเตอร์และรหัสผ่านสามรหัสแยกกัน ได้แก่ Web Control, PJLink และรีโมต อยู่ที่นั่น
ฉันซื้อ Pro ไปแล้ว ต้องซื้อ Home Automation ด้วยหรือไม่
ไม่ต้อง ผู้ที่ซื้อ Pro ก่อนที่แอปจะแยกเป็นสองส่วนจะยังได้ทุกอย่างที่ Pro เคยมี ไม่มีสิ่งใดที่ปลดล็อกไว้แล้วถูกเอาออก
รหัสผ่านของฉันจะไปอยู่ในไฟล์สำรองหรือไม่
ไม่ การสำรองและกู้คืนครอบคลุมการตั้งค่าแอปของคุณ ส่วนโปรเจกเตอร์ที่บันทึกไว้และรหัสผ่านของมันอยู่ในที่เก็บข้อมูลปลอดภัยที่เข้ารหัส และไม่เคยไปกับไฟล์สำรอง
ฉันเปลี่ยนความถี่ที่แอปสอบถามโปรเจกเตอร์ได้หรือไม่
ได้ ความถี่ในการอัปเดตสถานะกำหนดว่าสถานะสดรีเฟรชบ่อยแค่ไหน และการเปลี่ยนแปลงมีผลทันทีโดยไม่มีคำสั่งสอบถามพรั่งพรูขณะที่คุณลากแถบเลื่อน
