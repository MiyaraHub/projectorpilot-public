แท็บเลนส์

เลื่อนเลนส์ โฟกัส และซูม อย่างมีเป้าหมาย

เลื่อน โฟกัส และซูมเลนส์มอเตอร์ของโปรเจกเตอร์จากแผงปุ่มที่แม่นยำ เรียกคืนและบันทึกหน่วยความจำเลนส์ที่โปรเจกเตอร์รองรับ และอ่านตำแหน่งที่แน่นอนกลับมาจากตัวเครื่อง ทุกตัวเลขมาจากโปรเจกเตอร์ และตำแหน่งที่โปรเจกเตอร์ยืนยันไม่ได้จะแสดงว่าไม่ทราบ ไม่แกล้งทำเป็นว่าล็อกอยู่

แท็บเลนส์มีสองแท็บย่อย: เลนส์ สำหรับการเลื่อน โฟกัส ซูม และหน่วยความจำที่ใช้ทุกวัน และ การติดตั้ง สำหรับการปรับตั้งค่าครั้งเดียว

การเลื่อนเลนส์

แผงปุ่มทิศทาง และขนาดสเต็ปที่คุณเลือก

แผงเลื่อนขยับเลนส์ขึ้น ลง ซ้าย และขวา สิ่งที่เปลี่ยนมันจากของเล่นเป็นเครื่องมือคือตัวเลือกขนาดสเต็ปด้านล่าง เลือกได้ว่าการแตะครั้งเดียวขยับเลนส์ไกลแค่ไหน ตั้งแต่การจัดเฟรมละเอียดไปจนถึงการย้ายตำแหน่งแบบหยาบ

ขั้นตอนที่ 1

การขยับที่ละเอียดที่สุด ขยับภาพทีละนิดเพื่อจัดขอบให้ตรงกับกรอบจอของคุณ

ขั้นตอนที่ 5

การตั้งค่าระดับกลางที่สบายๆ สำหรับดึงภาพเข้าที่เมื่อใกล้ถึงตำแหน่งแล้ว

ขั้นตอนที่ 10

ขยับได้ไกลเร็วๆ ขณะที่ยังหาตำแหน่งคร่าวๆ อยู่

สเต็ป 25

การขยับแบบหยาบ สำหรับดันเลนส์ข้ามช่วงเลื่อนส่วนใหญ่ในไม่กี่แตะ

ขนาดสเต็ปที่คุณเลือกใช้กับการเลื่อน โฟกัส และซูมเหมือนกัน การตั้งค่าเดียวจึงกำหนดว่าตัวควบคุมเลนส์ทุกตัวขยับไกลแค่ไหนต่อหนึ่งแตะ เริ่มจากหยาบเพื่อเข้าใกล้ตำแหน่ง แล้วลดเหลือ 1 เพื่อจัดเฟรมให้เสร็จ
โฟกัส & ซูม

ความคมชัดและขนาด ในเงื่อนไขเดียวกัน

  • โฟกัส ปุ่มลบและบวกขับมอเตอร์โฟกัส แต่ละแตะขยับตามขนาดสเต็ปที่คุณตั้ง ตำแหน่งมอเตอร์โฟกัสปัจจุบันแสดงอยู่เหนือปุ่ม คุณจึงกลับไปยังค่าที่รู้ได้
  • ซูม ปุ่มลบและบวกคู่เดียวกันขับมอเตอร์ซูม ตามขนาดสเต็ปที่คุณเลือกเช่นกัน พร้อมตำแหน่งมอเตอร์ซูมสดแสดงอยู่ข้างๆ
  • อ่านกลับ ไม่ใช่เดา ค่าโฟกัสและซูมคือตำแหน่งมอเตอร์ที่โปรเจกเตอร์รายงาน สิ่งที่คุณเห็นจึงเป็นตำแหน่งที่เลนส์อยู่จริง ไม่ใช่ที่แอปหวังว่าจะไปถึง
หน่วยความจำเลนส์

เรียกคืนการตั้งค่าที่บันทึกไว้ หรือบันทึกอันนี้

โปรเจกเตอร์ที่มีหน่วยความจำเลนส์เก็บตำแหน่งการเลื่อน โฟกัส และซูมทั้งหมดไว้ในช่องที่มีชื่อ Projector Pilot แสดงรายการช่องที่โปรเจกเตอร์ของคุณรองรับจริง และให้คุณเรียกคืนได้ในการแตะครั้งเดียว หรือบันทึกตำแหน่งปัจจุบันลงในช่องนั้น

  • เรียกคืน แตะหน่วยความจำเพื่อส่งเลนส์ไปยังตำแหน่งการเลื่อน โฟกัส และซูมที่เก็บไว้ ตามที่การตั้งค่าแบบอะนามอร์ฟิกหรืออัตราส่วนภาพอื่นต้องการ
  • บันทึก เก็บตำแหน่งเลนส์ปัจจุบันลงในช่อง เพื่อกลับมาใช้ภายหลัง
  • เฉพาะช่องจริง แอปแสดงช่องหน่วยความจำที่โปรเจกเตอร์รายงานว่ามี ไม่ใช่รายการตายตัวที่สมมติว่าทุกรุ่นมี
หน่วยความจำเลนส์เข้ากันได้ดีกับฉาก: ฉากหนึ่งเก็บหน่วยความจำเลนส์ไว้ควบคู่กับอินพุตและโหมดภาพได้ การแตะครั้งเดียวจึงตั้งค่าทั้งห้องสำหรับหนังจอกว้างหรือรายการ 16:9
ค่าตำแหน่ง

ขอบเขตการเลื่อน ในรูปแผนภาพ

ด้านบนของแท็บเลนส์แสดงตำแหน่งเลนส์ปัจจุบันสองแบบ: เป็นตัวเลขและเป็นแผนภาพ

  • ค่า V-Shift และ H-Shift ตำแหน่งการเลื่อนแนวตั้งและแนวนอน แต่ละค่าแสดงเป็นค่าปัจจุบันจากช่วงเลื่อนเต็มของโปรเจกเตอร์ (เช่น 595 จาก 1023) คุณจึงรู้เสมอว่าเหลือที่ว่างเท่าไรก่อนเลนส์ถึงขีดจำกัด
  • แผนภาพขอบเขต กล่องที่พล็อตตำแหน่งเลนส์เป็นจุดภายในช่วงเลื่อนของโปรเจกเตอร์ แนวตั้งเทียบกับแนวนอน คุณจึงเห็นได้ในแวบเดียวว่าเลนส์อยู่กึ่งกลางหรือถูกดันไปทางมุมใดมุมหนึ่ง
ทิศทางเป็นหน้าที่ของโปรเจกเตอร์ และแอปเคารพสิ่งนั้น ติดเพดาน ฉายด้านหลัง หรือด้านหน้า ขึ้นคือขึ้น แอปทำตามการแมปของโปรเจกเตอร์เองและไม่สลับทิศแผงปุ่มเพื่อเดาการติดตั้งของคุณ แตะขึ้นแล้วภาพก็ขึ้น ไม่ว่าโปรเจกเตอร์จะยึดอยู่ที่ไหน
ซื่อตรงเป็นค่าเริ่มต้น

ตำแหน่งที่ยืนยันไม่ได้คือไม่ทราบ ไม่ใช่ล็อก

โปรเจกเตอร์บางรุ่นรับคำสั่งเลื่อนเลนส์และทำตาม แต่ตำแหน่งที่รายงานกลับมาไม่เปลี่ยนตามมอเตอร์ ในรุ่นอย่าง QB1000 ความล่าช้านั้นอ่านผิดได้ง่ายว่าเลนส์ค้าง

  • การเลื่อนที่ถูกรับแต่ตำแหน่งยืนยันไม่ได้ยังใช้งานได้ แอปไม่ทำให้ตัวควบคุมเป็นสีเทาหรือพาคุณไปที่ล็อกเลนส์อีกแล้ว เพียงเพราะค่าที่รายงานไม่ขยับ คำสั่งถูกรับแล้ว ตัวควบคุมจึงยังใช้งานได้
  • มีเพียงการปฏิเสธจริงเท่านั้นที่ถูกรายงานว่าเป็นล็อก หากโปรเจกเตอร์ปฏิเสธคำสั่งจริงๆ เมื่อนั้นเท่านั้นแอปจึงบอกว่าเลนส์ล็อกอยู่ และทำงานได้ทั้งมีและไม่มีรหัสผ่าน Web Control
  • การล็อกอินที่ถูกปฏิเสธคือไม่ทราบ ไม่ใช่ล็อก หากการเลื่อนเลนส์ผ่าน Web Control และล็อกอินนั้นถูกปฏิเสธ แอปจะถือว่าเลนส์ไม่ทราบสถานะ และแสดงข้อความเตือนให้แตะเพื่อแก้ไขโดยอัปเดตรหัสผ่าน Web Control แทนที่จะโทษเลนส์
แท็บย่อยการติดตั้ง

การปรับตั้งค่าครั้งเดียว

แท็บย่อยการติดตั้งเก็บตัวควบคุมรูปทรงและตัวควบคุมสำหรับช่างติดตั้งที่คุณตั้งครั้งเดียวตอนติดตั้งโปรเจกเตอร์และแทบไม่ได้แตะอีก เป็นคู่กับการเลื่อนเลนส์ประจำวันในแท็บย่อยเลนส์

ตัวควบคุมสำหรับช่างติดตั้งจะปรากฏเฉพาะที่โปรเจกเตอร์รองรับ และอ่านกลับมาจากตัวเครื่อง สิ่งที่คุณเห็นจึงเป็นสิ่งที่รุ่นของคุณมีจริง ไม่ใช่ชุดที่สมมติไว้
