Home Assistant · Hubitat · Webhooks

โปรเจกเตอร์ของคุณ ใน Home Assistant และ Hubitat

Projector Pilot เผยแพร่สถานะสดและทุกตัวควบคุมของโปรเจกเตอร์ไปยัง Home Assistant, Hubitat และWebhooksใดก็ได้ที่คุณต้องการ ตั้งค่าครั้งเดียว บ้านอัจฉริยะของคุณก็สั่งโปรเจกเตอร์ได้เอง ไม่ต้องมีโทรศัพท์อยู่ในเครือข่าย ไม่ต้องมีคลาวด์คั่นกลาง

ไม่ต้องมีเซิร์ฟเวอร์หลังตั้งค่าฉากกลายเป็นสคริปต์แดชบอร์ดสำเร็จรูปรายการตรวจสอบการตั้งค่าส่วนเสริมแบบเสียเงิน
ภาพรวม

ระบบอัตโนมัติในบ้านทำอะไรได้บ้าง

ระบบอัตโนมัติในบ้านเปลี่ยน Projector Pilot จากรีโมตในมือคุณให้เป็นอุปกรณ์ที่ทั้งบ้านมองเห็นได้ ระบบเผยแพร่สิ่งที่โปรเจกเตอร์กำลังทำ ทั้งเปิดปิด อินพุต โหมดสี ตัวเลขภาพ และชั่วโมงหลอดภาพ และมอบตัวควบคุมสำหรับทุกสิ่งที่แอปเปลี่ยนได้ให้กับบ้านอัจฉริยะของคุณ

  • เผยแพร่สถานะ โปรเจกเตอร์ปรากฏเป็นเซนเซอร์ใน Home Assistant อุปกรณ์ใน Hubitat หรือ JSON payload บนWebhooksของคุณ พร้อมค่าที่อ่านได้เหมือนที่แอปแสดงให้คุณเห็น
  • เผยแพร่ตัวควบคุม ทุกฉากที่คุณบันทึก รวมถึงเปิดปิด ทุกอินพุต ทุกโหมดสี และทุกหน่วยความจำเลนส์ จะกลายเป็นสิ่งที่ระบบอัตโนมัติหรือผู้ช่วยเสียงสั่งใช้ได้
  • ทำงานโดยไม่ต้องมีเซิร์ฟเวอร์ เมื่อตั้งค่าสคริปต์แล้ว Home Assistant จะส่งคำสั่งตรงไปยังที่อยู่ IP ของโปรเจกเตอร์ โทรศัพท์ของคุณไม่จำเป็นต้องอยู่ในเครือข่าย และไม่มีอะไรผ่านบัญชีคลาวด์
ระบบอัตโนมัติในบ้านเป็นส่วนเสริมแบบเสียเงิน ซื้อครั้งเดียว แยกจาก Projector Pilot Pro และชุดรวมซื้อทั้งสองอย่างพร้อมกันในราคาประหยัดกว่า ไม่มีค่าสมาชิก ไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ ดูราคา

สามทางเข้า ศูนย์กลางเดียว

การตั้งค่า › ระบบอัตโนมัติในบ้าน คือศูนย์กลาง เลือกแพลตฟอร์มที่คุณใช้ ไม่ว่าจะเป็น Home Assistant, Hubitat หรือWebhooks แล้วตั้งค่าที่นั่น คุณเชื่อมต่อได้มากกว่าหนึ่งแพลตฟอร์มพร้อมกัน แต่ละอันเป็นอิสระต่อกัน

Home Assistant

ตั้งค่า Home Assistant

เข้าสู่ระบบจากแอป เผยแพร่โปรเจกเตอร์เป็นเซนเซอร์ วางหนึ่งบล็อกลงในการกำหนดค่าของคุณ แล้วซิงค์ จากนั้น Home Assistant จะสั่งโปรเจกเตอร์ได้เอง

  1. เปิด การตั้งค่า › ระบบอัตโนมัติในบ้าน › Home Assistant
  2. พิมพ์ที่อยู่ Home Assistantของคุณ (เช่น http://homeassistant.local:8123 หรือ IP ของมัน) แล้วแตะเข้าสู่ระบบ เป็นการเข้าสู่ระบบผ่านเบราว์เซอร์กับอินสแตนซ์ของคุณเอง ไม่ต้องวางโทเคน ใช้การล็อกอิน Home Assistant ปกติของคุณ รวมถึงการยืนยันตัวตนสองขั้นตอน
  3. แอปเผยแพร่โปรเจกเตอร์เป็นเซนเซอร์ โดยมีเอนทิตีอย่าง sensor.projector_pilot_epson_qb1000b_qb1000w ที่มีสถานะเปิดปิด อินพุต โหมดสี ตัวเลขภาพ และชั่วโมงหลอดภาพ
  4. เปิดส่งสถานะของโปรเจกเตอร์ เพื่อให้ค่าเหล่านั้นอัปเดตใน Home Assistant ทุกครั้งที่เปลี่ยนขณะเปิดแอปอยู่ และเปิดซิงค์ตัวควบคุมขั้นสูง เพื่อเผยแพร่สคริปต์สำหรับโหมดภาพ อินพุต หน่วยความจำเลนส์ และเปิดปิด
  5. วางบล็อก shell_command หนึ่งบล็อก (ด้านล่าง) ลงใน configuration.yaml ของคุณ รีสตาร์ท Home Assistant แล้วแตะซิงค์กับ HA

บล็อก shell_command

นี่คือเคล็ดลับทั้งหมดของการทำงานโดยไม่ต้องมีเซิร์ฟเวอร์ แอปเขียนหนึ่งคำสั่งที่ Home Assistant รันเพื่อคุยกับ Web Control ของโปรเจกเตอร์ และทุกสคริปต์ที่ซิงค์จะเรียกคำสั่งนั้นด้วยคำกริยาที่ต่างกัน แตะคัดลอกบล็อกในแอปแล้ววางลงใน configuration.yaml ตัวอย่างด้านล่างเป็นเพียงภาพประกอบ แอปจะกรอกที่อยู่และชื่อคำสั่งของโปรเจกเตอร์คุณเองให้:

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

เป็นเพียงตัวอย่าง แอปสร้างของคุณโดยใช้ IP จริงของโปรเจกเตอร์และชื่อที่มาจากซีเรียล

ทำไมไม่ต้องมีเซิร์ฟเวอร์ curl นั้นรันบนเครื่อง Home Assistant ไม่ใช่โทรศัพท์ของคุณ Home Assistant เข้าถึง IP ของโปรเจกเตอร์โดยตรงผ่าน Web Control ระบบอัตโนมัติจึงทำงานไม่ว่าจะเปิดแอปอยู่หรือไม่ และไม่ว่าโทรศัพท์คุณจะอยู่บ้านหรือไม่ ผู้ใช้ digest EPSONWEB คือการล็อกอิน Web Control แอปใช้รหัสผ่าน Web Control ที่บันทึกไว้แล้วสำหรับโปรเจกเตอร์

ทดสอบการเชื่อมต่อ ซิงค์ และการล้างข้อมูล

  • ทดสอบการเชื่อมต่อ ตรวจสอบว่าแอปเข้าถึง Home Assistant ของคุณได้ และ shell_command ที่วางไว้มีอยู่จริง คุณจึงเจอข้อผิดพลาดในการพิมพ์ก่อนจะสร้างอะไรทับลงไป
  • ซิงค์กับ HA เขียนหรืออัปเดตสคริปต์สำหรับฉากและตัวควบคุมของคุณ และสร้างแดชบอร์ด Projector Pilot สำเร็จรูปลงใน Home Assistant โดยตรง รันอีกครั้งได้ทุกเมื่อที่คุณเพิ่มฉากหรือเปลี่ยนตัวควบคุม ระบบจะอัปเดตที่เดิมแทนที่จะสร้างซ้ำสะสม
  • ลบสคริปต์ที่ไม่มีเจ้าของ ค้นหาสคริปต์ที่แอปเขียนไว้ซึ่งไม่มีฉากหรือตัวควบคุมที่ตรงกันอีกต่อไป เช่นหลังจากที่คุณลบฉาก แสดงรายการที่จะลบอย่างชัดเจน และถามก่อน ไม่มีอะไรถูกลบจนกว่าคุณจะยืนยัน และแตะต้องเฉพาะสคริปต์ที่ Projector Pilot สร้างเท่านั้น ส่วนอื่นๆ ใน Home Assistant ของคุณไม่ถูกรบกวน และหาก Home Assistant ไม่แสดงรายการสคริปต์ ก็จะไม่มีอะไรถูกลบ
รายการตรวจสอบการตั้งค่า

แอปบอกคุณว่าอะไรเสร็จแล้วและอะไรยังขาด

หน้าจอ Home Assistant มีรายการตรวจสอบการตั้งค่าและแผงสิ่งที่ Home Assistant ของคุณมี คุณจึงไม่ต้องเดาว่าเหลือขั้นตอนไหน แต่ละแถวบอกว่าเสร็จแล้ว ขาด หรือระบุไม่ได้ และบอกว่าควรทำอะไรต่อ

  • เชื่อมต่อกับ Home Assistant แล้ว - เข้าสู่ระบบแล้วและตอบสนอง หาก Home Assistant ไม่ตอบสนอง แถวนี้จะบอกให้ตรวจสอบที่อยู่และว่าโทรศัพท์ของคุณอยู่ในเครือข่ายเดียวกัน
  • เพิ่มโปรเจกเตอร์ใน Home Assistant แล้ว - Home Assistant มีโปรเจกเตอร์นี้อยู่แล้วหรือไม่ หากยังไม่มี แถวนี้จะพาคุณไปเพิ่มการเชื่อมต่อ PJLink และขั้นตอนเพิ่มการเชื่อมต่อจะแสดงโฮสต์และพอร์ต PJLink ที่ Home Assistant ขอ
  • ลงทะเบียนเซนเซอร์ค่าที่อ่านแล้ว - เซนเซอร์ที่เก็บค่าที่อ่านได้ของโปรเจกเตอร์ จะลงทะเบียนเมื่อแอปอ่านโปรเจกเตอร์ครั้งแรก และแถวนี้มีปุ่มลงทะเบียนเลยหรือเปิดเมื่อมีบางอย่างขัดขวาง
  • สิ่งที่ Home Assistant ของคุณมี - HACS (ร้านค้าชุมชน) การเชื่อมต่อ Epson Projector Link การเชื่อมต่อ PJLink และคำสั่ง Projector Pilot ใน configuration.yaml แต่ละรายการแสดงว่าพบ ไม่ได้ติดตั้ง หรือไม่สามารถระบุได้ พร้อมปุ่มวิธีติดตั้งและเปิดใน HACS ในจุดที่ช่วยได้
ตรวจสอบอีกครั้งจะบอกว่าพบอะไร แตะตรวจสอบอีกครั้งหลังจากแก้ไขบางอย่าง แอปจะอ่าน Home Assistant ของคุณใหม่และรายงานผล แทนที่จะปล่อยให้คุณสงสัยว่าได้ผลหรือไม่ แถวที่ตรวจสอบไม่ได้จะแสดงไม่สามารถระบุได้ ไม่เคยเดาว่าใช่หรือไม่ใช่
ทำงานร่วมกับสิ่งที่คุณมีอยู่แล้ว

รองรับการเชื่อมต่อ PJLink หลัก และการ์ดที่หรูกว่าเมื่อคุณมี

Projector Pilot ตรวจสอบว่า Home Assistant ของคุณติดตั้งอะไรไว้ แล้วสร้างให้เหมาะกัน ทำงานร่วมกับการเชื่อมต่อ PJLink หลักที่ Home Assistant มีมาให้อยู่แล้ว โปรเจกเตอร์ PJLink ที่คุณเพิ่มไว้ที่นั่นจึงได้รับการดูแลอย่างเต็มที่

  • การ์ดในตัวมาก่อน หากคุณไม่มีการ์ดจากชุมชน การซิงค์จะสร้างแดชบอร์ดด้วยการ์ดในตัวของ Home Assistant และบอกคุณเมื่อเสร็จ ใช้งานได้ทันทีโดยไม่ต้องตั้งค่าเพิ่ม
  • อัปเกรดเมื่อติดตั้งการ์ด HACS แอปตรวจสอบว่าติดตั้งการ์ดจากชุมชนตัวไหนบ้าง (Mushroom, button-card, card-mod, apexcharts-card) และอัปเกรดแต่ละการ์ดเป็นแบบที่หรูกว่าเมื่อคุณมี คู่มือแดชบอร์ดที่สร้างเองไปได้ไกลกว่านั้นหากคุณต้องการลุคกระจกสีเขียวเต็มรูปแบบ
  • ฉากและตัวควบคุมต้องวางหนึ่งครั้ง หาก Home Assistant ยังไม่มีคำสั่งสำหรับส่งไปยังโปรเจกเตอร์ แดชบอร์ดก็ยังสร้างได้พร้อมค่าสด และการ์ดตั้งค่าให้เสร็จจะพาคุณทำตามขั้นตอน: แตะคัดลอกบล็อก วางลงใน configuration.yaml รีสตาร์ท Home Assistant แล้วแตะซิงค์อีกครั้ง
  • ไม่ได้ติดตั้งอะไรเลย? วางเอง หากไม่ได้ติดตั้งอะไรใน Home Assistant คุณยังคัดลอกทุกอย่างจากแอปแล้ววางเองได้
  • แจ้งเตือนเมื่อมีรหัสผ่าน บล็อกคำสั่งที่คุณวางจะบอกเมื่อมีรหัสผ่านโปรเจกเตอร์อยู่ในนั้น คุณจึงรู้ก่อนแชร์หรือเก็บบันทึก
ขณะที่โปรเจกเตอร์ปิดอยู่

ค่าที่อ่านได้ยังคงอยู่

โปรเจกเตอร์ในโหมดสแตนด์บายรายงานข้อมูลน้อยมาก แดชบอร์ดจึงมักว่างเปล่า เซนเซอร์ค่าล่าสุดที่เป็นทางเลือกจะเก็บค่าที่อ่านได้ล่าสุดของโปรเจกเตอร์ ไม่ว่าจะเป็นอินพุต ชั่วโมงหลอดภาพ หรือชั่วโมงเลเซอร์ ไว้ใน Home Assistant ขณะที่โปรเจกเตอร์ปิดอยู่

  • เป็นอีกบล็อกหนึ่งที่เป็นทางเลือก: วางไว้ท้าย configuration.yaml (หรือเพิ่มเฉพาะบรรทัดของมันใต้ส่วน template: ที่มีอยู่) แล้วรีสตาร์ท Home Assistant แอปมีปุ่มตรวจสอบว่ามีอยู่ที่บอกคุณว่า Home Assistant มีบล็อกนี้หรือไม่
  • การปิดเครื่องจะส่งถึง Home Assistant เป็นปิด แดชบอร์ดและระบบอัตโนมัติของคุณจึงเห็นว่าโปรเจกเตอร์ปิดอยู่เมื่อมันปิดอยู่จริง
ฉากเป็นสคริปต์

ทุกฉากกลายเป็นสคริปต์ Home Assistant

หลังซิงค์ ฉากของคุณไม่ได้ติดอยู่ในแอป แต่ละฉาก รวมถึงเปิดปิด ทุกอินพุต ทุกโหมดสี และทุกหน่วยความจำเลนส์ที่โปรเจกเตอร์ของคุณมีจริง จะถูกเขียนเป็นสคริปต์ Home Assistant

  • ระบบอัตโนมัติสั่งรันได้ “ตอนพระอาทิตย์ตก ถ้าTVเปิด ให้รัน Movie Night” เป็นระบบอัตโนมัติ Home Assistant ธรรมดาเมื่อฉากเป็นสคริปต์แล้ว
  • ผู้ช่วยเสียงสั่งรันได้ เปิดเผยสคริปต์ให้ผู้ช่วยของคุณ แล้วคำสั่ง “เปิด Movie Night” จะตั้งอินพุต โหมดภาพ และหน่วยความจำเลนส์พร้อมกัน
  • แสดงเฉพาะตัวควบคุมจริงของคุณ แอปเขียนสคริปต์สำหรับแต่ละอินพุต โหมดสี และหน่วยความจำเลนส์ที่โปรเจกเตอร์รายงาน ไม่ใช่รายการทั่วไปที่เดาเอา
  • การลบการซิงค์จะลบเฉพาะสิ่งที่แอปเขียน ปิดการซิงค์ หรือใช้ลบสคริปต์ที่ไม่มีเจ้าของ (ซึ่งแสดงรายการและถามก่อน) แล้ว Projector Pilot จะลบสคริปต์ที่มันสร้างและไม่แตะอย่างอื่น
ตั้งชื่อสคริปต์ให้การเปลี่ยนชื่ออัปเดตตัวเดิม ชื่อสคริปต์มาจากโปรเจกเตอร์และตัวควบคุม ดังนั้นการซิงค์ใหม่หลังจากที่คุณเปลี่ยนชื่อฉากจะอัปเดตสคริปต์เดิม แทนที่จะแตกเป็นสำเนาที่สอง
แดชบอร์ด

ซิงค์สร้างแดชบอร์ดให้คุณ

คุณไม่ต้องสร้างมุมมอง Lovelace ด้วยมือ และไม่ต้องวางมันอีกต่อไป เมื่อคุณแตะซิงค์กับ HA แอปจะสร้างแดชบอร์ด Projector Pilot ที่สมบูรณ์ใน Home Assistant โดยตรงผ่าน API ของมันเอง ประกอบด้วยสถานะสดของโปรเจกเตอร์และปุ่มสำหรับทุกฉากและตัวควบคุมที่ซิงค์ไว้ แดชบอร์ดจะปรากฏในแถบด้านข้างของ Home Assistant ในชื่อ Projector Pilot เปิดดูก็เสร็จแล้ว

  1. เข้าสู่ระบบ Home Assistant ในแอป
  2. วางบล็อกคัดลอกของแอปลงใน configuration.yaml หนึ่งครั้งแล้วรีสตาร์ท Home Assistant (ขั้นตอนที่ต้องทำเองเพียงอย่างเดียว เพราะ Home Assistant ไม่อนุญาตให้แอปเพิ่มคำสั่งนั้นจากระยะไกล)
  3. แตะซิงค์กับ HA แดชบอร์ดจะถูกสร้างให้และปรากฏในแถบด้านข้างในชื่อ Projector Pilot
อยากวางเองไหม? ปุ่มคัดลอกแดชบอร์ดยังอยู่ในหน้าจอ Home Assistant แตะปุ่มนั้น แล้วใน Home Assistant ไปที่ การตั้งค่า › แดชบอร์ด › เพิ่มแดชบอร์ด สร้างแดชบอร์ดว่าง เปิดเมนูสามจุด › แก้ไขแดชบอร์ด › เมนูสามจุด › ตัวแก้ไขการกำหนดค่าดิบ แล้ววาง YAML ที่คัดลอกไว้

ไม่ว่าจะถูกสร้างให้หรือคุณวางเอง แดชบอร์ดก็เหมือนกัน คือการ์ดสถานะพร้อมปุ่มสำหรับแต่ละตัวควบคุม (ตัวอย่างโค้ดประกอบ):

        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On

          action: perform-action

เป็นเพียงตัวอย่าง แดชบอร์ดของคุณมีเอนทิตีจริงของโปรเจกเตอร์และฉากของคุณเอง

ไม่ขึ้นกับรุ่น แดชบอร์ดสร้างจากความสามารถของโปรเจกเตอร์ของคุณ ทั้งเอนทิตี ตัวเลขภาพ อินพุต โหมดสี หน่วยความจำเลนส์ และฉากที่โปรเจกเตอร์รายงานจริง ภาพหน้าจอที่นี่เป็น QB1000 รุ่นของคุณอาจแสดงอินพุต ตัวควบคุม และค่าที่อ่านได้ต่างออกไป หากต้องการบอร์ดกระจกสีเขียวเต็มรูปแบบอย่างในภาพ ให้ทำตามคู่มือแดชบอร์ดทีละขั้นตอนหรือดาวน์โหลดมุมมองสมบูรณ์แล้วแก้สองสตริง
อยากได้ผนังที่หรูกว่านี้? สคริปต์เดียวกันขับเคลื่อนการ์ดใดก็ได้ที่คุณชอบ หากคุณเคยใช้ AVR Maestro แนวทางก็เหมือนกันทุกประการ คือสร้างไทล์แหล่งสัญญาณและโหมดที่สว่างขึ้น หัวข้อสด และประวัติ จากเซนเซอร์ตัวเดียวและสคริปต์ที่ซิงค์
Hubitat

ตั้งค่า Hubitat

บน Hubitat Projector Pilot มิเรอร์โปรเจกเตอร์ไปยังอุปกรณ์ในฮับของคุณผ่าน Maker API เพื่อให้ Rule Machine อ่านและสั่งการเปิดปิด ปิดเสียง และอินพุตได้

  1. ใน Hubitat เปิดใช้แอป Maker API จด URL สำหรับเข้าถึงและโทเคน และเลือกอุปกรณ์ที่ต้องการเปิดเผย
  2. ใน Projector Pilot เปิด การตั้งค่า › ระบบอัตโนมัติในบ้าน › Hubitat แล้วป้อนรายละเอียด Maker API ของฮับคุณ
  3. เลือกอุปกรณ์ที่แทนโปรเจกเตอร์ แอปจะแนะนำตัวที่น่าจะใช่ เลือกตัวนั้นหรือเลือกอุปกรณ์ของคุณเอง
  4. แอปมิเรอร์สถานะเปิดปิด ปิดเสียง และอินพุตไปยังอุปกรณ์นั้น โดยส่งเฉพาะคำสั่งที่อุปกรณ์รับได้
  5. สร้างกฎRule Machineกับอุปกรณ์นั้นเหมือนอุปกรณ์อื่นๆ โดยสถานะของโปรเจกเตอร์เป็นตัวขับเคลื่อนกฎ
เฉพาะสิ่งที่อุปกรณ์รับได้ แอปส่งค่าของโปรเจกเตอร์ไปยัง Hubitat ก็ต่อเมื่ออุปกรณ์ที่เลือกรองรับคำสั่งนั้น จึงไม่ส่งสิ่งที่อุปกรณ์จะปฏิเสธ
Webhooks

ตั้งค่าWebhooks

Webhooksคือตัวรับทุกอย่าง แอปจะโพสต์ไปยัง URL ของคุณเมื่อโปรเจกเตอร์เปิดเครื่อง ปิดเครื่อง เปลี่ยนอินพุต หรือเรียกฉาก ไม่ว่าจะเป็นWebhooks Home Assistant, Node-RED, IFTTT หรืออะไรก็ตามที่รับ JSON

  1. เปิด การตั้งค่า › ระบบอัตโนมัติในบ้าน › Webhooks
  2. ป้อน URL ที่จะโพสต์ไป Webhooks Home Assistant หน้าตาประมาณ http://homeassistant.local:8123/api/webhook/your-id
  3. เลือกเหตุการณ์ที่จะเรียกWebhooks: เปิดเครื่อง ปิดเครื่อง เปลี่ยนอินพุต เรียกฉาก และจะกรองเฉพาะอินพุตหรือฉากใดก็ได้
  4. ตั้งpayload แบบกำหนดเองได้หากบริการปลายทางต้องการรูปแบบเฉพาะ มิฉะนั้นแอปจะส่ง JSON เริ่มต้น
  5. บันทึก จากนั้นแอปจะโพสต์ทุกครั้งที่มีเหตุการณ์ที่ตรงกัน

payload เริ่มต้นเป็น JSON ธรรมดา ประกอบด้วยเหตุการณ์ โปรเจกเตอร์ และค่าที่เปลี่ยน:

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

ตัวอย่าง payload เหตุการณ์เปลี่ยนอินพุตหรือเปิดปิดจะมีช่องที่เกี่ยวข้องกับมัน

เชื่อมโยงใหม่แก้ได้ทั้งหมด หากคุณเชื่อมโยง Home Assistant ใหม่ที่ที่อยู่ใหม่ แอปจะอัปเดตทุกWebhooksที่ชี้ไปที่มันในคราวเดียว การย้ายอินสแตนซ์จึงไม่ต้องแก้ทีละอัน

การแก้ไขปัญหา

การเข้าสู่ระบบเด้งกลับไปที่หน้าล็อกอิน

ตรวจสอบให้แน่ใจว่าที่อยู่ที่คุณป้อนคือที่ที่คุณเข้าถึง Home Assistant จริงๆ รวมถึงพอร์ต (ปกติคือ :8123) การเข้าสู่ระบบเป็นการล็อกอินผ่านเบราว์เซอร์จริงกับอินสแตนซ์ของคุณ ชื่อผู้ใช้ รหัสผ่าน และรหัสยืนยันสองขั้นตอนจึงมีผลทั้งหมด บนโทรศัพท์ การเข้าสู่ระบบเสร็จสมบูรณ์ไม่ว่าเบราว์เซอร์ในแอปจะส่งผลกลับมาหรือคอลแบ็กในเครื่องจะกลับมาก่อน หากยังค้าง ให้ปิดชีตแล้วแตะเข้าสู่ระบบอีกครั้ง

เซนเซอร์โปรเจกเตอร์ไม่ปรากฏใน Home Assistant

เซนเซอร์จะถูกเผยแพร่ขณะเปิดแอปอยู่และเปิดส่งสถานะของโปรเจกเตอร์ ไว้ ให้เปิดแอปและยืนยันตัวสลับนั้น จากนั้นตรวจสอบเครื่องมือนักพัฒนา › สถานะใน Home Assistant และกรองด้วย projector_pilot โปรเจกเตอร์ในโหมดสแตนด์บายเผยแพร่ข้อมูลน้อยมาก ปลุกมันแล้วค่าที่อ่านได้จะเติมเข้ามา

สคริปต์ที่ซิงค์หายไป

สคริปต์ถูกเขียนโดยซิงค์กับ HA ซึ่งต้องมีบล็อก shell_command ที่วางไว้ใน configuration.yaml แล้วและรีสตาร์ท Home Assistant หนึ่งครั้ง รันทดสอบการเชื่อมต่อก่อน เพราะมันบอกว่ามีบล็อกอยู่หรือไม่ แล้วซิงค์อีกครั้ง หากสคริปต์เก่าที่ใช้ไม่ได้แล้วรกรายการ ให้ใช้ลบสคริปต์ที่ไม่มีเจ้าของ

สคริปต์ทำงานในแอป แต่ไม่ทำงานจาก Home Assistant เมื่อโทรศัพท์ไม่อยู่

นั่นคือจุดประสงค์ของบล็อก shell_command มันคือสิ่งที่ทำให้ Home Assistant เข้าถึง IP ของโปรเจกเตอร์ได้เอง หากใช้ได้เฉพาะตอนเปิดแอป แสดงว่าน่าจะยังไม่ได้วางบล็อก หรือไม่ได้รีสตาร์ท Home Assistant หลังวาง ยืนยันด้วยทดสอบการเชื่อมต่อ รีสตาร์ท Home Assistant แล้วซิงค์

เชื่อมโปรเจกเตอร์ของคุณเข้ากับทั้งบ้าน

ระบบอัตโนมัติในบ้านเป็นส่วนเสริมที่ซื้อครั้งเดียว ไม่มีค่าสมาชิก ไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ ซื้อครั้งเดียวปลดล็อกได้ทุกแพลตฟอร์มที่คุณมี
