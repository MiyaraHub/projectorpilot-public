ฉากโปรเจกเตอร์: ทั้งห้องของคุณ ในการแตะครั้งเดียว

ฉากเก็บสถานะโปรเจกเตอร์ของคุณตามที่เป็นอยู่ตอนนี้ แล้วนำทั้งหมดกลับมาภายหลังด้วยการแตะครั้งเดียว คืนหนังกับครอบครัว เกมใหญ่ รอบบ่ายวันอาทิตย์ที่สว่างสดใส แต่ละอย่างเป็นฉากของตัวเอง ห่างออกไปแค่หนึ่งแตะ คุณเลือกได้ว่าฉากจะเก็บส่วนไหน และจะเสนอเฉพาะส่วนที่โปรเจกเตอร์ของคุณรายงานจริง

ฉากเป็นส่วนหนึ่งของProjector Pilot Pro

วิธีบันทึก

ตั้งค่าห้อง แล้วบันทึก

  1. ตั้งค่า ปรับโปรเจกเตอร์ให้เป็นอย่างที่คุณต้องการ ทั้งอินพุต โหมดสี ภาพ หน่วยความจำเลนส์ ครบทุกอย่าง
  2. บันทึกปัจจุบัน ในแท็บฉาก แตะบันทึกปัจจุบัน ตั้งชื่อฉาก และติ๊กส่วนที่จะเก็บ ตัวเลือกจะเสนอเฉพาะสิ่งที่โปรเจกเตอร์ของคุณรายงาน คุณจึงไม่บันทึกการตั้งค่าที่รุ่นของคุณไม่มี
  3. เรียกคืน แตะฉากเพื่อใช้งาน Projector Pilot ยืนยันแต่ละการตั้งค่ากับโปรเจกเตอร์ระหว่างทาง และไม่อ้างว่ามีการเปลี่ยนแปลงที่ไม่ได้เกิดขึ้นจริง
สิ่งที่ฉากเก็บไว้

มากหรือน้อยตามที่คุณติ๊ก

ฉากเดียวบันทึกภาพรวมของสิ่งต่อไปนี้ได้ การเรียกคืนจะเล่นซ้ำเฉพาะส่วนที่คุณติ๊ก ฉาก “ดูดึก” จึงลดกำลังแสงและปล่อยทุกอย่างอื่นไว้ตามเดิมได้

สถานะเปิดปิด

สถานะเปิดปิดของโปรเจกเตอร์ ฉากจึงปลุกเครื่องหรือส่งเข้าสแตนด์บายเป็นส่วนหนึ่งของการตั้งค่าได้

อินพุต

แหล่งสัญญาณที่ฉากสลับไป “Movie Night” จึงไปที่ HDMI ที่ถูกต้องทุกครั้ง

ภาพ

โหมดสีและค่าของภาพ แต่ละค่าตามสเกลเมนูของโปรเจกเตอร์เอง

สัญญาณ

การตั้งค่าฝั่งสัญญาณที่โปรเจกเตอร์ของคุณมี สำหรับเนื้อหาที่คุณกำลังดู

แสง

กำลังแสงของแหล่งกำเนิดแสง ห้องสว่างกับห้องมืดจึงมีการตั้งค่าของตัวเอง

รูปทรง

สถานะการจัดแนวและรูปทรงที่จัดภาพให้พอดีกับจอของคุณ

เสียง

การตั้งค่าเสียงที่โปรเจกเตอร์รายงาน เก็บไว้พร้อมกับส่วนอื่น

เฉพาะที่รายงาน

รายการติ๊กสร้างจากสิ่งที่โปรเจกเตอร์ของคุณตอบกลับจริง ดังนั้นไม่มีสิ่งใดที่คุณบันทึกเป็นการเดา

ระบบอัตโนมัติ

ทุกฉากกลายเป็นสคริปต์ Home Assistant

วางหนึ่งบล็อกลงในการกำหนดค่า Home Assistant ของคุณครั้งเดียว แล้ว Projector Pilot จะเขียนสคริปต์ให้ทุกฉากที่คุณมี รวมถึงเปิดปิด ทุกอินพุต ทุกโหมดสี และทุกหน่วยความจำเลนส์ที่โปรเจกเตอร์ของคุณมีจริง จากนั้นระบบอัตโนมัติหรือผู้ช่วยเสียงจะสั่งรันฉากใดก็ได้ และแอปจะลบสคริปต์ที่มันเขียนเมื่อคุณปิดการซิงค์ โดยไม่แตะต้องสิ่งอื่น

ฉากยังทำงานผ่านwebhooks การเรียกคืนฉากโพสต์ไปยัง URL ของคุณได้ และมิเรอร์ไปยังHubitatผ่าน Maker API ทั้งหมดอยู่ในคู่มือ Home Assistant
