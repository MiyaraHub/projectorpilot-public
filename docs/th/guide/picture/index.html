เมนูภาพ

การตั้งค่าภาพโปรเจกเตอร์ ตามสเกลของโปรเจกเตอร์เอง

ทุกอย่างที่เมนูภาพของโปรเจกเตอร์มี ในหน้าจอเดียว ตั้งแต่ความสว่างไปจนถึงการแทรกเฟรม ทุกค่าคือตัวเลขที่เมนูของโปรเจกเตอร์คุณแสดง ไม่ใช่ไบต์ภายใน และทุกการเปลี่ยนแปลงจะถูกอ่านกลับจากโปรเจกเตอร์ภายหลัง คุณจึงเห็นค่าที่ฮาร์ดแวร์เก็บไว้จริงเสมอ

พื้นฐาน

ความสว่าง คอนทราสต์ โทนสี ความคมชัด

  • ความสว่างและคอนทราสต์ ระดับสีดำต่ำสุดและสีขาวสูงสุด ตามสเกล 0-100 ของโปรเจกเตอร์เอง (หรือสเกลของรุ่น)
  • โทนสีและความอิ่มตัว สมดุลและความเข้มของสี
  • ความคมชัด ความชัดของขอบ ตามช่วงที่รุ่นของคุณใช้

ตัวควบคุมแต่ละตัวแสดงตัวเลขตามเมนูจริง ในกรณีที่โปรเจกเตอร์ประกาศช่วงที่ตัวควบคุมใช้ แอปจะแปลงค่าตรงตามที่โปรเจกเตอร์ทำ หากไม่ได้ประกาศ ตัวเลขจะแสดงตามที่ส่งไป และตัวควบคุมจะระบุว่าค่าดิบแทนที่จะแสดงค่าที่เดามา

สี

อุณหภูมิสีและแกมมา

ตัวควบคุมสองตัวที่ทำงานต่างกันตามโหมด และแอปทำตามโปรเจกเตอร์ ไม่ทำให้เหมือนกันหมด

  • อุณหภูมิสีมีสิบสี่สเต็ป ไม่ใช่แถบเลื่อน มีหมายเลขกำกับ หรือแสดงเป็นเคลวินในโหมดภาพที่รายงานค่าเคลวิน เป็นการตั้งค่าแบบเป็นขั้น แอปจึงแสดงเป็นสเต็ป ไม่ใช่ช่วง 0-100 ที่จะทำให้อ่านผิด
  • แกมมาเป็นของแต่ละโหมดภาพ ตัวเลือกต่างกันตามโหมด Dynamic ให้สเต็ปในช่วงหนึ่ง Cinema ให้ค่าเส้นโค้ง ส่วน Custom ก็ต่างออกไปอีก แอปจะหาว่าชุดไหนใช้ได้จากโหมดภาพปัจจุบันก่อนเสนอตัวเลือก คุณจึงไม่เห็นตัวเลือกแกมมาที่โหมดปัจจุบันรับไม่ได้
  • RGB Gain และ Offset ตัวควบคุมไวต์บาลานซ์ แต่ละตัวตามสเกลของโปรเจกเตอร์เอง สำหรับปรับเกรย์สเกล
อุณหภูมิสีแสดงเป็นสเต็ปตามที่เมนูแสดง (เช่น 0 ถึง 13) หรือค่าเคลวินในโหมดที่แสดงค่านั้น ไม่ใช่ไบต์ และไม่ใช่ค่าที่แปลงซ้ำ
ขั้นสูง

ตัวควบคุมการประมวลผลภาพ

ตัวควบคุมทำอะไรได้
ลดสัญญาณรบกวนทำให้สัญญาณรบกวนจากแหล่งสัญญาณเนียนลง ตามสเกลของโปรเจกเตอร์เอง
Super Resolutionขั้นตอนเพิ่มรายละเอียดของ Epson ที่ทำให้แหล่งสัญญาณที่เบลอคมขึ้นโดยไม่เกิดขอบเงา
การแทรกเฟรมทำให้การเคลื่อนไหวระหว่างเฟรมนุ่มนวล ตามระดับที่รุ่นของคุณรองรับ
RGB Gain / Offsetไวต์บาลานซ์รายช่องสี สำหรับคาลิเบรตเกรย์สเกล
จะปรากฏเฉพาะตัวควบคุมที่รุ่นของคุณมีจริง พร้อมช่วงค่าที่รุ่นนั้นรายงาน ตัวควบคุมที่โปรเจกเตอร์ของคุณไม่มีจะไม่แสดง แอปไม่แต่งขึ้นมาเอง
กฎความซื่อตรง

HDR และช่วงสีแยกจากกัน

ไดนามิกเรนจ์ของสัญญาณและช่วงสีของสัญญาณเป็นคนละเรื่อง และแอปแยกให้เป็นเช่นนั้น BT.2020 ไม่ได้แปลว่า HDR และ SDR ไม่ได้แปลว่า BT.709

  • ไดนามิกเรนจ์ (SDR หรือ HDR) และช่วงสี (BT.2020, BT.709 และอื่นๆ) แสดงเป็นคนละช่อง
  • สัญญาณ BT.2020 SDR ซึ่งพบบ่อยกับโทนแมปเปอร์ภายนอกอย่าง MadVR จะแสดงตามจริงเช่นนั้น ไม่เคยถูกติดป้าย HDR10 ผิดๆ
  • ทุกค่าของภาพจะถูกอ่านกลับจากโปรเจกเตอร์หลังจากที่คุณตั้ง ค่าที่โปรเจกเตอร์เก็บไว้หรือไม่ยืนยันจึงถูกบอกตรงๆ แทนที่จะสมมติ
หน่วยความจำภาพ

บันทึก เรียกคืน และเปลี่ยนชื่อหน่วยความจำภาพของคุณ

หน้าจอภาพแสดงรายการหน่วยความจำที่โปรเจกเตอร์ของคุณมีจริง ด้วยชื่อที่คุณตั้งไว้บนเมนูของมัน บันทึกภาพปัจจุบันลงในช่อง เปลี่ยนชื่อ หรือลบ การบันทึกทับช่องที่มีหน่วยความจำอยู่แล้วจะถามก่อน
