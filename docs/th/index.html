ทำอะไรได้

ทุกตัวควบคุมที่โปรเจกเตอร์ของคุณมี ในแอปสะอาดตาเดียว

Projector Pilot คุยกับโปรเจกเตอร์ของคุณผ่าน ESC/VP21, PJLink และ Epson Web Control พร้อมกัน โดยใช้ช่องทางที่ตอบสนอง คุณจึงได้ควบคุมการเปิดปิด ภาพ รูปทรง และเลนส์ที่ใช้งานได้จริง พร้อมค่าที่อ่านกลับจากโปรเจกเตอร์ ไม่ใช่การเดา

แดชบอร์ด

ทุกอย่างในแวบเดียว สร้างในแบบที่คุณต้องการ

  • สถานะสด เปิดปิด อินพุต โหมดสี ชั่วโมงแหล่งกำเนิดแสง สัญญาณ และตัวเลขภาพ อัปเดตทันทีที่เปลี่ยน
  • เปิดปิดและอินพุตแตะเดียวจากด้านบนสุด พร้อมปุ่มเปิดปิดที่รู้จักช่วงวอร์มอัพและคูลดาวน์
  • การ์ดที่ปรับแต่งได้ เพิ่ม ซ่อน และจัดเรียงการ์ด แดชบอร์ดจึงแสดงสิ่งที่สำคัญกับคุณ
  • ข้อมูลการฉาย ไดนามิกเรนจ์ ช่วงสี แกมมา ชั่วโมงเลเซอร์ ซีเรียล และการติดตั้ง อ่านจากโปรเจกเตอร์
รีโมต & ภาพ

รีโมตแบบเจาะลึกและเมนูภาพแบบเต็ม

  • D-pad นำทางแบบเต็ม เมนู แหล่งสัญญาณ และปิดภาพหน้าจอ รีโมตบนหน้าจอที่ทำถูกวิธี
  • วิธีแก้ไข H/V-Keystone, Quick Corner, การแก้ไขแบบจุด, พื้นผิวโค้ง และมุมผนัง
  • ควบคุมภาพแบบเต็มรูปแบบ ความสว่าง คอนทราสต์ โทนสี ความคมชัด อุณหภูมิสี แกมมา HDR และเมนูภาพเชิงลึก แต่ละค่าตามสเกลของโปรเจกเตอร์เอง
  • HDR และช่วงสีแยกจากกัน สัญญาณ BT.2020 SDR แสดงตามจริงเช่นนั้น ไม่เคยมีป้าย HDR ปลอม
เลนส์

การเลื่อนเลนส์ โฟกัส ซูม และหน่วยความจำแบบมอเตอร์

  • เลื่อน โฟกัส และซูมจากแผงปุ่มที่แม่นยำ พร้อมขนาดสเต็ปที่คุณเลือก ละเอียดสำหรับจัดเฟรม หยาบสำหรับการขยับใหญ่
  • หน่วยความจำเลนส์ เรียกคืนและบันทึกตำแหน่งที่โปรเจกเตอร์ของคุณรองรับ
  • รู้ทิศทาง แอปทำตามการแมปของโปรเจกเตอร์เอง ไม่ว่าติดเพดานหรือฉายด้านหลัง ขึ้นจึงเป็นขึ้นเสมอ
  • ค่าที่อ่านอย่างตรงไปตรงมา ตำแหน่งที่โปรเจกเตอร์ยืนยันไม่ได้ไม่เคยแกล้งทำเป็นว่าล็อก
ฉาก

แตะเดียวทั้งห้อง

  • บันทึกฉาก เปิดปิด อินพุต ภาพ สัญญาณ แสง รูปทรง และเสียง และเลือกได้ว่าจะเก็บส่วนไหน
  • ใช้ด้วยการแตะเดียว “Movie Night” ตั้งอินพุต โหมดภาพ และหน่วยความจำเลนส์พร้อมกัน
  • ทุกฉากกลายเป็นสคริปต์ Home Assistant ระบบอัตโนมัติหรือผู้ช่วยเสียงจึงสั่งรันได้ด้วย
  • โปรไฟล์ที่แชร์ได้ ส่งออกฉากที่ปรับแต่งแล้วมอบให้เพื่อน
ระบบอัตโนมัติในบ้าน

Home Assistant, Hubitat และ Webhooks ของจริง

  • Home Assistant เข้าสู่ระบบ เผยแพร่สถานะของโปรเจกเตอร์เป็นเซนเซอร์ และแตะซิงค์กับ HA เพื่อรับสคริปต์สำหรับทุกฉากและตัวควบคุม
  • แดชบอร์ดที่สร้างให้คุณ การซิงค์สร้างใน Home Assistant ด้วยการ์ดในตัว และอัปเกรดเป็นการ์ด HACS ที่หรูกว่าเมื่อคุณมี ใช้งานร่วมกับการเชื่อมต่อ PJLink หลักได้ด้วย
  • รายการตรวจสอบการตั้งค่าแสดงสิ่งที่เสร็จแล้ว สิ่งที่ยังขาด และสิ่งที่ควรทำต่อ และค่าที่อ่านได้ของคุณอยู่ใน Home Assistant ขณะที่โปรเจกเตอร์ปิดอยู่
  • Hubitat มิเรอร์โปรเจกเตอร์ไปยังอุปกรณ์ผ่าน Maker API เพื่อให้ Rule Machine สั่งการได้
  • Webhooks โพสต์ไปยัง URL ใดก็ได้เมื่อโปรเจกเตอร์เปิดเครื่อง ปิดเครื่อง เปลี่ยนอินพุต หรือเรียกฉาก

และอีกมากมาย

รายละเอียดที่ทำให้รู้สึกว่าเสร็จสมบูรณ์

สลับโปรเจกเตอร์จากที่ไหนก็ได้

ตัวสลับโปรเจกเตอร์ในแถบด้านบนของทุกหน้าโปรเจกเตอร์พาคุณสลับระหว่างโปรเจกเตอร์โดยไม่ต้องย้อนกลับไปที่รายการ

ถามก่อนปิดเครื่อง

การปิดโปรเจกเตอร์จะขอให้คุณยืนยัน การแตะพลาดจึงไม่ทำให้หนังจบกลางคัน

ตัวควบคุมที่ตอบสนองทันที

การเลื่อนเลนส์ โฟกัส ซูม และตัวปรับกำลังแสงขยับทันทีที่กด และแอปรับรู้ว่าโปรเจกเตอร์เปิดเครื่องภายในประมาณสิบวินาที

เฟิร์มแวร์ในแวบเดียว

เวอร์ชันเฟิร์มแวร์ของโปรเจกเตอร์แสดงบนแดชบอร์ดและแท็บข้อมูล และในรายงานการวินิจฉัย เมื่อใดก็ตามที่โปรเจกเตอร์รายงานค่านี้

สลับอินพุตบนโปรเจกเตอร์ที่ใช้ PJLink อย่างเดียว

โปรเจกเตอร์ที่แสดงรายการอินพุตผ่าน PJLink เท่านั้น เช่น TW7300 และ Home Cinema 4040 สลับอินพุตได้ และโปรเจกเตอร์ PJLink ที่ไม่ใช่ Epson ก็ทำได้เช่นกัน

หาโปรเจกเตอร์ของคุณบน Wi-Fi

เพิ่มโปรเจกเตอร์สแกนเครือข่ายหาสิ่งที่ตอบสนองเป็นโปรเจกเตอร์และกรอกที่อยู่ให้ พร้อมแถบความคืบหน้าขณะค้นหาความสามารถของรุ่นของคุณ

สำรองและกู้คืน

ส่งออกการตั้งค่าแอปของคุณเป็นไฟล์แล้วนำเข้ากลับมาได้ ไฟล์ถูกแชร์ด้วยชื่อจริงของมัน และโปรเจกเตอร์ที่บันทึกไว้และรหัสผ่านไม่เคยไปกับไฟล์

รายงานข้อบกพร่องในขั้นตอนเดียว

รายงานข้อบกพร่องรวมบันทึกที่เกี่ยวข้องทั้งหมดเป็นชุดเดียว พร้อมส่ง
