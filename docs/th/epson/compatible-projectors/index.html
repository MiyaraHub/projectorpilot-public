รีโมทสำหรับโปรเจกเตอร์ที่รองรับ Epson

Projector Pilot เป็นแอปรีโมทอิสระที่ใช้งานกับโปรเจกเตอร์ Epson และโปรเจกเตอร์ PJLink ทุกรุ่นผ่านเครือข่ายของคุณเอง ด้านล่างคือรุ่นที่รองรับและสิ่งที่แต่ละรุ่นให้ใช้งานได้

วิธีการทำงาน

รองรับตามโปรโตคอล ไม่ใช่ตามรายชื่อรุ่น

แอปไม่ได้มีรายชื่อหมายเลขรุ่นมาให้ แต่จะสอบถามโปรเจกเตอร์ว่ารองรับอะไรบ้าง แล้วแสดงตัวควบคุมที่โปรเจกเตอร์ตอบกลับ ดังนั้นโปรเจกเตอร์ที่ใช้ PJLink หรือ Epson Web Control ก็ใช้งานได้ แม้จะไม่มีชื่ออยู่ด้านล่าง

  • PJLink (คลาส 1 และ 2) ให้การเปิดปิดเครื่อง อินพุต ปิดภาพและเสียง และสถานะหลอดไฟหรือเลเซอร์ บนโปรเจกเตอร์ Epson ที่เชื่อมต่อเครือข่ายเกือบทุกรุ่น
  • Epson Web Control เพิ่มการตั้งค่าภาพ เลนส์ Keystone และ HDR ในรุ่นที่มีฟังก์ชันนี้
  • ESC/VP21 เป็นโปรโตคอลคำสั่งของโปรเจกเตอร์เอง ใช้เมื่อโปรเจกเตอร์ตอบกลับด้วยโปรโตคอลนี้
ทดสอบแล้ว

โปรเจกเตอร์ที่ทดสอบกับอุปกรณ์จริง

โปรเจกเตอร์เลนส์การควบคุมผ่านเครือข่ายสิ่งที่คาดหวังได้
Epson QB1000B / QB1000Wเลนส์มอเตอร์ 3 แกนพร้อมหน่วยความจำPJLink, Web Controlทดสอบกับโปรเจกเตอร์จริง
Epson Home Cinema 4040 / Pro Cinema 4040เลนส์ โฟกัส และซูมแบบมอเตอร์PJLink คลาส 1, Web Control, ESC/VP.netทดสอบกับโปรเจกเตอร์จริง: แสดงเลนส์ ช่วงไดนามิก และรายการอินพุตตามที่โปรเจกเตอร์ตอบกลับ
โปรโตคอลเดียวกัน

รุ่นที่ใช้โปรโตคอลเดียวกัน

รุ่นเหล่านี้ใช้โปรโตคอลเครือข่ายเดียวกับโปรเจกเตอร์ที่ทดสอบแล้ว แต่ยังไม่ได้ทดสอบทุกรุ่นในห้องแล็บของเรา สิ่งที่คุณเห็นจึงขึ้นอยู่กับข้อมูลที่โปรเจกเตอร์ของคุณรายงาน

โปรเจกเตอร์เลนส์การควบคุมผ่านเครือข่ายสิ่งที่คาดหวังได้
Pro Cinema LS12000, LS9000เลนส์มอเตอร์พร้อมหน่วยความจำPJLink, Web Controlสถาปัตยกรรมเครือข่ายเดียวกับ QB1000 ที่ทดสอบแล้ว
Home Cinema LS11000, 5050UB, 4010เลนส์มอเตอร์พร้อมหน่วยความจำPJLink, Web Controlตัวควบคุมเลนส์ ภาพ และ HDR จะปรากฏเมื่อโปรเจกเตอร์รายงานข้อมูลนั้น
Home Cinema 3800, 3200, 2350เลนส์แบบปรับด้วยมือPJLink, Web Controlไม่มีแท็บเลนส์ แต่ใช้งานการเปิดปิดเครื่อง อินพุต ภาพ และโหมดสีได้
EB-PU2220B, EB-PU2120W, EB-PU2010B/W, EB-L770Uเลนส์มอเตอร์แบบเปลี่ยนได้PJLink, Web Control, Web APIรุ่นสำหรับติดตั้ง ตัวควบคุมเลนส์ขึ้นอยู่กับเลนส์ที่ติดตั้ง
EB-L730U, EB-L260F, EB-L265F, EB-L210W, EB-810E, EB-815Eเลนส์ติดตั้งถาวรPJLink, Web Controlไม่มีตัวควบคุมเลนส์ แต่มีการเปิดปิดเครื่อง อินพุต ปิดภาพและเสียง และภาพ
EB-U50, EB-W50, EB-X50, EB-L630U, EB-L530Uเลนส์แบบปรับด้วยมือPJLink, Web Controlรุ่นพกพาและรุ่นสำหรับธุรกิจ
EV-110, EV-115ระยะฉายสั้นพิเศษแบบเลนส์ติดตั้งถาวรPJLinkเฉพาะ PJLink: เปิดปิดเครื่อง อินพุต ปิดภาพและเสียง และสถานะ
ก่อนเชื่อมต่อ

เปิดการควบคุมผ่านเครือข่าย

  • ต่อโทรศัพท์และโปรเจกเตอร์เข้ากับเครือข่ายเดียวกัน
  • เปิดใช้ PJLink และ Web Control ในเมนูเครือข่ายของโปรเจกเตอร์
  • สแกนหาโปรเจกเตอร์ในแอป หรือเพิ่มด้วยที่อยู่ IP
