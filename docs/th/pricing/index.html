ชุดรวม

$11.99 ซื้อครั้งเดียว: Pro + Home Automation ในราคาประหยัดกว่า ทุกอย่างที่แอปทำได้ ในการซื้อครั้งเดียว ถูกกว่าซื้อสองส่วนแยกกัน

ราคาที่แสดงเป็นราคาของสโตร์ สิ่งที่แอปแสดงคือตัวเลขที่สโตร์เสนอ ในสกุลเงินของคุณ ก่อนที่คุณจะยืนยัน ราคาข้างต้นเป็นราคาอ้างอิงของสหรัฐฯ ภูมิภาคของคุณอาจต่างออกไป และแอปไม่เคยแต่งตัวเลขขึ้นเอง

การซื้อทำงานอย่างไร

  • ซื้อครั้งเดียว ไม่มีค่าสมาชิก คุณจ่ายครั้งเดียวและเป็นของคุณ
  • ไม่มีโฆษณา ไม่มีบัญชี ไม่มีคลาวด์ แอปคุยกับโปรเจกเตอร์ของคุณบนเครือข่ายของคุณ ไม่มีอะไรให้สมัคร และไม่มีการขายอะไรแอบแฝง
  • การซื้อครั้งเดียวปลดล็อกได้ทุกแพลตฟอร์มที่คุณมี ซื้อบนสโตร์หนึ่งแล้วกู้คืนบนสโตร์อื่นที่ผูกกับบัญชีเดียวกัน ทั้ง Android, iOS, Windows และ macOS
  • การซื้อหรือกู้คืนสิ่งที่คุณมีอยู่แล้วปลดล็อกได้เสมอ หากสโตร์บอกว่าคุณมี Pro, Home Automation หรือชุดรวมอยู่แล้ว แอปจะให้สิทธิ์แทนที่จะแสดงข้อผิดพลาด ฟีเจอร์ที่คุณจ่ายเงินแล้วจึงไม่มีวันล็อกคุณออก
  • บนแพลตฟอร์มที่ไม่มีสโตร์ แอปรวมทุกอย่างไว้ แทนที่จะแสดงเพย์วอลล์ที่ไม่มีใครจ่ายได้
พร้อมให้ดาวน์โหลดแล้วบน Google Play ส่วน App Store, Microsoft Store และ Mac App Store รอการอนุมัติ เมื่อผ่านแล้ว การซื้อครั้งเดียวจะใช้ได้ข้ามแพลตฟอร์มที่คุณมี
