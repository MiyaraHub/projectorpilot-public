โปรเจกเตอร์ JVC D-ILA

รีโมตผ่านเครือข่ายสำหรับโปรเจกเตอร์ JVC D-ILA ของคุณ

การเปิดปิดเครื่อง อินพุต เมนูภาพ การควบคุมเลนส์ โหมดการติดตั้ง ฉาก และตัวเลขการบำรุงรักษาสำหรับโปรเจกเตอร์ JVC D-ILA ผ่านเครือข่ายของคุณเอง ไม่ต้องมีบัญชี ไม่ใช้คลาวด์ ไม่ต้องสมัครสมาชิก

เร็วๆ นี้ Projector Pilot D-ILA กำลังจะมาบน Google Play, App Store และ Microsoft Store สำหรับ Android, iOS, macOS และ Windows ตอนนี้ยังไม่มีในร้านค้าใดเลย จึงยังไม่มีอะไรให้ดาวน์โหลดในวันนี้

ทำอะไรได้

ตัวควบคุมที่โปรเจกเตอร์ D-ILA ของคุณมี บนโทรศัพท์ของคุณ

แต่ละรุ่นจะได้ฟังก์ชันที่ตารางคำสั่ง JVC ของรุ่นนั้นระบุไว้ แอปจะแสดงสิ่งที่โปรเจกเตอร์ของคุณรองรับ และตัดสิ่งที่ไม่รองรับออก

การเปิดปิดเครื่องและอินพุต

เปิดเครื่องและสแตนด์บาย HDMI 1 และ HDMI 2 พร้อมแสดงการวอร์มอัปของโปรเจกเตอร์แบบเรียลไทม์

รีโมท

การนำทางเมนู โหมดภาพ ประเภทเนื้อหา ระดับ HDR แกมมา อุณหภูมิสี โปรไฟล์สี การเคลื่อนไหว ซ่อนภาพ และทางลัดเมนู

เลนส์และการติดตั้ง

รูรับแสงเลนส์ การเลื่อน โฟกัส และซูมแบบกดค้าง หน่วยความจำเลนส์ โหมดการติดตั้ง อัตราส่วนภาพ และอะนามอร์ฟิก

ฉาก

บันทึกชุดการตั้งค่าแล้วใช้ด้วยการแตะครั้งเดียว แชร์ฉากเป็นไฟล์ .ppscene การนำเข้าจะเก็บสิ่งที่รุ่นนั้นมี

การบำรุงรักษา

ชั่วโมงใช้งานแหล่งกำเนิดแสงเทียบกับอายุการใช้งานที่กำหนด ต้นทุนต่อชั่วโมง การแจ้งเตือนที่เลือกเปิดเอง และรายงานชั่วโมงที่ส่งออกได้

ระบบอัตโนมัติในบ้าน

เว็บฮุกเมื่อเกิดเหตุการณ์เปิดปิดเครื่อง อินพุต และฉาก Hubitat ผ่าน Maker API และ Home Assistant พร้อมแดชบอร์ดที่พร้อมใช้

โปรเจกเตอร์ที่รองรับ

ตั้งแต่ DLA-X ไปจนถึงซีรีส์ NZ ปี 2025

  • โปรไฟล์รุ่น 43 รายการ ครอบคลุมชื่อรุ่น DLA 64 ชื่อ ซึ่ง 52 ชื่อควบคุมผ่านเครือข่ายได้
  • ซีรีส์ NX ปี 2018: DLA-NX5, NX7, NX9 และชื่อรุ่น RS และชื่อรุ่นตามภูมิภาค
  • ซีรีส์ NZ ปี 2021: DLA-NZ7, NZ8, NZ9 และ DLA-NP5 พร้อมชื่อรุ่น RS และชื่อรุ่นตามภูมิภาค
  • ซีรีส์ NZ ปี 2024 และ 2025: DLA-NZ500, NZ700, NZ800 และ NZ900
  • รุ่นก่อนหน้าที่มี LAN เช่น DLA-X7, X9, X30, X70R และ X90R
  • โปรเจกเตอร์ D-ILA ที่ไม่อยู่ในรายการยังคงใช้การเปิดปิดเครื่อง อินพุต และปุ่มรีโมตได้
