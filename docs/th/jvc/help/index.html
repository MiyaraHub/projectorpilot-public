ช่วยเหลือ & FAQ

การเชื่อมต่อ การคงการเชื่อมต่อ รุ่นที่รองรับ การซื้อ และความเป็นส่วนตัว ปัญหาการเชื่อมต่อส่วนใหญ่มาจากสามเรื่อง คือ เครือข่ายเดียวกัน โปรเจกเตอร์อยู่ในสแตนด์บายพร้อมเชื่อมต่อสาย LAN และไม่มีตัวควบคุมอื่นครอบครองโปรเจกเตอร์อยู่

เริ่มที่นี่

รายการตรวจสอบด่วน

  1. โปรเจกเตอร์เปิดอยู่ หรืออยู่ในสแตนด์บายพร้อมเชื่อมต่อสาย LAN
  2. โทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์อยู่ในเครือข่ายและซับเน็ตเดียวกับโปรเจกเตอร์ ไม่ใช่เครือข่ายแขก
  3. ไม่มีสิ่งอื่นเชื่อมต่อกับโปรเจกเตอร์: Home Assistant ระบบควบคุม หรือแอปนี้อีกสำเนาหนึ่ง
  4. หากโปรเจกเตอร์มีรหัสผ่านเครือข่าย ให้เตรียมรหัสไว้ในมือ
  5. เรียกใช้การตั้งค่าแบบมีคำแนะนำจากการตั้งค่า โดยจะตรวจสอบแต่ละข้อและบอกว่าข้อใดล้มเหลว
คำถามที่พบบ่อย

คำถามที่พบบ่อย

แอปหาโปรเจกเตอร์ของฉันไม่พบหรือเชื่อมต่อไม่ได้

ให้โทรศัพท์และโปรเจกเตอร์อยู่ในเครือข่ายและซับเน็ตเดียวกัน เครือข่ายแขก VLAN ที่แยกขาด และการแยกไคลเอนต์จะทำให้อุปกรณ์มองไม่เห็นกัน การสแกนดูซับเน็ต /24 ของคุณเอง หากสแกนไม่พบโปรเจกเตอร์ ให้เพิ่มด้วยที่อยู่ IP การควบคุมผ่านเครือข่ายใช้พอร์ต TCP 20554 และรุ่นใหม่ต้องใช้รหัสผ่านเครือข่ายที่ตั้งไว้บนโปรเจกเตอร์

แอปขอรหัสผ่านอะไร?

รหัสผ่านเครือข่ายที่ตั้งค่าบนโปรเจกเตอร์เอง ไม่ใช่รหัสผ่าน Wi-Fi รุ่นใหม่ใช้ 8 ถึง 10 ตัวอักษร แอปเก็บรหัสไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์ เฉพาะอุปกรณ์เครื่องนี้ และไม่รวมอยู่ในข้อมูลสำรอง

โปรเจกเตอร์อยู่ในสแตนด์บายและแอปเข้าถึงไม่ได้

โปรเจกเตอร์ที่ปิดสนิทตอบสนองไม่ได้ ให้คงไว้ในสแตนด์บายพร้อมเชื่อมต่อสาย LAN ในบางรุ่น การตั้งค่าสแตนด์บายประหยัดพลังงาน เช่น โหมดประหยัด ทำให้เครือข่ายไม่ตอบในสแตนด์บาย ให้ตรวจสอบการตั้งค่าเครือข่ายและสแตนด์บายของโปรเจกเตอร์เอง

แจ้งว่ามีตัวควบคุมอื่นเชื่อมต่ออยู่

โปรเจกเตอร์ JVC รองรับตัวควบคุมเครือข่ายครั้งละหนึ่งตัว หาก Home Assistant ระบบควบคุม หรือแอปอื่นเชื่อมต่ออยู่ แอปนี้จะเชื่อมต่อไม่ได้จนกว่าตัวนั้นจะปล่อย และในทางกลับกันก็เช่นกัน แอปนี้จะปล่อยโปรเจกเตอร์เมื่อไปอยู่เบื้องหลัง

โปรเจกเตอร์ของฉันเปลี่ยนที่อยู่ IP

หลังจากล้มเหลวติดต่อกันสามครั้ง แอปจะค้นหาโปรเจกเตอร์ในเครือข่ายของคุณด้วยที่อยู่ MAC แล้วเชื่อมต่อใหม่ที่ที่อยู่ใหม่ ต้องเคยเชื่อมต่อมาก่อนหนึ่งครั้งเพื่อให้รู้ที่อยู่ MAC คุณยังเปลี่ยนที่อยู่ได้ด้วย แก้ไขการเชื่อมต่อ ในการตั้งค่า

รุ่นของฉันไม่อยู่ในรายการ

โปรเจกเตอร์ D-ILA ที่ไม่อยู่ในรายการยังคงได้สถานะเปิดปิด อินพุต และปุ่มรีโมต การตั้งค่าที่ตารางคำสั่งของรุ่นนั้นไม่มีจะไม่แสดง แทนที่จะส่งคำสั่งแบบมั่วๆ การตั้งค่า, เกี่ยวกับ, โปรเจกเตอร์ที่รองรับ แสดงทุกรุ่นที่แอปรู้จักและระดับการรองรับ

เหตุใดตัวควบคุมจึงหายไปบนโปรเจกเตอร์ของฉัน

แอปแสดงตัวควบคุมก็ต่อเมื่อตารางคำสั่งของรุ่นคุณระบุไว้และโปรเจกเตอร์ตอบสำหรับตัวควบคุมนั้น ตัวควบคุมจะรอด้วยขณะที่โปรเจกเตอร์อยู่ในสแตนด์บายหรือกำลังวอร์มอัพ และจะปรากฏเมื่อเปิดเครื่อง

เป็นการซื้อครั้งเดียวหรือไม่

ใช่ Pro, Home Automation และชุดรวมเป็นการซื้อครั้งเดียว ไม่มีการสมัครสมาชิกและไม่มีโฆษณา ร้านค้าจะแสดงราคาในสกุลเงินของคุณก่อนที่คุณจะยืนยัน

จะนำการซื้อของฉันไปใช้บนอุปกรณ์ใหม่ได้อย่างไร

เข้าสู่ระบบบัญชีร้านค้าเดียวกัน แล้วแตะ กู้คืน บนการ์ด Pro ในการตั้งค่า การซื้อเป็นของบัญชีร้านค้า ไม่ใช่ของอุปกรณ์ หากไม่พบสิ่งใด แอปจะแจ้ง

แอปเก็บรวบรวมข้อมูลหรือไม่?

รายงานการขัดข้องบน Android และ iOS เปิดไว้โดยค่าเริ่มต้นและปิดได้ในการตั้งค่า, เกี่ยวกับ การวิเคราะห์การใช้งานปิดอยู่จนกว่าคุณจะยอมรับ และไม่เคยรวมชื่อ ที่อยู่ MAC หรือรหัสผ่านของโปรเจกเตอร์ของคุณ

แอปเคยทดสอบกับโปรเจกเตอร์ JVC จริงหรือไม่

เคย บน DLA-NZ500: เชื่อมต่อด้วยรหัสผ่านเครือข่าย อ่านสถานะ และเปลี่ยนการตั้งค่า รุ่นอื่นรองรับตามตารางคำสั่งที่ JVC เผยแพร่ และแอปเสนอเฉพาะสิ่งที่ตารางของแต่ละรุ่นระบุไว้

การแก้ไขปัญหา

สิ่งที่การตรวจสอบการเชื่อมต่อบอกคุณ

การตั้งค่าแบบมีคำแนะนำและหน้าเพิ่มจะตรวจสอบที่อยู่ที่คุณให้และระบุสิ่งแรกที่ล้มเหลว ผลแต่ละแบบมาพร้อมสิ่งที่ควรทำต่อ

ผลลัพธ์ความหมายควรทำอะไร
คนละเครือข่ายโทรศัพท์และโปรเจกเตอร์อยู่คนละซับเน็ตให้โทรศัพท์อยู่ในเครือข่ายเดียวกับโปรเจกเตอร์ ไม่ใช่เครือข่ายแขก หรืออนุญาตการรับส่งข้อมูลระหว่าง VLAN
ไม่มีอุปกรณ์ที่ที่อยู่นั้นไม่มีอะไรตอบกลับที่ที่อยู่นั้นตรวจสอบ IP ในการตั้งค่าเครือข่ายของโปรเจกเตอร์ และตรวจว่าอยู่ในสแตนด์บายพร้อมเชื่อมต่อสาย LAN
พอร์ตควบคุมปฏิเสธมีบางอย่างอยู่ที่ที่อยู่นั้นแต่ปฏิเสธพอร์ตควบคุมตรวจสอบพอร์ต โปรเจกเตอร์ JVC D-ILA ใช้ 20554 โดยค่าเริ่มต้น
ไม่มีการตอบกลับบนพอร์ตควบคุมพอร์ตหมดเวลาโดยไม่มีการตอบกลับโปรเจกเตอร์อาจปิดสนิท อาจมีตัวควบคุมอื่นเชื่อมต่ออยู่ หรือเครือข่ายอาจบล็อกการรับส่งข้อมูลระหว่างอุปกรณ์ (การแยกไคลเอนต์หรือ AP)
ต้องใช้รหัสผ่านโปรเจกเตอร์ขอรหัสผ่านเครือข่ายป้อนรหัสผ่านเครือข่ายที่ตั้งไว้บนโปรเจกเตอร์
ไม่ยอมรับรหัสผ่านโปรเจกเตอร์ปฏิเสธรหัสผ่านตรวจสอบรหัสผ่านบนโปรเจกเตอร์แล้วป้อนอีกครั้ง
โปรเจกเตอร์ไม่ว่างมีตัวควบคุมอื่นเชื่อมต่ออยู่ปิดแอปหรือระบบอื่นที่ควบคุมโปรเจกเตอร์ รอสักครู่ แล้วตรวจสอบอีกครั้ง
ไม่ใช่การตอบกลับของ JVCมีบางอย่างตอบกลับแต่ไม่ผ่านแฮนด์เชกของ JVCตรวจสอบที่อยู่: พอร์ตอาจเป็นของอุปกรณ์อื่น
ขณะเชื่อมต่อ

ข้อความที่คุณอาจเห็น

  • ไม่มีอะไรตอบกลับที่ที่อยู่นี้บนพอร์ต 20554 โปรเจกเตอร์หลุดจากเครือข่ายหรืออยู่ที่ที่อยู่อื่น
  • โปรเจกเตอร์ไม่ยอมรับการเชื่อมต่อบนพอร์ต 20554 อาจหลุดจากเครือข่าย หรือมีตัวควบคุมอื่น เช่น Home Assistant เชื่อมต่ออยู่
  • โปรเจกเตอร์ปิดการเชื่อมต่อ โปรเจกเตอร์จบเซสชัน แอปจะเชื่อมต่อใหม่เอง
  • อ่านรหัสผ่านที่บันทึกไว้จากที่เก็บข้อมูลที่ปลอดภัยไม่ได้ ตั้งใหม่ด้วย เปลี่ยนรหัสผ่าน ในการตั้งค่า
รุ่นที่รองรับ

กลุ่มรุ่น

แอปรู้จัก 43 โปรไฟล์รุ่น แต่ละชื่อด้านล่างเป็นชื่อรุ่นหรือชื่อประจำภูมิภาคของรุ่นหนึ่ง

  • รุ่นก่อนหน้าที่มี LAN: DLA-X7, X9, RS50, RS60, X30, RS45, X70R, X90R, RS55 และ RS65
  • ปี 2018: DLA-NX5, NX7, NX9 และชื่อรุ่น RS1000, RS2000, RS3000, N5, N6, N8, N11, V5, V7 และ V9R
  • ปี 2021: DLA-NZ7, NZ8, NZ9, NP5 และชื่อรุ่น RS1100, RS2100, RS3100, RS4100, N88, N98, V50, V70R, V80R และ V90R
  • ปี 2024: DLA-NZ500, NZ700 และชื่อรุ่น RS1200, RS2200, N700, N788, N799, N800, N888, N899, Z5 และ Z7
  • ปี 2025: DLA-NZ800 และ NZ900
  • รุ่นก่อนหน้าที่ไม่มี LAN เช่น DLA-HD350, HD550, HD750, HD950, HD990, X3, RS10, RS15, RS20, RS25, RS35 และ RS40 ไม่สามารถควบคุมผ่านเครือข่ายได้
