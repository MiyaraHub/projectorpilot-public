คำถามที่พบบ่อย

  • แอปหาโปรเจกเตอร์ของฉันไม่พบหรือเชื่อมต่อไม่ได้ ให้โทรศัพท์และโปรเจกเตอร์อยู่ในเครือข่ายและซับเน็ตเดียวกัน เครือข่ายแขกและ VLAN ที่แยกขาดจะทำให้ทั้งสองอยู่คนละเครือข่าย การสแกนจะดูเฉพาะซับเน็ต /24 ของคุณเอง หากสแกนไม่พบโปรเจกเตอร์ ให้เพิ่มด้วยที่อยู่ IP การควบคุมผ่านเครือข่ายใช้พอร์ต TCP 20554 และรุ่นใหม่ๆ ต้องใช้รหัสผ่านเครือข่ายที่ตั้งไว้บนโปรเจกเตอร์
  • แอปขอรหัสผ่านอะไร? รหัสผ่านเครือข่ายที่กำหนดไว้บนตัวโปรเจกเตอร์เอง แอปเก็บรหัสไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์ เฉพาะบนอุปกรณ์เครื่องนี้เท่านั้น และไม่รวมไว้ในข้อมูลสำรอง
  • โปรเจกเตอร์ของฉันเปลี่ยนที่อยู่ IP หลังจากล้มเหลวสามครั้ง แอปจะค้นหาโปรเจกเตอร์ในเครือข่ายของคุณด้วยที่อยู่ MAC และเชื่อมต่อกับที่อยู่ใหม่ของโปรเจกเตอร์อีกครั้ง
  • รุ่นของฉันไม่อยู่ในรายการ โปรเจกเตอร์ D-ILA ที่ไม่อยู่ในรายการยังคงใช้การเปิดปิดเครื่อง อินพุต และปุ่มรีโมตได้ การตั้งค่าที่ตารางคำสั่งของรุ่นนั้นไม่มีจะไม่แสดง แทนที่จะส่งไปแบบไม่รู้ผล
  • เป็นการซื้อครั้งเดียวหรือไม่? ใช่ Pro, Home Automation และชุดรวมเป็นการซื้อครั้งเดียว ไม่มีการสมัครสมาชิกและไม่มีโฆษณา ร้านค้าจะแสดงราคาในสกุลเงินของคุณก่อนที่คุณจะยืนยัน
  • แอปเก็บรวบรวมข้อมูลหรือไม่? รายงานแครชบน Android และ iOS เปิดอยู่โดยค่าเริ่มต้น และปิดได้ในการตั้งค่า เกี่ยวกับ การวิเคราะห์การใช้งานปิดอยู่จนกว่าคุณจะยอมรับ และไม่รวมชื่อ ที่อยู่ MAC หรือรหัสผ่านของโปรเจกเตอร์ของคุณเลย
