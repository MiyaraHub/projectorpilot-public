การบำรุงรักษา

การบำรุงรักษาและข้อมูลเชิงลึก

รู้ว่าแหล่งกำเนิดแสงทำงานหนักเพียงใด หน้าการบำรุงรักษาอ่านชั่วโมงจากโปรเจกเตอร์ คำนวณอายุการใช้งานที่คาดการณ์และต้นทุนการใช้งานจากตัวเลขที่คุณป้อน และเตือนเมื่ออายุที่กำหนดใกล้ถึง เป็นส่วนหนึ่งของ Pro ภายใต้ การตั้งค่า, การบำรุงรักษาและข้อมูลเชิงลึก

ชั่วโมง

อ่านอย่างเดียว จากโปรเจกเตอร์

  • ชั่วโมงแหล่งกำเนิดแสง จำนวนชั่วโมงรวมที่เลเซอร์หรือหลอดภาพทำงาน อ่านจากโปรเจกเตอร์ ป้ายชื่อเปลี่ยนตามแหล่งกำเนิดแสงที่รุ่นของคุณรายงาน
  • นับตั้งแต่เพิ่ม จำนวนชั่วโมงที่ใช้งานนับตั้งแต่คุณทำเครื่องหมายว่าติดตั้งโปรเจกเตอร์เครื่องนี้ เมื่อคุณตั้งค่าเส้นฐานด้านล่างแล้ว
  • ยังไม่มีชั่วโมงใช่หรือไม่ เชื่อมต่อและเปิดโปรเจกเตอร์เพื่อให้แอปอ่านค่าได้
ไม่มีสิ่งใดบนหน้าจอนี้ถูกเขียนกลับไปยังโปรเจกเตอร์ แอปไม่รีเซ็ตหรือเปลี่ยนจำนวนชั่วโมงของโปรเจกเตอร์เอง
ข้อมูลเชิงลึก

อายุการใช้งานที่คาดการณ์และต้นทุนต่อชั่วโมง

แอปไม่ทราบอายุที่กำหนดของรุ่นใดเลย จึงไม่เคยแต่งตัวเลขขึ้นเอง ป้อนตัวเลขจากเอกสารของโปรเจกเตอร์หรือจากตัวแทนจำหน่าย แล้วข้อมูลเชิงลึกจะถูกเติมให้

ข้อมูลเชิงลึกสิ่งที่คุณป้อนสิ่งที่แสดง
อายุการใช้งานที่คาดการณ์อายุที่กำหนด เป็นชั่วโมง เช่น 20000ชั่วโมงที่เหลือของอายุที่กำหนดและเปอร์เซ็นต์ที่ใช้ไป
ต้นทุนต่อชั่วโมงราคาแหล่งกำเนิดแสงหรือยูนิตทดแทน เช่น 3500ต้นทุนต่อชั่วโมงของการใช้งาน ไม่มีการเพิ่มสัญลักษณ์สกุลเงิน จึงใช้ได้กับทุกสกุลเงิน
เส้นฐานการติดตั้งทำเครื่องหมายตอนนี้ หรือแก้ไขชั่วโมงด้วยตนเอง ล้างจะลบเส้นฐานตัวเลข นับตั้งแต่เพิ่ม ข้างต้น
การเตือน

การเตือนการบำรุงรักษา

การเตือนปิดอยู่จนกว่าคุณจะเลือกเปิด เปิดการแจ้งเตือนการบำรุงรักษา แล้วเปิดคำเตือนอายุแหล่งกำเนิดแสง

  • เมื่อใด ที่ 90% ของอายุที่กำหนดซึ่งคุณป้อน จากนั้นทุก 100 ชั่วโมง
  • อย่างไร การแจ้งเตือนที่มีชื่อว่า ชั่วโมงแหล่งกำเนิดแสง การตรวจสอบทำงานขณะที่แอปเปิดและเชื่อมต่อกับโปรเจกเตอร์อยู่
  • ต้องมี อายุที่กำหนดภายใต้ข้อมูลเชิงลึก และสิทธิ์การแจ้งเตือน หากระบบปฏิเสธการแจ้งเตือน การเตือนจะยังปิดอยู่จนกว่าคุณจะอนุญาต
  • ที่ไหน Android, iOS และ macOS ส่วน Windows ไม่มีการเตือน
ข้อความเตือนเป็นภาษาอังกฤษไม่ว่าแอปจะตั้งเป็นภาษาใด
บันทึก

ส่งออกรายงานชั่วโมง

ส่งออกรายงานชั่วโมงจะบันทึกไฟล์ข้อความขนาดเล็ก ประกอบด้วย เวอร์ชันของแอป รุ่น ชั่วโมงแหล่งกำเนิดแสงที่แอปอ่านได้ เวลา และค่าตรวจสอบ SHA-256

เป็นภาพรวมของสิ่งที่แอปอ่านได้ในขณะนั้น ใช้เป็นบันทึกการใช้งานโปรเจกเตอร์ได้สะดวก แอปรับรองเอง ไม่ได้รับการรับรองจาก JVC

ข้อมูลของคุณ

ตัวเลขเก็บไว้ที่ไหน

  • อายุที่กำหนด ราคาต่อหน่วย และเส้นฐานเก็บไว้บนอุปกรณ์เครื่องนี้
  • การสำรองและกู้คืนข้อมูลไม่รวมค่าเหล่านี้
  • ชั่วโมงเองมาจากโปรเจกเตอร์เสมอ จึงถูกต้องบนทุกอุปกรณ์ที่คุณเชื่อมต่อ
  • ชิปชั่วโมงแหล่งกำเนิดแสงบนแดชบอร์ดและวิดเจ็ตสถานะโปรเจกเตอร์แสดงค่าที่อ่านได้เดียวกัน ดูแดชบอร์ด
ตัวอย่าง

ตัวอย่างการคำนวณ

สมมติว่าโปรเจกเตอร์ของคุณทำงานมาแล้ว 4000 ชั่วโมง และคุณป้อนอายุที่กำหนด 20000 ชั่วโมงและค่าทดแทน 3500

ตัวเลขผลลัพธ์วิธีคำนวณ
ชั่วโมงที่เหลือ16000อายุที่กำหนดลบด้วยชั่วโมงที่ใช้ไป
อายุที่ใช้ไป20%ชั่วโมงที่ใช้ไปหารด้วยอายุที่กำหนด
ต้นทุนต่อชั่วโมง0.875ค่าทดแทนหารด้วยชั่วโมงที่ใช้ไปจนถึงตอนนี้
การเตือนครั้งแรกที่ 18000 ชั่วโมง90% ของอายุที่กำหนด จากนั้นทุก 100 ชั่วโมง

ต้นทุนต่อชั่วโมงจะลดลงยิ่งแหล่งกำเนิดแสงทำงานนานขึ้น เพราะต้นทุนเท่าเดิมถูกกระจายไปตามชั่วโมงที่มากขึ้น

ดูได้ในพริบตา

ชั่วโมงบนหน้าจอแรก

คุณไม่ต้องเปิดหน้าจอนี้เพื่อดูชั่วโมง ชิปชั่วโมงแหล่งกำเนิดแสงบนแดชบอร์ดและวิดเจ็ตสถานะโปรเจกเตอร์แสดงค่าเดียวกับที่โปรเจกเตอร์รายงาน ดูแดชบอร์ด

คำถาม

คำถามเกี่ยวกับการบำรุงรักษา

เหตุใดแอปจึงไม่กรอกอายุที่กำหนดให้ฉัน

แอปไม่มีอายุที่กำหนดของรุ่นใดเลย และไม่เคยแต่งขึ้นเอง ป้อนตัวเลขจากเอกสารของโปรเจกเตอร์หรือจากตัวแทนจำหน่าย

แอปรีเซ็ตจำนวนชั่วโมงของโปรเจกเตอร์ได้หรือไม่

ไม่ได้ ไม่มีสิ่งใดบนหน้าจอนี้ถูกเขียนไปยังโปรเจกเตอร์ เส้นฐานการติดตั้งเป็นวิธีของแอปเองในการนับชั่วโมงนับจากวันที่คุณเลือก

การเตือนใช้ได้บน Windows หรือไม่

ไม่ การเตือนใช้ได้บน Android, iOS และ macOS ขณะที่แอปเปิดและเชื่อมต่อกับโปรเจกเตอร์อยู่
