รีโมท

รีโมตบนโทรศัพท์ของคุณ

แท็บรีโมตควบคุมเมนูของโปรเจกเตอร์เอง และมีทุกปุ่มรีโมตที่รุ่นของคุณระบุไว้ มีสี่หน้าที่ปัดสลับกันได้ คือ รีโมต การทำงาน อุปกรณ์ และเครือข่าย

หน้ารีโมต

นำทางในเมนูของโปรเจกเตอร์

  • การนำทาง ปุ่มกดทิศทางทรงกลมที่มี ขึ้น ลง ซ้าย ขวา และ OK รวมถึง เมนู และ ย้อนกลับ เหมือนบนรีโมตของ JVC
  • อินพุต ในรุ่นที่ตารางปุ่มมี ปุ่มอินพุตจะสลับไปตามอินพุต เป็นปุ่ม Pro
  • แหล่งอินพุต หนึ่งปุ่มต่ออินพุตที่รุ่นของคุณมี เช่น HDMI 1 และ HDMI 2 HDMI 1 ใช้ได้ฟรี ส่วนอินพุตอื่นต้องใช้ Pro
  • ตัวควบคุมเพิ่มเติม โหมดภาพ ซ่อน และปุ่มรีโมตอื่นทั้งหมด ในหน้าของตัวเอง
  • รีเฟรช ปุ่มรีเฟรชที่แถบด้านบนจะอ่านสถานะของโปรเจกเตอร์อีกครั้ง
ระดับฟรี

การกดนำทางฟรี

หากไม่มี Pro จะนับการกดปุ่มกดทิศทาง (ขึ้น ลง ซ้าย ขวา OK ย้อนกลับ และเมนู) คุณได้ 20 ครั้งตลอดอายุการติดตั้ง จากนั้นวันละ 3 ครั้ง Pro ยกเลิกการนับ

  • ตัวนับใต้ปุ่มกดทิศทางแสดง "เหลือการกดนำทางฟรี 18 ครั้ง" และเมื่อใช้ 20 ครั้งแรกหมดแล้วจะแสดง "เหลือการกดนำทางฟรีวันนี้ 3 ครั้ง"
  • วันเริ่มเมื่อใด สิทธิ์รายวันรีเซ็ตเมื่อเที่ยงคืนตามเวลาท้องถิ่น ไม่ใช่ 24 ชั่วโมงหลังการกดครั้งล่าสุด ในวันที่ 20 ครั้งแรกหมดลง 3 ครั้งของวันนั้นยังคงอยู่
  • สิ่งที่นับ การกดจะถูกนับเมื่อแอปส่ง แม้โปรเจกเตอร์จะไม่ตอบรับก็ตาม จะไม่นับขณะที่แอปไม่ได้เชื่อมต่อ บนโปรเจกเตอร์สาธิต หรือเมื่อใช้ Pro
  • เมื่อหมด ปุ่มกดทิศทางยังอยู่บนหน้าจอ แต่ไม่ส่งสิ่งใด และแสดงข้อความ "ใช้การกดนำทางฟรีของวันนี้หมดแล้ว พรุ่งนี้จะมีเพิ่ม หรือปลดล็อก Pro เพื่อกดได้ไม่จำกัด"
การนับจะรีเซ็ตหรือไม่หากฉันติดตั้งใหม่

บน iOS และ macOS ไม่รีเซ็ต: มีสำเนาที่สองเก็บไว้ใน Keychain และใช้ค่าที่สูงกว่า บน Android การนับจะเริ่มใหม่หลังติดตั้งใหม่ เว้นแต่การสำรองข้อมูลของ Android เองจะกู้คืนข้อมูลของแอป บน Windows การนับจะเริ่มใหม่หลังติดตั้งใหม่

ตัวควบคุมเพิ่มเติม

ปุ่มรีโมตอื่นทั้งหมด

ตัวควบคุมเพิ่มเติมเป็นหน้า Pro เริ่มด้วยการ์ดโหมดภาพเมื่อรุ่นของคุณตั้งค่าได้ จากนั้นเป็นซ่อน แล้วจึงเป็นปุ่มรีโมตที่จัดกลุ่มตามหน้าที่ แสดงเฉพาะปุ่มที่ตารางของรุ่นคุณระบุไว้

ตามรุ่น

ปุ่มที่รุ่นของคุณมี

JVC แต่ละรุ่นมีตารางปุ่มของตัวเอง และแอปเลือกตารางจากรหัสรุ่นที่โปรเจกเตอร์รายงาน ปุ่มที่รุ่นของคุณไม่มีจะไม่ถูกเสนอ หากมีปุ่มไปถึงรุ่นที่ไม่มีปุ่มนั้น แอปจะไม่ส่งสิ่งใด และระบุตัวควบคุมกับรุ่น โดยปิดท้ายว่า "ไม่ได้ส่งสิ่งใด" รุ่นที่แอปไม่ได้ระบุไว้ยังคงได้สถานะเปิดปิด อินพุต และปุ่มรีโมต

หน้าการทำงาน

โปรเจกเตอร์ทำงานอย่างไร

หน้าการทำงานมี ตัวตั้งเวลาปิด โหมดประหยัด ทริกเกอร์ ซ่อนประหยัด และ Control4 ในรุ่นที่รองรับ ทั้งหมดเป็น Pro

โหมดประหยัดและเครือข่าย เมื่อเปิดโหมดประหยัด โปรเจกเตอร์อาจหยุดตอบบนเครือข่ายขณะสแตนด์บาย ซึ่งอาจทำให้แอปเปิดเครื่องกลับมาไม่ได้ แอปจะเตือนก่อนที่คุณเปิด เอกสารคำสั่งของ JVC ไม่ได้ระบุไว้ชัดเจน คำเตือนจึงใช้คำว่า "อาจ"
หน้าอุปกรณ์

สิ่งที่โปรเจกเตอร์รายงานเกี่ยวกับตัวเอง

หน้าอุปกรณ์ (Pro) มีสองส่วน โปรเจกเตอร์แสดงรหัสรุ่นและค่าอื่นที่รุ่นของคุณรายงานเกี่ยวกับตัวเอง สัญญาณแสดงสิ่งที่โปรเจกเตอร์รายงานเกี่ยวกับสัญญาณขาเข้า และจะถูกละไว้เมื่อไม่มีสัญญาณ การแตะโปรเจกเตอร์ในการตั้งค่าจะเปิดรายละเอียดเดียวกันในชื่อข้อมูลอุปกรณ์

หน้าเครือข่าย

มุมมองแบบอ่านอย่างเดียวของเครือข่าย

หน้าเครือข่าย (Pro) แสดงการตั้งค่า LAN แบบมีสายของโปรเจกเตอร์ ได้แก่ DHCP, ที่อยู่ IP, ซับเน็ต, เกตเวย์, พอร์ต และที่อยู่ MAC เท่าที่รุ่นของคุณรายงาน ตั้งใจให้อ่านอย่างเดียว เพราะแอปเข้าถึงโปรเจกเตอร์ผ่านเครือข่ายเดียวกันนี้ การเปลี่ยนที่อยู่จากที่นี่จะตัดการเชื่อมต่อของแอปเอง ให้เปลี่ยนในเมนูบนหน้าจอของโปรเจกเตอร์แล้วเชื่อมต่อใหม่ เริ่มต้นใช้งานอธิบายกรณีที่โปรเจกเตอร์เปลี่ยนที่อยู่
