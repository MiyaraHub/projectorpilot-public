Home Assistant

ตั้งค่าโปรเจกเตอร์ JVC ของคุณใน Home Assistant

แอปเข้าสู่ระบบ Home Assistant ของคุณ เพิ่มโปรเจกเตอร์ลงในอินทิเกรชัน JVC Projector ของ Home Assistant เอง เผยแพร่ฉากและตัวควบคุมของคุณเป็นสคริปต์ และสร้างแดชบอร์ดให้ คุณไม่ต้องวางโทเคนหรือเขียน YAML ต้องใช้แอดออน Home Automation

อ่านก่อน

ครั้งละหนึ่งตัวควบคุม

โปรเจกเตอร์ JVC รองรับตัวควบคุมเครือข่ายครั้งละหนึ่งตัว ขณะที่แอปนี้เปิดและเชื่อมต่อกับโปรเจกเตอร์อยู่ Home Assistant จะเข้าถึงโปรเจกเตอร์ไม่ได้ ตัวควบคุมโปรเจกเตอร์และสคริปต์ของ Home Assistant ทำงานได้เมื่อปิดแอป และแอปจะปล่อยโปรเจกเตอร์เมื่อไปอยู่เบื้องหลัง

ขั้นตอนที่ 1

เข้าสู่ระบบ

  1. เปิด การตั้งค่า, Home Automation, Home Assistant
  2. ป้อนที่อยู่ Home Assistant ของคุณ โดยขึ้นต้นด้วย http:// หรือ https://
  3. แตะ เข้าสู่ระบบ หน้าเข้าสู่ระบบของ Home Assistant เองจะเปิดในเบราว์เซอร์ ให้เข้าสู่ระบบที่นั่นแล้วกลับมา
  4. แตะ ทดสอบการเชื่อมต่อ เพื่อยืนยัน
หากเข้าถึง Home Assistant ไม่ได้ ให้ตรวจสอบที่อยู่ และตรวจว่าอุปกรณ์เครื่องนี้อยู่ในเครือข่ายเดียวกับ Home Assistant
ขั้นตอนที่ 2

สิ่งที่ Home Assistant ของคุณมี

แผงหนึ่งจะอ่านข้อมูลจาก Home Assistant ของคุณและทำเครื่องหมายแต่ละส่วนว่า พบ ไม่ได้ติดตั้ง หรือ ไม่สามารถระบุได้ ตรวจสอบอีกครั้งจะอ่านใหม่

ส่วนใช้สำหรับ
อินทิเกรชัน Mobile Appเซนเซอร์สถานะสด
อินทิเกรชัน JVC Projectorการควบคุมโปรเจกเตอร์เครื่องนี้จาก Home Assistant
HACSเฉพาะรูปลักษณ์แบบตกแต่งของแดชบอร์ด
ขั้นตอนที่ 3

รายการตรวจสอบการตั้งค่า

  1. เข้าสู่ระบบ Home Assistant
  2. เพิ่มโปรเจกเตอร์นี้ลงในอินทิเกรชัน JVC Projector ของ Home Assistant แตะ เพิ่ม แอปจะส่งที่อยู่ พอร์ต และรหัสผ่านเครือข่ายของโปรเจกเตอร์ไปยังอินทิเกรชัน JVC Projector ของ Home Assistant หลังจากถามคุณก่อน
  3. เปิดใช้เอนทิตีที่สคริปต์ต้องใช้ เอนทิตี JVC Projector บางรายการเริ่มต้นเป็นปิดใช้งานใน Home Assistant แตะ เปิดใช้งาน ข้างแต่ละรายการ Home Assistant อาจต้องโหลดใหม่หรือรีสตาร์ตก่อนรายการนั้นจะปรากฏ
  4. เซนเซอร์สถานะสด เปิด ส่งสถานะของโปรเจกเตอร์ เซนเซอร์จะถูกสร้างในครั้งถัดไปที่แอปส่งสถานะของโปรเจกเตอร์ขณะเชื่อมต่ออยู่
เรื่องรหัสผ่าน เมื่อคุณเพิ่มโปรเจกเตอร์ รหัสผ่านเครือข่ายของโปรเจกเตอร์จะถูกส่งไปยัง Home Assistant ของคุณและเก็บไว้ที่นั่น ในรายการ JVC Projector แอปไม่ส่งรหัสนี้ไปที่อื่น แอปจะปล่อยโปรเจกเตอร์ขณะที่ Home Assistant เชื่อมต่อกับโปรเจกเตอร์ แล้วจึงเชื่อมต่อใหม่
รายการไหน

แอปหาโปรเจกเตอร์ของคุณใน Home Assistant อย่างไร

แอปจับคู่รายการ JVC Projector ด้วยที่อยู่ MAC ของโปรเจกเตอร์ จึงต้องเชื่อมต่อกับโปรเจกเตอร์อย่างน้อยหนึ่งครั้งก่อน หาก Home Assistant ไม่มีรายการที่มี MAC นั้น หรือมีมากกว่าหนึ่งรายการ รายการตรวจสอบจะแจ้งไว้พร้อมวิธีดำเนินการ หากโปรเจกเตอร์เปลี่ยนที่อยู่ แอปจะเสนอให้ส่งที่อยู่ใหม่ไปยัง Home Assistant

เซนเซอร์

สถานะสด

สถานะของเซนเซอร์คือสถานะพลังงานที่แอปอ่านล่าสุด ส่วนแอตทริบิวต์คืออินพุต รุ่น และการตั้งค่าที่แอปอ่านได้ เซนเซอร์ทำงานผ่านอินทิเกรชัน Mobile App และไม่ส่งอะไรไปยังโปรเจกเตอร์ เซนเซอร์อัปเดตทุกครั้งที่สถานะเปลี่ยนขณะที่แอปเปิดและเชื่อมต่ออยู่

สคริปต์

ฉากและการควบคุม

ฉากที่บันทึกไว้แต่ละฉากจะกลายเป็นสคริปต์ใน Home Assistant ที่ทำงานผ่านเอนทิตี JVC Projector สคริปต์ไม่เก็บที่อยู่และรหัสผ่าน รหัสสคริปต์ขึ้นต้นด้วย ppjvc

  • Sync With HA เขียนฉากของคุณเป็นสคริปต์ และแสดงจำนวนขั้นตอนของแต่ละสคริปต์ รวมถึงสิ่งที่ถูกตัดออกและเหตุผล
  • Sync Advanced Controls เผยแพร่สคริปต์สำหรับสถานะเปิดปิด อินพุต โหมดภาพ หน่วยความจำเลนส์ และซ่อน
  • ผลลัพธ์ มีการนับ: ซิงค์สคริปต์สำเร็จกี่รายการ Home Assistant ปฏิเสธกี่รายการ และ Home Assistant ยืนยันการโหลดใหม่หรือไม่
  • Remove orphaned scripts ลบสคริปต์ที่แอปนี้สร้างขึ้นซึ่งไม่มีฉากใดใช้อีกต่อไป โดยแสดงรายการและถามก่อน
หากยังไม่ได้อ่านสิ่งที่การซิงค์ต้องใช้ จะไม่มีการเขียน เปลี่ยนแปลง หรือลบสิ่งใด การซิงค์ไม่เคยทำงานครึ่งๆ กลางๆ จากการคาดเดา
แดชบอร์ด

แดชบอร์ดสำเร็จรูป

ส่งแดชบอร์ดสร้างแดชบอร์ดโปรเจกเตอร์ใน Home Assistant ของคุณจากเอนทิตี JVC Projector สคริปต์ และเซนเซอร์ ส่วนคัดลอกแดชบอร์ดจะคัดลอกแทน เพื่อให้คุณนำไปวางในแดชบอร์ดใหม่เอง รายละเอียดทั้งหมดอยู่ในหน้าแดชบอร์ด Home Assistant

กฎ

สิ่งที่แอปไม่เคยทำ

  • จะไม่มีสิ่งใดออกจากอุปกรณ์ขณะที่เลือกโปรเจกเตอร์สาธิตอยู่ หรือยังไม่ได้ปลดล็อก Home Automation
  • ยกเลิกการเชื่อมโยงจะลบการเชื่อมโยงออกจากแอปนี้เท่านั้น อุปกรณ์และเอนทิตีของโปรเจกเตอร์ยังคงอยู่ใน Home Assistant จนกว่าคุณจะลบที่นั่น
  • หาก Home Assistant ไม่ยอมรับการเข้าสู่ระบบอีกต่อไป แอปจะแจ้งและขอให้คุณเข้าสู่ระบบอีกครั้ง
