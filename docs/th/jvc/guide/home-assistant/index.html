Home Assistant

ตั้งค่าโปรเจกเตอร์ JVC ของคุณใน Home Assistant จากในแอป

การตั้งค่า

ตั้งแต่ลงชื่อเข้าใช้จนถึงแดชบอร์ด

  • ลงชื่อเข้าใช้ Home Assistant ด้วยการลงชื่อเข้าใช้ OAuth ของ Home Assistant เอง
  • การผสานรวม: แอปจะเพิ่มการผสานรวม jvc_projector หลักของ Home Assistant โดยส่งโฮสต์ พอร์ต และรหัสผ่านไปให้
  • เซนเซอร์: เซนเซอร์ mobile_app รายงานผ่านเว็บฮุก
  • ซิงก์ตัวควบคุมขั้นสูง สร้างสคริปต์ที่มีคำนำหน้า ppjvc
  • แดชบอร์ด: แดชบอร์ด Lovelace แบบสไตล์หลักหรือสไตล์ HACS
  • รายการตรวจสอบการตั้งค่า จะแสดงสิ่งที่ทำเสร็จแล้วและสิ่งที่เหลืออยู่
