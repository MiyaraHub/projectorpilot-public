เพิ่มโปรเจกเตอร์ของคุณ

แอปค้นหาโปรเจกเตอร์ JVC D-ILA ในเครือข่ายของคุณเองและสื่อสารกับโปรเจกเตอร์โดยตรง ผ่านพอร์ต TCP 20554 การตั้งค่าใช้การสแกนหรือที่อยู่ IP และรหัสผ่านเครือข่ายของโปรเจกเตอร์ หากมีการตั้งไว้

เปิดครั้งแรก

หน้าจอต้อนรับ

  1. ยินดีต้อนรับสู่ Projector Pilot D-ILA ทัวร์สั้นๆ ว่าอะไรใช้ได้ฟรี Pro เพิ่มอะไรให้ และขอความช่วยเหลือได้ที่ไหน: เข้าร่วม Discord หรือ อีเมลบันทึกข้อมูล
  2. การวิเคราะห์ แอปจะถามว่าอนุญาตให้ส่งข้อมูลการใช้งานแบบไม่ระบุตัวตนหรือไม่ ปิดไว้เว้นแต่คุณยอมรับ และเปลี่ยนภายหลังได้ที่ การตั้งค่า, เกี่ยวกับ
  3. ก่อนเริ่มต้น รายการตรวจสอบ: โทรศัพท์และโปรเจกเตอร์อยู่ในเครือข่ายท้องถิ่นเดียวกัน โปรเจกเตอร์เชื่อมต่อผ่านพอร์ต LAN พร้อมรหัสผ่านเครือข่ายหากมี และที่อยู่ IP ของโปรเจกเตอร์ ซึ่งดูได้จากการตั้งค่าเครือข่ายของเครื่อง
  4. เพิ่มโปรเจกเตอร์ เลือก สแกนเครือข่าย เพิ่มโปรเจกเตอร์ด้วย IP หรือ ลองใช้โหมดสาธิต
ทางเลือกที่ 1

สแกนเครือข่าย

  • ค้นหาที่ไหน ทุกช่วงที่อยู่ส่วนตัวที่อุปกรณ์ของคุณอยู่ คือที่อยู่ 1 ถึง 254 ของซับเน็ต /24 นั้น บนพอร์ต 20554
  • ตัดสินอย่างไร โปรเจกเตอร์ JVC จะทักทายการเชื่อมต่อใหม่ การสแกนจะแสดงอุปกรณ์ที่ทักทายว่าพร้อมใช้งาน หรือกำลังใช้งานกับตัวควบคุมอื่น ความคืบหน้าแสดงจำนวนที่อยู่ที่ตรวจแล้วจากทั้งหมด
  • เมื่อไม่มีอะไรตอบกลับ "ไม่มีโปรเจกเตอร์ JVC ตอบกลับในเครือข่ายนี้" โปรเจกเตอร์ที่ตัวควบคุมอื่น เช่น Home Assistant เชื่อมต่ออยู่แล้วจะไม่ตอบการสแกน ให้เพิ่มเครื่องนั้นด้วยที่อยู่แทน
  • ไม่มี Wi-Fi หากอุปกรณ์ไม่ได้อยู่ในเครือข่ายท้องถิ่น การสแกนจะแจ้งว่า "ไม่พบเครือข่ายท้องถิ่น เชื่อมต่อ Wi-Fi แล้วสแกนอีกครั้ง"
ทางเลือกที่ 2

เพิ่มด้วยที่อยู่ IP

ใช้วิธีนี้เมื่อการสแกนไม่พบโปรเจกเตอร์ หรือเมื่อโปรเจกเตอร์อยู่ในซับเน็ตอื่นที่อุปกรณ์ของคุณยังเข้าถึงได้

  1. ตั้งชื่อโปรเจกเตอร์ เช่น ตามชื่อห้องที่ใช้งาน
  2. ที่อยู่ IP: ที่อยู่ IPv4 ของโปรเจกเตอร์ จากเมนูเครือข่ายของเครื่อง ไม่รองรับชื่อโฮสต์
  3. รหัสผ่านเครือข่าย: รหัสที่ตั้งไว้บนโปรเจกเตอร์ เว้นว่างไว้หากโปรเจกเตอร์ไม่มีรหัสผ่านเครือข่าย
  4. ทดสอบการเชื่อมต่อ หากทดสอบผ่านจะแสดง "เชื่อมต่อแล้ว" และรุ่นที่โปรเจกเตอร์รายงาน
  5. บันทึก โปรเจกเตอร์จะปรากฏบนแดชบอร์ด การบันทึกโปรเจกเตอร์เครื่องเดิมซ้ำสองครั้งจะถูกปฏิเสธพร้อมข้อความ "บันทึกโปรเจกเตอร์นี้ไว้แล้ว"
หน้าจอเพิ่มใช้พอร์ตมาตรฐาน 20554 หากต้องการใช้พอร์ตอื่น ให้ใช้การตั้งค่าแบบมีคำแนะนำด้านล่าง ช่องพอร์ตควบคุมจะส่งพอร์ตนั้นไปยังหน้าจอเพิ่ม
ทางเลือกที่ 3

การตั้งค่าและการวินิจฉัยแบบมีคำแนะนำ

"เชื่อมต่อมีปัญหา? เรียกใช้การวินิจฉัยแบบมีคำแนะนำ" จะเปิด ตั้งค่าโปรเจกเตอร์ ป้อนที่อยู่ IP ของโปรเจกเตอร์และพอร์ตควบคุม (20554 หากไม่ได้เปลี่ยน) จากนั้นแตะ วินิจฉัยการเชื่อมต่อ

การตรวจสอบสิ่งที่พิสูจน์ได้
เครือข่ายเดียวกับโปรเจกเตอร์อุปกรณ์ของคุณและโปรเจกเตอร์อยู่ในซับเน็ตเดียวกัน จึงมองเห็นกันได้
เข้าถึงพอร์ตควบคุมได้มีบางอย่างรับการเชื่อมต่อบนพอร์ตควบคุม
แฮนด์เชกและรหัสผ่านของโปรเจกเตอร์ตอบสนองเหมือนโปรเจกเตอร์ JVC และรหัสผ่าน (หากมี) ได้รับการยอมรับ

เมื่อผ่านทั้งสามข้อ ผลลัพธ์จะเป็น "เชื่อมต่อได้" พร้อมปุ่ม เพิ่มโปรเจกเตอร์นี้ เมื่อข้อใดล้มเหลว หน้าจอจะระบุข้อนั้นและแสดง "เกิดอะไรขึ้น" และ "วิธีแก้ไข" หากโปรเจกเตอร์ต้องการรหัสผ่าน ช่องรหัสผ่านเครือข่ายและปุ่ม ลองใช้รหัสผ่าน จะปรากฏในหน้าเดิม การวินิจฉัยแต่ละแบบแสดงไว้ในหน้าวิธีใช้

รหัสผ่าน

รหัสผ่านเครือข่าย

  • รหัสไหน รหัสผ่านเครือข่ายที่ตั้งไว้ในเมนูเครือข่ายของโปรเจกเตอร์เอง แอปไม่มีบัญชีของตัวเอง
  • รุ่นปี 2024 และ 2025 ใช้ 8 ถึง 10 ตัวอักษร แอปตรวจสอบความยาวก่อนส่งสิ่งใดออกไป โดยจะลองรูปแบบ SHA-256 ก่อน แล้วจึงลองรูปแบบธรรมดา
  • รุ่นปี 2018 และ 2021 จะส่งรหัสผ่านก็ต่อเมื่อโปรเจกเตอร์ร้องขอ รุ่นก่อนหน้านั้นไม่เคยได้รับรหัสผ่าน
  • เก็บไว้ที่ไหน ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์ เฉพาะอุปกรณ์เครื่องนี้ และไม่รวมอยู่ในข้อมูลสำรอง
  • การเปลี่ยนรหัส เปิดเมนูของโปรเจกเตอร์บนแดชบอร์ดแล้วเลือก เปลี่ยนรหัสผ่าน
ตัวควบคุมเดียว

ใช้ได้ครั้งละหนึ่งแอปเท่านั้น

โปรเจกเตอร์ JVC รองรับตัวควบคุมเครือข่ายครั้งละหนึ่งตัว ขณะที่ Projector Pilot D-ILA เชื่อมต่ออยู่ Home Assistant ระบบควบคุม หรือโทรศัพท์เครื่องอื่นจะเข้าถึงโปรเจกเตอร์ไม่ได้ และในทางกลับกันก็เช่นกัน

  • รุ่นปี 2024 และ 2025 เปิดการเชื่อมต่อค้างไว้หนึ่งการเชื่อมต่อ ส่วนรุ่นเก่ากว่าจะเชื่อมต่อใหม่ทุกครั้งที่ส่งคำสั่ง
  • แอปจะปล่อยโปรเจกเตอร์เมื่อไปอยู่เบื้องหลัง เพื่อให้ตัวควบคุมอื่นเข้าควบคุมต่อได้
  • หากการเชื่อมต่อหลุด แอปจะลองใหม่หลังจาก 3, 5, 8 และต่อไปทุก 10 วินาที และลองทันทีเมื่อเครือข่ายกลับมา แต่จะไม่ลองใหม่หลังจากใช้รหัสผ่านผิด
ที่อยู่ใหม่

เมื่อโปรเจกเตอร์เปลี่ยนที่อยู่

แอปจะจดจำที่อยู่ MAC ของโปรเจกเตอร์เมื่อเชื่อมต่อ หากเชื่อมต่อสามครั้งติดต่อกันแล้วไม่พบอะไร สถานะจะแสดง "กำลังค้นหาเครือข่าย" และแอปจะค้นหาที่อยู่ MAC นั้นทั่วซับเน็ตไม่เกินสามครั้ง เมื่อพบโปรเจกเตอร์ที่ตรงกันเพียงเครื่องเดียว แอปจะย้ายที่อยู่ที่บันทึกไว้ไปยังที่อยู่นั้นและเชื่อมต่อใหม่ หากต้องการตั้งที่อยู่เอง ให้เลือก แก้ไขการเชื่อมต่อ จากเมนูของโปรเจกเตอร์

ไม่มีโปรเจกเตอร์อยู่ใกล้ตัว

โปรเจกเตอร์สาธิต

  • ลองใช้โหมดสาธิตจะเพิ่มโปรเจกเตอร์สาธิตที่จำลองบนอุปกรณ์เอง มีป้าย DEMO และข้อความ "จำลองบนอุปกรณ์นี้ ไม่มีฮาร์ดแวร์"
  • โปรเจกเตอร์สาธิตรายงานตัวเองเป็นรุ่นปี 2024 และมีช่วงวอร์มอัพและคูลดาวน์สั้นๆ การ์ดสถานะจึงทำงานเหมือนกับโปรเจกเตอร์จริง
  • ทุกอย่างปลดล็อกอยู่แล้วบนโปรเจกเตอร์สาธิต และไม่นับการกดปุ่มนำทาง
  • โปรเจกเตอร์สาธิตไม่เคยส่งอะไรไปยังทริกเกอร์อัตโนมัติ Hubitat หรือ Home Assistant และไม่เคยสแกนเครือข่าย
  • นำออกด้วย ปิดการสาธิต จากเมนูของโปรเจกเตอร์สาธิตหรือจากการตั้งค่า
