แดชบอร์ด Home Assistant

แดชบอร์ดโปรเจกเตอร์ใน Home Assistant

แตะครั้งเดียวก็สร้างแดชบอร์ดเต็มรูปแบบสำหรับโปรเจกเตอร์ JVC ของคุณใน Home Assistant: สถานะเปิดปิด สถานะ ตัวเลือกภาพ ฉากของคุณ อินพุต หน่วยความจำเลนส์ ค่าสัญญาณ และอื่นๆ แดชบอร์ดสร้างจากสิ่งที่ Home Assistant ของคุณมีอยู่จริง และไม่เก็บที่อยู่หรือรหัสผ่าน ต้องใช้แอดออน Home Automation

ก่อนส่ง

สิ่งที่ต้องมี

  • เชื่อมโยง Home Assistant แล้ว และเพิ่มโปรเจกเตอร์ในอินทิเกรชัน JVC Projector แล้ว ดูการตั้งค่า Home Assistant
  • ซิงค์สคริปต์แล้ว หากต้องการปุ่มฉาก สถานะเปิดปิด อินพุต หน่วยความจำเลนส์ และตัวควบคุม แดชบอร์ดใช้สคริปต์ที่มีอยู่
  • เปิดเซนเซอร์สถานะสด สำหรับไทล์สถานะและค่าที่อ่านได้
  • บัญชีผู้ดูแลระบบใน Home Assistant เพราะการสร้างแดชบอร์ดต้องใช้บัญชีนี้ หากไม่มี Home Assistant จะปฏิเสธและแอปจะแจ้งให้ทราบ
สองวิธี

ส่งหรือคัดลอก

  • ส่งแดชบอร์ดสร้างแดชบอร์ดใน Home Assistant ที่แถบด้านข้าง โดยตั้งชื่อตามชื่อโปรเจกเตอร์ของคุณและใช้ไอคอนโปรเจกเตอร์ ส่งอีกครั้งเพื่ออัปเดต การซิงค์กับ Home Assistant ก็ส่งแดชบอร์ดด้วยเช่นกัน
  • คัดลอกแดชบอร์ดไม่ส่งสิ่งใด แต่คัดลอกแดชบอร์ดเพื่อให้คุณวางลงในตัวแก้ไขการกำหนดค่าดิบของแดชบอร์ดใหม่เอง และแก้ไขได้ตามต้องการ
โปรเจกเตอร์แต่ละเครื่องมีแดชบอร์ดของตัวเอง ที่ที่อยู่ซึ่งขึ้นต้นด้วย projector-pilot-jvc- ดังนั้นโปรเจกเตอร์สองเครื่องจึงไม่เขียนทับกัน
เลย์เอาต์

มีอะไรบ้าง จากบนลงล่าง

ส่วนหนึ่งจะปรากฏก็ต่อเมื่อมีเนื้อหา ดังนั้นโปรเจกเตอร์ที่ไม่มีหน่วยความจำเลนส์จะไม่มีส่วนหน่วยความจำเลนส์

ส่วนประกอบด้วย
ส่วนหัวชื่อของโปรเจกเตอร์ เวลาที่อัปเดตสถานะล่าสุด สถานะเปิดปิด สถานะ และชั่วโมงแหล่งกำเนิดแสง
ภาพอินพุตและตัวเลือกภาพที่ Home Assistant เสนอสำหรับโปรเจกเตอร์ เช่น โหมดภาพ กำลังแสง การควบคุมแบบไดนามิก Clear Motion Drive อะนามอร์ฟิก การประมวลผล HDR และโหมดการติดตั้ง เมื่อรุ่นของคุณมีและเปิดใช้งานอยู่
ฉากหนึ่งปุ่มต่อสคริปต์ฉาก
สถานะเปิดปิดสคริปต์สถานะเปิดปิด
อินพุตสคริปต์อินพุต
หน่วยความจำเลนส์หนึ่งปุ่มต่อช่องหน่วยความจำเลนส์ที่รุ่นของคุณมี
ตัวควบคุมสคริปต์ควบคุมอื่นๆ เช่น โหมดภาพและซ่อน
สัญญาณความละเอียด ความลึกสี ปริภูมิสี โคลอริเมตรี และ HDR ตามที่ Home Assistant รายงาน
ค่าที่อ่านได้การตั้งค่าที่แอปอ่านได้ จากเซนเซอร์สถานะสด
รูปลักษณ์

การ์ดหลักหรือรูปลักษณ์แบบตกแต่ง

หลัก

สร้างจากการ์ดของ Home Assistant เองเท่านั้น ใช้ได้กับ Home Assistant ทุกระบบ ไม่ต้องติดตั้งอะไร

ตกแต่ง

ใช้การ์ด button-card, card-mod และ Mushroom จาก HACS เพื่อรูปลักษณ์ที่หรูหรากว่า ใช้ก็ต่อเมื่อมีครบทั้งสามอย่าง

หากขาดไปอย่างใดอย่างหนึ่งในสามอย่างนี้ แอปจะส่งเวอร์ชันหลักและบอกว่าต้องติดตั้งการ์ดใดจาก HACS เพื่อให้ได้รูปลักษณ์แบบตกแต่ง ติดตั้งแล้วส่งอีกครั้ง

ซื่อตรงโดยการออกแบบ

เหตุใดบางอย่างจึงไม่อยู่บนแดชบอร์ด

  • ไม่มีเกจ JVC ไม่ได้ให้ช่วงค่าของระดับที่ Home Assistant รายงาน แดชบอร์ดจึงไม่วาดเกจที่ต้องเดาเอง
  • ไม่มีที่อยู่หรือรหัสผ่าน แดชบอร์ดเก็บเฉพาะรหัสเอนทิตี ชื่อ และป้ายกำกับ
  • ไม่มีเอนทิตีที่แต่งขึ้น ไทล์จะปรากฏเฉพาะเอนทิตีหรือสคริปต์ที่มีอยู่จริงใน Home Assistant ของคุณ
หากเกิดปัญหา

ข้อความ

  • ส่งแดชบอร์ดแล้ว เปิดได้จากแถบด้านข้างของ Home Assistant
  • ถูกปฏิเสธ Home Assistant ปฏิเสธแดชบอร์ด: เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ แล้วส่งอีกครั้ง
  • ไม่ยอมรับการเข้าสู่ระบบ เข้าสู่ระบบอีกครั้ง แล้วส่งแดชบอร์ด
  • ไม่มีการตอบกลับ Home Assistant ไม่ตอบกลับ จึงยืนยันแดชบอร์ดไม่ได้ ตรวจสอบการเชื่อมต่อแล้วส่งอีกครั้ง
  • ไม่อนุญาต จะไม่มีสิ่งใดออกจากอุปกรณ์ขณะที่เลือกโปรเจกเตอร์สาธิตอยู่ หรือยังไม่ได้ปลดล็อก Home Automation
แดชบอร์ดควบคุมโปรเจกเตอร์ผ่านอินทิเกรชัน JVC Projector ของ Home Assistant ซึ่งเข้าถึงโปรเจกเตอร์ได้เฉพาะเมื่อแอปนี้ไม่ได้เชื่อมต่ออยู่ ปิดแอปก่อนใช้แดชบอร์ด
