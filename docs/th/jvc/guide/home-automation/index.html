เชื่อมต่อโปรเจกเตอร์ของคุณเข้ากับบ้าน

ให้ส่วนอื่นของบ้านตอบสนองเมื่อโปรเจกเตอร์เปิด เข้าสู่สแตนด์บาย เปลี่ยนอินพุต หรือเรียกใช้ฉาก มีลิงก์สามแบบอยู่ใต้ การตั้งค่า, Home Automation ได้แก่ ทริกเกอร์เว็บฮุก Hubitat และ Home Assistant ทั้งสามแบบต้องใช้แอดออน Home Automation ซึ่งขายแยกหรือในชุดรวม Pro อย่างเดียวไม่รวมแอดออนนี้

เลือกหนึ่งแบบ

ควรใช้ลิงก์ไหน

Webhooks

ระบบใดก็ได้ที่รับคำขอเว็บ: Node-RED เซิร์ฟเวอร์ในบ้าน ระบบอัตโนมัติบนคลาวด์ แอปเป็นฝ่ายส่ง คุณเป็นฝ่ายกำหนดว่าจะเกิดอะไรขึ้น

Hubitat

มิเรอร์ทางเดียวของสถานะเปิดปิดและอินพุตไปยังอุปกรณ์ในฮับของคุณ ผ่าน Maker API เพื่อให้ Rule Machine นำไปใช้งานต่อ

Home Assistant

ตั้งค่าอินทิเกรชัน JVC Projector ของ Home Assistant เอง สคริปต์สำหรับฉากของคุณ และแดชบอร์ดสำเร็จรูป

Webhooks

ทริกเกอร์อัตโนมัติ

ทริกเกอร์จะส่งคำขอเว็บไปยังที่อยู่ที่คุณป้อนเมื่อมีเหตุการณ์เกิดขึ้นกับโปรเจกเตอร์เครื่องนี้ โปรเจกเตอร์แต่ละเครื่องมีรายการของตัวเอง แตะ เพิ่มทริกเกอร์ แล้วเลือก:

  • เมื่อ: โปรเจกเตอร์เปิด โปรเจกเตอร์เข้าสู่สแตนด์บาย อินพุตเปลี่ยนแปลง (เป็นอินพุตใดก็ได้หรืออินพุตที่ระบุ) หรือ มีการเรียกใช้ฉาก (ฉากใดก็ได้หรือฉากที่ระบุ)
  • เมธอด: POST (ค่าเริ่มต้น) PUT หรือ GET
  • ที่อยู่เว็บ: ที่อยู่ http:// หรือ https:// ที่มีชื่อโฮสต์
  • เปิดใช้งาน เพื่อหยุดทริกเกอร์ชั่วคราวโดยไม่ต้องลบ
ที่อยู่ที่ขึ้นต้นด้วย http:// จะถูกส่งโดยไม่เข้ารหัส และตัวแก้ไขจะแจ้งให้ทราบ ใช้ https:// เมื่อระบบของคุณรองรับ
เพย์โหลด

สิ่งที่คำขอส่งไป

POST และ PUT ส่งเนื้อหา JSON ส่วน GET ไม่ส่ง เฮดเดอร์เดียวที่แอปเพิ่มคือ Content-Type ฟิลด์ที่ไม่เกี่ยวกับเหตุการณ์จะถูกละไว้

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
ช่องความหมาย
eventpower_on, power_off, input_changed หรือ scene_recalled
projectorชื่อของโปรเจกเตอร์ในแอป
inputอินพุต เช่น hdmi1 หรือ hdmi2
scene_id, scene_nameฉาก สำหรับการเรียกใช้ฉาก
timestampเวลาที่เกิดเหตุการณ์ ในเวลา UTC
testมีอยู่และเป็น true เฉพาะในคำขอที่ส่งจาก ส่งการทดสอบ
การส่งมอบ

ลองครั้งเดียว รายงานตามจริง

  • แต่ละเหตุการณ์ส่งเพียงครั้งเดียว โดยมีขีดจำกัด 10 วินาที และไม่ตามการเปลี่ยนเส้นทาง
  • ทริกเกอร์แสดงผลล่าสุด: ส่งแล้ว พร้อมเวลาและรหัสสถานะ ถูกปฏิเสธ ไม่มีการตอบกลับ เข้าถึงที่อยู่ไม่ได้ การเชื่อมต่อที่ปลอดภัยล้มเหลว หรือ ยังไม่ได้ส่ง
  • ส่งการทดสอบจะส่งคำขอที่ทำเครื่องหมายว่าเป็นการทดสอบ เพื่อให้คุณเชื่อมต่อปลายทางอีกฝั่งได้ก่อนที่โปรเจกเตอร์จะทำอะไร
ทริกเกอร์ทำงานเมื่อใด

กฎ

  • เฉพาะขณะที่แอปเปิดและเชื่อมต่อกับโปรเจกเตอร์อยู่ แอปเฝ้าดูสถานะของโปรเจกเตอร์ ไม่ใช่บริการเบื้องหลัง
  • การเปลี่ยนแปลง ไม่ใช่ค่าที่อ่านได้ ค่าที่อ่านครั้งแรกหลังแอปเชื่อมต่อใช้เป็นจุดเริ่มต้นเท่านั้น การเปิดแอปจึงไม่ทำให้เกิด "เปิด" สำหรับโปรเจกเตอร์ที่เปิดอยู่แล้ว
  • ไม่เคยจากโปรเจกเตอร์สาธิต จะไม่มีสิ่งใดออกจากอุปกรณ์ขณะที่เลือกโปรเจกเตอร์สาธิตอยู่ หรือยังไม่ได้ปลดล็อก Home Automation
  • บันทึกอย่างปลอดภัย ที่อยู่ของทริกเกอร์เก็บไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์
Hubitat

มิเรอร์โปรเจกเตอร์ไปยัง Hubitat

แอปมิเรอร์โปรเจกเตอร์เครื่องนี้ไปยังอุปกรณ์ในฮับ Hubitat ของคุณผ่าน Maker API ได้แก่ เปิดและสแตนด์บาย และอินพุตเป็น HDMI 1 หรือ HDMI 2 เท่าที่อุปกรณ์นั้นรับได้ จากนั้น Rule Machine จะนำไปใช้งานต่อได้

  1. ใน Hubitat ให้เพิ่ม Maker API และจดรหัสแอป (ตัวเลขใน URL ของแอป) และโทเคนการเข้าถึงไว้
  2. ในแอป ให้ป้อนที่อยู่ฮับ รหัสแอป Maker API และโทเคนการเข้าถึง
  3. แตะ ค้นหาอุปกรณ์ แล้วเลือกอุปกรณ์ที่แทนโปรเจกเตอร์เครื่องนี้ หากไม่มีอุปกรณ์ใดดูตรงกัน ให้เพิ่ม Virtual Switch ที่ตั้งชื่อตามโปรเจกเตอร์ใน Hubitat แล้วลองอีกครั้ง
  4. เปิด มิเรอร์สถานะของโปรเจกเตอร์ อุปกรณ์จะเปลี่ยนตามโปรเจกเตอร์ทุกครั้งที่สถานะเปลี่ยนขณะที่แอปเปิดและเชื่อมต่ออยู่
ทางเดียวเท่านั้น ไม่มีสิ่งใดถูกส่งจาก Hubitat ไปยังโปรเจกเตอร์ ยกเลิกการเชื่อมโยงจะลบการเชื่อมโยงออกจากแอป
Home Assistant

การเชื่อมโยงที่ลึกที่สุด

แอปเข้าสู่ระบบ Home Assistant เพิ่มโปรเจกเตอร์ของคุณลงในอินทิเกรชัน JVC Projector เผยแพร่ฉากและตัวควบคุมของคุณเป็นสคริปต์ และสร้างแดชบอร์ด มีหน้าของตัวเอง: การตั้งค่า Home Assistant และแดชบอร์ด Home Assistant
