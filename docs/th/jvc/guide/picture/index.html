ภาพ

เมนูภาพ

สามแท็บ: ภาพ สัญญาณ และการแสดงผล

หน้าภาพ

การตั้งค่าที่รุ่นของคุณระบุไว้

  • ภาพ: โหมดภาพ แกมมา อุณหภูมิสี โปรไฟล์สี และการตั้งค่าภาพอื่นๆ ที่รุ่นของคุณมี
  • สัญญาณ และการแสดงผล: ประเภทเนื้อหา ระดับ HDR การเคลื่อนไหว อัตราส่วนภาพ และการตั้งค่าที่เกี่ยวข้องสำหรับรุ่นของคุณ
  • แต่ละการตั้งค่ามาจากตารางคำสั่ง JVC ของรุ่นนั้น แต่ละรุ่นจึงเห็นเฉพาะสิ่งที่รองรับ
  • การตั้งค่าที่โปรเจกเตอร์ไม่รายงานกลับมาจะแสดงว่าส่งไปแล้ว ไม่ใช่อ่านค่ามา
การตั้งค่าภาพต้องใช้ Pro
