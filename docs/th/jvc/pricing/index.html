ฟรี

ฟรีหมายถึงอะไรจริงๆ

ฟรีไม่ใช่การทดลองใช้ที่หมดอายุ การเปิดปิดเครื่องและ HDMI 1 ใช้ได้ตลอดไป และปุ่มเมนูยังใช้ได้ทุกวัน

  • ฟรีเสมอ: การเปิดโปรเจกเตอร์และเข้าสู่สแตนด์บาย และการสลับไปที่ HDMI 1
  • ปุ่มที่นับ: ขึ้น ลง ซ้าย ขวา OK ย้อนกลับ และเมนู คุณได้ 20 ครั้งตลอดอายุของแอป จากนั้นวันละ 3 ครั้ง
  • วันเริ่มเมื่อเที่ยงคืนตามเวลาท้องถิ่นของคุณ หากคุณใช้ 20 ครั้งสุดท้ายหมดในวันนี้ 3 ครั้งของวันนี้ก็ยังใช้ได้ วันแรกจึงอาจถึง 23 ครั้ง
  • นับเฉพาะการกดที่ส่งออกไป การกดจะไม่ถูกนับเมื่อแอปไม่ได้เชื่อมต่อ บนโปรเจกเตอร์สาธิต หรือเมื่อคุณมี Pro แล้ว
Pro

สิ่งที่ Pro เพิ่มให้

รีโมตเต็มรูปแบบ

ทุกปุ่มรีโมตโดยไม่นับ ทุกอินพุต อัตราส่วนภาพ และซ่อน ดูรีโมต

ภาพ

โหมดภาพ ประเภทเนื้อหา HDR สี ISF การเคลื่อนไหว และการตั้งค่าภาพอื่นๆ ของรุ่นคุณ ดูภาพ

เลนส์และการติดตั้ง

การเลื่อนเลนส์ โฟกัส และซูม หน่วยความจำเลนส์ และโหมดการติดตั้ง ดูเลนส์

ฉาก

บันทึกลุคและเรียกกลับมาได้ในการแตะครั้งเดียว ดูฉาก

การบำรุงรักษา

ชั่วโมงแหล่งกำเนิดแสง อายุการใช้งานที่คาดการณ์ และการเตือน ดูการบำรุงรักษา

วิดเจ็ตและอื่นๆ

วิดเจ็ตหน้าจอหลักบน Android และ iOS ข้อมูลอุปกรณ์ เมนู การตั้งค่าการทำงาน และแพตเทิร์นทดสอบ

ตัวควบคุมแต่ละอย่างปรากฏในรุ่นที่รองรับ Pro ปลดล็อกสิ่งที่โปรเจกเตอร์ของคุณมี ไม่ได้เพิ่มฟังก์ชันที่รุ่นของคุณไม่มี

ระบบบ้านอัตโนมัติ

แอดออนแยกต่างหาก

Home Automation ขายแยก คุณจึงมีได้โดยไม่ต้องมี Pro และ Pro อย่างเดียวไม่รวมแอดออนนี้ ปลดล็อกทริกเกอร์เว็บฮุก มิเรอร์ Hubitat และการตั้งค่ากับแดชบอร์ด Home Assistant ดูระบบอัตโนมัติในบ้าน ชุดรวมมีทั้งสองอย่างในราคาที่ถูกกว่าซื้อแยก

ลองก่อน

โปรเจกเตอร์สาธิต

แตะลองใช้โหมดสาธิตเมื่อเปิดแอปครั้งแรกเพื่อลองทุกหน้า โดยปลดล็อกทุกอย่างและไม่ส่งสิ่งใดไปที่ไหน ไม่มีค่าใช้จ่ายและไม่ใช้การกดฟรี ดูเริ่มต้นใช้งาน

การซื้อของคุณ

การกู้คืนและอุปกรณ์ใหม่

  • การซื้อเป็นของบัญชีร้านค้าของคุณ บนอุปกรณ์ใหม่ที่เข้าสู่ระบบด้วยบัญชีเดียวกัน แตะกู้คืนบนการ์ด Pro ในการตั้งค่า
  • รีเฟรชจะตรวจสอบร้านค้าอีกครั้งหากการซื้อไม่ปรากฏทันที
  • รีเซ็ตข้อมูลแอปทั้งหมดจะไม่ลบการซื้อของคุณ ข้อมูลสำรองการตั้งค่าไม่เคยมีการซื้อ กู้คืนจะนำกลับมา
การติดตั้งใหม่

การนับฟรีหลังติดตั้งใหม่

Androidการนับเริ่มใหม่ เว้นแต่การสำรองข้อมูลของ Android จะกู้คืนข้อมูลของแอป
