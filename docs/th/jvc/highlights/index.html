โปรเจกเตอร์สาธิต

ลองใช้ทุกหน้าจอได้โดยไม่ต้องมีโปรเจกเตอร์ ทุกอย่างปลดล็อกอยู่

เร็วๆ นี้ Projector Pilot D-ILA กำลังจะมาบน Google Play, App Store และ Microsoft Store สำหรับ Android, iOS, macOS และ Windows ตอนนี้ยังไม่มีในร้านค้าใดเลย จึงยังไม่มีอะไรให้ดาวน์โหลดในวันนี้
การเชื่อมต่อ

ค้นหาโปรเจกเตอร์ของคุณ และบอกเหตุผลเมื่อค้นหาไม่พบ

  • การสแกนเครือข่ายของคุณจะพบโปรเจกเตอร์ JVC ที่ตอบบนพอร์ตควบคุม
  • เพิ่มด้วยที่อยู่ IP เมื่อการสแกนไม่พบ
  • การตั้งค่าแบบมีคำแนะนำตรวจสอบเครือข่าย พอร์ต และรหัสผ่านทีละข้อ และระบุข้อแรกที่ล้มเหลว พร้อมวิธีแก้ไข
  • เมื่อโปรเจกเตอร์ย้ายไปที่อยู่ใหม่ แอปจะค้นหาพบอีกครั้งด้วยที่อยู่ MAC
ตัวควบคุมที่ซื่อตรง

เฉพาะสิ่งที่รุ่นของคุณมี

แอปแสดงตัวควบคุมก็ต่อเมื่อตารางคำสั่งของรุ่นคุณระบุไว้ คุณจึงไม่เคยแตะการตั้งค่าที่โปรเจกเตอร์รับไม่ได้ การเปลี่ยนแปลงที่โปรเจกเตอร์ไม่ยอมรับจะรายงานว่าไม่ได้รับการยอมรับ ไม่ใช่แสดงว่าเสร็จแล้ว การตั้งค่า, เกี่ยวกับ, โปรเจกเตอร์ที่รองรับ แสดงทุกรุ่นที่แอปรู้จักและระดับที่แอปควบคุมได้

การใช้งานประจำวัน

รีโมต ภาพ และเลนส์

  • รีโมต: ปุ่มกดทิศทาง ปุ่มเมนู อินพุต อัตราส่วนภาพ และซ่อน ดูรีโมต
  • ภาพ: โหมดภาพ HDR สี การเคลื่อนไหว และการตั้งค่าภาพอื่นๆ ของรุ่นคุณ ดูภาพ
  • เลนส์: ขับการเลื่อน โฟกัส และซูมขณะกดค้าง และเรียกใช้หน่วยความจำเลนส์ ดูเลนส์
  • แดชบอร์ด: สถานะเปิดปิด อินพุต สถานะ และการดำเนินการด่วน ดูได้ในพริบตา ดูแดชบอร์ด
บ้านของคุณ

ระบบอัตโนมัติในบ้าน

ทริกเกอร์เว็บฮุกเมื่อโปรเจกเตอร์เปิด เข้าสู่สแตนด์บาย เปลี่ยนอินพุต หรือเรียกใช้ฉาก มิเรอร์ Hubitat ผ่าน Maker API และการตั้งค่า Home Assistant ที่เข้าสู่ระบบ เพิ่มโปรเจกเตอร์ลงในอินทิเกรชันของ Home Assistant เอง เผยแพร่ฉากของคุณเป็นสคริปต์ และสร้างแดชบอร์ด ดูระบบอัตโนมัติในบ้านและแดชบอร์ด Home Assistant

  • ธีมสว่าง มืด และ AMOLED พร้อมตัวเลือกสีเน้น
ความเป็นส่วนตัว

โปรเจกเตอร์ของคุณยังเป็นของคุณ

ไม่ต้องมีบัญชี รหัสผ่านของโปรเจกเตอร์เก็บอยู่ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์และไม่อยู่ในข้อมูลสำรอง การวิเคราะห์การใช้งานปิดอยู่จนกว่าคุณจะยอมรับ รายงานการวินิจฉัยจะละที่อยู่ พอร์ต ที่อยู่ MAC และรหัสผ่าน ดูหน้าความเป็นส่วนตัว
