ความเป็นส่วนตัว

สิ่งที่ Projector Pilot D-ILA ส่งและส่งไปที่ไหน นโยบายความเป็นส่วนตัวของ MiyaraHub Technologies ที่ miyarahub.com/privacy.html เป็นนโยบายฉบับเต็ม

ข้อมูล

สิ่งที่ออกจากอุปกรณ์ของคุณ

  • ไม่ต้องมีบัญชีและไม่มีโฆษณา
  • โปรเจกเตอร์ของคุณ: คำสั่งจะส่งไปยังโปรเจกเตอร์ในเครือข่ายภายในของคุณ
  • ร้านค้า สำหรับการซื้อและการกู้คืน
  • รายงานแครช (Firebase Crashlytics) เฉพาะบน Android และ iOS เปิดอยู่โดยค่าเริ่มต้น และมีสวิตช์ในการตั้งค่า เกี่ยวกับ ข้อความจะถูกลบที่อยู่ ชื่อโฮสต์ ที่อยู่ MAC URL และโทเค็นออก ส่วนสแตกเทรซมีตำแหน่งของโค้ด
  • การวิเคราะห์การใช้งาน (Firebase) ปิดอยู่จนกว่าคุณจะยอมรับ และไม่รวมชื่อ ที่อยู่ MAC หรือรหัสผ่านของโปรเจกเตอร์ของคุณ หรือ Home Assistant, Hubitat, โทเค็น หรือที่อยู่ทริกเกอร์ใดๆ เลย
  • เฉพาะเมื่อใช้ Home Automation และไม่เคยมาจากโปรเจกเตอร์สาธิต: คำขอไปยังที่อยู่ทริกเกอร์ที่คุณป้อน ไปยัง Hubitat และไปยัง Home Assistant
  • รหัสผ่านของโปรเจกเตอร์ เก็บไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์ เฉพาะบนอุปกรณ์เครื่องนี้เท่านั้น และไม่รวมอยู่ในข้อมูลสำรอง
