จุดเด่นของ Projector Pilot

จุดเด่นของ Projector Pilot สำหรับรุ่นใช้งานจริงรุ่นแรก จัดกลุ่มตามสิ่งที่คุณทำกับแอป ทุกบรรทัดที่นี่มีอยู่ในแอปแล้วในวันนี้ แอปพร้อมใช้งานบน Google Play ส่วนสโตร์อื่นรอการอนุมัติ

Home Assistant

Home Assistant ที่สร้างตัวเองและทำงานต่อเนื่อง

อ่านคู่มือ Home Assistant

  • ซิงค์กับ HA สร้างแดชบอร์ดทั้งหมดของคุณ ไม่ใช่แค่สคริปต์ คู่มือทีละขั้นตอนบนหน้าจอ Home Assistant แสดงขั้นตอนตั้งค่าเดียวที่ Home Assistant ยังให้คุณทำเอง
  • ทำงานร่วมกับการเชื่อมต่อที่คุณมีอยู่แล้ว รวมถึงการเชื่อมต่อ PJLink หลัก การ์ดจะถูกอัปเกรดเป็นการ์ด HACS ที่หรูกว่าเมื่อติดตั้งไว้
  • รายการตรวจสอบการตั้งค่าแสดงว่าขั้นตอนไหนเสร็จแล้ว ขั้นตอนไหนยังขาด และควรทำอะไรต่อ และตรวจสอบอีกครั้งบอกว่าพบอะไร
  • เซนเซอร์ค่าล่าสุดเก็บค่าที่อ่านได้ของคุณไว้ใน Home Assistant ขณะที่โปรเจกเตอร์ปิดอยู่ และการปิดเครื่องจะส่งถึง Home Assistant เป็นปิด
  • บล็อกคำสั่งบอกเมื่อมีรหัสผ่านโปรเจกเตอร์ และขั้นตอนเพิ่มการเชื่อมต่อแสดงโฮสต์และพอร์ต PJLink ไม่ได้ติดตั้งอะไรเลย? วางทุกอย่างด้วยมือ
  • ลบสคริปต์ที่ไม่มีเจ้าของแสดงรายการที่จะลบและถามก่อน
  • คัดลอกแดชบอร์ดสร้างบอร์ดสำหรับตัวควบคุมของโปรเจกเตอร์ของคุณเอง โดยติดป้ายชั่วโมงหลอดภาพหรือเลเซอร์ให้ตรงกัน
  • การเข้าสู่ระบบจากเบราว์เซอร์ในแอปสำเร็จได้ และใช้งานผ่าน HTTP ธรรมดาบนเครือข่ายของคุณเอง
การควบคุมประจำวัน

เร็วขึ้น นิ่งขึ้น และกดพลาดยากขึ้น

ดูคู่มือแดชบอร์ดและคู่มือเลนส์

  • ตัวสลับโปรเจกเตอร์ในแถบด้านบนของทุกหน้าโปรเจกเตอร์พาคุณสลับระหว่างโปรเจกเตอร์โดยไม่ต้องย้อนกลับไปที่รายการ
  • การปิดโปรเจกเตอร์จะถามก่อน
  • การเลื่อนเลนส์ โฟกัส ซูม และตัวปรับกำลังแสงตอบสนองทันทีที่กด โดยไม่กะพริบ หากกดซ้ำขณะที่ยังส่งคำสั่งก่อนหน้าอยู่ ระบบจะข้ามการกดนั้นแทนที่จะต่อคิว
  • แอปรับรู้ว่าโปรเจกเตอร์เปิดเครื่องภายในประมาณสิบวินาที และบอกว่ากำลังตรวจสอบ แทนที่จะแสดงสถานะปิดที่ไม่จริงเมื่อเปิดแอปใหม่
  • เวอร์ชันเฟิร์มแวร์แสดงบนแดชบอร์ดและแท็บข้อมูล และในรายงานการวินิจฉัย เมื่อใดก็ตามที่โปรเจกเตอร์รายงานค่านี้
  • ตัวเลือกขนาดสเต็ปในหน้าเลนส์ ตั้งแต่ละเอียดไปจนถึงหยาบ ตัวควบคุมเลนส์ไม่แสดงว่าล็อกอีกต่อไปเมื่อไม่ได้ล็อก
  • การสลับอินพุตทำงานได้บนโปรเจกเตอร์ที่แสดงรายการอินพุตผ่าน PJLink เท่านั้น เช่น TW7300 และ Home Cinema 4040 และบนโปรเจกเตอร์ PJLink ที่ไม่ใช่ Epson
  • ฉากปลุกโปรเจกเตอร์ในโหมดสแตนด์บายผ่าน PJLink และรอการตอบกลับก่อนขั้นตอนถัดไป การบันทึกฉากให้คุณติ๊กได้ว่าจะเก็บส่วนไหน
การเพิ่มโปรเจกเตอร์

ค้นหา เพิ่ม และดูมันเรียนรู้รุ่นของคุณ

  • เพิ่มโปรเจกเตอร์เริ่มต้นด้วยการสแกน Wi-Fi หรือเครือข่ายแบบสายหาสิ่งที่ตอบสนองเป็นโปรเจกเตอร์ และกรอกที่อยู่ให้ การพิมพ์ IP ก็ยังใช้ได้
  • แถบความคืบหน้าไล่ขึ้นจาก 0 ถึง 100 เปอร์เซ็นต์ขณะค้นหาความสามารถของรุ่นของคุณ โปรเจกเตอร์ถูกสแกนครั้งเดียวและจดจำไว้
  • โหมดสี ความสว่าง และคอนทราสต์แสดงค่าจริงทันทีหลังเพิ่ม
  • รู้จัก TW7300, Home Cinema 4040 และ 5050UB
ภาษาและแพลตฟอร์ม

29 ภาษา สี่แพลตฟอร์ม

  • ภาษาอังกฤษและอีก 28 ภาษา พร้อมการตั้งค่าภาษาและเลย์เอาต์จากขวาไปซ้ายสำหรับภาษาอาหรับและฮีบรู ข้อความขอสิทธิ์บน iPhone, iPad และ Mac ก็แสดงเป็นภาษาของคุณเช่นกัน ดูรายการภาษา
  • Android, iOS, Windows และ macOS
  • การแชร์บันทึก รายงาน ฉาก หรือไฟล์สำรองใช้งานได้บน iPad และไฟล์สำรองถูกแชร์ด้วยชื่อจริงของมัน
  • รายงานข้อบกพร่องรวมบันทึกที่เกี่ยวข้องทั้งหมดเป็นชุดเดียว พร้อมส่ง
ความเป็นส่วนตัวและรหัสผ่าน

ข้อมูลของคุณ คุณเป็นคนตัดสินใจ

  • การวิเคราะห์การใช้งานที่เป็นทางเลือกปิดไว้เป็นค่าเริ่มต้น แอปถามครั้งเดียว และคุณเปลี่ยนได้ทุกเมื่อในการตั้งค่า › ความเป็นส่วนตัว
  • รหัสผ่านสามรหัสของโปรเจกเตอร์ (Web Control, PJLink และรีโมต) ได้รับการยืนยันบนสายจริงกับโปรเจกเตอร์ตัวจริง และบรรทัดการวินิจฉัยไม่อ้างอีกต่อไปว่าโปรเจกเตอร์ไม่มีรหัสผ่านทั้งที่แค่ไม่จำเป็นต้องใช้
