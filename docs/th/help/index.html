ความช่วยเหลือ & FAQ ของ Projector Pilot

การเชื่อมต่อ

การเชื่อมต่อ

Projector Pilot คุยกับโปรเจกเตอร์ของคุณโดยตรงบนเครือข่ายของคุณ สามอย่างที่ทำให้เชื่อมต่อได้ และมีหนึ่งอย่างที่ทำให้คนส่วนใหญ่สะดุด

Wi-Fi เดียวกัน ซับเน็ตเดียวกัน

โทรศัพท์และโปรเจกเตอร์ต้องอยู่ในเครือข่ายและซับเน็ตเดียวกัน เครือข่ายสำหรับแขก VLAN ของอุปกรณ์ IoT และระบบเมชบางแบบแยกอุปกรณ์ออกจากกัน โปรเจกเตอร์ที่อยู่ใน SSID “IoT” จึงเข้าถึงจากโทรศัพท์ที่อยู่ในเครือข่ายหลักไม่ได้ ให้ต่อทั้งสองเข้ากับเครือข่ายเดียวกัน

เปิดใช้ PJLink และ Web Control บนโปรเจกเตอร์

ต้องเปิดการควบคุมผ่านเครือข่ายที่ตัวโปรเจกเตอร์ ในเมนูเครือข่ายของโปรเจกเตอร์ ให้เปิด PJLink และ Web Control (Epson เรียกอย่างหลังว่า web remote / Web Control) หากปิดการควบคุมผ่านเครือข่าย โปรเจกเตอร์ก็จะไม่ตอบสนองเลย

หาที่อยู่ IP ของโปรเจกเตอร์

แอปสแกนเครือข่ายหาโปรเจกเตอร์ และคุณยังเพิ่มด้วย IP ได้ด้วย หากต้องการหา IP ให้เปิดหน้าจอข้อมูลเครือข่ายในเมนูของโปรเจกเตอร์เอง ซึ่งแสดงที่อยู่ปัจจุบัน หากการสแกนไม่พบอะไร ให้เพิ่ม IP นั้นด้วยตนเอง

รหัสผ่านสามรหัสของโปรเจกเตอร์

โปรเจกเตอร์ Epson มีรหัสผ่านสามรหัสแยกกัน: Web Control, PJLink และรีโมต ไม่ใช่ช่องเดียวกัน และโปรเจกเตอร์อาจต้องการหนึ่งรหัส หลายรหัส หรือไม่ต้องการเลย ป้อนรหัสที่โปรเจกเตอร์ของคุณขอ แอปจะตรวจสอบว่าโปรเจกเตอร์ต้องการรหัสไหนจริงและเชื่อมต่อได้ไม่ว่าอย่างไร และการวินิจฉัยจะบอกว่าใช้เส้นทางใด หากโปรเจกเตอร์ตอบโดยไม่ต้องใช้รหัสผ่าน แอปจะบอกว่ารหัสผ่านที่บันทึกไว้ไม่จำเป็นที่นี่ แทนที่จะอ้างว่าไม่ได้ตั้งไว้

ความเข้ากันได้

โปรเจกเตอร์ที่รองรับ

  • โปรเจกเตอร์ Epson ผ่าน ESC/VP21 และ Web Control สองอย่างนี้ร่วมกันให้คุณควบคุมการเปิดปิด เมนูภาพแบบเต็ม รูปทรง และเลนส์มอเตอร์
  • โปรเจกเตอร์ PJLink ทุกเครื่อง เปิดปิด อินพุต และสถานะผ่านมาตรฐาน PJLink โปรเจกเตอร์ที่ไม่ใช่ Epson หรือ Epson ที่ใช้ PJLink อย่างเดียวจึงเป็นอุปกรณ์ที่รองรับตามปกติ
  • ใช้ช่องทางที่ตอบสนอง ไม่ใช่ช่องทางที่ตั้งค่าไว้ แอปเลือก ESC/VP21 ก่อน แล้ว PJLink แล้ว Web Control แต่จะถอยไปใช้ช่องทางใดก็ได้ที่โปรเจกเตอร์ตอบสนองจริง โปรเจกเตอร์ที่ไม่มี Web Control ยังใช้งานได้ผ่าน PJLink ค่าที่ช่องทางหนึ่งปฏิเสธจะถือว่าไม่ทราบ ไม่ใช่ไม่รองรับ
ไม่แน่ใจเรื่องรุ่นของคุณ? หน้าจอเกี่ยวกับของแอปแสดงรายการโปรเจกเตอร์ที่รองรับจากฐานข้อมูลรุ่น และบอกในแต่ละรุ่นว่าผ่านการยืนยันบนฮาร์ดแวร์หรือคาดการณ์ หากหน้าเว็บและการควบคุมผ่านเครือข่ายของโปรเจกเตอร์ใช้งานได้ Projector Pilot ก็ควรเข้าถึงได้เช่นกัน
การซื้อ & การกู้คืน

การซื้อ และการได้กลับคืนมา

เป็นการซื้อครั้งเดียวหรือไม่

ใช่ Pro ส่วนเสริม Home Automation และชุดรวมล้วนเป็นการซื้อครั้งเดียว ไม่มีค่าสมาชิก ไม่มีโฆษณา ไม่ต้องมีบัญชี ดูราคา

ฉันจะกู้คืนบนอุปกรณ์ใหม่ได้อย่างไร

เข้าสู่ระบบบัญชีสโตร์เดียวกับที่ซื้อ แล้วใช้กู้คืนการซื้อในแอป การซื้อครั้งเดียวปลดล็อกได้ทุกแพลตฟอร์มที่คุณมี ทั้ง Android, iOS, Windows และ macOS โดยผูกกับบัญชีสโตร์นั้น

ฉันมีอยู่แล้วแต่แอปแสดงข้อผิดพลาด

ไม่ควรเป็นเช่นนั้น และบิลด์ใหม่แก้เรื่องนี้โดยเฉพาะ หากสโตร์รายงานว่า Pro, Home Automation หรือชุดรวมเป็นของคุณอยู่แล้ว แอปจะให้สิทธิ์และรีเฟรชการซื้อของคุณเงียบๆ การซื้อหรือกู้คืนสิ่งที่คุณมีอยู่แล้วจึงปลดล็อกได้เสมอ

ทำไมราคาจึงต่างจากที่ฉันอ่านเจอทางออนไลน์

แอปแสดงราคาของสโตร์ในสกุลเงินของคุณก่อนยืนยัน ราคาแต่ละภูมิภาคต่างกัน และแอปไม่เคยถอยไปใช้ตัวเลขที่เขียนตายไว้ หากสโตร์ยังไม่ตอบกลับ แอปจะบอกตรงๆ แทนที่จะแต่งตัวเลขขึ้นมา

  • การวิเคราะห์ที่เป็นทางเลือก ต้องเลือกเปิดเอง การวิเคราะห์การใช้งานปิดไว้เป็นค่าเริ่มต้น แอปจะถามครั้งเดียวตอนเปิดครั้งแรก และคุณเปิดหรือปิดได้ทุกเมื่อในการตั้งค่า › เกี่ยวกับ จะไม่มีการเก็บหรือส่งอะไรเลยจนกว่าคุณจะเปิด
  • ไม่มีการขายข้อมูล ข้อมูลของคุณไม่ถูกขายให้ใคร จบ

คำตอบฉับไว

Projector Pilot หาหรือเชื่อมต่อโปรเจกเตอร์ของฉันไม่ได้

ตรวจสอบให้แน่ใจว่าโทรศัพท์และโปรเจกเตอร์อยู่ใน Wi-Fi และซับเน็ตเดียวกัน เครือข่ายสำหรับแขกและ VLAN ของอุปกรณ์ IoT อาจแยกอุปกรณ์ออกจากกัน บนโปรเจกเตอร์ ให้เปิดการควบคุมผ่านเครือข่าย (PJLink และ/หรือ Web Control) ในเมนูเครือข่าย หา IP ของโปรเจกเตอร์ได้ในหน้าจอข้อมูลเครือข่ายของมันเอง และเพิ่มด้วยตนเองหากการสแกนไม่พบ

Projector Pilot รองรับโปรเจกเตอร์รุ่นใดบ้าง

โปรเจกเตอร์ Epson ผ่าน ESC/VP21 และ Web Control และโปรเจกเตอร์ PJLink ทุกเครื่อง แอปใช้ช่องทางที่ตอบสนอง ไม่ใช่ช่องทางที่ตั้งค่าไว้ แอปจะใช้ช่องทางใดก็ได้ที่โปรเจกเตอร์ตอบสนอง โปรเจกเตอร์ที่ใช้ PJLink อย่างเดียวจึงเป็นอุปกรณ์ที่รองรับตามปกติ

Projector Pilot ต้องมีบัญชีหรือส่งข้อมูลของฉันขึ้นคลาวด์หรือไม่
