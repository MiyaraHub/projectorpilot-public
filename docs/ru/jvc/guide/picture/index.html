Изображение

Меню изображения

Три вкладки: «Изображение», «Сигнал» и «Экран».

Страница «Изображение»

Настройки, описанные для вашей модели

  • Изображение: режим изображения, гамма, цветовая температура, цветовой профиль и другие настройки изображения, которые есть у вашей модели.
  • Сигнал и Экран: тип контента, уровень HDR, движение, формат кадра и связанные настройки вашей модели.
  • Каждая настройка берётся из таблицы команд JVC для этой модели, поэтому модель видит только то, что поддерживает.
  • Настройка, которую проектор не передаёт обратно, показывается как отправленная, а не как считанная.
Для настроек изображения нужен Pro.
