Панель Home Assistant

Панель проектора в Home Assistant

Одно нажатие создаёт в Home Assistant полную панель для вашего проектора JVC: питание, статус, параметры изображения, ваши сцены, входы, память объектива, показания сигнала и многое другое. Она строится из того, что в вашем Home Assistant действительно есть, и не хранит ни адреса, ни пароля. Требуется дополнение «Автоматизация дома».

Перед отправкой

Что требуется

  • Home Assistant связан, проектор добавлен в интеграцию JVC Projector. См. Настройка Home Assistant.
  • Скрипты синхронизированы, если вам нужны кнопки сцен, питания, входов, памяти объектива и управления. Панель использует те скрипты, которые существуют.
  • Живой датчик состояния включён, для плиток статуса и показаний.
  • Учётная запись администратора в Home Assistant, потому что для создания панели она необходима. Без неё Home Assistant отказывает, и приложение сообщает об этом.
Два способа

Отправить или скопировать

  • Отправить панель создаёт панель в Home Assistant, в боковой панели, с названием вашего проектора и значком проектора. Отправьте её снова, чтобы обновить. Синхронизация с Home Assistant тоже её отправляет.
  • Копировать панель ничего не отправляет. Она копирует панель, чтобы вы могли сами вставить её в редактор исходной конфигурации новой панели и изменить как угодно.
У каждого проектора своя панель по адресу, который начинается с projector-pilot-jvc-, поэтому два проектора никогда не перезаписывают друг друга.
Компоновка

Что на ней, сверху вниз

Раздел появляется, только если в нём что-то есть, поэтому у проектора без памяти объектива нет раздела памяти объектива.

Вид

Базовые карточки или стилизованный вид

Базовый

Строится только из собственных карточек Home Assistant. Работает в любом Home Assistant, ничего устанавливать не нужно.

Стилизованный

Использует button-card, card-mod и карточки Mushroom из HACS для более богатого вида. Применяется, только когда присутствуют все три.

Если любой из трёх отсутствует, приложение отправляет базовую версию и сообщает, какие карточки установить из HACS для стилизованного вида. Установите их и отправьте панель снова.

Честно по замыслу

Почему некоторых элементов на ней нет

  • Никаких шкал. JVC не задаёт диапазон для уровней, которые сообщает Home Assistant, поэтому панель не рисует шкалу, диапазон которой пришлось бы угадывать.
  • Ни адреса, ни пароля. Панель содержит только идентификаторы сущностей, названия и подписи.
  • Никаких выдуманных сущностей. Плитка появляется только для сущности или скрипта, которые существуют в вашем Home Assistant.
Если что-то пошло не так

Сообщения

  • Панель отправлена. Откройте её из боковой панели Home Assistant.
  • Отказано. Home Assistant отказал в создании панели: войдите с учётной записью администратора и отправьте её снова.
  • Вход не принят. Войдите снова, затем отправьте панель.
  • Нет ответа. Home Assistant не ответил, поэтому отправка панели не подтверждена. Проверьте подключение и отправьте её снова.
  • Не разрешено. Ничто не покидает устройство, пока выбран демо-проектор или не разблокирована Автоматизация дома.
Панель управляет проектором через интеграцию JVC Projector в Home Assistant, которая может достучаться до проектора, только пока это приложение не подключено к нему. Закройте приложение, прежде чем пользоваться панелью.
