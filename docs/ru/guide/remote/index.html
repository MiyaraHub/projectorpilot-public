Пульт

Настоящий пульт проектора - без батареек

Вкладка «Пульт» содержит экранный пульт и рабочие элементы управления, разделённые на страницы, между которыми можно листать: Пульт, Работа, Устройство и Сеть. Всё, что открывает проектор, и ни одной кнопки, которой у него нет.

Страница «Пульт»

Навигация по меню проектора

  • Навигационный D-pad с центральной кнопкой выбора, а также Menu, Back, Home и Source - управляйте экранным меню проектора точно так же, как с обычного пульта.
  • Выбор входа - чтобы сразу перейти к нужному источнику.
  • Цветовой режим - чтобы переключать режим изображения с того же экрана.
  • Скрытие экрана - чтобы скрыть картинку. Питание находится на панели управления, а не здесь, так что элемент управления питанием один, а не три.
Скрытие экрана - это не A/V Mute. Скрытие экрана прячет изображение, пока проектор продолжает работать и сигнал продолжает поступать, поэтому картинка возвращается мгновенно. Используйте его для паузы, а не для выключения.
Страница «Работа» - геометрия

Исправьте форму изображения

Выберите метод коррекции, подходящий для вашей установки. Приложение показывает методы, которые поддерживает проектор, и одновременно активна только одна коррекция геометрии, как того требует оборудование.

МетодДля чего подходит
Выкл.Без коррекции - проектору, выставленному строго перпендикулярно экрану, она не нужна.
Гориз./верт. трапецияНезависимая горизонтальная и вертикальная трапеция для проектора, смещённого вверх/вниз или влево/вправо.
Быстрая коррекция угловПеретащите каждый из четырёх углов на место - повседневное решение для не совсем ровного изображения.
Точечная коррекцияСетка точек, которые смещаются по отдельности, для тонких локальных искажений.
Изогнутая поверхностьКомпенсация при проекции на изогнутый экран или стену.
Угол стеныКоррекция при проекции в угол комнаты, где сходятся две стены.
Каждое значение геометрии считывается с проектора после изменения, поэтому коррекция, которую проектор не применил, никогда не показывается как применённая.
Страница «Устройство» - пароли

Три пароля, а не один

У проектора Epson три отдельных пароля, и они защищают разное. Projector Pilot знает разницу, поэтому ввод ненужного пароля никогда не блокирует вам доступ к приложению.

ПарольЧто защищает
Web ControlВеб-интерфейс проектора и команды, которые через него идут, - в том числе перемещения объектива и считывание изображения на многих моделях. Именно этот пароль запрашивает собственная веб-страница проектора.
PJLinkПротокол PJLink (TCP 4352), который используют системы управления и который приложение применяет как запасной способ связи.
ПультКанал дистанционного управления ESC/VP.net (TCP 3629), предпочтительный способ связи приложения.
Прежде чем что-либо решать, приложение выясняет, нужен ли пароль вообще. Проектор, который отвечает без запроса, помечается как «пароль здесь не нужен», а не ошибочно как защищённый, - и приложение никогда не путает «не задан» с «задан, но для этого протокола не требуется». Если сохранённый пароль Web Control перестаёт работать, элементы управления объективом и изображением не отключаются с обвинением в адрес объектива: показывается подсказка с нажатием для исправления - обновить пароль.
Страница «Устройство» - блокировки

Блокировки, которые применяет проектор

Страница «Устройство» показывает собственные блокировки проектора. Если элемент управления недоступен, потому что проектор его заморозил, приложение сообщает, какая блокировка за это отвечает, вместо того чтобы молча отказать.

  • Блокировка объектива. Когда блокировка объектива проектора включена, сдвиг, фокус и зум удерживаются. Приложение сообщает об объективе как о заблокированном, только когда проектор действительно отклоняет команду - принятое перемещение, положение которого проектор не может подтвердить, не считается блокировкой, поэтому элементы управления остаются доступными.
  • Детский замок. Отключает кнопку питания на самом проекторе, чтобы ребёнок не мог его включить и смотреть на свет. Переключается отсюда.
  • Блокировка панели управления. Блокирует кнопки на корпусе проектора, так что управлять им можно только с пульта (и из приложения) - удобно в общественной или общей комнате.
Страница «Сеть»

Понятный режим только для чтения

Сетевые настройки находятся в проекторе, потому что приложение обращается к проектору по этой сети. Страница «Сеть» - простой режим только для чтения с адресацией проектора и пояснением причины: менять эти настройки нужно в собственном интерфейсе проектора, об этом написано в разделе «Начало работы».
