대시보드

프로젝터를 한눈에

대시보드에는 선택한 프로젝터의 연결 여부, 전원 상태, 현재 표시 중인 내용, 그리고 직접 고른 카드가 표시됩니다. 모든 정보는 추측이 아니라 프로젝터에서 직접 읽어 온 값입니다.

상태 카드

연결 및 전원

  • 이름과 모델. 프로젝터의 이름, 주소, 그리고 프로젝터가 보고한 모델입니다. 데모 프로젝터에는 DEMO 배지가 붙습니다.
  • 전원 표시. 프로젝터가 켜짐 또는 대기 상태를 보고한 뒤에 표시됩니다. 전원 제어는 모든 프로젝터에서 무료입니다.
  • 상태 라벨은 전원 상태를 아직 알 수 없을 때 표시됩니다. 연결 중, 연결 끊김, 연결할 수 없음, 비밀번호 문제, 네트워크 검색 중, 또는 전원: 대기, 전원: 예열 중 같은 전원 상태가 나타납니다.
  • 예열 및 냉각 중에는 진행 표시줄과 "예열 중..." 또는 "냉각 중..."이 표시됩니다. 앱은 이 동안 2초마다, 그 외에는 15초마다 프로젝터를 읽습니다.
전원

끄기 전에 먼저 확인합니다

프로젝터를 끄면 "프로젝터를 끌까요?"라고 묻고, 시청 중인 모든 사람의 화면이 꺼진다는 안내를 함께 표시합니다. 켤 때는 묻지 않습니다. 레이저 또는 램프 프로젝터는 대기 상태가 되기 전에 자체 냉각을 거치며, 카드가 그 과정을 그대로 따라갑니다.

카드

나만의 레이아웃

대시보드 맞춤 설정

  1. 상단 바에서 맞춤 설정을 누릅니다.
  2. 카드를 끌어서 옮기거나, 카드의 빼기 버튼을 눌러 제거합니다.
  3. 추가를 누르면 "카드 추가"에서 카드를 다시 불러올 수 있고, 초기화를 누르면 기본 레이아웃으로 돌아갑니다.
  4. 완료를 탭하세요.
레이아웃은 앱 전체에 적용되는 하나의 설정입니다. 따라서 모든 프로젝터가 같은 카드를 같은 순서로 보여 주며, 해당 모델이 지원하지 않는 카드만 빠집니다.
여러 대의 프로젝터

프로젝터 전환

  • 저장된 프로젝터가 둘 이상이면 이름 칩이 한 줄로 나타나며, 칩을 누르면 해당 프로젝터가 선택됩니다. 상단 바의 제목을 눌러도 프로젝터를 전환할 수 있습니다.
  • 프로젝터 추가 버튼으로 언제든 프로젝터를 더 추가할 수 있습니다.
  • 프로젝터 메뉴에는 이름 변경, 연결 정보 편집, 비밀번호 변경, 제거가 있습니다. 제거하면 이 기기에서 프로젝터와 저장된 비밀번호가 삭제됩니다. 데모 프로젝터의 메뉴에는 데모 종료 항목만 있습니다.
  • 아래로 당겨 새로고침합니다. 앱이 카드를 다시 읽고, 연결되어 있지 않으면 다시 연결합니다.
메시지

카드가 없을 때

대시보드가 비어 있으면 이유를 알려 주므로, 아무것도 없는 빈 화면으로 남지 않습니다.

  • 연결되지 않음: "이 프로젝터에 연결되어 있지 않아 컨트롤을 표시할 수 없습니다."
  • 대기: "프로젝터가 대기 상태입니다. 전원을 켜면 컨트롤이 나타납니다."
  • 예열 또는 냉각 중: 프로젝터가 안정되면 컨트롤이 다시 나타납니다.
  • 모든 카드를 제거함: 맞춤 설정에서 다시 불러올 수 있습니다.
  • 잘못된 비밀번호: "프로젝터가 네트워크 비밀번호를 거부했습니다. 눌러서 다시 입력하세요."
  • 오프라인: "이 주소의 포트 20554에서 응답이 없습니다."처럼 실패 원인을 쉬운 말로 알려 줍니다. 각 원인은 도움말 페이지에서 설명합니다.
홈 화면

위젯

Android와 iOS에서 Pro를 사용하면 위젯 다섯 가지로 프로젝터를 홈 화면에 둘 수 있습니다. 위젯은 각각 프로젝터 한 대에 맞춰 설정합니다.

프로젝터 빠른 제어

전원, 입력, 픽처 모드, 숨기기.

프로젝터 상태

전원, 연결, 광원 사용 시간.

프로젝터 장면

한 번 누르면 저장된 장면이 적용됩니다.

프로젝터 정보

전원, 입력, 픽처 모드, 광원.

프로젝터 입력

한 번 누르면 입력이 전환됩니다.

위젯은 프로젝터와 직접 통신하지 않습니다. 위젯을 누르면 앱이 열리고, 앱이 대시보드와 동일한 검사를 거쳐 명령을 보냅니다. 앱이 30초 안에 연결하지 못하면 해당 입력은 버려집니다. 위젯에는 주소나 비밀번호가 저장되지 않습니다.
