유지관리

유지관리 및 인사이트

광원이 얼마나 오래 사용되었는지 확인하세요. 유지관리 화면은 프로젝터에서 사용 시간을 읽고, 직접 입력한 수치로 예상 수명과 운영 비용을 계산하며, 정격 수명이 가까워지면 알려 줄 수도 있습니다. Pro에 포함되며 설정, 유지관리 및 인사이트에 있습니다.

사용 시간

읽기 전용, 프로젝터에서 가져옴

  • 광원 사용 시간. 프로젝터에서 읽은 레이저 또는 램프의 총 가동 시간입니다. 라벨은 모델이 보고하는 광원에 따라 달라집니다.
  • 추가한 이후. 아래에서 기준값을 설정하면, 이 프로젝터를 설치한 것으로 표시한 이후의 사용 시간이 나타납니다.
  • 아직 사용 시간이 없나요? 앱이 읽을 수 있도록 프로젝터를 연결하고 전원을 켜세요.
이 화면의 어떤 내용도 프로젝터에 다시 쓰이지 않습니다. 앱은 프로젝터 자체의 사용 시간 값을 초기화하거나 바꾸지 않습니다.
인사이트

예상 수명 및 시간당 비용

앱은 어떤 모델의 정격 수명도 알지 못하므로 임의로 만들어 내지 않습니다. 프로젝터 설명서나 판매처에서 확인한 수치를 입력하면 인사이트가 채워집니다.

인사이트입력하는 값표시 내용
예상 수명정격 수명(시간 단위). 예: 20000.정격 수명 중 남은 시간과 사용 비율입니다.
시간당 비용교체용 광원 또는 유닛의 비용입니다. 예: 3500.운영 시간당 비용입니다. 통화 기호는 붙지 않으므로 어떤 통화로도 사용할 수 있습니다.
설치 기준값지금 표시를 누르거나 사용 시간을 직접 편집합니다. 지우기를 누르면 제거됩니다.위에 표시되는 추가한 이후 수치입니다.
알림

유지관리 알림

알림은 직접 켜기 전에는 꺼져 있습니다. 유지관리 알림을 켠 다음 광원 수명 경고를 켜세요.

  • 시점. 입력한 정격 수명의 90%에 도달했을 때 알리고, 이후 100시간마다 알립니다.
  • 방식. 제목이 광원 사용 시간인 알림이 표시됩니다. 확인은 앱이 열려 있고 프로젝터에 연결된 동안 실행됩니다.
  • 필요 조건. 인사이트에 정격 수명이 입력되어 있고 알림 권한이 허용되어 있어야 합니다. 시스템이 알림을 거부하면 허용하기 전까지 알림이 꺼진 상태로 유지됩니다.
  • 지원 플랫폼. Android, iOS, macOS. Windows에서는 알림을 지원하지 않습니다.
알림 문구는 앱 언어 설정과 관계없이 영어로 표시됩니다.
기록

사용 시간 리포트 내보내기

사용 시간 리포트 내보내기는 작은 텍스트 파일을 저장합니다. 파일에는 앱 버전, 모델, 앱이 읽은 광원 사용 시간, 시각, SHA-256 체크섬이 들어 있습니다.

이 파일은 앱이 그 시점에 읽은 값의 스냅샷으로, 프로젝터 사용 기록으로 쓰기에 편리합니다. 앱이 스스로 증명한 값이며 JVC가 인증한 것은 아닙니다.

내 데이터

수치가 저장되는 위치

  • 정격 수명, 단가, 기준값은 이 기기에 저장됩니다.
  • 백업 및 복원에는 포함되지 않습니다.
  • 사용 시간 자체는 항상 프로젝터에서 가져오므로, 어떤 기기에서 연결하더라도 정확합니다.
  • 대시보드의 광원 사용 시간 칩과 프로젝터 상태 위젯은 같은 값을 표시합니다. 대시보드를 참고하세요.
예시

계산 예시

프로젝터가 4000시간 사용되었고, 정격 수명으로 20000시간, 교체 비용으로 3500을 입력했다고 가정해 보겠습니다.

수치결과계산 방법
남은 시간16000정격 수명에서 사용한 시간을 뺀 값입니다.
수명 사용률20%사용한 시간을 정격 수명으로 나눈 값입니다.
시간당 비용0.875교체 비용을 지금까지 사용한 시간으로 나눈 값입니다.
첫 알림18000시간에정격 수명의 90%에 알리고, 이후 100시간마다 알립니다.

같은 비용이 더 많은 시간에 나뉘므로, 광원을 오래 사용할수록 시간당 비용은 줄어듭니다.

첫 화면에서 보는 사용 시간

사용 시간을 보려고 이 화면을 열 필요는 없습니다. 대시보드의 광원 사용 시간 칩과 프로젝터 상태 위젯이 프로젝터가 보고하는 것과 같은 값을 보여 줍니다. 대시보드를 참고하세요.

질문

유지관리 관련 질문

앱이 정격 수명을 대신 채워 주지 않는 이유는 무엇인가요?

앱은 어떤 모델의 정격 수명도 알지 못하며 임의로 만들어 내지 않습니다. 프로젝터 설명서나 판매처에서 확인한 수치를 입력하세요.

앱에서 프로젝터의 사용 시간을 초기화할 수 있나요?

아니요. 이 화면의 어떤 내용도 프로젝터에 쓰이지 않습니다. 설치 기준값은 사용자가 정한 날짜부터의 사용 시간을 세는 앱 자체의 방법입니다.

Windows에서도 알림이 동작하나요?

아니요. 알림은 Android, iOS, macOS에서 앱이 열려 있고 프로젝터에 연결된 동안에만 동작합니다.
