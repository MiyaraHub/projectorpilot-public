Home Assistant

Home Assistant에서 JVC 프로젝터 설정하기

앱이 Home Assistant에 로그인하여 프로젝터를 Home Assistant 자체 JVC Projector 통합구성요소에 추가하고, 장면과 컨트롤을 스크립트로 게시하며, 대시보드까지 만들어 줍니다. 토큰을 붙여넣거나 YAML을 작성할 필요가 없습니다. Home Automation 애드온이 필요합니다.

먼저 읽어 보세요

한 번에 컨트롤러 하나

JVC 프로젝터는 한 번에 하나의 네트워크 컨트롤러만 지원합니다. 이 앱이 열려 있고 프로젝터에 연결되어 있는 동안에는 Home Assistant가 프로젝터에 접근할 수 없습니다. 앱을 닫아 두면 Home Assistant의 프로젝터 컨트롤과 스크립트가 동작하며, 앱은 백그라운드로 이동할 때 프로젝터 연결을 해제합니다.

1단계

로그인

  1. 설정, Home Automation, Home Assistant를 엽니다.
  2. Home Assistant 주소를 http:// 또는 https://로 시작하게 입력합니다.
  3. 로그인을 누릅니다. 브라우저에서 Home Assistant 자체 로그인 페이지가 열립니다. 그곳에서 로그인한 후 앱으로 돌아오세요.
  4. 연결 테스트를 눌러 확인합니다.
Home Assistant에 연결할 수 없으면 주소를 확인하고, 이 기기가 Home Assistant와 같은 네트워크에 있는지도 확인하세요.
2단계

Home Assistant에 있는 항목

패널이 Home Assistant를 읽어 각 항목을 찾음, 설치되지 않음, 확인할 수 없음으로 표시합니다. 다시 확인을 누르면 다시 읽습니다.

항목필요한 이유
Mobile App 통합구성요소실시간 상태 센서.
JVC Projector 통합구성요소Home Assistant에서 이 프로젝터를 제어합니다.
HACS대시보드의 스타일 디자인에만 필요합니다.
3단계

설정 체크리스트

  1. Home Assistant에 로그인합니다.
  2. 이 프로젝터를 Home Assistant의 JVC Projector 통합구성요소에 추가합니다. 추가를 누르세요. 앱이 먼저 사용자에게 확인한 뒤, 프로젝터의 주소, 포트, 네트워크 비밀번호를 Home Assistant의 JVC Projector 통합구성요소로 보냅니다.
  3. 스크립트에 필요한 엔티티를 사용 설정합니다. 일부 JVC Projector 엔티티는 Home Assistant에서 사용 안 함 상태로 시작합니다. 각 엔티티 옆의 사용을 누르세요. 엔티티가 나타나기 전에 Home Assistant를 다시 불러오거나 재시작해야 할 수도 있습니다.
  4. 실시간 상태 센서. 프로젝터 상태 전송을 켭니다. 센서는 앱이 연결된 상태에서 다음번에 프로젝터 상태를 보낼 때 만들어집니다.
비밀번호에 관해. 프로젝터를 추가하면 프로젝터의 네트워크 비밀번호가 사용자의 Home Assistant로 전송되어 JVC Projector 항목에 저장됩니다. 앱은 그 외의 어떤 곳으로도 비밀번호를 보내지 않습니다. Home Assistant가 프로젝터에 연결하는 동안 앱은 프로젝터 연결을 해제했다가 이후 다시 연결합니다.
어떤 항목인가요?

앱이 Home Assistant에서 프로젝터를 찾는 방법

앱은 프로젝터의 MAC 주소로 JVC Projector 항목을 찾아 맞춥니다. 그래서 먼저 프로젝터에 한 번 이상 연결해야 합니다. 해당 MAC 주소를 가진 항목이 Home Assistant에 없거나 둘 이상이면, 체크리스트가 그 사실과 해결 방법을 알려 줍니다. 프로젝터 주소가 바뀐 경우에는 앱이 새 주소를 Home Assistant로 보내도록 제안합니다.

센서

실시간 상태

센서의 상태 값은 앱이 마지막으로 읽은 전원 상태이고, 속성은 입력, 모델, 앱이 읽은 설정입니다. 센서는 Mobile App 통합구성요소를 거치며 프로젝터에는 아무것도 보내지 않습니다. 앱이 열려 있고 연결된 상태에서 값이 바뀔 때마다 갱신됩니다.

스크립트

장면 및 컨트롤

저장된 각 장면은 JVC Projector 엔티티를 통해 실행되는 Home Assistant 스크립트가 됩니다. 스크립트에는 주소도 비밀번호도 들어 있지 않습니다. 스크립트 ID는 ppjvc로 시작합니다.

  • HA와 동기화는 장면을 스크립트로 작성하고, 각 스크립트의 단계 수와 제외된 항목 및 그 이유를 표시합니다.
  • 고급 컨트롤 동기화는 전원, 입력, 픽처 모드, 렌즈 메모리, 숨기기용 스크립트를 게시합니다.
  • 결과는 동기화된 스크립트 수, Home Assistant가 거부한 수, 스크립트 다시 불러오기를 확인했는지 여부로 집계됩니다.
  • 고아 스크립트 제거는 앱이 만들었지만 더 이상 어떤 장면도 사용하지 않는 스크립트를 삭제합니다. 삭제 전에 목록을 보여 주고 먼저 확인을 요청합니다.
동기화에 필요한 항목 중 읽지 못한 것이 있으면 아무것도 쓰거나 변경하거나 삭제하지 않습니다. 동기화는 추측에 의존해 절반만 실행되는 일이 없습니다.
대시보드

바로 쓸 수 있는 대시보드

대시보드 전송은 JVC Projector 엔티티, 스크립트, 센서를 이용해 Home Assistant에 프로젝터 대시보드를 만듭니다. 대시보드 복사는 대신 대시보드를 복사하므로 새 대시보드에 직접 붙여넣을 수 있습니다. 대시보드에 관한 모든 내용은 Home Assistant 대시보드 페이지에 있습니다.

규칙

앱이 절대 하지 않는 일

  • 데모 프로젝터를 선택했거나 Home Automation이 잠금 해제되지 않은 상태에서는 기기 밖으로 아무것도 전송되지 않습니다.
  • 연동 해제는 이 앱에서만 연결을 제거합니다. 프로젝터의 기기와 엔티티는 Home Assistant에서 직접 삭제하기 전까지 그대로 남아 있습니다.
  • Home Assistant가 로그인을 더 이상 받아 주지 않으면 앱이 그 사실을 알리고 다시 로그인하라고 안내합니다.
