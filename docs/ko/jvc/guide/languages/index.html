지원 언어

29개 언어, 원하는 대로 선택

Projector Pilot D-ILA는 29개 언어를 지원합니다. 기본적으로 기기의 언어를 따르며, 기기의 나머지 설정은 그대로 두고 언제든 다른 언어를 선택할 수 있습니다.

언어 변경

언어 선택

  1. 설정을 연 다음 언어를 선택합니다.
  2. 기기 언어를 따르려면 시스템 기본값을 선택하고, 아니면 언어를 직접 고릅니다. 각 언어는 해당 언어 자체의 이름으로 표시되므로, 앱이 읽을 수 없는 언어로 되어 있어도 원하는 언어를 찾을 수 있습니다.
  3. 앱은 즉시 전환됩니다. 재시작도, 다운로드도 필요 없습니다.
직접 고른 언어는 다시 바꿀 때까지 유지되며, 나중에 기기 언어를 바꿔도 그대로입니다. 다시 기기 언어를 따르려면 시스템 기본값을 선택하세요.

오른쪽에서 왼쪽

아랍어와 히브리어

아랍어와 히브리어에서는 앱 전체가 오른쪽에서 왼쪽으로 배치됩니다. 탐색, 목록, 텍스트가 모두 읽는 방향으로 흐릅니다. 렌즈 패드만 예외입니다. 앱의 언어와 관계없이 왼쪽으로 시프트하면 화면이 왼쪽으로 움직여야 하므로, 렌즈 패드는 왼쪽에서 오른쪽 방향을 유지합니다.

그대로 유지되는 것

번역되지 않는 항목

  • 사용자가 정한 이름. 프로젝터 이름과 장면 이름은 사용자의 것이므로 입력한 그대로 유지됩니다.
  • 유지관리 알림은 항상 영어로 표시됩니다.
  • 프로젝터 자체의 화면 메뉴에는 별도의 언어 설정이 있습니다. 지원하는 모델에서는 화질의 디스플레이 페이지에 있는 언어 설정으로 바꿀 수 있으며, 앱 언어를 바꿔도 프로젝터 메뉴 언어는 바뀌지 않습니다.
질문

언어 관련 질문

언어가 프로젝터의 기능에 영향을 주나요?

아니요. 무료든 유료든 모든 기능은 어떤 언어에서나 동일합니다. 바뀌는 것은 표시되는 단어뿐입니다.

앱과 휴대폰에서 서로 다른 언어를 쓸 수 있나요?

네. 설정, 언어에서 언어를 고르면 앱만 바뀝니다. 기기의 나머지 부분은 원래 언어를 유지합니다.

선택한 언어가 백업에 포함되나요?

백업 및 복원은 앱 설정을 다룹니다. 백업에 포함되는 항목과 절대 포함되지 않는 항목은 설정에서 확인하세요.

이 웹사이트

내 언어로 보는 가이드

이 웹사이트도 같은 언어로 제공됩니다. 아무 페이지나 열고 상단의 언어 메뉴에서 전환하세요.

프로젝터에서

프로젝터 자체 메뉴

프로젝터가 화면에 표시하는 메뉴에는 프로젝터에서 설정하는 별도의 언어가 있습니다. 지원하는 모델에서는 화질의 디스플레이 페이지에 있는 언어 설정으로 앱에서 바꿀 수 있습니다. 앱 언어를 바꿔도 프로젝터는 바뀌지 않으며, 프로젝터의 메뉴 언어를 바꿔도 앱은 바뀌지 않습니다.

도와주세요

잘못된 표현을 발견하셨나요?

사용 중인 언어에서 어색한 표현이 있다면 설정의 피드백 보내기 또는 버그 신고, 혹은 Discord로 알려 주세요. 어떤 언어의 어떤 화면인지, 그리고 어떻게 표시되어야 하는지도 함께 적어 주세요.
