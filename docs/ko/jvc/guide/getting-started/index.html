시작하기

프로젝터 추가

앱은 사용자의 네트워크에서 JVC D-ILA 프로젝터를 찾아 TCP 포트 20554로 직접 통신합니다. 설정에는 네트워크 검색 또는 IP 주소가 필요하며, 프로젝터에 네트워크 비밀번호가 있다면 그것도 필요합니다.

처음 실행

시작 화면

  1. Projector Pilot D-ILA에 오신 것을 환영합니다. 무료로 쓸 수 있는 기능, Pro에서 추가되는 기능, 도움을 받을 수 있는 곳(Discord 참여하기, 로그 이메일로 보내기)을 짧게 소개합니다.
  2. 분석. 앱이 익명 사용 분석 데이터를 보내도 되는지 묻습니다. 동의하지 않으면 꺼져 있으며, 나중에 설정, 정보에서 바꿀 수 있습니다.
  3. 시작하기 전에. 체크리스트입니다. 휴대폰과 프로젝터가 같은 로컬 네트워크에 있어야 하고, 프로젝터가 LAN 포트로 연결되어 있어야 하며(네트워크 비밀번호가 있다면 그것도 필요), 프로젝터의 IP 주소는 프로젝터의 네트워크 설정에서 확인할 수 있습니다.
  4. 프로젝터 추가. 네트워크 검색, IP로 프로젝터 추가, 데모 모드 체험 중에서 선택합니다.
방법 1

네트워크 검색

  • 검색 범위. 기기가 연결된 각 사설 주소 대역에서, 해당 /24 서브넷의 1번부터 254번 주소를 포트 20554로 검색합니다.
  • 판단 방식. JVC 프로젝터는 새 연결에 인사 메시지를 보냅니다. 검색은 이 메시지를 보내는 기기를 사용 가능 또는 다른 컨트롤러가 사용 중으로 나열합니다. 진행 상황에는 전체 주소 중 몇 개를 확인했는지가 표시됩니다.
  • 응답이 없을 때. "이 네트워크에서 응답한 JVC 프로젝터가 없습니다."라고 표시됩니다. Home Assistant 같은 다른 컨트롤러가 이미 연결되어 있는 프로젝터는 검색에 응답하지 않으므로, 그 프로젝터는 주소로 직접 추가하세요.
  • Wi-Fi 없음. 기기에 로컬 네트워크가 없으면 "로컬 네트워크를 찾을 수 없습니다. Wi-Fi에 연결한 후 다시 검색하세요."라고 표시됩니다.
방법 2

IP 주소로 추가

검색에서 프로젝터가 발견되지 않거나, 프로젝터가 기기에서 접근할 수 있는 다른 서브넷에 있을 때 사용하세요.

  1. 프로젝터에 이름을 붙입니다. 예를 들어 설치된 방 이름을 사용할 수 있습니다.
  2. IP 주소: 프로젝터의 네트워크 메뉴에서 확인한 프로젝터의 IPv4 주소입니다. 호스트 이름은 사용할 수 없습니다.
  3. 네트워크 비밀번호: 프로젝터에 설정된 비밀번호입니다. 프로젝터에 네트워크 비밀번호가 없다면 비워 두세요.
  4. 연결 테스트. 테스트에 성공하면 "연결되었습니다"와 프로젝터가 보고한 모델이 표시됩니다.
  5. 저장. 프로젝터가 대시보드에 나타납니다. 같은 프로젝터를 두 번 저장하려고 하면 "이미 저장된 프로젝터입니다."라며 거부됩니다.
추가 화면은 표준 포트 20554를 사용합니다. 다른 포트를 사용하려면 아래의 단계별 설정을 실행하세요. 제어 포트 필드의 값이 추가 화면으로 전달됩니다.
방법 3

단계별 설정 및 진단

"연결에 문제가 있나요? 단계별 진단 실행"을 누르면 프로젝터 설정이 열립니다. 프로젝터 IP 주소와 제어 포트(변경하지 않았다면 20554)를 입력한 다음 연결 진단을 누르세요.

검사확인하는 내용
프로젝터와 같은 네트워크기기와 프로젝터가 같은 서브넷을 사용하므로 서로를 볼 수 있습니다.
제어 포트 연결 가능제어 포트에서 연결을 받아 주는 대상이 있습니다.
프로젝터 핸드셰이크 및 비밀번호JVC 프로젝터처럼 응답하며, 비밀번호가 있다면 그 비밀번호가 받아들여집니다.

세 가지가 모두 통과하면 결과는 "연결이 정상입니다"이고, 이 프로젝터 추가 버튼이 나타납니다. 하나라도 실패하면 화면에 해당 항목이 표시되고 "현재 상태"와 "해결 방법"이 함께 나타납니다. 프로젝터가 비밀번호를 요구하면 네트워크 비밀번호 필드와 비밀번호로 시도 버튼이 그 자리에 나타납니다. 각 진단 결과는 도움말 페이지에 정리되어 있습니다.

비밀번호

네트워크 비밀번호

  • 어떤 비밀번호인가요? 프로젝터의 네트워크 메뉴에 설정한 네트워크 비밀번호입니다. 앱에는 자체 계정이 없습니다.
  • 2024년 및 2025년 모델은 8~10자의 비밀번호를 사용하며, 앱은 전송하기 전에 길이를 확인합니다. SHA-256 형식을 먼저 시도하고, 그다음 일반 형식을 시도합니다.
  • 2018년 및 2021년 모델은 프로젝터가 요구할 때만 비밀번호를 보냅니다. 그보다 이전 모델에는 비밀번호를 보내지 않습니다.
  • 저장 위치. 이 기기의 보안 저장소에만 저장되며 백업에는 포함되지 않습니다.
  • 변경 방법. 대시보드에서 프로젝터 메뉴를 열고 비밀번호 변경을 선택하세요.
컨트롤러 하나

한 번에 앱 하나만

JVC 프로젝터는 한 번에 하나의 네트워크 컨트롤러만 지원합니다. Projector Pilot D-ILA가 연결되어 있는 동안에는 Home Assistant, 제어 시스템, 다른 휴대폰이 프로젝터에 접근할 수 없으며, 반대의 경우도 마찬가지입니다.

  • 2024년 및 2025년 모델은 연결을 계속 유지하고, 이전 모델은 명령마다 연결합니다.
  • 앱이 백그라운드로 이동하면 프로젝터 연결을 해제하므로, 다른 컨트롤러가 이어받을 수 있습니다.
  • 연결이 끊어지면 3초, 5초, 8초, 그다음부터는 10초 간격으로 다시 시도하며, 네트워크가 복구되면 즉시 시도합니다. 비밀번호가 틀린 경우에는 다시 시도하지 않습니다.
새 주소

프로젝터 주소가 바뀌었을 때

앱은 프로젝터에 연결할 때 프로젝터의 MAC 주소를 기억합니다. 연속 세 번 연결했는데 아무것도 응답하지 않으면 상태가 "네트워크 검색 중"으로 표시되고, 앱이 서브넷 전체에서 해당 MAC 주소를 최대 세 번 찾습니다. 일치하는 프로젝터가 정확히 하나일 때는 저장된 주소를 그쪽으로 옮기고 다시 연결합니다. 주소를 직접 설정하려면 프로젝터 메뉴에서 연결 정보 편집을 선택하세요.

프로젝터가 없다면

데모 프로젝터

  • 데모 모드 체험은 기기 자체에서 시뮬레이션되는 데모 프로젝터를 추가합니다. DEMO와 "이 기기에서 시뮬레이션됨, 하드웨어 없음"이라는 표시가 붙습니다.
  • 2024년 모델로 보고하며 짧은 예열 및 냉각 시간을 거치므로, 상태 카드가 실제 프로젝터와 똑같이 동작합니다.
  • 모든 기능이 잠금 해제되어 있고 방향 키 누름 횟수도 집계되지 않습니다.
  • 자동화 트리거, Hubitat, Home Assistant로는 아무것도 전송하지 않으며 네트워크를 검색하지도 않습니다.
  • 프로젝터 메뉴 또는 설정에서 데모 종료를 눌러 제거하세요.
