홈 오토메이션

프로젝터를 스마트홈에 연결하기

프로젝터가 켜지거나, 대기 상태가 되거나, 입력이 바뀌거나, 장면을 불러올 때 집 안의 다른 기기가 반응하게 하세요. 설정, Home Automation 아래에 웹훅 트리거, Hubitat, Home Assistant 세 가지 연결이 있습니다. 세 가지 모두 Home Automation 애드온이 필요하며, 애드온은 단독으로 또는 번들로 판매됩니다. Pro만으로는 포함되지 않습니다.

하나를 선택하세요

어떤 연결을 쓸까요

웹훅

웹 요청을 받을 수 있는 모든 시스템(Node-RED, 홈 서버, 클라우드 자동화)에 사용할 수 있습니다. 앱은 보내기만 하고, 그다음 동작은 사용자가 정합니다.

Hubitat

Maker API를 통해 허브의 기기에 전원과 입력을 한 방향으로 미러링하며, Rule Machine이 이를 바탕으로 동작할 수 있습니다.

Home Assistant

Home Assistant 자체 JVC Projector 통합구성요소, 장면용 스크립트, 바로 쓸 수 있는 대시보드를 설정합니다.

웹훅

자동화 트리거

트리거는 이 프로젝터에서 어떤 일이 일어났을 때 사용자가 입력한 주소로 웹 요청을 보냅니다. 프로젝터마다 자체 목록이 있습니다. 트리거 추가를 누른 다음 선택하세요.

  • 조건: 프로젝터가 켜질 때, 프로젝터가 대기 상태가 될 때, 입력 변경(모든 입력 또는 특정 입력), 장면을 불러올 때(모든 장면 또는 특정 장면) 중에서 선택합니다.
  • 방식: POST(기본값), PUT, GET.
  • 웹 주소: 호스트 이름이 있는 http:// 또는 https:// 주소입니다.
  • 사용: 트리거를 삭제하지 않고 일시 중지할 때 사용합니다.
http://로 시작하는 주소는 암호화 없이 전송되며, 편집기에도 그렇게 표시됩니다. 시스템이 지원한다면 https://를 사용하세요.
페이로드

요청에 담기는 내용

POST와 PUT은 JSON 본문을 보내고, GET은 본문을 보내지 않습니다. 앱이 추가하는 헤더는 Content-Type뿐입니다. 이벤트에 해당하지 않는 필드는 생략됩니다.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
항목의미
eventpower_on, power_off, input_changed 또는 scene_recalled.
projector앱에 표시된 프로젝터 이름입니다.
inputhdmi1, hdmi2 같은 입력입니다.
scene_id, scene_name장면을 불러올 때의 장면입니다.
timestamp이벤트가 일어난 시각(UTC)입니다.
test테스트 전송으로 보낸 요청에만 있으며, 값은 true입니다.
전송

한 번만 시도하고 솔직하게 보고합니다

  • 각 이벤트는 10초 제한으로 한 번만 전송되며, 리디렉션은 따라가지 않습니다.
  • 트리거에는 마지막 결과가 표시됩니다. 상태 코드와 함께 시각이 표시된 전달됨, 거부됨, 응답 없음, 주소에 연결할 수 없음, 보안 연결 실패, 아직 전송되지 않음 중 하나입니다.
  • 테스트 전송은 테스트로 표시된 요청을 보냅니다. 프로젝터가 아무 동작도 하기 전에 상대편을 미리 연결해 볼 수 있습니다.
트리거가 실행되는 때

규칙

  • 앱이 열려 있고 프로젝터에 연결된 동안에만 실행됩니다. 앱은 프로젝터의 상태를 지켜볼 뿐, 백그라운드 서비스가 아닙니다.
  • 읽은 값이 아니라 변화에 반응합니다. 앱이 연결된 뒤 처음 읽은 값은 기준점만 정합니다. 따라서 이미 켜져 있던 프로젝터에 대해 앱을 열었다는 이유로 "켜질 때" 트리거가 실행되지는 않습니다.
  • 데모 프로젝터에서는 절대 실행되지 않습니다. 데모 프로젝터를 선택했거나 Home Automation이 잠금 해제되지 않은 상태에서는 기기 밖으로 아무것도 전송되지 않습니다.
  • 안전하게 저장됩니다. 트리거 주소는 기기의 보안 저장소에 보관됩니다.
Hubitat

프로젝터를 Hubitat에 미러링

앱은 Maker API를 통해 Hubitat 허브의 기기에 이 프로젝터를 미러링합니다. 켜짐과 대기, 그리고 입력(HDMI 1 또는 HDMI 2)을 기기가 받아들이는 범위에서 반영하며, 그러면 Rule Machine이 이를 바탕으로 동작할 수 있습니다.

  1. Hubitat에서 Maker API를 추가하고 앱 ID(URL에 있는 숫자)와 액세스 토큰을 메모해 둡니다.
  2. 앱에서 허브 주소, Maker API 앱 ID, 액세스 토큰을 입력합니다.
  3. 기기 찾기를 누르고 이 프로젝터에 해당하는 기기를 선택합니다. 비슷한 기기가 없으면 Hubitat에서 프로젝터 이름의 가상 스위치를 추가한 다음 다시 시도하세요.
  4. 프로젝터 상태 미러링을 켭니다. 앱이 열려 있고 연결된 동안 프로젝터 상태가 바뀔 때마다 기기가 그에 따라 바뀝니다.
한 방향만 지원합니다. Hubitat에서 프로젝터로는 아무것도 전송되지 않습니다. 연동 해제를 누르면 앱에서 연결이 제거됩니다.
Home Assistant

가장 깊은 연결

앱이 Home Assistant에 로그인하여 프로젝터를 JVC Projector 통합구성요소에 추가하고, 장면과 컨트롤을 스크립트로 게시하며, 대시보드를 만들어 줍니다. 전용 페이지가 따로 있습니다. Home Assistant 설정과 Home Assistant 대시보드입니다.
