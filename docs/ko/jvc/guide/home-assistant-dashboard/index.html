Home Assistant 대시보드

Home Assistant의 프로젝터 대시보드

한 번만 누르면 Home Assistant에 JVC 프로젝터용 전체 대시보드가 만들어집니다. 전원, 상태, 화질 옵션, 장면, 입력, 렌즈 메모리, 신호 정보 등이 포함됩니다. 대시보드는 Home Assistant에 실제로 있는 항목을 바탕으로 만들어지며 주소나 비밀번호는 들어 있지 않습니다. Home Automation 애드온이 필요합니다.

전송하기 전에

필요한 것

  • Home Assistant가 연결되어 있고 프로젝터가 JVC Projector 통합구성요소에 추가되어 있어야 합니다. Home Assistant 설정을 참고하세요.
  • 장면, 전원, 입력, 렌즈 메모리, 컨트롤 버튼이 필요하면 스크립트를 동기화해야 합니다. 대시보드는 존재하는 스크립트를 사용합니다.
  • 상태 및 측정값 타일을 쓰려면 실시간 상태 센서를 켜야 합니다.
  • 대시보드를 만들려면 Home Assistant의 관리자 계정이 필요합니다. 관리자 계정이 아니면 Home Assistant가 거부하고 앱이 그 사실을 알려 줍니다.
두 가지 방법

전송 또는 복사

  • 대시보드 전송은 Home Assistant 사이드바에 대시보드를 만들며, 제목은 프로젝터 이름이고 프로젝터 아이콘이 붙습니다. 다시 전송하면 대시보드가 갱신됩니다. Home Assistant와 동기화할 때도 함께 전송됩니다.
  • 대시보드 복사는 아무것도 전송하지 않습니다. 대시보드를 복사해 두므로, 새 대시보드의 원시 구성 편집기에 직접 붙여넣고 원하는 대로 수정할 수 있습니다.
프로젝터마다 projector-pilot-jvc-로 시작하는 주소에 각자의 대시보드가 만들어지므로, 두 프로젝터가 서로를 덮어쓰는 일이 없습니다.
레이아웃

구성 내용(위에서 아래로)

섹션은 내용이 있을 때만 나타납니다. 따라서 렌즈 메모리가 없는 프로젝터에는 렌즈 메모리 섹션이 생기지 않습니다.

화질입력과, Home Assistant가 프로젝터에 제공하는 화질 옵션입니다. 모델이 지원하고 사용 설정된 경우에 한해 픽처 모드, 광원 출력, 다이내믹 컨트롤, Clear Motion Drive, 아나모픽, HDR 처리, 설치 모드 등이 포함됩니다.

컨트롤픽처 모드, 숨기기 같은 나머지 제어 스크립트입니다.

스타일

코어 카드 또는 스타일 디자인

코어

Home Assistant 자체 카드만으로 만듭니다. 어떤 Home Assistant에서도 동작하며 따로 설치할 것이 없습니다.

스타일

HACS의 button-card, card-mod, Mushroom 카드를 사용해 더 풍부한 디자인을 만듭니다. 세 가지가 모두 있을 때만 사용됩니다.

세 가지 중 하나라도 없으면 앱은 코어 버전을 전송하고, 스타일 디자인을 위해 HACS에서 어떤 카드를 설치해야 하는지 알려 줍니다. 설치한 뒤 다시 전송하세요.

솔직한 설계

일부 항목이 대시보드에 없는 이유

  • 게이지 없음. JVC는 Home Assistant가 보고하는 레벨의 범위를 제공하지 않으므로, 추측해야 하는 게이지는 그리지 않습니다.
  • 주소와 비밀번호 없음. 대시보드에는 엔티티 ID, 이름, 라벨만 들어갑니다.
  • 가짜 엔티티 없음. 타일은 Home Assistant에 실제로 있는 엔티티나 스크립트에 대해서만 나타납니다.
문제가 생겼을 때

메시지

  • 대시보드 전송 완료. Home Assistant 사이드바에서 엽니다.
  • 거부됨. Home Assistant가 대시보드를 거부했습니다. 관리자 계정으로 로그인한 후 다시 전송하세요.
  • 로그인이 거부됨. 다시 로그인한 다음 대시보드를 전송하세요.
  • 응답 없음. Home Assistant가 응답하지 않아 대시보드를 확인하지 못했습니다. 연결을 확인하고 다시 전송하세요.
  • 허용되지 않음. 데모 프로젝터를 선택했거나 Home Automation이 잠금 해제되지 않은 상태에서는 기기 밖으로 아무것도 전송되지 않습니다.
대시보드는 Home Assistant의 JVC Projector 통합구성요소를 통해 프로젝터를 제어하며, 이 통합구성요소는 이 앱이 프로젝터에 연결되어 있지 않을 때만 프로젝터에 접근할 수 있습니다. 대시보드를 사용하기 전에 앱을 닫으세요.
