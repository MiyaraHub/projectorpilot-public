Projector Pilot D-ILA 사용자 가이드

JVC D-ILA 프로젝터를 추가하고 모든 화면을 사용하는 방법입니다. 모든 화면은 사용 중인 모델에 맞춰 달라집니다. 앱은 프로젝터가 보고한 모델 코드를 읽고, 해당 모델의 JVC 명령표에 문서화된 기능만 제공하며 그 밖의 기능은 제공하지 않습니다.

시작하기 전에

준비물

  • LAN 포트가 있는 JVC D-ILA 프로젝터를 케이블로 네트워크에 연결합니다. 앱이 인식하는 모델 계열은 도움말 페이지에 나와 있습니다.
  • 같은 로컬 네트워크에 있는 휴대폰, 태블릿 또는 컴퓨터. 앱은 로컬 네트워크에서만 동작하며, 거쳐 가는 클라우드 서비스가 없습니다.
  • 프로젝터에 설정되어 있다면 프로젝터의 네트워크 비밀번호가 필요합니다. 최신 모델은 8~10자를 사용합니다.
  • 아직 프로젝터가 없나요? 기기에서 시뮬레이션되는 데모 프로젝터로 모든 화면을 열어 볼 수 있습니다. 시작하기를 참고하세요.
무료 및 유료

무료로 사용할 수 있는 기능

전원, HDMI 1, 방향 키 사용 횟수는 모든 프로젝터에서 무료입니다. Pro는 프로젝터의 나머지 기능을 열어 주고, Home Automation은 스마트홈 연결을 열어 줍니다. 둘 다 일회성 구매입니다.

무료

전원 켜기와 대기, HDMI 1, 그리고 설치 후 평생 방향 키 20회, 이후에는 하루 3회.

Pro

모든 입력과 리모컨 키, 화질, 렌즈, 설치, 장면, 유지관리, 테스트 패턴, 홈 화면 위젯.

Home Automation

웹훅 트리거, Hubitat 미러, 대시보드를 포함한 Home Assistant 연결.

자세한 내용은 요금 페이지에서 확인하세요.

모델별 차이

컨트롤이 보이지 않을 수 있는 이유

  • 모델이 해당 기능을 문서화하지 않았습니다. JVC 명령표에 사용 중인 모델용으로 나와 있지 않은 설정은 무작정 보내지 않고 표시하지 않습니다.
  • 프로젝터가 응답하지 않습니다. 프로젝터가 켜져 있는 동안 계속 응답하지 않는 설정은 "이 프로젝터는 이 설정에 응답하지 않습니다."라는 문구와 함께 비활성화되어 표시됩니다.
  • 다른 설정이 제한하고 있습니다. 일부 설정은 HDR 신호가 있을 때의 HDR 처리처럼 특정 조건에서만 적용됩니다. 컨트롤에 어느 설정이 제한하고 있는지 표시됩니다.
  • 프로젝터가 대기 상태입니다. 대부분의 설정은 프로젝터가 켜지면 나타납니다.
지원 여부는 프로젝터에서 직접 확인합니다. 따라서 이 가이드 곳곳에 나오는 "지원하는 모델에서"라는 표현은 말 그대로 앱이 사용 중인 모델을 확인한 다음 해당하는 항목만 보여 준다는 뜻입니다.
