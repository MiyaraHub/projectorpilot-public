화질

프로젝터에서 읽어 온 화질 설정

화질 탭에는 모델이 문서화한 영상 설정이 화질, 신호, 디스플레이 세 페이지로 나뉘어 있습니다. 모든 값은 프로젝터에서 읽어 오고, 모든 변경은 다시 읽어 확인합니다. 모두 Pro에 포함됩니다.

화질 페이지

영상 자체

  • 지원하는 모델에서는 픽처 모드와 픽처 모드 이름 편집.
  • 색상: 컬러 프로파일, 보정이 포함된 색온도, 빨강, 초록, 파랑의 게인과 오프셋, 감마 보정이 포함된 감마.
  • HDR: 콘텐츠 유형, HDR 처리, HDR 레벨, 자동 톤 매핑, 매핑 레벨.
  • 광원: 레이저 출력(램프 모델은 램프 출력), LD 전류값, 다이내믹 컨트롤, 딥 블랙, 인텔리전트 렌즈 조리개.
  • 모션 및 지연: Clear Motion Drive, 모션 인핸스, 저지연.
  • 조정: 명암비, 밝기, 색, 색조, 픽처 톤, 밝은 레벨과 어두운 레벨, NR, 인핸스, 스무딩 등.
어떤 항목이 보이는지는 모델에 따라 다릅니다. 2024년 모델과 2018년 모델은 문서화된 설정이 다르며, 앱은 각 모델에 맞는 목록을 보여 줍니다.
색상 관리

색상 축 (ISF 캘리브레이션)

지원하는 모델에서는 색상 축 카드에 색상 관리가 있으며, 여섯 가지 색마다 축 위치, 색조, 채도, 밝기를 설정할 수 있습니다.

신호 페이지

입력을 읽는 방식

  • HDMI 입력 레벨과 HDMI 색 공간.
  • 신호별 픽처 모드: HDR10 픽처 모드, SDR(2D) 픽처 모드, SDR(3D) 픽처 모드, HLG 픽처 모드를 설정하면 각 신호 종류가 사용자가 고른 모드로 열립니다.
  • FILMMAKER MODE 설정과 ALLM (자동 저지연 모드).
  • 3D 설정이 있는 3D 카드.
디스플레이 페이지

화면 맞추기 및 메뉴

  • 수평 및 수직의 화면비, 마스크, 화면 위치.
  • 마스크 가장자리: 위, 아래, 왼쪽, 오른쪽.
  • 화면 메뉴: 배경색, 메뉴 위치, 소스 표시, 로고, 언어, OSD 다크 모드, OSD 밝기 동기화.
  • 패널 얼라인먼트과 픽셀 조정.
값 변경

목록, 버튼, 슬라이더

  • 픽처 모드나 감마 같은 선택 항목은 모델이 문서화한 값을 제공합니다.
  • 레벨은 빼기와 더하기 버튼을 사용합니다. 버튼을 누르고 있으면 반복되며, 400ms 후에 시작해서 300ms마다 한 단계씩 변경됩니다.
  • 슬라이더는 JVC가 범위를 정의한 곳에서만 나타납니다. 현재는 0에서 100퍼센트까지의 LD 전류값이 해당됩니다.
연동된 설정

다른 설정이 컨트롤을 제한할 때

일부 설정은 특정 조건에서만 적용됩니다. 앱이 이 규칙을 따르므로, 효과를 낼 수 없는 컨트롤은 "현재 저지연 설정에서는 사용할 수 없음" 또는 해당 컨트롤을 제한하는 설정 이름과 함께 비활성화되며 아무것도 전송되지 않습니다.

설정변경할 수 있는 조건
HDR 처리입력 신호가 HDR, HDR10+, HLG 또는 ST2084입니다.
다이내믹 컨트롤저지연이 꺼져 있습니다.
리모컨 키를 포함한 Clear Motion Drive저지연이 꺼져 있습니다.
마스크 가장자리마스크가 켜져 있습니다.
컨트롤을 제한하는 설정을 앱이 아직 읽지 못했다면, 아무것도 막지 않습니다.
정직한 표시

메시지의 의미

  • "이 프로젝터는 이 설정에 응답하지 않습니다." 프로젝터가 켜져 있는 동안 계속 응답하지 않았으므로 컨트롤이 비활성화됩니다.
  • "프로젝터가 이 설정을 보고하지 않습니다." 설정은 할 수 있지만, 프로젝터가 현재 값을 알려 주지 않습니다.
  • "프로젝터가 해당 명령을 확인하지 않았습니다. 적용되었는지는 알 수 없습니다." 이 경우 앱이 설정을 다시 읽으므로, 화면에는 프로젝터가 실제로 가진 값이 표시됩니다.
  • 먼저 확인을 요구하는 값은 해당 카드에서만, 확인한 뒤에 전송됩니다.
  • 대기. 대부분의 화질 설정은 프로젝터가 켜지면 나타납니다.
