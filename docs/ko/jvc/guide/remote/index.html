리모컨

휴대폰으로 쓰는 리모컨

리모컨 탭은 프로젝터 자체 메뉴를 조작하며 모델이 문서화한 모든 리모컨 키를 제공합니다. 밀어서 넘기는 네 페이지, 리모컨, 작동, 기기, 네트워크가 있습니다.

리모컨 페이지

프로젝터 메뉴 탐색

  • 탐색. JVC 리모컨과 같이 위, 아래, 왼쪽, 오른쪽, OK가 있는 원형 방향 패드와 메뉴, 뒤로 버튼이 있습니다.
  • 입력. 키 표에 입력 키가 있는 모델에서는 입력 키로 입력을 순환합니다. Pro 키입니다.
  • 입력 소스. 모델이 지원하는 입력마다 버튼이 하나씩 있습니다(예: HDMI 1, HDMI 2). HDMI 1은 무료이고, 나머지는 Pro가 필요합니다.
  • 추가 컨트롤. 픽처 모드, 숨기기, 그 밖의 모든 리모컨 키가 별도 페이지에 있습니다.
  • 새로고침. 상단 바의 새로고침 버튼을 누르면 프로젝터의 상태를 다시 읽습니다.
무료 등급

무료 방향 키 사용 횟수

Pro가 없으면 방향 키(위, 아래, 왼쪽, 오른쪽, OK, 뒤로, 메뉴)의 사용 횟수가 집계됩니다. 설치 후 평생 20회를 사용할 수 있고, 이후에는 하루 3회입니다. Pro를 사용하면 횟수 집계가 없어집니다.

  • 방향 패드 아래의 카운터에는 "무료 방향 키 사용 횟수 18회 남음"이 표시되며, 처음 20회를 모두 쓰고 나면 "오늘 무료 방향 키 사용 횟수 3회 남음"이 표시됩니다.
  • 하루가 시작되는 때. 하루 사용 횟수는 마지막으로 누른 때로부터 24시간 뒤가 아니라 현지 시각 자정에 초기화됩니다. 처음 20회를 모두 쓴 날에도 그날의 3회는 그대로 남아 있습니다.
  • 집계 대상. 키 입력은 프로젝터가 확인하지 않더라도 앱이 전송한 시점에 집계됩니다. 앱이 연결되지 않은 상태, 데모 프로젝터, Pro 사용 중에는 집계되지 않습니다.
  • 모두 소진되었을 때. 방향 패드는 화면에 그대로 있지만 아무것도 전송하지 않으며 "오늘의 무료 방향 키 사용 횟수를 모두 사용했습니다. 내일 다시 제공되며, Pro를 잠금 해제하면 횟수 제한 없이 사용할 수 있습니다."라고 표시됩니다.
앱을 다시 설치하면 횟수가 초기화되나요?

iOS와 macOS에서는 초기화되지 않습니다. 키체인에 사본이 하나 더 저장되며 더 높은 횟수가 적용됩니다. Android에서는 Android 자체 백업이 앱 데이터를 복원하지 않는 한 재설치 후 횟수가 다시 시작됩니다. Windows에서는 재설치 후 다시 시작됩니다.

추가 컨트롤

그 밖의 모든 리모컨 키

추가 컨트롤은 Pro 페이지입니다. 모델이 설정할 수 있다면 픽처 모드 카드가 먼저 나오고, 그다음 숨기기, 그리고 기능별로 묶인 리모컨 키가 나옵니다. 모델의 키 표에 문서화된 키만 나타납니다.

그룹예시
숨기기숨기기, 숨기기 켬, 숨기기 끔.
콘텐츠 유형과 HDR 레벨콘텐츠 유형과 HDR 레벨을 단계별로 바꾸는 키입니다.
색상감마, 색온도, 컬러 프로파일.
ISF지원하는 모델의 ISF 화질 키입니다.
모션Clear Motion Drive 메뉴, 저지연.
렌즈 및 설치렌즈 컨트롤, 조리개, 아나모픽 A~D, 설치 모드용 설정 메모리.
화면비, 메뉴 및 작동화면비 키, 정보, 고급 메뉴 및 그 밖의 메뉴 바로 가기.
테스트 패턴테스트 패턴 키입니다.
숨기기는 대기가 아닙니다. 숨기기는 프로젝터가 계속 켜진 채로 화면만 차단하므로 즉시 다시 나타납니다. JVC 프로젝터는 화면이 숨겨져 있는지 보고하지 않으므로, 앱은 상태를 표시하는 대신 숨기기 켬과 숨기기 끔을 제공합니다.
모델별 차이

모델별로 제공되는 키

JVC는 세대마다 키 표가 따로 있으며, 앱은 프로젝터가 보고하는 모델 코드로 키 표를 고릅니다. 모델에 없는 키는 제공하지 않습니다. 키가 해당 키가 없는 모델에 도달하는 경우에도 앱은 아무것도 보내지 않고, 컨트롤과 모델을 알려 주며 "아무것도 전송되지 않았습니다."로 끝납니다. 앱의 목록에 없는 모델도 전원, 입력, 리모컨 키는 사용할 수 있습니다.

작동 페이지

프로젝터 작동 방식

작동 페이지에는 지원하는 모델에서 끄기 타이머, 에코 모드, 트리거, 숨기기 에코, Control4가 있습니다. 모두 Pro입니다.

에코 모드와 네트워크. 에코 모드를 켜면 프로젝터가 대기 중에 네트워크 응답을 멈출 수 있으며, 그러면 앱으로 다시 켤 수 없게 될 수 있습니다. 앱은 켜기 전에 경고를 표시합니다. JVC 명령 문서에는 어느 쪽인지 나와 있지 않으므로 경고에는 "~할 수 있음"이라고 표시됩니다.
기기 페이지

프로젝터가 자신에 대해 보고하는 내용

기기 페이지(Pro)에는 두 개의 섹션이 있습니다. 프로젝터에는 모델 코드와 모델이 자신에 대해 보고하는 그 밖의 값이 표시됩니다. 신호에는 프로젝터가 보고하는 입력 신호 정보가 표시되며, 신호가 없으면 표시되지 않습니다. 설정에서 프로젝터를 누르면 기기 정보로 같은 내용이 열립니다.

네트워크 페이지

네트워크 정보 읽기 전용 보기

네트워크 페이지(Pro)에는 모델이 보고하는 범위에서 프로젝터의 유선 LAN 설정인 DHCP, IP 주소, 서브넷, 게이트웨이, 포트, MAC 주소가 표시됩니다. 일부러 읽기 전용으로 만들었습니다. 앱은 같은 네트워크로 프로젝터에 접속하므로, 여기서 주소를 바꾸면 앱 자신의 연결이 끊어집니다. 프로젝터의 화면 메뉴에서 바꾼 다음 다시 연결하세요. 프로젝터 주소가 바뀐 경우는 시작하기에서 다룹니다.

질문

리모컨 관련 질문

어떤 키가 무료 사용 횟수에 포함되나요?

위, 아래, 왼쪽, 오른쪽, OK, 뒤로, 메뉴이며, 연결된 프로젝터로 전송될 때만 집계됩니다. 전원과 HDMI 1은 항상 무료입니다.

키가 보이지 않는 이유는 무엇인가요?

앱은 모델의 명령표에 나와 있는 키를 표시합니다. 모델이 문서화하지 않은 키는 표시되지 않습니다.

데모 프로젝터에서도 리모컨이 동작하나요?

네. 데모 프로젝터에서의 키 입력은 집계되지 않습니다.
