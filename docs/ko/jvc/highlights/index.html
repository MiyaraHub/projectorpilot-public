버전 1.0.1의 구성

Projector Pilot D-ILA의 첫 번째 릴리스입니다. 각 모델의 명령표를 바탕으로 만든, 로컬 네트워크의 JVC D-ILA 프로젝터용 리모컨 및 설정 앱입니다.

하이라이트

첫 출시 버전에 포함된 기능

모델별 기능

설정은 43개 모델 프로필에 대해 각 모델의 JVC 명령 표에서 가져옵니다.

렌즈 및 설치

누르고 있는 동안 구동되는 렌즈 시프트, 초점, 줌, 렌즈 메모리, 설치 모드.

장면

장면을 .ppscene 파일로 저장, 적용, 공유합니다.

유지관리

사용 시간, 정격 수명, 시간당 비용, 알림, 사용 시간 리포트.

Home Assistant

기본 jvc_projector 통합구성요소, 스크립트, Lovelace 대시보드를 추가합니다.

데모 프로젝터

프로젝터 없이도 모든 화면을 사용해 볼 수 있으며, 데모에서는 모든 기능이 잠금 해제됩니다.

곧 출시 Projector Pilot D-ILA 앱은 Android, iOS, macOS, Windows용으로 Google Play, App Store, Microsoft Store에 출시될 예정입니다. 아직 어느 스토어에도 올라와 있지 않아 지금은 내려받을 수 없습니다.
연결

프로젝터를 찾고, 찾지 못하면 이유를 알려 줍니다

  • 네트워크를 검색하면 제어 포트에서 응답하는 JVC 프로젝터가 나타납니다.
  • 검색에서 찾지 못하면 IP 주소로 추가하세요.
  • 단계별 설정은 네트워크, 포트, 비밀번호를 하나씩 확인하고 처음 실패한 항목과 해결 방법을 알려 줍니다.
  • 프로젝터가 새 주소로 옮겨 가면 앱이 MAC 주소로 다시 찾아냅니다.
솔직한 컨트롤

모델이 제공하는 기능만

앱은 모델의 명령표에 있는 컨트롤만 표시하므로, 프로젝터가 받아들일 수 없는 설정을 누르게 되는 일이 없습니다. 프로젝터가 받아들이지 않은 변경은 완료된 것으로 표시되지 않고 받아들여지지 않았다고 보고됩니다. 설정, 정보, 지원 프로젝터에서 앱이 아는 모든 모델과 앱이 제어하는 범위를 확인할 수 있습니다.

일상적인 사용

리모컨, 화질, 렌즈

  • 리모컨: 방향 패드, 메뉴 키, 입력, 화면비, 숨기기. 리모컨을 참고하세요.
  • 화질: 픽처 모드, HDR, 색, 모션, 그 밖에 모델이 제공하는 화질 설정. 화질을 참고하세요.
  • 렌즈: 누르고 있는 동안 시프트, 초점, 줌을 구동하고 렌즈 메모리를 불러옵니다. 렌즈를 참고하세요.
  • 대시보드: 전원, 입력, 상태, 빠른 동작을 한눈에 확인합니다. 대시보드를 참고하세요.
우리 집

홈 오토메이션

프로젝터가 켜지거나, 대기 상태가 되거나, 입력이 바뀌거나, 장면을 불러올 때의 웹훅 트리거, Maker API를 통한 Hubitat 미러, 로그인하여 Home Assistant 자체 통합구성요소에 프로젝터를 추가하고 장면을 스크립트로 게시하며 대시보드를 만들어 주는 Home Assistant 설정을 제공합니다. 홈 오토메이션과 Home Assistant 대시보드를 참고하세요.

어디서나

플랫폼 및 언어

  • Android, iOS, macOS, Windows용으로 만들었습니다.
  • 아랍어와 히브리어 같은 오른쪽에서 왼쪽 방향 언어를 포함해 29개 언어를 지원합니다. 언어를 참고하세요.
  • 라이트, 다크, AMOLED 테마와 강조색 선택.
개인정보 보호

프로젝터는 계속 내 것

계정이 필요 없습니다. 프로젝터 비밀번호는 기기의 보안 저장소에만 보관되며 백업에는 포함되지 않습니다. 사용 분석 데이터는 동의하기 전까지 꺼져 있습니다. 진단 보고서에는 주소, 포트, MAC 주소, 비밀번호가 빠집니다. 개인정보 보호 페이지를 참고하세요.
