하이라이트

첫 출시 버전에 포함된 기능

모델별 기능

설정은 43개 모델 프로필에 대해 각 모델의 JVC 명령 표에서 가져옵니다.

렌즈 및 설치

누르고 있는 동안 구동되는 렌즈 시프트, 초점, 줌, 렌즈 메모리, 설치 모드.

장면

장면을 .ppscene 파일로 저장, 적용, 공유합니다.

유지관리

사용 시간, 정격 수명, 시간당 비용, 알림, 사용 시간 리포트.

Home Assistant

기본 jvc_projector 통합구성요소, 스크립트, Lovelace 대시보드를 추가합니다.

데모 프로젝터

프로젝터 없이도 모든 화면을 사용해 볼 수 있으며, 데모에서는 모든 기능이 잠금 해제됩니다.

곧 출시 Projector Pilot D-ILA 앱은 Android, iOS, macOS, Windows용으로 Google Play, App Store, Microsoft Store에 출시될 예정입니다. 아직 어느 스토어에도 올라와 있지 않아 지금은 내려받을 수 없습니다.
