도움말

도움말 & FAQ

연결, 연결 유지, 지원 모델, 구매, 개인정보 보호를 다룹니다. 대부분의 연결 문제는 세 가지로 귀결됩니다. 같은 네트워크일 것, 프로젝터가 LAN 케이블이 연결된 대기 상태일 것, 다른 컨트롤러가 프로젝터를 점유하고 있지 않을 것입니다.

시작하기

간단 체크리스트

  1. 프로젝터가 켜져 있거나, LAN 케이블이 연결된 대기 상태입니다.
  2. 휴대폰, 태블릿 또는 컴퓨터가 게스트 네트워크가 아닌 프로젝터와 같은 네트워크 및 서브넷에 있습니다.
  3. Home Assistant, 제어 시스템, 이 앱의 다른 사본 등 다른 어떤 것도 프로젝터에 연결되어 있지 않습니다.
  4. 프로젝터에 네트워크 비밀번호가 있다면 그 비밀번호를 알고 있습니다.
  5. 설정에서 단계별 설정을 실행하세요. 위 항목을 모두 확인하고 어느 항목이 실패했는지 알려 줍니다.
FAQ

자주 묻는 질문

앱이 프로젝터를 찾지 못하거나 연결하지 못합니다

휴대폰과 프로젝터를 같은 네트워크와 서브넷에 두세요. 게스트 네트워크, 격리된 VLAN, 클라이언트 격리는 둘을 갈라놓습니다. 검색은 사용자의 /24 서브넷을 확인합니다. 검색에서 프로젝터가 나타나지 않으면 IP 주소로 추가하세요. 네트워크 제어는 TCP 포트 20554를 사용하며, 최신 모델은 프로젝터에 설정한 네트워크 비밀번호가 필요합니다.

앱이 요구하는 비밀번호는 무엇인가요?

프로젝터 자체에 설정한 네트워크 비밀번호이며 Wi-Fi 비밀번호가 아닙니다. 최신 모델은 8~10자를 사용합니다. 앱은 이 비밀번호를 이 기기의 보안 저장소에만 보관하고 백업에는 포함하지 않습니다.

프로젝터가 대기 상태이고 앱이 연결할 수 없습니다

전원이 완전히 꺼진 프로젝터는 응답할 수 없습니다. LAN 케이블을 연결한 채 대기 상태로 두세요. 일부 모델에서는 에코 모드 같은 절전 대기 설정이 대기 중 네트워크 응답을 멈춥니다. 프로젝터 자체의 네트워크 및 대기 설정을 확인하세요.

다른 컨트롤러가 연결되어 있다고 표시됩니다

JVC 프로젝터는 한 번에 하나의 네트워크 컨트롤러만 지원합니다. Home Assistant, 제어 시스템, 다른 앱이 연결되어 있으면 그것이 연결을 해제하기 전까지 이 앱은 연결할 수 없으며, 반대의 경우도 마찬가지입니다. 이 앱은 백그라운드로 이동하면 프로젝터 연결을 해제합니다.

프로젝터의 IP 주소가 바뀌었습니다

연속으로 세 번 연결에 실패하면 앱이 MAC 주소로 네트워크에서 프로젝터를 찾아 새 주소로 다시 연결합니다. 앱이 MAC 주소를 알려면 이전에 한 번 연결한 적이 있어야 합니다. 설정의 연결 정보 편집에서 주소를 직접 바꿀 수도 있습니다.

내 모델이 목록에 없습니다

목록에 없는 D-ILA 프로젝터도 전원, 입력, 리모컨 키는 사용할 수 있습니다. 모델의 명령표에 없는 설정은 무작정 보내지 않고 표시하지 않습니다. 설정, 정보, 지원 프로젝터에서 앱이 아는 모든 모델과 지원 수준을 확인할 수 있습니다.

내 프로젝터에서 컨트롤이 보이지 않는 이유는 무엇인가요?

앱은 모델의 명령표에 있고 프로젝터가 응답하는 컨트롤만 표시합니다. 프로젝터가 대기 상태이거나 예열 중일 때는 컨트롤이 나타나지 않고 기다리며, 프로젝터가 켜지면 나타납니다.

한 번만 결제하는 방식인가요?

네. Pro, Home Automation, 번들은 구독과 광고가 없는 일회성 구매입니다. 구매를 확인하기 전에 스토어가 사용자의 통화로 가격을 표시합니다.

새 기기에서 구매한 항목을 사용하려면 어떻게 하나요?

같은 스토어 계정에 로그인한 다음 설정의 Pro 카드에서 복원을 누르세요. 구매는 기기가 아니라 스토어 계정에 귀속됩니다. 아무것도 찾지 못하면 앱이 그렇게 알려 줍니다.

앱이 데이터를 수집하나요?

Android와 iOS에서 크래시 보고서는 기본적으로 켜져 있으며 설정, 정보에서 끌 수 있습니다. 사용 분석 데이터는 동의하기 전까지 꺼져 있으며, 프로젝터의 이름, 주소, MAC, 비밀번호는 절대 포함하지 않습니다.

실제 JVC 프로젝터에서 앱을 테스트했나요?

네. DLA-NZ500에서 네트워크 비밀번호로 연결하고, 상태를 읽고, 설정을 변경해 확인했습니다. 다른 모델은 JVC가 공개한 명령표를 근거로 지원하며, 앱은 각 모델의 표에 있는 기능만 제공합니다.

문제 해결

연결 검사가 알려 주는 내용

단계별 설정과 추가 화면은 입력한 주소를 확인하고 처음으로 실패한 항목을 알려 줍니다. 각 결과에는 다음에 할 일이 함께 표시됩니다.

결과의미해야 할 일
다른 네트워크휴대폰과 프로젝터가 서로 다른 서브넷에 있습니다.휴대폰을 게스트 네트워크가 아닌 프로젝터와 같은 네트워크에 연결하거나, VLAN 간 트래픽을 허용하세요.
해당 주소에 기기 없음해당 주소에서 응답이 없습니다.프로젝터의 네트워크 설정에서 IP를 확인하고, 프로젝터가 LAN 케이블이 연결된 대기 상태인지 확인하세요.
제어 포트 거부됨해당 주소에 무언가 있지만 제어 포트를 거부했습니다.포트를 확인하세요. JVC D-ILA 프로젝터는 기본적으로 20554를 사용합니다.
제어 포트에서 응답 없음응답 없이 포트 연결 시간이 초과되었습니다.프로젝터의 전원이 완전히 꺼져 있거나, 다른 컨트롤러가 연결되어 있거나, 네트워크가 기기 간 트래픽을 차단(클라이언트 또는 AP 격리)하고 있을 수 있습니다.
비밀번호 필요프로젝터가 네트워크 비밀번호를 요구합니다.프로젝터에 설정된 네트워크 비밀번호를 입력하세요.
비밀번호가 거부됨프로젝터가 비밀번호를 거부했습니다.프로젝터의 비밀번호를 확인하고 다시 입력하세요.
프로젝터 사용 중다른 컨트롤러가 연결되어 있습니다.프로젝터를 제어하는 다른 앱이나 시스템을 닫고 몇 초 기다린 다음 다시 확인하세요.
JVC 응답이 아님무언가 응답했지만 JVC 핸드셰이크를 완료하지 않았습니다.주소를 확인하세요. 해당 포트가 다른 기기의 것일 수 있습니다.
연결된 동안

표시될 수 있는 메시지

  • 이 주소의 포트 20554에서 응답이 없습니다. 프로젝터가 네트워크에서 분리되어 있거나 다른 주소에 있습니다.
  • 프로젝터가 포트 20554의 연결을 받아들이지 않았습니다. 네트워크에서 분리되어 있거나, Home Assistant 같은 다른 컨트롤러가 연결되어 있습니다.
  • 프로젝터가 연결을 종료했습니다. 프로젝터가 세션을 끝냈으며, 앱이 자동으로 다시 연결합니다.
  • 저장된 비밀번호를 보안 저장소에서 읽을 수 없습니다. 설정의 비밀번호 변경에서 다시 설정하세요.
