Projector Pilot 가격: 한 번만 구매하면 계속 내 것입니다.

Projector Pilot은 한 번만 구매하는 두 부분으로 판매됩니다. 깊이 있는 제어를 위한 Pro와 스마트홈을 위한 홈 오토메이션이며, 번들로 구매하면 더 저렴합니다. 구독도, 광고도, 계정도, 클라우드도 없습니다.

요금제

무료, Pro, 홈 오토메이션, 번들

기본 제어와 실시간 상태는 무료로 시작하세요. 화질, 렌즈, 장면이 할 수 있는 모든 것을 원하면 Pro를 추가하고, 프로젝터를 Home Assistant, Hubitat, 웹훅에 연결하려면 홈 오토메이션을 추가하세요. 번들은 둘 다 포함하며 함께 구매하면 더 저렴합니다.

각각의 가격

간단하게 한 번만 결제

무료

기본 기능은 영원히. 프로젝터 추가, 전원 켜기/끄기, 입력 전환, 실시간 상태 확인, 화면 리모컨 기본 기능을 사용할 수 있습니다. 체험 기간 제한도, 결제 유도도 없습니다.

Pro

$9.99, 한 번만 결제. 장면, 여러 대의 프로젝터, 전체 화질 제어, 렌즈와 지오메트리, 유지관리 및 인사이트, 홈 화면 위젯, 테스트 패턴, 공유 가능한 장면 프로필.

Home Automation

$2.99, 한 번만 결제하는 추가 기능. Home Assistant, Hubitat, 웹훅. 정확히 어떤 기능인지 설정 가이드에서 확인하세요.

번들

$11.99, 한 번만 결제: Pro + 홈 오토메이션을 더 저렴하게. 앱의 모든 기능을 한 번의 결제로 이용하며, 두 부분을 따로 사는 것보다 저렴합니다.

표시되는 가격은 스토어의 가격입니다. 앱에 표시되는 금액은 확정하기 전에 스토어가 내 통화로 안내한 금액입니다. 위의 가격은 미국 기준 참고 가격이며 지역에 따라 다를 수 있고, 앱이 임의로 금액을 만들어 내는 일은 없습니다.

구매 방식

  • 한 번만 결제. 구독은 없습니다. 한 번 결제하면 계속 내 것입니다.
  • 광고도, 계정도, 클라우드도 없습니다. 앱은 내 네트워크에서 프로젝터와 통신합니다. 가입할 것도, 뒤에서 판매되는 것도 없습니다.
  • 한 번 구매하면 보유한 모든 플랫폼에서 잠금이 해제됩니다. 한 스토어에서 구매하고 같은 계정에 연결된 다른 스토어에서 복원하세요. Android, iOS, Windows, macOS 모두 가능합니다.
  • 이미 가진 것을 구매하거나 복원해도 항상 잠금이 해제됩니다. 스토어에서 Pro, 홈 오토메이션, 번들을 이미 보유 중이라고 하면 앱은 오류를 표시하지 않고 적용하므로, 결제한 기능 때문에 사용하지 못하는 일은 없습니다.
  • 스토어가 없는 플랫폼에서는 아무도 결제할 수 없는 유료 장벽을 보여 주는 대신 앱이 모든 기능을 포함합니다.
