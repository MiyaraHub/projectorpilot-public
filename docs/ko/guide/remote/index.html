리모컨

건전지가 필요 없는 진짜 프로젝터 리모컨

리모컨 탭에는 화면 리모컨과 작동 컨트롤이 있으며, 스와이프로 오가는 하위 페이지인 리모컨, 작동, 기기, 네트워크로 나뉩니다. 프로젝터가 제공하는 모든 것을 담고, 제공하지 않는 버튼은 보여 주지 않습니다.

리모컨 페이지

프로젝터 자체 메뉴 탐색

  • 가운데 선택 버튼이 있는 방향 패드와 메뉴, 뒤로, 홈, 소스 버튼으로, 실제 리모컨과 똑같이 프로젝터의 화면 메뉴를 조작할 수 있습니다.
  • 입력 선택으로 원하는 소스로 바로 이동합니다.
  • 색상 모드로 같은 화면에서 화질 모드를 전환합니다.
  • 화면 차단으로 화면을 숨깁니다. 전원은 이 페이지가 아니라 대시보드에 있어서, 전원 컨트롤이 세 개가 아니라 하나만 존재합니다.
화면 차단은 A/V 음소거와 다릅니다. 화면 차단은 프로젝터가 계속 작동하고 신호도 계속 흐르는 상태에서 영상만 숨기므로 즉시 복귀합니다. 종료가 아니라 잠시 멈출 때 사용하세요.
작동 페이지 - 지오메트리

영상의 모양 보정하기

설치 환경에 맞는 보정 방식을 선택하세요. 앱은 프로젝터가 지원하는 방식을 보여 주며, 하드웨어 특성상 한 번에 하나의 지오메트리 보정만 활성화할 수 있습니다.

방식용도
끄기보정 없음 - 스크린과 수직으로 맞춰진 프로젝터에는 필요하지 않습니다.
수평/수직 키스톤프로젝터가 위아래 또는 좌우로 치우쳐 있을 때 수평과 수직 키스톤을 각각 독립적으로 보정합니다.
퀵 코너네 모서리를 하나씩 끌어서 맞춥니다. 살짝 어긋난 영상을 바로잡는 일상적인 방법이에요.
포인트 보정격자의 점을 하나씩 조금씩 움직여서 국소적인 미세 왜곡을 보정합니다.
곡면곡면 스크린이나 벽에 투사할 때 보정합니다.
코너 월두 벽이 만나는 방 모서리에 투사할 때 보정합니다.
모든 지오메트리 값은 변경한 뒤 프로젝터에서 다시 읽어 오므로, 프로젝터가 적용하지 않은 보정이 적용된 것처럼 표시되는 일은 없습니다.
기기 페이지 - 비밀번호

비밀번호는 하나가 아니라 세 개

Epson 프로젝터에는 서로 다른 것을 보호하는 세 가지 비밀번호가 있습니다. Projector Pilot은 그 차이를 알고 있으므로, 필요 없는 비밀번호를 입력해도 앱에서 쫓겨나는 일은 없습니다.

비밀번호보호 대상
Web Control프로젝터의 웹 인터페이스와 그 위에서 오가는 명령으로, 많은 모델에서 렌즈 이동과 이미지 읽기도 포함됩니다. 프로젝터 자체 웹 페이지가 요구하는 바로 그 비밀번호입니다.
PJLink제어 시스템에서 사용하고, 앱에서는 대체 전송 방식으로 쓰이는 PJLink 프로토콜(TCP 4352)입니다.
리모컨앱이 가장 선호하는 전송 방식인 ESC/VP.net 원격 제어 채널(TCP 3629)입니다.
앱은 어떤 판단을 하기 전에 비밀번호가 필요한지부터 확인합니다. 묻지 않고 응답하는 프로젝터는 보호된 것으로 잘못 표시하지 않고 “여기서는 비밀번호가 필요 없음”으로 보고하며, “설정 안 됨”과 “설정되었지만 이 프로토콜에서는 필요 없음”을 혼동하지 않습니다. 저장된 Web Control 비밀번호가 더 이상 작동하지 않더라도 렌즈나 화질 컨트롤이 렌즈를 탓하며 꺼지는 일 없이, 비밀번호를 업데이트하라는 탭해서 해결하는 안내가 표시됩니다.
기기 페이지 - 잠금

프로젝터가 적용하는 잠금

기기 페이지에는 프로젝터 자체의 잠금이 표시됩니다. 프로젝터가 고정해서 컨트롤을 쓸 수 없을 때, 앱은 조용히 실패하는 대신 어떤 잠금 때문인지 알려 줍니다.

  • 렌즈 잠금. 프로젝터의 렌즈 잠금이 켜져 있으면 시프트, 초점, 줌이 고정됩니다. 앱은 프로젝터가 명령을 실제로 거부할 때만 렌즈가 잠겼다고 보고합니다. 수락되었지만 위치를 프로젝터가 확인하지 못하는 이동은 잠금으로 처리하지 않으므로 컨트롤은 계속 사용할 수 있습니다.
  • 자녀 보호 잠금. 프로젝터 자체의 전원 버튼을 비활성화해서 아이가 켜고 빛을 바라보는 일을 막습니다. 여기서 켜고 끌 수 있어요.
  • 조작 패널 잠금. 프로젝터 본체의 버튼을 잠가서 리모컨(과 앱)으로만 조작할 수 있게 합니다. 공공장소나 공유 공간에서 유용해요.
네트워크 페이지

읽기 전용의 깔끔한 보기

앱이 그 네트워크를 통해 프로젝터에 연결하기 때문에 네트워크 설정은 프로젝터에 있습니다. 네트워크 페이지는 프로젝터의 주소 정보를 읽기 전용으로 보여 주고 이유를 설명하는 안내를 함께 제공합니다. 설정 변경은 프로젝터 자체 인터페이스에서 하며, 시작하기에서 다룹니다.
