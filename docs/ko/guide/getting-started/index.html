시작하기

Epson 또는 PJLink 프로젝터를 약 1분 만에 추가하세요

Projector Pilot은 클라우드 계정이나 페어링 코드 없이, 사용 중인 네트워크에서 프로젝터를 바로 찾아냅니다. 스마트폰을 같은 Wi-Fi에 연결하고 프로젝터를 한 번만 추가하면, 앱이 프로젝터의 기능을 검사해서 기억해 둡니다. 전체 과정은 다음과 같아요.

시작하기 전에

준비물

  • 같은 네트워크. 스마트폰, 태블릿, 컴퓨터가 프로젝터와 같은 Wi-Fi(또는 유선 LAN)에 연결되어 있어야 합니다. 앱은 그 네트워크에서 프로젝터와 직접 통신해요.
  • 프로젝터가 켜져 있거나 대기 상태. 프로젝터를 켜 두거나, 네트워크 제어가 활성화된 대기 상태로 두세요. 대부분의 Epson 모델은 대기 중에도 응답하기 때문에 앱에서 바로 전원을 켤 수 있습니다.
  • 프로젝터의 IP 주소 (직접 추가할 때만 필요). 프로젝터 자체 네트워크 메뉴에서 확인할 수 있으며, 위치는 아래를 참고하세요.
프로젝터가 없나요? 첫 화면에서 데모 모드 체험하기를 탭하면, 실제 Epson QB1000에서 캡처한 데이터로 앱 전체가 실제 프로젝터처럼 응답합니다. 구매하기 전에 모든 화면을 직접 써 볼 수 있어요.
단계별 안내

프로젝터 추가하기

프로젝터 추가를 열고 찾는 방법을 고르세요. 어느 쪽이든 도착하는 곳은 같습니다.

  1. 네트워크 검색 또는 IP로 추가를 선택하세요. 네트워크 검색은 Wi-Fi 또는 유선 LAN에서 프로젝터로 응답하는 기기를 찾아 주소를 자동으로 채워 줍니다. IP로 추가는 주소를 직접 입력하고 싶을 때 사용하세요.
  2. 프로젝터를 선택하거나 IP를 입력하세요. 검색했다면 목록에서 프로젝터를 탭하세요. 직접 추가한다면 프로젝터 네트워크 메뉴에서 확인한 IP 주소를 입력하고 계속 진행합니다.
  3. 지원 기능 검사를 마치세요. 처음 추가하면 앱이 프로젝터를 조사하며 진행 표시줄로 진행 상황을 보여 줍니다. 어떤 프로토콜이 응답하는지, 어떤 컨트롤이 있는지, 렌즈와 화질의 범위는 어떤지 프로젝터에게 직접 물어보기 때문에, 앱에는 실제로 쓸 수 있는 컨트롤만 나타나요.
  4. 연결 테스트를 탭하세요. 앱이 프로젝터에 연결할 수 있는지 확인하고 프로젝터의 식별 정보를 읽어 옵니다. 프로젝터가 Web Control 비밀번호를 요구하면 여기서 입력하세요. 비밀번호가 필요한지 아닌지는 앱이 알아서 판단하고 결과를 알려 줍니다.
  5. 저장. 프로젝터가 추가되고 지원 기능 검사 결과가 기억됩니다. 앱을 다시 열어도 검사를 반복하지 않아요. 곧바로 대시보드로 이동해서 실시간 값을 읽어 옵니다.
프로젝터는 한 번만 검사하고 그 결과를 저장해 둡니다. 두 번째 실행부터 즉시 시작되는 이유예요. 앱이 이미 내 하드웨어가 할 수 있는 일을 알고 있으니까요.
주소 찾기

프로젝터 IP 주소는 어디에 있나요

IP로 추가하려면 네트워크상의 프로젝터 주소가 필요합니다. 모든 Epson 프로젝터에서 같은 위치에서 확인할 수 있어요.

  1. 프로젝터에서 화면 메뉴를 열고 네트워크로 이동하세요(일부 모델은 확장 설정 › 네트워크).
  2. 네트워크 설정 › 유선 LAN 또는 무선 LAN을 열고 IP 주소를 확인하세요.
  3. 그 주소를 IP로 추가에 입력하세요. 공유기에서 고정 주소나 예약 주소로 설정해 두면 앱에서 쓰는 주소가 바뀌는 일을 막을 수 있습니다.
네트워크 설정은 앱이 아니라 프로젝터에서 합니다. Projector Pilot은 그 네트워크를 통해 프로젝터에 연결하므로, 네트워크 페이지는 읽기 전용으로 깔끔하게 보여 드립니다. 주소 변경은 프로젝터 자체 인터페이스에서 하세요.
연결되지 않을 때

빠른 해결 방법

  • 네트워크를 다시 확인하세요. 스마트폰이 게스트 Wi-Fi나 모바일 데이터로 넘어가면 프로젝터가 보이지 않습니다. 양쪽 모두 같은 네트워크여야 해요.
  • 프로젝터를 깨우세요. 네트워크 대기가 꺼진 모델은 전원이 켜질 때까지 응답하지 않습니다. 한 번 켠 다음 추가하세요.
  • 비밀번호를 물어보나요? Web Control 비밀번호를 입력하세요(프로젝터 자체 웹 페이지가 요구하는 유일한 비밀번호입니다). 프로젝터의 나머지 비밀번호는 앱이 알아서 처리합니다. 리모컨 가이드를 참고하세요.
  • PJLink 전용 프로젝터인가요? 전혀 문제없는 일반 기기입니다. 앱은 응답하는 전송 방식으로 자동 전환하므로, Web Control이 없는 프로젝터도 정상적으로 동작해요.
