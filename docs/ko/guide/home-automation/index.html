Home Assistant · Hubitat · 웹훅

내 프로젝터를 Home Assistant와 Hubitat에서.

Projector Pilot은 프로젝터의 실시간 상태와 모든 컨트롤을 Home Assistant, Hubitat, 그리고 원하는 웹훅으로 게시합니다. 한 번만 설정하면 스마트홈이 알아서 프로젝터를 제어해요. 네트워크에 스마트폰이 없어도, 중간에 클라우드가 없어도 됩니다.

한 번 설정하면 서버 불필요장면이 스크립트로바로 쓰는 대시보드설정 체크리스트유료 추가 기능
개요

홈 오토메이션이 하는 일

홈 오토메이션은 Projector Pilot을 손에 든 리모컨에서 집 전체가 볼 수 있는 기기로 바꿔 줍니다. 전원, 입력, 색상 모드, 화질 수치, 램프 사용 시간처럼 프로젝터가 하고 있는 일을 공개하고, 앱이 바꿀 수 있는 모든 것을 스마트홈이 제어할 수 있게 해 줍니다.

  • 상태를 게시합니다. 프로젝터는 Home Assistant 센서, Hubitat 기기, 또는 웹훅으로 전달되는 JSON 페이로드로 나타나며, 앱에 보이는 것과 같은 측정값을 담고 있어요.
  • 컨트롤을 게시합니다. 저장한 모든 장면과 전원, 각 입력, 각 색상 모드, 각 렌즈 메모리가 자동화나 음성 비서가 실행할 수 있는 항목이 됩니다.
  • 서버 없이 작동합니다. 스크립트를 설정하고 나면 Home Assistant가 프로젝터의 IP 주소로 직접 명령을 보냅니다. 스마트폰이 네트워크에 있을 필요가 없고, 클라우드 계정을 거치는 것도 없어요.
홈 오토메이션은 유료 추가 기능입니다. Projector Pilot Pro와는 별도로 한 번만 결제하며, 번들로 구매하면 두 가지를 함께 더 저렴하게 이용할 수 있습니다. 구독도, 계정도, 클라우드도 필요 없어요. 가격을 확인하세요.

세 가지 방법, 하나의 허브

설정 › 홈 오토메이션이 허브입니다. 사용 중인 플랫폼인 Home Assistant, Hubitat, Webhooks 중에서 선택해 그곳에서 설정하세요. 여러 개를 동시에 연결해도 되며, 각각 독립적으로 작동합니다.

Home Assistant

Home Assistant 설정하기

앱에서 로그인하고, 프로젝터를 센서로 게시하고, 구성에 블록 하나를 붙여 넣은 뒤 동기화하세요. 그다음부터는 Home Assistant가 직접 프로젝터를 제어합니다.

  1. 설정 › 홈 오토메이션 › Home Assistant를 엽니다.
  2. Home Assistant 주소(예: http://homeassistant.local:8123 또는 IP)를 입력하고 로그인을 탭하세요. 내 인스턴스에 대한 브라우저 로그인이며, 붙여 넣을 토큰은 없습니다. 평소 쓰는 Home Assistant 계정으로 로그인하면 되고, 2단계 인증도 그대로 적용됩니다.
  3. 앱이 프로젝터를 센서로 게시하며, sensor.projector_pilot_epson_qb1000b_qb1000w 같은 엔티티가 만들어집니다. 전원, 입력, 색상 모드, 화질 수치, 램프 사용 시간을 담고 있어요.
  4. 프로젝터 상태 전송을 켜면 앱이 열려 있는 동안 값이 바뀔 때마다 Home Assistant의 측정값이 갱신됩니다. 고급 컨트롤 동기화를 켜면 화질 모드, 입력, 렌즈 메모리, 전원용 스크립트가 게시됩니다.
  5. 아래의 shell_command 블록을 configuration.yaml에 한 번 붙여 넣고 Home Assistant를 재시작한 다음 HA와 동기화를 탭하세요.

shell_command 블록

이것이 서버 없이 작동하는 비결의 전부입니다. 앱은 Home Assistant가 프로젝터의 Web Control과 통신할 때 실행하는 명령 하나를 만들고, 동기화되는 모든 스크립트는 동사만 달리해서 그 명령을 호출합니다. 앱에서 블록 복사를 탭하고 configuration.yaml에 붙여 넣으세요. 아래 예시는 설명용이며, 앱이 실제로는 내 프로젝터의 주소와 명령 이름을 채워 넣습니다.

shell_command:
  projector_pilot_epson: >-
    curl -s --max-time 5 --digest -u 'EPSONWEB:'
    -H "X-Requested-With: XMLHttpRequest"
    -H "Referer: http://192.168.1.50/cgi-bin/webconf"
    "http://192.168.1.50/cgi-bin/directsend?{{ verb }}={{ value | urlencode }}"

예시일 뿐입니다. 앱은 프로젝터의 실제 IP와 시리얼 번호에서 따온 이름으로 내 블록을 생성합니다.

서버가 필요 없는 이유. 이 curl는 스마트폰이 아니라 Home Assistant 기기에서 실행됩니다. Home Assistant가 Web Control을 통해 프로젝터의 IP에 직접 접속하므로, 앱이 열려 있든 아니든, 스마트폰이 집에 있든 없든 자동화가 실행됩니다. EPSONWEB 다이제스트 사용자는 Web Control 로그인이며, 앱은 해당 프로젝터에 이미 저장된 Web Control 비밀번호를 사용합니다.

연결 테스트, 동기화, 정리

  • 연결 테스트는 앱이 Home Assistant에 연결할 수 있는지, 붙여 넣은 shell_command가 실제로 있는지 확인합니다. 그 위에 무언가를 만들기 전에 오타를 찾을 수 있어요.
  • HA와 동기화는 장면과 컨트롤용 스크립트를 만들거나 갱신하고, 바로 쓸 수 있는 Projector Pilot 대시보드를 Home Assistant 안에 직접 만듭니다. 장면을 추가하거나 컨트롤을 바꿀 때마다 다시 실행하세요. 중복이 쌓이지 않고 그 자리에서 갱신됩니다.
  • 사용되지 않는 스크립트 제거는 앱이 만들었지만 더 이상 일치하는 장면이나 컨트롤이 없는 스크립트를 찾아냅니다. 예를 들어 장면을 삭제한 경우가 그렇습니다. 제거할 스크립트를 정확히 목록으로 보여 주고 먼저 확인을 요청합니다. 확인하기 전에는 아무것도 삭제되지 않습니다. Projector Pilot이 만든 스크립트만 건드리며, Home Assistant의 다른 것은 영향을 받지 않고, Home Assistant가 스크립트 목록을 알려 주지 않으면 아무것도 제거하지 않아요.
설정 체크리스트

무엇이 끝났고 무엇이 빠졌는지 앱이 알려 줍니다

Home Assistant 화면에는 설정 체크리스트와 내 Home Assistant에 있는 것 패널이 있어서, 어떤 단계가 남았는지 추측할 필요가 없습니다. 각 항목은 완료, 누락, 확인 불가 중 하나로 표시되고 다음에 할 일을 알려 줍니다.

  • Home Assistant에 연결됨 - 로그인되었고 응답하는 상태입니다. Home Assistant가 응답하지 않으면 주소를 확인하고 스마트폰이 같은 네트워크에 있는지 확인하라고 안내합니다.
  • Home Assistant에 프로젝터 추가됨 - Home Assistant에 이 프로젝터가 이미 있는지 알려 줍니다. 없다면 PJLink 통합구성요소를 추가하도록 안내하고, 통합구성요소 추가 단계에서 Home Assistant가 요구하는 PJLink 호스트와 포트를 보여 줍니다.
  • 값 센서 등록됨 - 프로젝터의 측정값을 담는 센서입니다. 앱이 프로젝터를 처음 읽을 때 등록되며, 무언가 막고 있을 때는 지금 등록 또는 켜기를 제안합니다.
  • 내 Home Assistant에 있는 것 - HACS(커뮤니티 스토어), Epson Projector Link 통합구성요소, PJLink 통합구성요소, configuration.yaml의 Projector Pilot 명령입니다. 각 항목은 찾음, 설치 안 됨, 확인할 수 없음 중 하나로 표시되며, 도움이 되는 곳에는 설치 방법과 HACS에서 열기 버튼이 있습니다.
다시 확인은 찾은 결과를 알려 줍니다. 문제를 고친 뒤 다시 확인을 탭하면 앱이 Home Assistant를 다시 읽고 결과를 보고합니다. 제대로 됐는지 궁금해할 필요가 없어요. 확인할 수 없었던 항목에는 확인할 수 없음이 표시되며, 추측으로 맞다 틀리다 하는 일은 없습니다.
이미 가진 것과 함께 작동

핵심 PJLink 통합구성요소를 지원하고, 있으면 더 풍부한 카드를 사용합니다

Projector Pilot은 내 Home Assistant에 무엇이 설치되어 있는지 파악해서 그에 맞춰 대시보드를 만듭니다. Home Assistant에 기본 포함된 핵심 PJLink 통합구성요소와도 함께 작동하므로, 이미 거기에 추가해 둔 PJLink 프로젝터도 완벽하게 지원됩니다.

  • 기본 제공 카드를 먼저 사용합니다. 커뮤니티 카드가 없으면 동기화가 Home Assistant 기본 카드로 대시보드를 만들고, 끝나면 그렇게 했다고 알려 줍니다. 별도 설치 없이 바로 작동해요.
  • HACS 카드가 설치되어 있으면 업그레이드됩니다. 앱은 커뮤니티 카드(Mushroom, button-card, card-mod, apexcharts-card) 중 어떤 것이 설치되어 있는지 확인하고, 있는 경우 각 카드를 더 풍부한 카드로 업그레이드합니다. 완전한 그린 글래스 스타일을 원한다면 직접 만드는 대시보드 가이드에서 더 자세히 안내합니다.
  • 장면과 컨트롤에는 한 번의 붙여 넣기가 필요합니다. Home Assistant에 프로젝터로 명령을 보내는 기능이 아직 없어도 실시간 측정값이 있는 대시보드는 만들어지며, 설정 마무리 카드가 과정을 안내합니다. 블록 복사를 탭하고, configuration.yaml에 붙여 넣고, Home Assistant를 재시작한 다음, 동기화를 다시 탭하세요.
  • 아무것도 설치되어 있지 않나요? 직접 붙여 넣으세요. Home Assistant에 아무것도 설치되어 있지 않아도 앱에서 모든 내용을 복사해 직접 붙여 넣을 수 있습니다.
  • 비밀번호는 눈에 띄게 표시됩니다. 붙여 넣는 명령 블록에 프로젝터 비밀번호가 들어 있으면 그렇다고 알려 주므로, 공유하거나 저장하기 전에 미리 알 수 있어요.
프로젝터가 꺼져 있는 동안

그대로 유지되는 측정값

대기 중인 프로젝터는 보고하는 값이 거의 없어서 대시보드가 보통은 텅 비게 됩니다. 선택 사항인 마지막 값 센서는 프로젝터가 꺼져 있는 동안에도 입력, 램프 또는 레이저 사용 시간 같은 마지막 측정값을 Home Assistant에 유지해 줍니다.

  • 이는 선택 사항인 블록 하나를 더 추가하는 일입니다. configuration.yaml의 끝에 붙여 넣거나(또는 기존 template: 섹션 아래에 해당 줄만 추가) Home Assistant를 재시작하세요. 앱의 있는지 확인 버튼이 Home Assistant에 이 블록이 있는지 알려 줍니다.
  • 이제 전원을 끄면 Home Assistant에 꺼짐으로 전달되므로, 대시보드와 자동화가 프로젝터가 꺼졌을 때 꺼진 것으로 인식합니다.
스크립트가 되는 장면

모든 장면이 Home Assistant 스크립트가 됩니다

동기화하고 나면 장면은 앱 안에만 갇혀 있지 않습니다. 각 장면과 전원, 각 입력, 각 색상 모드, 프로젝터가 실제로 가진 각 렌즈 메모리가 Home Assistant 스크립트로 만들어집니다.

  • 자동화가 실행할 수 있습니다. 장면이 스크립트가 되면 “해 질 녘에 TV가 켜지면 무비 나이트를 실행해”라는 일반적인 Home Assistant 자동화를 만들 수 있어요.
  • 음성 비서가 실행할 수 있습니다. 스크립트를 음성 비서에 노출하면 “무비 나이트 켜 줘”라는 말 한마디로 입력, 화질 모드, 렌즈 메모리가 함께 설정됩니다.
  • 실제 컨트롤만 나타납니다. 앱은 추측으로 만든 일반 목록이 아니라, 프로젝터가 보고하는 각 입력, 색상 모드, 렌즈 메모리에 대해서만 스크립트를 만듭니다.
  • 동기화를 끄면 앱이 만든 것만 제거됩니다. 동기화를 끄거나 사용되지 않는 스크립트 제거(목록을 보여 주고 먼저 확인합니다)를 사용하면 Projector Pilot이 만든 스크립트만 삭제하고 다른 것은 건드리지 않습니다.
스크립트는 이름이 바뀌어도 같은 스크립트가 갱신되도록 이름이 붙습니다. 스크립트 이름은 프로젝터와 컨트롤에서 파생되므로, 장면 이름을 바꾼 뒤 다시 동기화하면 복사본이 하나 더 생기는 대신 기존 스크립트가 갱신됩니다.
대시보드

동기화가 대시보드를 만들어 줍니다

Lovelace 뷰를 직접 만들 필요도, 이제는 붙여 넣을 필요도 없습니다. HA와 동기화를 탭하면 앱이 Home Assistant 자체 API를 통해 완전한 Projector Pilot 대시보드를 Home Assistant 안에 직접 만듭니다. 프로젝터의 실시간 상태와 동기화된 모든 장면 및 컨트롤용 버튼이 들어 있어요. Home Assistant 사이드바에 Projector Pilot이라는 이름으로 나타나며, 열기만 하면 끝입니다.

  1. 앱에서 Home Assistant에 로그인합니다.
  2. 앱의 블록 복사 내용을 configuration.yaml에 한 번 붙여 넣고 Home Assistant를 재시작합니다(유일하게 수동으로 해야 하는 단계입니다. Home Assistant는 앱이 원격으로 그 명령을 추가하는 것을 허용하지 않습니다).
  3. HA와 동기화를 탭합니다. 대시보드가 만들어지고 사이드바에 Projector Pilot으로 나타납니다.
직접 붙여 넣고 싶나요? Home Assistant 화면에는 대시보드 복사가 그대로 있습니다. 탭한 뒤 Home Assistant에서 설정 › 대시보드 › 대시보드 추가로 가서 빈 대시보드를 만들고, 점 세 개 메뉴 › 대시보드 편집 › 점 세 개 메뉴 › Raw 구성 편집기를 열어 복사한 YAML을 붙여 넣으세요.

자동으로 만들어졌든 직접 붙여 넣었든 대시보드는 같습니다. 상태 카드 하나와 각 컨트롤용 버튼으로 구성돼요(설명용 코드 조각).

views:
  - title: Projector
    cards:
      - type: entity
        entity: sensor.projector_pilot_epson_qb1000b_qb1000w
        name: Projector
      - type: button
        name: Power On
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_power_on
      - type: button
        name: Movie Night
        tap_action:
          action: perform-action
          perform_action: script.turn_on
          target:
            entity_id: script.projector_pilot_scene_movie_night

예시일 뿐입니다. 실제 대시보드에는 내 프로젝터의 실제 엔티티와 내 장면이 들어갑니다.

모델에 구애받지 않습니다. 대시보드는 내 프로젝터가 실제로 보고한 엔티티, 화질 수치, 입력, 색상 모드, 렌즈 메모리, 장면 등 프로젝터 자체의 기능으로 만들어집니다. 여기 있는 스크린샷은 QB1000이며, 내 모델은 입력, 컨트롤, 측정값이 다를 수 있습니다. 사진과 같은 완전한 그린 글래스 보드를 원한다면 단계별 대시보드 가이드를 따르거나 완성된 뷰를 내려받아 문자열 두 개를 바꾸세요.
더 화려한 벽면을 원하나요? 같은 스크립트로 원하는 어떤 카드든 구동할 수 있습니다. AVR Maestro를 사용해 보셨다면 방식은 똑같습니다. 센서 하나와 동기화된 스크립트로 불이 들어오는 소스 및 모드 타일, 실시간 헤더, 기록을 만드세요.
Hubitat

Hubitat 설정하기

Hubitat에서는 Projector Pilot이 Maker API를 통해 프로젝터를 허브의 기기로 미러링하므로, Rule Machine이 전원, 음소거, 입력을 읽고 처리할 수 있습니다.

  1. Hubitat에서 Maker API 앱을 활성화하고 접속 URL과 토큰을 메모한 다음, 어떤 기기를 노출할지 선택하세요.
  2. Projector Pilot에서 설정 › 홈 오토메이션 › Hubitat을 열고 허브의 Maker API 정보를 입력하세요.
  3. 프로젝터를 나타내는 기기를 선택하세요. 앱이 가능성 높은 기기를 추천하며, 그대로 선택하거나 직접 고를 수 있습니다.
  4. 앱이 그 기기에 전원, 음소거, 입력을 미러링하며, 기기가 받아들이는 명령만 보냅니다.
  5. 그 기기를 대상으로 다른 기기와 똑같이 Rule Machine 규칙을 만드세요. 프로젝터의 상태가 규칙을 구동합니다.
기기가 받아들이는 것만 보냅니다. 앱은 선택한 기기가 해당 명령을 지원할 때만 프로젝터 값을 Hubitat으로 보내므로, 기기가 거부할 값을 밀어 넣는 일이 없습니다.
웹훅

Webhooks 설정하기

Webhooks는 만능 연결 수단입니다. 프로젝터가 켜지거나, 꺼지거나, 입력이 바뀌거나, 장면이 호출될 때 앱이 내 URL로 데이터를 보냅니다. Home Assistant 웹훅, Node-RED, IFTTT 등 JSON을 받는 어떤 서비스든 쓸 수 있어요.

  1. 설정 › 홈 오토메이션 › Webhooks를 엽니다.
  2. 데이터를 보낼 URL을 입력하세요. Home Assistant 웹훅은 http://homeassistant.local:8123/api/webhook/your-id와 같은 형태입니다.
  3. 웹훅을 실행할 이벤트를 선택하세요. 전원 켜짐, 전원 꺼짐, 입력 변경, 장면 호출 중에서 고를 수 있고, 특정 입력이나 장면으로 필터링할 수도 있습니다.
  4. 받는 서비스가 특정 형식을 요구한다면 선택적으로 사용자 지정 페이로드를 설정하세요. 설정하지 않으면 앱이 기본 JSON을 보냅니다.
  5. 저장하세요. 그때부터 앱이 해당 이벤트가 발생할 때마다 데이터를 보냅니다.

기본 페이로드는 일반 JSON으로, 이벤트, 프로젝터, 바뀐 값으로 구성됩니다.

{
  "event": "scene_recalled",
  "projector": "Epson QB1000B/QB1000W",
  "scene": "Movie Night",
  "power": "on",
  "input": "HDMI1",
  "color_mode": "Cinema",
  "timestamp": "2026-09-23T20:14:07Z"
}

페이로드 예시입니다. 입력 변경이나 전원 이벤트에는 해당 이벤트와 관련된 필드가 담깁니다.

다시 연결하면 모두 해결됩니다. Home Assistant를 새 주소로 다시 연결하면 앱이 그 주소를 가리키는 모든 웹훅을 한꺼번에 업데이트하므로, 인스턴스를 옮겨도 하나씩 직접 수정할 필요가 없습니다.

문제 해결

로그인하면 다시 로그인 페이지로 돌아갈 때

입력한 주소가 실제로 Home Assistant에 접속하는 주소(포트 포함, 보통 :8123)와 같은지 확인하세요. 로그인은 내 인스턴스에 대한 실제 브라우저 로그인이므로 사용자 이름, 비밀번호, 2단계 인증 코드가 모두 적용됩니다. 스마트폰에서는 앱 내 브라우저가 결과를 전달하든 로컬 콜백이 먼저 돌아오든 로그인이 완료됩니다. 그래도 멈춘다면 시트를 닫고 로그인을 다시 탭하세요.

Home Assistant에 프로젝터 센서가 나타나지 않을 때

센서는 앱이 열려 있고 프로젝터 상태 전송이 켜져 있는 동안 게시되므로, 앱을 열어 해당 토글을 확인하세요. 그런 다음 Home Assistant의 개발자 도구 › 상태에서 projector_pilot로 필터링해 보세요. 대기 중인 프로젝터는 거의 아무것도 게시하지 않으니, 프로젝터를 깨우면 측정값이 채워집니다.

동기화된 스크립트가 없을 때

스크립트는 HA와 동기화가 만들며, 이를 위해서는 shell_command 블록이 configuration.yaml에 이미 붙여 넣어져 있고 Home Assistant가 한 번 재시작되어 있어야 합니다. 먼저 연결 테스트를 실행하세요. 블록이 있는지 알려 줍니다. 그런 다음 다시 동기화하세요. 쓸모없는 오래된 스크립트가 목록을 어지럽힌다면 사용되지 않는 스크립트 제거를 사용하세요.

스마트폰이 집에 없을 때 앱에서는 스크립트가 실행되지만 Home Assistant에서는 실행되지 않을 때

바로 shell_command 블록이 필요한 이유입니다. 이 블록이 있어야 Home Assistant가 스스로 프로젝터의 IP에 접속할 수 있어요. 앱이 열려 있을 때만 작동한다면 블록을 붙여 넣지 않았거나, 붙여 넣은 뒤 Home Assistant를 재시작하지 않았을 가능성이 높습니다. 연결 테스트로 확인하고, Home Assistant를 재시작한 다음, 동기화하세요.

프로젝터를 집 전체에 연결하세요

FAQ

빠른 답변

Home Assistant 자동화를 실행하려면 스마트폰이 계속 네트워크에 있어야 하나요?

아니요. shell_command 블록을 Home Assistant에 한 번 붙여 넣고 동기화하면, 이후에는 Home Assistant가 프로젝터의 IP 주소로 직접 명령을 보냅니다. Projector Pilot은 설정 도구일 뿐이에요. 설정이 끝나면 스마트폰이 집에 있든 없든 Home Assistant가 알아서 프로젝터와 통신합니다.

프로젝터는 Home Assistant에 어떻게 나타나나요?

sensor.projector_pilot_epson_qb1000b_qb1000w 같은 센서로 나타나며, 전원, 입력, 색상 모드, 화질 수치, 램프 사용 시간을 담고 있습니다. 앱이 열려 있는 동안 값이 바뀔 때마다 갱신돼요. 고급 컨트롤 동기화를 켜면 앱이 모든 장면은 물론 전원, 각 입력, 각 색상 모드, 프로젝터가 가진 각 렌즈 메모리용 Home Assistant 스크립트도 만들어 줍니다.

홈 오토메이션은 무료인가요?

홈 오토메이션은 Projector Pilot Pro와는 별도로 한 번만 결제하는 유료 추가 기능입니다. 번들로 구매하면 두 가지를 함께 더 저렴하게 이용할 수 있어요. 가격 페이지를 확인하세요.
