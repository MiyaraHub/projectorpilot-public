프로젝터 앱 하나, 29개 언어

모든 화면, 모든 설정, 모든 대화상자를 내 언어로 만나 보세요. Projector Pilot은 영어와 28개 언어를 지원하며, iPhone, iPad, Mac의 권한 요청 안내까지 포함됩니다. 기본적으로 기기 언어를 따르고, 설정에서 직접 선택할 수도 있어요. 아랍어와 히브리어는 전체 레이아웃이 오른쪽에서 왼쪽으로 바뀝니다.

설정 위치

설정 › 언어

기본적으로 앱은 기기 언어를 따릅니다. 직접 선택하려면 설정을 열고 언어를 탭하세요. 시스템 기본값을 선택하면 선택권이 다시 기기로 돌아가며, 그 아래에는 모든 언어가 각 언어 고유의 이름으로 나열되어 있어서 다른 언어를 읽지 않고도 내 언어를 찾을 수 있습니다.

  • 자동. 설정 없이 스마트폰이나 태블릿의 언어를 그대로 따릅니다.
  • 직접 선택. 기기 설정을 덮어쓰면 바로 적용되고, 앱을 다시 시작해도 유지됩니다.
  • 오른쪽에서 왼쪽. 아랍어와 히브리어에서는 탐색, 카드, 목록까지 전체 레이아웃이 반전됩니다. 단, 프로젝터에서 읽어 온 값은 프로젝터가 쓰는 방식 그대로 표시돼요.
프로젝터의 용어는 프로젝터의 것으로 유지됩니다. 입력 이름, 색상 모드, 프로젝터가 보고하는 모든 값은 어떤 언어에서든 프로젝터가 말하는 그대로 표시됩니다. 번역되는 것은 Projector Pilot 자체의 문구뿐이에요.

언어 FAQ

앱이 기기 언어를 자동으로 따르나요?
네. 기본적으로 기기 언어를 따릅니다. 직접 선택하려면 설정 › 언어를 여세요. 시스템 기본값을 선택하면 선택권이 다시 기기로 돌아갑니다.
아랍어와 히브리어는 오른쪽에서 왼쪽으로 표시되나요?
네. 탐색, 카드, 목록 등 앱 전체가 반전됩니다. 단, 프로젝터에서 읽어 온 값은 프로젝터가 쓰는 방식 그대로 표시돼요.
입력 이름이 왜 여전히 원래 언어로 나오나요?
앱의 문구가 아니라 프로젝터 자체의 용어이기 때문입니다. 입력 이름, 색상 모드, 프로젝터가 보고하는 모든 값은 프로젝터가 말하는 그대로 표시되며, 번역되는 것은 Projector Pilot 자체의 문구뿐입니다.
