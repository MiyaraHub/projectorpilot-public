Projector Pilot 하이라이트

첫 정식 출시 버전의 Projector Pilot 하이라이트를 앱으로 하는 일에 따라 묶었습니다. 여기 있는 모든 항목은 지금 앱에 들어 있습니다. 앱은 Google Play에서 이용할 수 있으며, 다른 스토어는 승인 대기 중입니다.

Home Assistant

스스로 만들어지고 계속 작동하는 Home Assistant

Home Assistant 가이드를 읽어 보세요.

  • HA와 동기화는 스크립트뿐 아니라 대시보드 전체를 만들어 줍니다. Home Assistant 화면의 단계별 가이드가 Home Assistant에서 여전히 직접 해야 하는 설정 단계 하나를 알려 줍니다.
  • 핵심 PJLink 통합구성요소를 포함해 이미 가지고 있는 통합구성요소와 함께 작동합니다. 더 풍부한 HACS 카드가 설치되어 있으면 카드가 업그레이드됩니다.
  • 설정 체크리스트가 완료된 단계, 누락된 단계, 다음에 할 일을 보여 주고, 다시 확인이 찾은 결과를 알려 줍니다.
  • 마지막 값 센서가 프로젝터가 꺼져 있는 동안에도 Home Assistant에 측정값을 유지하며, 전원을 끄면 Home Assistant에 꺼짐으로 전달됩니다.
  • 명령 블록에 프로젝터 비밀번호가 들어 있으면 그렇다고 알려 주고, 통합구성요소 추가 단계에서 PJLink 호스트와 포트를 보여 줍니다. 아무것도 설치되어 있지 않나요? 모두 직접 붙여 넣으세요.
  • 사용되지 않는 스크립트 제거는 제거할 항목을 목록으로 보여 주고 먼저 확인을 요청합니다.
  • 대시보드 복사는 내 프로젝터의 컨트롤에 맞는 보드를 만들어 주며, 램프 또는 레이저 사용 시간 라벨도 그에 맞춰 표시됩니다.
  • 앱 내 브라우저에서의 로그인이 완료되며, 내 네트워크에서는 일반 HTTP로도 작동합니다.
일상적인 제어

더 빠르고, 더 차분하고, 오작동은 더 적게

대시보드 가이드와 렌즈 가이드를 참고하세요.

  • 모든 프로젝터 페이지의 상단 바에 있는 프로젝터 전환기로 목록으로 돌아가지 않고도 프로젝터 사이를 오갈 수 있습니다.
  • 프로젝터를 끌 때는 먼저 확인합니다.
  • 렌즈 시프트, 초점, 줌, 광 출력 스테퍼가 깜빡임 없이 누르는 즉시 반응합니다. 전송 중에 들어온 입력은 대기열에 쌓지 않고 무시해요.
  • 앱이 프로젝터가 켜지는 것을 약 10초 안에 알아채고, 다시 열었을 때 잘못된 꺼짐 대신 확인 중이라고 알려 줍니다.
  • 프로젝터가 펌웨어 버전을 보고하면 대시보드, 정보 탭, 진단 리포트에 펌웨어 버전이 표시됩니다.
  • 렌즈 페이지에 미세한 단계부터 큰 단계까지 고를 수 있는 스텝 크기 선택기가 생겼습니다. 렌즈 컨트롤이 잠기지 않았는데 잠긴 것처럼 표시되던 문제도 사라졌습니다.
  • TW7300, Home Cinema 4040처럼 PJLink로만 입력을 나열하는 프로젝터와 Epson이 아닌 PJLink 프로젝터에서도 입력 전환이 작동합니다.
  • 장면이 대기 중인 프로젝터를 PJLink로 깨우고, 다음 단계로 넘어가기 전에 응답을 기다립니다. 장면을 저장할 때 어떤 항목을 담을지 체크할 수 있습니다.
프로젝터 추가

찾고, 추가하고, 내 모델을 익히는 모습을 지켜보세요

  • 프로젝터 추가는 Wi-Fi 또는 유선 네트워크에서 프로젝터로 응답하는 기기를 먼저 검색하고 주소를 채워 줍니다. IP를 직접 입력하는 방법도 그대로 사용할 수 있습니다.
  • 내 모델의 지원 기능을 파악하는 동안 진행 표시줄이 0에서 100퍼센트까지 올라갑니다. 프로젝터는 한 번만 검사하고 기억됩니다.
  • 추가한 직후부터 색상 모드, 밝기, 명암이 실제 값으로 바로 표시됩니다.
  • TW7300, Home Cinema 4040, 5050UB를 인식합니다.
언어와 플랫폼

29개 언어, 4개 플랫폼

  • 영어와 28개 번역을 지원하며, 언어 설정과 아랍어 및 히브리어용 오른쪽에서 왼쪽 레이아웃이 있습니다. iPhone, iPad, Mac의 권한 요청 안내도 내 언어로 표시됩니다. 언어 목록을 참고하세요.
  • Android, iOS, Windows, macOS.
  • 로그, 리포트, 장면, 백업 공유가 iPad에서도 작동하며, 백업 파일은 실제 파일 이름으로 공유됩니다.
  • 버그 신고는 관련 로그를 모두 담은 번들 하나를 만들어 바로 보낼 수 있게 해 줍니다.
개인정보와 비밀번호

내 데이터, 내 선택

  • 선택적 사용 분석은 기본적으로 꺼져 있습니다. 앱은 한 번만 묻고, 설정 › 개인정보 보호에서 언제든 바꿀 수 있습니다.
  • 프로젝터의 세 가지 비밀번호(Web Control, PJLink, 리모컨)는 실제 프로젝터로 통신 단계에서 검증되었으며, 진단 메시지가 프로젝터에 비밀번호가 필요 없었을 뿐인데 비밀번호가 없다고 말하는 일도 사라졌습니다.
