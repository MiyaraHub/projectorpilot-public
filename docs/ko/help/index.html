Projector Pilot 도움말 & FAQ

연결 방법, 지원하는 프로젝터, 구매와 복원 방식, 앱의 개인정보 처리 방식을 안내합니다. 아직 해결되지 않았나요? 커뮤니티에서 개발자에게 문의하거나 앱에서 피드백 보내기를 탭하세요.

연결

연결하기

Projector Pilot은 내 네트워크에서 프로젝터와 직접 통신합니다. 연결에는 세 가지가 필요하고, 그중 하나는 많은 분이 헷갈려 합니다.

같은 Wi-Fi, 같은 서브넷

스마트폰과 프로젝터는 같은 네트워크와 서브넷에 있어야 합니다. 게스트 네트워크, IoT VLANs, 일부 메시 구성은 기기를 서로 격리하므로, “IoT” SSID에 있는 프로젝터는 메인 네트워크의 스마트폰에서 접근할 수 없습니다. 둘을 같은 네트워크에 두세요.

프로젝터에서 PJLink와 Web Control 켜기

네트워크 제어는 프로젝터에서 켜야 합니다. 프로젝터의 네트워크 메뉴에서 PJLink와 Web Control을 켜세요(Epson에서는 후자를 웹 리모컨 / Web Control이라고 부릅니다). 네트워크 제어가 꺼져 있으면 프로젝터는 아예 응답하지 않습니다.

프로젝터의 IP 주소 찾기

앱은 네트워크에서 프로젝터를 검색하며, IP로 직접 추가할 수도 있습니다. IP를 찾으려면 프로젝터 자체 메뉴에서 네트워크 정보 화면을 여세요. 현재 주소가 나옵니다. 검색 결과가 비어 있다면 그 IP를 직접 추가하세요.

프로젝터의 세 가지 비밀번호

Epson 프로젝터에는 세 가지 별도의 비밀번호인 Web Control, PJLink, 리모컨이 있습니다. 같은 항목이 아니며, 프로젝터는 그중 하나, 일부, 또는 아무것도 요구하지 않을 수 있습니다. 프로젝터가 요구하는 것만 입력하세요. 앱이 프로젝터가 실제로 무엇을 필요로 하는지 파악해서 어느 쪽이든 연결하며, 진단에서 어떤 경로가 사용되었는지 알려 줍니다. 프로젝터가 비밀번호 없이 응답하면 앱은 설정된 비밀번호가 없다고 단정하지 않고 저장된 비밀번호가 여기서는 필요하지 않았다고 알려 줍니다.

호환성

지원 프로젝터

  • ESC/VP21과 Web Control을 사용하는 Epson 프로젝터로, 두 가지를 함께 쓰면 전원, 전체 화질 메뉴, 지오메트리, 전동 렌즈 제어를 사용할 수 있습니다.
  • 모든 PJLink 프로젝터 - PJLink 표준을 통한 전원, 입력, 상태 제어를 지원하므로 Epson이 아닌 프로젝터나 PJLink 전용 Epson도 문제없이 지원되는 일반 기기입니다.
  • 전송 방식은 설정했기 때문이 아니라 응답하기 때문에 사용됩니다. 앱은 ESC/VP21을 가장 먼저, 그다음 PJLink, 그다음 Web Control을 선호하지만 프로젝터가 실제로 응답하는 방식으로 자동 전환합니다. Web Control이 없는 프로젝터도 PJLink로 계속 작동하며, 전송 방식이 거부한 값은 지원되지 않는 것이 아니라 알 수 없음으로 처리됩니다.
내 모델이 확실하지 않나요? 앱의 정보 화면에는 모델 데이터베이스에서 지원하는 프로젝터가 나열되며, 각각 하드웨어에서 확인되었는지 추정인지도 알려 줍니다. 프로젝터 자체 웹 페이지와 네트워크 제어가 작동한다면 Projector Pilot도 연결할 수 있을 거예요.
구매 & 복원

구매하기와 되찾기

한 번만 결제하는 방식인가요?

네. Pro, 홈 오토메이션 추가 기능, 번들 모두 한 번만 결제합니다. 구독도, 광고도, 계정도 없습니다. 가격을 확인하세요.

새 기기에서는 어떻게 복원하나요?

구매한 것과 같은 스토어 계정에 로그인하고 앱에서 구매 복원을 사용하세요. 한 번 구매하면 그 스토어 계정에 연결되어 Android, iOS, Windows, macOS 등 보유한 모든 플랫폼에서 잠금이 해제됩니다.

이미 구매했는데 앱에 오류가 표시돼요

그럴 일이 없어야 하며, 최신 빌드에서는 바로 그 문제를 고쳤습니다. 스토어가 Pro, 홈 오토메이션, 번들을 이미 보유 중이라고 알려 주면 앱은 구매를 적용하고 조용히 구매 내역을 새로 고치므로, 이미 가진 것을 구매하거나 복원해도 항상 잠금이 해제됩니다.

온라인에서 본 가격과 왜 다른가요?

앱은 확정하기 전에 스토어의 가격을 내 통화로 보여 줍니다. 지역별로 가격이 다르며, 앱은 고정된 금액으로 대체하지 않습니다. 스토어가 아직 응답하지 않았다면 숫자를 만들어 내는 대신 그렇다고 알려 줍니다.

개인정보 보호

내 데이터는 내 것입니다

Projector Pilot은 로컬 앱입니다. 내 네트워크에서 프로젝터와 통신하며, 가입할 것은 아무것도 없습니다.

  • 계정도 클라우드도 없습니다. 계정을 만들 필요가 없고, 프로젝터의 데이터는 우리 서버로 전송되지 않습니다.
  • Crashlytics를 통한 충돌 진단. 앱이 충돌하면 버그를 고칠 수 있도록 진단 리포트를 보냅니다. 추적이 아니라 표준적인 충돌 보고입니다.
  • 선택적, 동의 기반 분석. 사용 분석은 기본적으로 꺼져 있습니다. 앱은 처음 실행할 때 한 번 묻고, 설정 › 정보에서 언제든 켜고 끌 수 있습니다. 직접 켜지 않으면 아무것도 수집되거나 전송되지 않습니다.
  • 데이터는 판매되지 않습니다. 내 데이터는 누구에게도 판매되지 않습니다. 예외는 없습니다.
이용약관

쉬운 말로 풀어쓴 이용약관

  • 제공 내용. Projector Pilot은 내 네트워크의 호환되는 Epson 및 PJLink 프로젝터를 제어하기 위해 있는 그대로 제공됩니다. 정확하고 안정적으로 유지하기 위해 노력하지만, 모든 모델과 펌웨어가 똑같이 작동한다고 보장할 수는 없습니다.
  • 구매는 구매한 앱 스토어가 그 스토어의 약관과 환불 정책에 따라 처리합니다. 복원은 구매한 스토어 계정에 따라 달라집니다.
  • 독립 앱. Projector Pilot은 MiyaraHub Technologies LLC의 독립 앱이며 Epson이나 PJLink 표준 기구와 제휴, 보증, 후원 관계가 없습니다. Epson과 PJLink는 각 소유자의 상표입니다.
  • 사용자의 책임. 명령은 내가 소유한 하드웨어로 전송됩니다. 테스트 패턴, 지오메트리, 렌즈 컨트롤은 상식적으로 사용하세요. 사용자가 변경한 프로젝터 설정에 대해서는 책임지지 않습니다.
FAQ

빠른 답변

Projector Pilot이 프로젝터를 찾거나 연결하지 못해요

스마트폰과 프로젝터가 같은 Wi-Fi 네트워크와 서브넷에 있는지 확인하세요. 게스트 네트워크나 IoT VLANs는 기기를 서로 격리할 수 있습니다. 프로젝터의 네트워크 메뉴에서 네트워크 제어(PJLink 및/또는 Web Control)를 켜세요. 프로젝터의 네트워크 정보 화면에서 IP를 확인하고, 검색에서 나타나지 않으면 직접 추가하세요.

Projector Pilot은 어떤 프로젝터를 지원하나요?

ESC/VP21과 Web Control을 사용하는 Epson 프로젝터, 그리고 모든 PJLink 프로젝터를 지원합니다. 전송 방식은 설정했기 때문이 아니라 응답하기 때문에 사용됩니다. 앱은 프로젝터가 응답하는 방식으로 자동 전환하므로, PJLink 전용 프로젝터도 문제없이 지원되는 일반 기기입니다.

Projector Pilot은 계정이 필요하거나 내 데이터를 클라우드로 보내나요?

계정도 클라우드도 없습니다. 앱은 내 네트워크에서 프로젝터와 통신합니다. Crashlytics를 통한 충돌 진단과, 기본적으로 꺼져 있으며 설정 > 정보에서 끌 수 있는 선택적 사용 분석을 사용합니다. 판매되는 데이터는 없습니다.
