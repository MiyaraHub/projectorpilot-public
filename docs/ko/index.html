기능

프로젝터가 제공하는 모든 컨트롤을 깔끔한 앱 하나에.

Projector Pilot은 ESC/VP21, PJLink, Epson Web Control을 동시에 사용해 응답하는 방식으로 프로젝터와 통신합니다. 그래서 전원, 화질, 지오메트리, 렌즈 제어가 실제로 작동하며, 모든 값은 추측이 아니라 프로젝터에서 읽어 옵니다.

대시보드

한눈에 볼 수 있고, 원하는 대로 꾸밀 수 있습니다.

  • 실시간 상태 - 전원, 입력, 색상 모드, 광원 사용 시간, 신호, 화질 수치가 바뀌는 대로 갱신됩니다.
  • 상단에서 바로 전원과 입력을 한 번에 조작하며, 전원 버튼은 예열과 냉각 과정까지 반영합니다.
  • 카드 맞춤 설정 - 카드를 추가하고, 숨기고, 순서를 바꿔 대시보드에 중요한 정보만 표시하세요.
  • 투사 정보 - 다이내믹 레인지, 색 공간, 감마, 레이저 사용 시간, 시리얼 번호, 설치 방식을 프로젝터에서 읽어 옵니다.
리모컨 & 화질

깊이 있는 리모컨과 전체 화질 메뉴.

  • 전체 방향 패드, 메뉴, 소스, 화면 차단까지 제대로 만든 화면 리모컨입니다.
  • 보정 방식 - 수평/수직 키스톤, 퀵 코너, 포인트 보정, 곡면, 코너 월.
  • 전체 화질 제어 - 밝기, 명암, 색조, 선명도, 색온도, 감마, HDR, 깊이 있는 화질 메뉴를 각각 프로젝터 자체의 눈금으로 조정합니다.
  • HDR과 색 공간은 분리됩니다 - BT.2020 SDR 신호는 있는 그대로 표시되며, 잘못된 HDR 배지가 붙는 일은 없습니다.
렌즈

전동 렌즈 시프트, 초점, 줌, 메모리.

  • 정밀한 패드로 시프트, 초점, 줌을 조작하며, 직접 고르는 스텝 크기로 프레이밍에는 미세하게, 큰 이동에는 크게 움직입니다.
  • 렌즈 메모리 - 프로젝터가 지원하는 위치를 불러오고 저장합니다.
  • 설치 방향 인식 - 앱이 천장 설치든 리어 프로젝션이든 프로젝터 자체의 매핑을 따르므로, 위는 언제나 위입니다.
  • 솔직한 위치 표시 - 프로젝터가 확인하지 못하는 위치를 잠금으로 포장하지 않습니다.
장면

방 전체를 탭 한 번으로.

  • 장면 저장 - 전원, 입력, 화질, 신호, 광원, 지오메트리, 오디오 중 어떤 항목을 담을지 정확히 고를 수 있습니다.
  • 탭 한 번으로 적용 - “무비 나이트”가 입력, 화질 모드, 렌즈 메모리를 한꺼번에 설정합니다.
  • 모든 장면이 Home Assistant 스크립트가 되므로, 자동화나 음성 비서도 실행할 수 있습니다.
  • 공유 가능한 프로필 - 잘 맞춘 장면을 내보내서 친구에게 전해 주세요.
홈 오토메이션

Home Assistant, Hubitat, 웹훅까지 제대로 지원합니다.

  • Home Assistant - 로그인하고, 프로젝터 상태를 센서로 게시하고, HA와 동기화를 탭하면 모든 장면과 컨트롤용 스크립트가 만들어집니다.
  • 나를 위해 만들어지는 대시보드 - 동기화가 Home Assistant에 기본 카드로 대시보드를 만들고, HACS 카드가 있으면 더 풍부한 카드로 업그레이드합니다. 핵심 PJLink 통합구성요소와도 함께 작동합니다.
  • 설정 체크리스트가 완료된 것, 빠진 것, 다음에 할 일을 보여 주며, 프로젝터가 꺼져 있는 동안에도 측정값이 Home Assistant에 남아 있습니다.
  • Hubitat - Maker API를 통해 프로젝터를 기기로 미러링해서 Rule Machine이 제어할 수 있습니다.
  • Webhooks - 프로젝터가 켜지거나, 꺼지거나, 입력이 바뀌거나, 장면이 호출될 때 원하는 URL로 데이터를 보냅니다.

그 외에도

완성도를 느끼게 하는 디테일들.

어디서든 프로젝터 전환

모든 프로젝터 페이지의 상단 바에 있는 프로젝터 전환기로 목록으로 돌아가지 않고도 프로젝터 사이를 오갈 수 있습니다.

전원을 끌 때는 먼저 확인

프로젝터를 끌 때 확인을 요청하므로, 실수로 탭해서 영화가 끝나는 일은 없습니다.

즉각 반응하는 컨트롤

렌즈 시프트, 초점, 줌, 광 출력 스테퍼가 누르는 즉시 움직이며, 앱은 프로젝터가 켜지는 것을 약 10초 안에 알아챕니다.

펌웨어를 한눈에

프로젝터가 펌웨어 버전을 보고하면 대시보드, 정보 탭, 진단 리포트에 표시됩니다.

PJLink 전용 프로젝터의 입력 전환

TW7300, Home Cinema 4040처럼 PJLink로만 입력을 나열하는 프로젝터에서도 입력을 전환할 수 있으며, Epson이 아닌 PJLink 프로젝터도 마찬가지입니다.

Wi-Fi에서 프로젝터 찾기

프로젝터 추가는 네트워크에서 프로젝터로 응답하는 기기를 검색해 주소를 채워 주며, 내 모델의 지원 기능을 파악하는 동안 진행 표시줄을 보여 줍니다.

백업과 복원

앱 설정을 파일로 내보내고 다시 가져오세요. 파일은 실제 이름으로 공유되며, 저장된 프로젝터와 비밀번호는 포함되지 않습니다.

한 번에 버그 신고

버그 신고는 관련 로그를 모두 담은 번들 하나를 만들어 바로 보낼 수 있게 해 줍니다.

FAQ

가장 먼저 묻는 질문들

Projector Pilot은 Epson에서 만든 앱인가요?

아니요. Projector Pilot은 MiyaraHub Technologies LLC의 독립 앱입니다. Epson, PJLink 표준 기구, Home Assistant, Hubitat과 제휴, 보증, 후원 관계가 없습니다. 이 이름들은 각 소유자의 상표이며, 앱이 함께 작동하는 프로젝터와 스마트홈 시스템을 설명하기 위해서만 여기에 표시되었습니다.

Projector Pilot은 어떤 프로젝터를 지원하나요?

ESC/VP21과 Web Control을 사용하는 Epson 프로젝터, 그리고 모든 PJLink 프로젝터를 지원합니다. 앱은 프로젝터가 응답하는 방식을 사용하므로, PJLink 전용 프로젝터도 문제없이 지원되는 일반 기기입니다.

Projector Pilot은 구독 서비스인가요?

아니요. 기본 제어는 무료이며, Pro, 홈 오토메이션, 번들은 한 번만 결제합니다. 구독도, 광고도 없습니다.

Projector Pilot은 계정이나 클라우드가 필요한가요?

계정도 클라우드도 없습니다. 앱은 내 네트워크에서 프로젝터와 직접 통신합니다.
