Epson 호환 프로젝터 리모컨

Projector Pilot은 Epson 프로젝터와 모든 PJLink 프로젝터를 내 네트워크로 제어하는 독립 리모컨 앱입니다. 어떤 모델과 호환되는지, 모델별로 어떤 기능을 쓸 수 있는지 안내합니다.

사용 방법

모델 목록이 아닌 프로토콜 기준 호환

앱에는 모델 번호 목록이 들어 있지 않습니다. 프로젝터에 지원 기능을 물어보고, 응답한 컨트롤만 보여 줍니다. 그래서 PJLink 또는 Epson Web Control을 지원하는 프로젝터라면 아래에 없어도 작동합니다.

  • PJLink(클래스 1, 2)로 네트워크에 연결된 거의 모든 Epson 프로젝터에서 전원, 입력, 음소거, 램프 또는 레이저 상태를 확인하고 제어할 수 있습니다.
  • Epson Web Control을 지원하는 모델에서는 화질 설정, 렌즈, 키스톤, HDR도 제어할 수 있습니다.
  • ESC/VP21은 프로젝터 고유의 명령 프로토콜로, 프로젝터가 이 프로토콜에 응답할 때 사용됩니다.

테스트한 프로젝터와 같은 네트워크 프로토콜을 사용합니다. 모든 모델을 연구실에서 일일이 테스트한 것은 아니므로, 화면에 보이는 내용은 사용 중인 프로젝터가 보고하는 정보에 따라 달라집니다.
