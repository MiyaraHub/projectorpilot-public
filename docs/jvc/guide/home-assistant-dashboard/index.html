Home Assistant dashboard

A projector dashboard in Home Assistant

One tap builds a full dashboard for your JVC projector in Home Assistant: power, status, picture options, your scenes, inputs, lens memories, signal readings and more. It is built from what your Home Assistant actually has, and it holds no address or password. It needs the Home Automation add-on.

Before you send

What it needs

  • Home Assistant linked, with the projector added to the JVC Projector integration. See Home Assistant setup.
  • Scripts synced if you want scene, power, input, lens memory and control buttons. The dashboard uses the scripts that exist.
  • The live state sensor turned on, for the status and readings tiles.
  • An administrator account in Home Assistant, because creating a dashboard needs one. Without it, Home Assistant refuses and the app says so.
Two ways

Send or copy

  • Send dashboard creates the dashboard in Home Assistant, in the sidebar, titled with your projector's name and the projector icon. Send it again to update it. Syncing with Home Assistant sends it too.
  • Copy dashboard sends nothing. It copies the dashboard so you can paste it into the raw configuration editor of a new dashboard yourself, and change it as you like.
Each projector gets its own dashboard, at an address that starts with projector-pilot-jvc-, so two projectors never overwrite each other.
Layout

What is on it, top to bottom

A section appears only when it has something in it, so a projector without lens memories gets no lens memory section.

SectionHolds
HeaderThe projector's name, when the state was last updated, power, status and light source hours.
PictureThe input and the picture options Home Assistant offers for the projector, such as picture mode, light power, dynamic control, Clear Motion Drive, anamorphic, HDR processing and installation mode, where your model offers them and they are enabled.
ScenesA button per scene script.
PowerPower scripts.
InputsInput scripts.
Lens memoriesA button per lens memory slot your model has.
ControlsThe other control scripts, such as picture modes and Hide.
SignalResolution, color depth, color space, colorimetry and HDR, as Home Assistant reports them.
ReadingsThe settings the app has read, from the live state sensor.
Look

Core cards or the styled look

Core

Built only from Home Assistant's own cards. Works on any Home Assistant, nothing to install.

Styled

Uses button-card, card-mod and Mushroom cards from HACS for a richer look. Used only when all three are present.

If any of the three is missing, the app sends the core version and tells you which cards to install from HACS for the styled look. Install them, then send it again.

Honest by design

Why some things are not on it

  • No gauges. JVC gives no range for the levels Home Assistant reports, so the dashboard does not draw a gauge it would have to guess.
  • No address or password. The dashboard holds entity ids, names and labels only.
  • No made-up entities. A tile appears only for an entity or script that exists in your Home Assistant.
If it goes wrong

Messages

  • Dashboard sent. Open it from the Home Assistant sidebar.
  • Refused. Home Assistant refused the dashboard: sign in with an administrator account, then send it again.
  • Sign-in not accepted. Sign in again, then send the dashboard.
  • No answer. Home Assistant did not answer, so the dashboard was not confirmed. Check the connection and send it again.
  • Not allowed. Nothing leaves the device while the demo projector is selected or Home Automation is not unlocked.
The dashboard controls the projector through Home Assistant's JVC Projector integration, which can reach the projector only while this app is not connected to it. Close the app before using the dashboard.
