Dashboard

Your projector at a glance

The dashboard shows the selected projector: whether it is connected, whether it is on, what it is showing, and the cards you pick. Everything on it is read from the projector, not guessed.

Status card

Connection and power

  • Name and model. The projector's name, its address and the model it reported. The demo projector carries a DEMO badge.
  • Power pill. Shown once the projector has reported on or standby. Power is free on every projector.
  • Status label when power is not known yet: Connecting, Disconnected, Unreachable, Password problem, Searching the network, or a power state such as Power: standby or Power: warming up.
  • Warm-up and cool-down show a progress bar, "Warming up..." or "Cooling down...". The app reads the projector every 2 seconds during these and every 15 seconds otherwise.
Power

Turning it off asks first

Turning the projector off asks "Turn off the projector?" with the reminder that the picture goes off for everyone watching. Turning it on does not ask. A laser or lamp projector then runs its own cool-down before it reaches standby, and the card follows it.

Status chips

Four facts under the name

ChipShows
Light source hoursThe hours the projector reports for its laser or lamp.
InputThe current input.
Picture modeThe active picture mode, while the projector is on.
FirmwareThe firmware version, as FW and the version.
A chip appears only when the projector answered that value. The chips are for reading only, and every user sees them, free or Pro.

Your layout

Customize the dashboard

  1. Tap Customize in the top bar.
  2. Drag a card to move it, or tap the minus on a card to remove it.
  3. Tap Add to bring a card back from "Add a card", or RESET for the default layout.
  4. Tap Done.
The layout is one setting for the whole app, so every projector shows the same cards in the same order, minus the ones its model does not offer.
Several projectors

Switching between projectors

  • With more than one projector saved, a row of name chips appears; tap one to select it. The title in the top bar switches projectors too.
  • The Add projector button adds another one at any time.
  • The projector menu holds Rename, Edit connection, Change password and Remove. Remove deletes the projector and its saved password from this device. On the demo projector the only item is Close the demo.
  • Pull down to refresh: the app reads the cards again, or reconnects if it is not connected.
Messages

When there are no cards

An empty dashboard says why, so it is never just blank.

  • Not connected: "Not connected to this projector, so none of its controls can be shown."
  • Standby: "The projector is in standby. Its controls appear once it is on."
  • Warming up or cooling down: the controls come back when the projector settles.
  • Every card removed: Customize brings them back.
  • Wrong password: "The projector turned down the network password. Tap to enter it again."
  • Offline: the failure in plain words, such as "Nothing answered at this address on port 20554." The help page explains each one.
Home screen

Widgets

With Pro, on Android and iOS, five widgets put the projector on your home screen. Each one is set up for one projector.

Projector Quick Control

Power, input, picture mode and hide.

Projector Status

Power, connection and light source hours.

Projector Scenes

One tap applies a saved scene.

Projector Info

Power, input, picture mode and light source.

Projector Input

One tap switches the input.

A widget never talks to the projector itself. A tap opens the app, which sends the command through the same checks as the dashboard; if the app cannot connect within 30 seconds the tap is dropped. Widgets hold no address or password.
