Home Assistant

Set up your JVC projector in Home Assistant

The app signs in to your Home Assistant, adds the projector to Home Assistant's own JVC Projector integration, publishes your scenes and controls as scripts, and builds a dashboard. You never paste a token or write YAML. It needs the Home Automation add-on.

Read this first

One controller at a time

A JVC projector serves one network controller at a time. While this app is open and connected to the projector, Home Assistant cannot reach it. Home Assistant's projector controls and scripts work when the app is closed, and the app lets go of the projector when it goes to the background.

Step 1

Sign in

  1. Open Settings, Home Automation, Home Assistant.
  2. Enter your Home Assistant address, starting with http:// or https://.
  3. Tap Sign in. Home Assistant's own sign-in page opens in the browser; sign in there and come back.
  4. Tap Test connection to confirm.
If Home Assistant cannot be reached, check the address, and that this device is on the same network as Home Assistant.
Step 2

What your Home Assistant has

A panel reads your Home Assistant and marks each part Found, Not installed or Could not tell. Check again re-reads it.

Step 3

The setup checklist

  1. Sign in to Home Assistant.
  2. Add this projector to Home Assistant's JVC Projector integration. Tap Add. The app sends the projector's address, port and network password to Home Assistant's JVC Projector integration, after asking you first.
  3. Enable the entities scripts need. Some JVC Projector entities start disabled in Home Assistant; tap Enable beside each one. Home Assistant may need a reload or a restart before it appears.
  4. Live state sensor. Turn on Send the projector's state. The sensor is created the next time the app sends the projector's state while connected.
About the password. When you add the projector, its network password is sent to your Home Assistant and stored there, in its JVC Projector entry. The app sends it nowhere else. The app lets go of the projector while Home Assistant connects to it, then reconnects.
Which entry?

How the app finds your projector in Home Assistant

The app matches the JVC Projector entry by the projector's MAC address, so connect to the projector at least once first. If Home Assistant has no entry with that MAC, or more than one, the checklist says so and what to do. If the projector has moved, the app offers to send the new address to Home Assistant.

The sensor

Live state

The sensor's state is the power the app last read, and its attributes are the input, the model and the settings the app has read. It goes through the Mobile App integration and sends nothing to the projector. It updates whenever the state changes while the app is open and connected.

Scripts

Scenes and controls

Each saved scene becomes a script in Home Assistant that runs through the JVC Projector entities. A script holds no address and no password. Script ids start with ppjvc.

  • Sync With HA writes your scenes as scripts and shows how many steps each one carries, and what was left out and why.
  • Sync Advanced Controls publishes scripts for power, inputs, picture modes, lens memories and Hide.
  • Results are counted: how many scripts synced, how many Home Assistant refused, and whether it confirmed reloading them.
  • Remove orphaned scripts deletes scripts this app created that no scene uses any more. It lists them and asks first.
If something a sync depends on has not been read, nothing is written, changed or removed. A sync never half-runs on a guess.
Dashboard

A ready-made dashboard

Send dashboard builds a projector dashboard in your Home Assistant from the JVC Projector entities, the scripts and the sensor. Copy dashboard copies it instead, to paste into a new dashboard yourself. Everything about it is on the Home Assistant dashboard page.

Rules

What the app never does

  • Nothing leaves the device while the demo projector is selected or Home Automation is not unlocked.
  • Unlink removes the link from this app only. The projector's device and entities stay in Home Assistant until you delete them there.
  • If Home Assistant stops accepting the sign-in, the app says so and asks you to sign in again.
