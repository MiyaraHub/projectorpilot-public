Home automation

Connect your projector to your home

Let the rest of the house react when the projector turns on, goes to standby, changes input or recalls a scene. Three links live under Settings, Home Automation: webhook triggers, Hubitat and Home Assistant. All three need the Home Automation add-on, sold alone or in the bundle; Pro on its own does not include it.

Pick one

Which link to use

Webhooks

Any system that accepts a web request: Node-RED, a home server, a cloud automation. The app sends, you decide what happens.

Hubitat

A one-way mirror of power and input onto a device in your hub, through Maker API, for Rule Machine to act on.

Home Assistant

Sets up Home Assistant's own JVC Projector integration, scripts for your scenes and a ready-made dashboard.

Webhooks

Automation triggers

A trigger sends a web request to an address you enter when something happens on this projector. Each projector has its own list. Tap Add trigger, then choose:

  • When: Projector turns on, Projector goes to standby, Input changes (to any input or a specific one), or A scene is recalled (any scene or a specific one).
  • Method: POST (the default), PUT or GET.
  • Web address: an http:// or https:// address with a host name.
  • Enabled, to pause a trigger without deleting it.
An address that starts with http:// is sent without encryption, and the editor says so. Use https:// when your system supports it.
Payload

What the request carries

POST and PUT send a JSON body; GET sends none. The only header the app adds is Content-Type. A field that does not apply to the event is left out.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
FieldMeaning
eventpower_on, power_off, input_changed or scene_recalled.
projectorThe projector's name in the app.
inputThe input, such as hdmi1 or hdmi2.
scene_id, scene_nameThe scene, for a scene recall.
timestampWhen it happened, in UTC.
testPresent, and true, only on a request sent by Send test.
Delivery

One attempt, honestly reported

  • Each event is sent once, with a 10 second limit, and redirects are not followed.
  • The trigger shows its last result: Delivered at a time with the status code, Refused, No answer, Could not reach the address, Secure connection failed, or Not sent yet.
  • Send test sends a request marked as a test, so you can wire up the other end before the projector does anything.
When triggers fire

The rules

  • Only while the app is open and connected to the projector. The app watches the projector's state; it is not a background service.
  • Changes, not readings. The first reading after the app connects only sets the starting point, so opening the app does not fire "turns on" for a projector that was already on.
  • Never from the demo projector. Nothing leaves the device while the demo projector is selected or Home Automation is not unlocked.
  • Saved securely. Trigger addresses are kept in the device's secure storage.
Hubitat

Mirror the projector into Hubitat

The app mirrors this projector onto a device in your Hubitat hub through Maker API: on and standby, and the input as HDMI 1 or HDMI 2, for whichever of those the device accepts. Rule Machine can then act on it.

  1. In Hubitat, add Maker API and note its app id (the number in its URLs) and its access token.
  2. In the app, enter the Hub address, the Maker API app id and the Access token.
  3. Tap Find device and pick the device that stands for this projector. If none looks like it, add a Virtual Switch named after the projector in Hubitat and try again.
  4. Turn on Mirror the projector's state. The device follows the projector whenever it changes while the app is open and connected.
One way only. Nothing is sent from Hubitat to the projector. Unlink removes the link from the app.
Home Assistant

The deepest link

The app signs in to Home Assistant, adds your projector to its JVC Projector integration, publishes your scenes and controls as scripts, and builds a dashboard. It has its own pages: Home Assistant setup and the Home Assistant dashboard.
