Scenes

One tap, the whole setup

A scene saves the projector's current settings under a name, such as Movie Night, and puts them all back with one tap. Scenes belong to each projector and are part of Pro.

Create

Save the current settings

  1. Set the projector up the way you want it.
  2. On the Scenes tab, tap Save Current.
  3. Give it a Scene name of up to 30 characters.
  4. Under What to capture, pick which groups of settings the scene holds.
  5. Save. Each projector holds up to 20 scenes.
What a scene holds

The capture groups

A scene captures only the settings your model offers.

GroupCovers
PowerWhether the projector should be on.
Input sourceThe input to switch to.
Color mode & picturePicture mode and the picture settings.
Signal & HDRSignal and HDR settings.
Light outputLight output settings.
GeometryThe anamorphic setting.
Apply

Tap to apply

A tap applies the scene at once, with no confirmation. A scene that turns the projector on waits for it to warm up before it sends the rest.

When it finishes, a report lists what happened to each setting, so a scene never claims more than it did:

  • Applied: the projector took it.
  • Rejected: the projector refused it.
  • Unconfirmed: the projector did not acknowledge it, so whether it took effect is not known.
  • Held by another setting: another setting stops it applying right now, such as HDR Processing without an HDR signal.
  • Not supported: this model does not offer it.
Manage

Hold a tile for options

  • Apply, as a tap does.
  • Update with Current Settings, to save the projector's present state into the scene.
  • Rename and Change Icon & Color.
  • Export & Share, covered below.
  • Delete, which takes effect at once.
  • Drag tiles to put them in the order you want.
Share

Scene files

Export & Share writes a scene as a .ppscene file, a small JSON file you can send to another device or another person.

  • What is in it. The scene and its settings, with a checksum. No address, password or MAC address.
  • Import. Open a Scene File, or Paste Scene Text.
  • Another model. The import shows what "Applies here" and what is "Left out on this model", so a scene from a different projector brings only what yours can take.
Beyond the app

Scenes in your smart home

  • The dashboard Scenes card and the Projector Scenes widget apply a scene from the first screen or the home screen.
  • With Home Automation, recalling a scene fires the "A scene is recalled" trigger, for any scene or a specific one.
  • Each saved scene can become a script in Home Assistant, and the Home Assistant dashboard shows them as buttons.
Scenes are kept on this device only. Backup & Restore does not include them; export the ones you want to keep as files.
Ideas

Scenes worth saving

  • Movie night. Power, the input your player uses, and your film picture mode.
  • HDR films. Picture plus the Signal & HDR group, for the settings you use with HDR discs.
  • Daytime viewing. A brighter light output for a room that is not fully dark.
  • Scope screen. The Geometry group, for the anamorphic setting, together with a lens memory recalled from the Lens tab or the dashboard.

Each scene holds only the groups you tick, so a small scene changes only what it names.

Questions

Scene questions

How many scenes can I save?

Up to 20 for each projector.

Does a scene move the lens?

No. A scene holds the groups listed above. Recall a lens memory from the Lens tab, the dashboard Lens Memory card or a Home Assistant script.

What happens to a setting my projector refuses?

The report after applying lists it as Rejected, and the rest of the scene still applies.

Can I give a scene to a friend with another model?

Yes. Export it as a .ppscene file. When they import it, the app shows what applies on their model and what is left out.
