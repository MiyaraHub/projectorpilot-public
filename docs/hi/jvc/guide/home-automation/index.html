होम ऑटोमेशन

अपने प्रोजेक्टर को अपने घर से जोड़ें

प्रोजेक्टर के चालू होने, स्टैंडबाय में जाने, इनपुट बदलने या सीन बुलाने पर घर के बाकी हिस्से को प्रतिक्रिया करने दें। Settings, Home Automation के नीचे तीन लिंक हैं: वेबहुक ट्रिगर, Hubitat और Home Assistant। तीनों के लिए Home Automation ऐड-ऑन चाहिए, जो अकेला या बंडल में बिकता है; केवल Pro में यह शामिल नहीं है।

कोई एक चुनें

कौन-सा लिंक इस्तेमाल करें

वेबहुक

कोई भी सिस्टम जो वेब अनुरोध स्वीकार करता है: Node-RED, होम सर्वर, क्लाउड ऑटोमेशन। ऐप भेजता है, आप तय करते हैं कि क्या होगा।

Hubitat

आपके हब के किसी डिवाइस पर पावर और इनपुट का एकतरफ़ा मिरर, Maker API के ज़रिए, ताकि Rule Machine उस पर कार्रवाई कर सके।

Home Assistant

Home Assistant का अपना JVC Projector इंटीग्रेशन, आपके सीन के लिए स्क्रिप्ट और बना-बनाया डैशबोर्ड सेट अप करता है।

वेबहुक

ऑटोमेशन ट्रिगर

ट्रिगर इस प्रोजेक्टर पर कुछ होने पर आपके दिए पते पर एक वेब अनुरोध भेजता है। हर प्रोजेक्टर की अपनी सूची होती है। Add trigger टैप करें, फिर चुनें:

  • जब: Projector turns on, Projector goes to standby, Input changes (किसी भी इनपुट पर या किसी खास इनपुट पर), या A scene is recalled (कोई भी सीन या कोई खास सीन)।
  • विधि: POST (डिफ़ॉल्ट), PUT या GET।
  • वेब पता: होस्ट नाम वाला http:// या https:// पता।
  • सक्षम, ट्रिगर को हटाए बिना रोकने के लिए।
http:// से शुरू होने वाला पता बिना एन्क्रिप्शन के भेजा जाता है, और एडिटर यह बताता है। अगर आपका सिस्टम सपोर्ट करता है तो https:// इस्तेमाल करें।
पेलोड

अनुरोध में क्या जाता है

POST और PUT JSON बॉडी भेजते हैं; GET कुछ नहीं भेजता। ऐप केवल Content-Type हेडर जोड़ता है। जो फ़ील्ड घटना पर लागू नहीं होती उसे छोड़ दिया जाता है।

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
फ़ील्डमतलब
eventpower_on, power_off, input_changed या scene_recalled।
projectorऐप में प्रोजेक्टर का नाम।
inputइनपुट, जैसे hdmi1 या hdmi2।
scene_id, scene_nameसीन, सीन रीकॉल के लिए।
timestampयह कब हुआ, UTC में।
testकेवल Send test से भेजे गए अनुरोध पर मौजूद, और true।
डिलीवरी

एक कोशिश, ईमानदारी से बताई गई

  • हर घटना एक बार भेजी जाती है, 10 सेकंड की सीमा के साथ, और रीडायरेक्ट नहीं अपनाए जाते।
  • ट्रिगर अपना आख़िरी नतीजा दिखाता है: Delivered, समय और स्टेटस कोड के साथ, Refused, No answer, Could not reach the address, Secure connection failed, या Not sent yet।
  • Send test टेस्ट के रूप में चिह्नित अनुरोध भेजता है, ताकि प्रोजेक्टर कुछ करे इससे पहले आप दूसरा सिरा जोड़ सकें।
ट्रिगर कब चलते हैं

नियम

  • केवल तब जब ऐप खुला हो और प्रोजेक्टर से कनेक्टेड हो। ऐप प्रोजेक्टर की स्थिति देखता है; वह बैकग्राउंड सर्विस नहीं है।
  • बदलाव, रीडिंग नहीं। ऐप के कनेक्ट होने के बाद की पहली रीडिंग केवल शुरुआती बिंदु तय करती है, इसलिए पहले से चालू प्रोजेक्टर के लिए ऐप खोलने पर "turns on" नहीं चलता।
  • डेमो प्रोजेक्टर से कभी नहीं। जब डेमो प्रोजेक्टर चुना हो या Home Automation अनलॉक न हो, तब डिवाइस से कुछ बाहर नहीं जाता।
  • सुरक्षित रूप से सेव। ट्रिगर के पते डिवाइस के सुरक्षित स्टोरेज में रखे जाते हैं।
Hubitat

प्रोजेक्टर को Hubitat में मिरर करें

ऐप इस प्रोजेक्टर को Maker API के ज़रिए आपके Hubitat हब के किसी डिवाइस पर मिरर करता है: चालू और स्टैंडबाय, और इनपुट HDMI 1 या HDMI 2 के रूप में, उनमें से जो भी डिवाइस स्वीकार करे। फिर Rule Machine उस पर कार्रवाई कर सकता है।

  1. Hubitat में Maker API जोड़ें और उसका ऐप आईडी (उसके URL में आने वाली संख्या) और उसका एक्सेस टोकन नोट करें।
  2. ऐप में हब पता, Maker API ऐप आईडी और एक्सेस टोकन दर्ज करें।
  3. डिवाइस खोजें टैप करें और वह डिवाइस चुनें जो इस प्रोजेक्टर का प्रतिनिधित्व करता है। अगर कोई मेल न खाए, तो Hubitat में प्रोजेक्टर के नाम पर एक Virtual Switch जोड़ें और फिर कोशिश करें।
  4. प्रोजेक्टर की स्थिति मिरर करें चालू करें। ऐप के खुले और कनेक्टेड रहते प्रोजेक्टर में जब भी बदलाव होता है, डिवाइस उसके साथ चलता है।
केवल एकतरफ़ा। Hubitat से प्रोजेक्टर को कुछ नहीं भेजा जाता। अनलिंक करें ऐप से लिंक हटा देता है।
Home Assistant

सबसे गहरा लिंक

ऐप Home Assistant में साइन इन करता है, आपके प्रोजेक्टर को उसके JVC Projector इंटीग्रेशन में जोड़ता है, आपके सीन और कंट्रोल को स्क्रिप्ट के रूप में प्रकाशित करता है, और एक डैशबोर्ड बनाता है। इसके अपने पेज हैं: Home Assistant सेटअप और Home Assistant डैशबोर्ड।
