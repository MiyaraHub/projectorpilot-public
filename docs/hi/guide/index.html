Projector Pilot यूज़र गाइड

अपना प्रोजेक्टर जोड़ने और हर स्क्रीन इस्तेमाल करने के लिए जो कुछ चाहिए - डैशबोर्ड, गहरा रिमोट, पूरा पिक्चर मेनू, मोटराइज़्ड लेंस, सीन और असली होम ऑटोमेशन। हर स्क्रीन आपके हार्डवेयर के हिसाब से ढलती है: ऐप सिर्फ़ वही कंट्रोल दिखाता है जो आपका प्रोजेक्टर सचमुच देता है, और हर वैल्यू प्रोजेक्टर से वापस पढ़ी जाती है, अंदाज़े से नहीं। इसलिए आपकी स्क्रीन पर यहाँ के पेज से कम विकल्प दिख सकते हैं, और यह ऐप की ईमानदारी है, खराबी नहीं।

गाइड देखें

हर स्क्रीन, समझाई हुई

शुरुआत करने से शुरू करें, फिर किसी भी स्क्रीन में उतरें। यहाँ किसी चीज़ के लिए क्लाउड अकाउंट नहीं चाहिए - Projector Pilot आपके प्रोजेक्टर से आपके अपने नेटवर्क पर ESC/VP21, PJLink और Epson Web Control के ज़रिए बात करता है, जो भी जवाब दे उसका इस्तेमाल करके।

अपना प्रोजेक्टर जोड़ें

अपना नेटवर्क स्कैन करें या IP से जोड़ें, एक बार का कैपेबिलिटी स्कैन चलाएं, Test Connection करें और Save करें। उसी Wi-Fi पर करीब एक मिनट में।
📊

डैशबोर्ड पढ़ें

लाइव पावर, इनपुट, कलर मोड और प्रोजेक्शन जानकारी, ऐसे कार्डों के साथ जिन्हें आप जोड़ते, छिपाते और क्रम में लगाते हैं ताकि अपना मनचाहा व्यू बन सके।
🎭

एक सीन सेव करें

पावर, इनपुट, पिक्चर, लेंस और बहुत कुछ कैप्चर करें, फिर पूरे कमरे को एक टैप में वापस लाएं - और उसे Home Assistant को भी सौंप दें।
