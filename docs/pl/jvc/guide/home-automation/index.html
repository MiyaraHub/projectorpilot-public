Automatyka domowa

Połącz projektor ze swoim domem

Pozwól reszcie domu reagować, gdy projektor się włącza, przechodzi w gotowość, zmienia wejście lub przywołuje scenę. Trzy odnośniki znajdują się w Ustawieniach, Automatyka domowa: wyzwalacze webhook, Hubitat i Home Assistant. Wszystkie trzy wymagają dodatku Automatyka domowa, sprzedawanego osobno lub w pakiecie; samo Pro go nie zawiera.

Wybierz jedno

Którego odnośnika użyć

Webhooki

Dowolny system przyjmujący żądanie sieciowe: Node-RED, serwer domowy, automatyzacja w chmurze. Aplikacja wysyła, a Ty decydujesz, co się stanie.

Hubitat

Jednokierunkowe odbicie zasilania i wejścia na urządzeniu w Twoim hubie, przez Maker API, aby Rule Machine mógł na nie reagować.

Home Assistant

Konfiguruje własną integrację JVC Projector w Home Assistant, skrypty dla Twoich scen i gotowy kokpit.

Webhooki

Wyzwalacze automatyzacji

Wyzwalacz wysyła żądanie sieciowe na wpisany przez Ciebie adres, gdy coś dzieje się z tym projektorem. Każdy projektor ma własną listę. Stuknij Dodaj wyzwalacz, a potem wybierz:

  • Kiedy: Projektor się włącza, Projektor przechodzi w gotowość, Wejście się zmienia (na dowolne lub konkretne wejście) albo Scena zostaje przywołana (dowolna lub konkretna scena).
  • Metoda: POST (domyślnie), PUT lub GET.
  • Adres internetowy: adres http:// lub https:// z nazwą hosta.
  • Włączony, aby wstrzymać wyzwalacz bez jego usuwania.
Adres zaczynający się od http:// jest wysyłany bez szyfrowania, o czym informuje edytor. Używaj https://, gdy Twój system to obsługuje.
Ładunek

Co niesie żądanie

POST i PUT wysyłają treść JSON; GET nie wysyła żadnej. Jedynym nagłówkiem dodawanym przez aplikację jest Content-Type. Pole, które nie dotyczy zdarzenia, jest pomijane.

{
  "event": "input_changed",
  "projector": "Theater",
  "input": "hdmi2",
  "timestamp": "2026-11-15T20:00:00.000Z"
}
PoleZnaczenie
eventpower_on, power_off, input_changed lub scene_recalled.
projectorNazwa projektora w aplikacji.
inputWejście, na przykład hdmi1 lub hdmi2.
scene_id, scene_nameScena, przy przywołaniu sceny.
timestampKiedy to się stało, w UTC.
testObecne i równe true tylko w żądaniu wysłanym przez Wyślij test.
Dostarczenie

Jedna próba, uczciwie zgłoszona

  • Każde zdarzenie jest wysyłane raz, z limitem 10 sekund, a przekierowania nie są śledzone.
  • Wyzwalacz pokazuje swój ostatni wynik: Dostarczono o określonej godzinie z kodem statusu, Odrzucono, Brak odpowiedzi, Nie udało się połączyć z adresem, Bezpieczne połączenie nie powiodło się lub Jeszcze nie wysłano.
  • Wyślij test wysyła żądanie oznaczone jako testowe, abyś mógł skonfigurować drugą stronę, zanim projektor cokolwiek zrobi.
Kiedy wyzwalacze się uruchamiają

Zasady

  • Tylko gdy aplikacja jest otwarta i połączona z projektorem. Aplikacja obserwuje stan projektora; nie jest usługą działającą w tle.
  • Zmiany, a nie odczyty. Pierwszy odczyt po połączeniu aplikacji ustawia tylko punkt wyjścia, więc otwarcie aplikacji nie uruchamia zdarzenia "włącza się" dla projektora, który już był włączony.
  • Nigdy z projektora demo. Nic nie opuszcza urządzenia, gdy wybrany jest projektor demo lub gdy Automatyka domowa nie jest odblokowana.
  • Zapisane bezpiecznie. Adresy wyzwalaczy są przechowywane w bezpiecznej pamięci urządzenia.
Hubitat

Odbicie projektora w Hubitat

Aplikacja odbija ten projektor na urządzeniu w Twoim hubie Hubitat przez Maker API: włączenie i gotowość oraz wejście jako HDMI 1 lub HDMI 2, dla tych z nich, które urządzenie akceptuje. Rule Machine może wtedy na to reagować.

  1. W Hubitat dodaj Maker API i zapisz jego identyfikator aplikacji (liczbę w jego adresach URL) oraz token dostępu.
  2. W aplikacji wpisz Adres huba, Identyfikator aplikacji Maker API i Token dostępu.
  3. Stuknij Znajdź urządzenie i wybierz urządzenie reprezentujące ten projektor. Jeśli żadne go nie przypomina, dodaj w Hubitat Virtual Switch nazwany jak projektor i spróbuj ponownie.
  4. Włącz Duplikuj stan projektora. Urządzenie podąża za projektorem za każdym razem, gdy ten się zmienia, gdy aplikacja jest otwarta i połączona.
Tylko w jedną stronę. Nic nie jest wysyłane z Hubitat do projektora. Odłącz usuwa połączenie z aplikacji.
Home Assistant

Najgłębszy odnośnik

Aplikacja loguje się do Home Assistant, dodaje Twój projektor do jego integracji JVC Projector, publikuje Twoje sceny i elementy sterowania jako skrypty i buduje kokpit. Ma własne strony: Konfiguracja Home Assistant i kokpit Home Assistant.
